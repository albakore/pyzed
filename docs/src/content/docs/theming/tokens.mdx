A theme is a list of **tokens**: names such as `accent` or `text_muted` with a color (or a size) each. Components
never hard-code colors; they ask the theme for a token. That is why one change to the theme restyles everything.

You use tokens in two ways:

```python
pz.text("Total").style(color="text_muted")                 # by name, anywhere a color goes
pz.container(body, bg=self.resolved_theme().surface)          # as an attribute of the theme
```

Colors are `#rrggbb` or `#rrggbbaa` (the last two digits are the opacity). Token names work in `style()`, in a
component's `color=`/`tint=` parameters, in [`pz.Paint`](/pyzed/theming/styles/#gradients-opacity-and-masks) and in
the designer's color fields.

<Aside type="tip" title="Think in layers">
From back to front: the **window** (`background`), **surfaces** on it (`surface`, `panel`, `elevated`), **elements**
on those (`element`, `ghost_*`), and **text and icons** on top. Pick each layer a little lighter (dark themes) or
darker (light themes) than the one behind it.
</Aside>

## Syntax, terminal and people

These three are collections instead of single colors.

- **`syntax`**: a dictionary from a highlighting name to a color, or to `(color, "italic")` / `(color, "bold")`.
  The main names are `primary`, `comment`, `comment.doc`, `keyword`, `function`, `type`, `string`,
  `string.escape`, `number`, `boolean`, `constant`, `property`, `attribute`, `operator`, `variable`,
  `variable.special`, `punctuation`, `punctuation.bracket`, `tag`, `title` and `link_uri`. A missing dotted name
  falls back to its first part (`string.escape` → `string`).
- **`ansi`**: the terminal's colors: `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`,
  `bright_black` and `dim`.
- **`players`**: a tuple of colors for avatars and collaborators; `ui.avatar(index=n)` and `ui.facepile` take
  the n-th one.

## Sizes and metadata

| Token | Default | What it sets |
| --- | --- | --- |
| `radius` | `6.0` | Corner radius of cards, dialogs and large surfaces (cards use `radius + 2`). |
| `radius_sm` | `4.0` | Corner radius of buttons, inputs, chips and list rows. |
| `ui_font_size` | `14.0` | The base size of interface text; a form's **Font size** and the global style's `size` set it. |
| `buffer_font_size` | `14.0` | Text size in the code editor. |
| `name` | | The name used by `pz.themes.get` and `theme = "..."`. |
| `appearance` | | `"dark"` or `"light"`; `theme.is_dark` reads it. |

## From Python

```python
t = pz.themes.get("One Dark")
t.accent                 # '#74ade8'
t.color("text_muted")    # the same as t.text_muted; hex colors pass through unchanged
t.tokens()               # every token as a dictionary
t.to_dict()              # JSON-friendly, the format Theme.save writes
```

The names follow the theme format of the Zed editor, so themes made for it can be imported (see
[Creating themes](/pyzed/theming/custom-themes/#import-a-zed-theme)). The [Theme API](/pyzed/reference/theme/) lists
every method.
