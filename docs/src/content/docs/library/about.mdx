## When to use

## Usage

```python
from pyzed import ui

ui.about("Notes", "1.2.0", "A small notes app built with Pyzed.", icon="notebook-pen",
         details=[("Python", "3.12"), ("Pyzed", "0.4")],
         links=[("Website", on_website), ("GitHub", on_github)])
```

## API

### `ui.about`

```python
about(
    name,
    version='',
    description='',
    *,
    icon='app-window',
    details=(),
    links=(),
    theme=None,
)
```

An About box: icon, name, version, a description, a few details and link buttons.

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | *required* | App name. |
| `version` | `""` | Version text. |
| `description` | `""` | One or two sentences. |
| `icon` | `"app-window"` | Lucide icon. |
| `details` | `()` | `(label, value)` rows. |
| `links` | `()` | `(label, on_press)` buttons. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
