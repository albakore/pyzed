:::tip[In plain words]
Plain text on the screen, in the colors of the current theme.
:::

Text that takes its color from the theme. `color` is a theme token (`"text"`, `"accent"`, `"error"`…) or a hex color, and `size` is a named step (`"xs"` to `"2xl"`) or a number. `ui.muted(...)` is a label with the `"text_muted"` color, for secondary text.

`ui.label` · Category: [Display](/pyzed/library/#display) · [Full reference →](/pyzed/reference/ui/#label)

## When to use

- For any text in a themed UI: it follows theme changes, unlike a hard-coded `pz.text`.
- Use `ui.muted` for descriptions, hints and metadata.
- For titles use [Heading](/pyzed/library/heading/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.label("Pyzed draws native UIs with Iced."),
    ui.muted("Secondary text uses the muted color."),
    ui.label("Accent and semibold", color="accent", weight="semibold"),
    ui.label("def mono(): ...", mono=True, size="sm"),
], spacing=8)
```

## API

### `ui.label`

```python
label(
    content,
    *,
    color='text',
    size='md',
    weight=None,
    mono=False,
    italic=False,
    wrap=True,
    theme=None,
    **kwargs,
)
```

Text with a theme color.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
| `color` | `"text"` | Theme token or hex color. Defaults to `"text"`. |
| `size` | `"md"` | `"xs"` (11), `"sm"` (12), `"md"` (13.5), `"lg"` (16), `"xl"` (20), `"2xl"` (26) or a number. |
| `weight` | `None` | Weight: `"medium"`, `"semibold"`, `"bold"`… |
| `mono` | `False` | Uses the monospace font (IBM Plex Mono). |
| `italic` | `False` | Italic. |
| `wrap` | `True` | Line wrapping. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
| `**kwargs` | — | Passed to `pyzed.text`. |

[Full reference →](/pyzed/reference/ui/#label)
