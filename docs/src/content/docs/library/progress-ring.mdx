:::tip[In plain words]
A circle that fills up to show how much of a task is done.
:::

A ring that fills clockwise from the top as `value` reaches `max`. `show_value` writes the percentage in the middle; `value=None` spins until the task knows how far it is.

`ui.progress_ring` · Category: [Feedback](/pyzed/library/#feedback) · [Full reference →](/pyzed/reference/ui/#progress_ring)

## When to use

- For a download, an upload or a goal shown in little space.
- In a row of a list, use a small one without text.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.progress_ring(0.25),
    ui.progress_ring(0.6, size=56, thickness=5, show_value=True),
    ui.progress_ring(1.0, size=56, thickness=5, tint="success", label="Done"),
    ui.progress_ring(None),
```

## Properties and API

### `ui.progress_ring`

```python
progress_ring(
    value,
    *,
    max=1.0,
    size=40,
    thickness=4,
    tint='accent',
    show_value=False,
    label=None,
    theme=None,
)
```

A round progress bar that fills clockwise from the top. `value=None` spins.

| Property | Default | Description |
| --- | --- | --- |
| `value` | *required* | Progress up to `max`, or `None` to spin. |
| `max` | `1.0` | The value of a full ring. |
| `size` | `40` | Diameter in pixels. |
| `thickness` | `4` | Width of the ring. |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `show_value` | `False` | Writes the percentage in the middle. |
| `label` | `None` | Any other text in the middle (`"3/8"`). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
