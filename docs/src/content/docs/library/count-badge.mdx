## When to use

- Next to an icon or tab to show how many unread items or errors there are.
- For text statuses use a [Badge](/pyzed/library/badge/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.count_badge(3),
    ui.count_badge(42, tint="success"),
    ui.count_badge(120, tint="error"),
    pz.row([ui.icon_button("bell", on_press), ui.count_badge(7)], spacing=2, align="center"),
```

## API

### `ui.count_badge`

```python
count_badge(count, *, tint='accent', max=99, theme=None)
```

A round counter (notifications, problems…). Shows `99+` above `max`.

| Parameter | Default | Description |
| --- | --- | --- |
| `count` | *required* | The number. |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `max` | `99` | Maximum before showing `N+`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
