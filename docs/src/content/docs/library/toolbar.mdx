## When to use

- Between the tab bar and the editor, or at the top of any content view.

## Usage

```python
from pyzed import ui

ui.toolbar(
    [ui.breadcrumbs([("file-code", "src"), "main.rs", "fn main"])],
    [ui.icon_button("search", on_search, size="sm"), ui.icon_button("sparkles", on_assist, size="sm")],
)
```

## API

### `ui.toolbar`

```python
toolbar(start=(), end=(), *, height=32, theme=None)
```

The bar below the tabs: breadcrumbs on the left and buffer actions on the right.

| Parameter | Default | Description |
| --- | --- | --- |
| `start` | `()` | Widgets at the start (left). |
| `end` | `()` | Widgets at the end (right). |
| `height` | `32` | Height. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
