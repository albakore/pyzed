## When to use

- Inside a `ui.modal` opened from a Help menu or with Ctrl+K Ctrl+S.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.shortcuts([
    ("File", [("Save", "ctrl-s"), ("Open file", "ctrl-p")]),
    ("View", [("Command palette", "ctrl-shift-p"), ("Toggle left dock", "ctrl-b")]),
], on_query=on_query, height=240), width=420)
```

## API

### `ui.shortcuts`

```python
shortcuts(groups, *, query='', on_query=None, height=380, theme=None)
```

A searchable list of key bindings, grouped (for a Keyboard shortcuts dialog).

| Parameter | Default | Description |
| --- | --- | --- |
| `groups` | *required* | `[(title, [(label, keys), ...]), ...]`, keys like `"ctrl-s"`. |
| `query` | `""` | Filter text. |
| `on_query` | `None` | Adds a search box. |
| `height` | `380` | Height of the list. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
