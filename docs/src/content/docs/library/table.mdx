A data table with a fixed header, optional sorting and row selection. Columns are `ui.Column` objects whose `key` is a dict key, an attribute name or a function of the row; `render` turns a value into any widget. The table sorts the rows itself by the column whose **title** is `sort_by`: you only store that title and the direction.

## When to use

- For records with several comparable fields: files, users, processes, results.
- For a single column of items, a list of [List items](/pyzed/library/list-item/) is lighter.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Files(pz.App):
    def __init__(self):
        self.rows = [{"name": "app.py", "lines": 512}, {"name": "theme.py", "lines": 730}]
        self.sort_by, self.descending, self.selected = "Lines", True, None

    def sort(self, title):
        self.descending = not self.descending if self.sort_by == title else False
        self.sort_by = title

    def view(self):
        return ui.table(
            [ui.Column("File", "name"), ui.Column("Lines", "lines", width=80, align="end")],
            self.rows, sort_by=self.sort_by, descending=self.descending, on_sort=self.sort,
            on_row_press=lambda row: setattr(self, "selected", row), selected=self.selected,
        )
```

## API

### `ui.table`

```python
table(
    columns,
    rows,
    *,
    sort_by=None,
    descending=False,
    on_sort=None,
    on_row_press=None,
    selected=None,
    striped=False,
    row_height=30,
    height=None,
    theme=None,
)
```

A data table with a fixed header, optional sorting and row selection. Sorting happens here when `sort_by` names a column: clicking a header calls `on_sort(title)` and you update `sort_by`/`descending` in your state.

| Parameter | Default | Description |
| --- | --- | --- |
| `columns` | *required* | `ui.Column` or plain keys. |
| `rows` | *required* | Dicts or objects. |
| `sort_by` | `None` | Title of the column to sort by. |
| `descending` | `False` | Descending order. |
| `on_sort` | `None` | Callable that receives the clicked title. |
| `on_row_press` | `None` | Callable that receives the clicked row. |
| `selected` | `None` | The highlighted row. |
| `striped` | `False` | Shaded alternating rows. |
| `row_height` | `30` | Height of each row. |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `ui.Column`

```python
@dataclass
class Column(title, key, width='fill', align='start', render=None, sortable=True)
```

A column of `ui.table`. `key` is a dict key, an attribute name or a function of the row; `render` (optional) turns the value into a widget. `width` is `"fill"`, a number or `("fill", 2)`.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Header (and name used for sorting). |
| `key` | *required* | How to get the value from each row. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `align` | `"start"` | `"start"`, `"center"` or `"end"`. |
| `render` | `None` | Function value → widget. |
| `sortable` | `True` | Whether the header can be clicked to sort. |
