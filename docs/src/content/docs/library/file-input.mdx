:::tip[In plain words]
A box with the location of a file and a button that opens the usual window to look for it.
:::

`ui.file_input` shows a path and a browse button. The button opens the operating system's own dialog to open a file (`mode="open"`), several (`"open_many"`), a folder (`"folder"`) or to choose where to save (`"save"`), and `on_change` receives what the user chose: a path, or a list of paths with `open_many`. The path can also be typed or pasted. `filters` limits the file types (`"Images: png, jpg"`).

## When to use

- For settings that point to a file or folder: a project folder, a log file, an export target.
- `button="Browse…"` shows text instead of the folder icon.
- `ui.system.pick(then, mode=...)` returns the same dialog as a `Command`, for your own buttons.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Export(pz.App):
    def __init__(self):
        self.target = ""

    def view(self):
        return ui.file_input(self.target, lambda path: setattr(self, "target", path),
                             mode="save", file_name="report.pdf", filters="PDF: pdf")
```

## Events

File picker has **1 event of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Handler gets | When |
| --- | --- | --- |
| `on_change` | `(value)` | Receives the path (a list with `"open_many"`). |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">

class Export(pz.App):
    def __init__(self):
        self.folder = ""

    def chosen(self, path):              # on_change: the path (a list with mode="open_many")
        self.folder = path

    def view(self):
        return pz.column([
            ui.file_input(self.folder, self.chosen, mode="folder", placeholder="Choose a folder"),
            ui.label(f"Saving to {self.folder or '…'}"),
        ], spacing=8, width=360)

from dataclasses import dataclass


@dataclass
class Chosen:

class Export(pz.App):
    path = ""

    def update(self, message):
        match message:
            case Chosen(path):
                self.path = path

    def view(self):

## Properties and API

### `ui.file_input`

```python
file_input(
    value,
    on_change=None,
    *,
    mode='open',
    filters=None,
    title=None,
    directory=None,
    file_name='',
    placeholder=None,
    button=None,
    editable=True,
    disabled=False,
    invalid=False,
    id=None,
    width='fill',
    theme=None,
)
```

A path field with a button that opens the system's file dialog, so nobody types a path by hand. See the [File picker](/pyzed/library/file-input/) page.

| Property | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current value. |
| `mode` | `"open"` | `"open"` (a file), `"open_many"` (a list), `"save"` or `"folder"`. |
| `filters` | `None` | Files shown: `{"Images": "png jpg"}` or `"Images: png, jpg"`. |
| `title` | `None` | The dialog's title. |
| `directory` | `None` | Where the dialog opens (default: the folder of the current path). |
| `file_name` | `""` | The name suggested when saving. |
| `placeholder` | `None` | Hint text shown when empty. |
| `button` | `None` | Text for the button instead of a folder icon. |
| `editable` | `True` | `False` keeps the path from being typed. |
| `disabled` | `False` | Disables it (ignores clicks). |
| `invalid` | `False` | Paints the border in the error color. |
| `id` | `None` | Stable identifier used to focus or scroll it with a `Command`. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

Events: `on_change` ([events](#events)).

### `ui.system.pick`

```python
pick(then, *, mode='open', title=None, filters=None, directory=None, file_name='')
```

The system's file dialog as a `Command`: return it from a callback and `then` receives what the user chose (a path, a list of paths with `"open_many"`, or `None` when they cancel). `ui.file_input` uses it.

| Property | Default | Description |
| --- | --- | --- |
| `then` | *required* | Called with the result. |
| `mode` | `"open"` | `"open"`, `"open_many"`, `"save"` or `"folder"`. |
| `title` | `None` | The dialog's title. |
| `filters` | `None` | Files shown: `{"Images": "png jpg"}` or `"Images: png, jpg"`. |
| `directory` | `None` | Where the dialog opens. |
| `file_name` | `""` | The name suggested when saving. |
