A semibold title. `level=1` (default), `2` or `3` pick the size, so headings stay consistent across screens.

`ui.heading` · Category: [Display](/pyzed/library/#display) · [Full reference →](/pyzed/reference/ui/#heading)

## When to use

- For the title of a page, a dialog section or a settings group.
- For a small uppercase list title, use [List header](/pyzed/library/list-header/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.heading("Heading 1"),
    ui.heading("Heading 2", level=2),
    ui.heading("Heading 3", level=3),
    ui.muted("Body text below the headings."),
], spacing=6)
```

## API

### `ui.heading`

```python
heading(content, *, level=1, theme=None, **kwargs)
```

A semibold heading.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
| `level` | `1` | 1 (26 px), 2 (20 px), 3 (16 px) or 4 (13.5 px). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
| `**kwargs` | — | Same as `label`. |
