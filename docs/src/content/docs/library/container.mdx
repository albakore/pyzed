Wraps one child to give it a size, padding and alignment, and to draw a background (color or gradient), a border, rounded corners and a shadow. `pz.center(child)` is a container that centers its child in all the available space.

`pz.container` · Category: [Layout](/pyzed/library/#layout) · [Full reference →](/pyzed/reference/widgets/#container)

## When to use

- Whenever a widget needs a box: cards, colored areas, fixed sizes, centering.

## Usage

```python
import pyzed as pz
from pyzed import ui

t = pz.theme.current()
pz.row([
    pz.container(ui.label("padding + bg"), padding=16, bg=t.element, radius=8),
    pz.container(ui.label("border"), padding=16, border_color=t.accent, border_width=2, radius=8),
    pz.container(ui.label("shadow", color="#ffffff"), padding=16, radius=12,
                 gradient=(135, ["#7c3aed", "#3b82f6"]),
                 shadow=("#00000066", (0, 6), 18)),
], spacing=16, align="center")
```

## API

### `pz.container`

```python
container(
    content=None,
    *,
    padding=None,
    width=None,
    height=None,
    max_width=None,
    max_height=None,
    align_x=None,
    align_y=None,
    center=False,
    bg=None,
    color=None,
    border_color=None,
    border_width=0.0,
    radius=None,
    shadow=None,
    clip=False,
    gradient=None,
)
```

Wraps a child to give it size, alignment, background, border, radius and shadow.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | `None` | The child (or `None` for an empty box, handy as a colored rectangle). |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `max_width` | `None` | Maximum width in pixels. |
| `max_height` | `None` | Maximum height in pixels. |
| `align_x` | `None` | Horizontal alignment: `"start"`/`"left"`, `"center"`, `"end"`/`"right"`. |
| `align_y` | `None` | Vertical alignment: `"start"`/`"top"`, `"center"`, `"end"`/`"bottom"`. |
| `center` | `False` | Centers the content on both axes and fills all the space. |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `color` | `None` | Text or icon color. |
| `border_color` | `None` | Border color. |
| `border_width` | `0.0` | Border width in pixels. |
| `radius` | `None` | Corner radius: a number or `(top_left, top_right, bottom_right, bottom_left)`. |
| `shadow` | `None` | Shadow: `(color, (dx, dy), blur)`. |
| `clip` | `False` | Clips content that overflows the bounds. |
| `gradient` | `None` | Linear background gradient: `(angle, [colors])` or `(angle, [(position, color), ...])`. |

[Full reference →](/pyzed/reference/widgets/#container)

### `pz.center`

```python
center(content, **kwargs)
```

Centers `content` in all the available space. Equivalent to `container(content, center=True)`.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
| `**kwargs` | — | Any `container` parameter. |
