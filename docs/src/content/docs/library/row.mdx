:::tip[In plain words]
Puts things side by side, from left to right.
:::

Lays out its children horizontally, with `spacing` between them and `align` on the cross axis. `wrap=True` moves children that don't fit to the next line. Lists are flattened and `None`/`False` are skipped, so `cond and widget` works.

`pz.row` · Category: [Layout](/pyzed/library/#layout) · [Full reference →](/pyzed/reference/widgets/#row)

## When to use

- For toolbars, button groups, form rows: anything side by side.
- Push items apart with `pz.hspace()` between them.

## Usage

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.row([box("A"), box("B"), box("C")], spacing=8),
    pz.row([box("Start"), pz.hspace(), box("End")], spacing=8, width=420),
    pz.row([box("tall", h=70), box("center"), box("end")], spacing=8, align="center"),
], spacing=14)
```

## API

### `pz.row`

```python
row(
    children=None,
    *,
    spacing=0.0,
    padding=None,
    width=None,
    height=None,
    align=None,
    clip=False,
    wrap=False,
    line_spacing=None,
)
```

Lays out its children horizontally.

| Parameter | Default | Description |
| --- | --- | --- |
| `children` | `None` | List of children. Nested lists are flattened and `None` and `False` are ignored, so you can write `cond and widget`. |
| `spacing` | `0.0` | Space between children, in pixels. |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `align` | `None` | Alignment of the children on the cross axis: `"start"`, `"center"` or `"end"`. |
| `clip` | `False` | Clips content that overflows the bounds. |
| `wrap` | `False` | Line wrapping / moves children to a new row when they don't fit. |
| `line_spacing` | `None` | Space between rows when `wrap=True`. |
