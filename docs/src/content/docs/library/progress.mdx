## When to use

- For work whose progress you can measure: downloads, builds, imports.
- When you can't measure it, show a [Spinner](/pyzed/library/spinner/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Download(pz.App):
    def __init__(self):
        self.done, self.total = 0, 1

    def update(self, message):
        self.done, self.total = message  # posted from a worker thread with pz.post((done, total))

    def view(self):
        return ui.progress(self.done, max=self.total)
```

## API

### `ui.progress`

```python
progress(value, *, max=1.0, tint='accent', height=4, width='fill', theme=None)
```

A thin progress bar.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current value. |
| `max` | `1.0` | Maximum value. |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `height` | `4` | Thickness. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
