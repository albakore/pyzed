:::tip[In plain words]
A panel with an edge you can drag to make it bigger or smaller.
:::

A panel whose `edge` (`"left"`, `"right"`, `"top"` or `"bottom"`) can be dragged to resize it, between `min_size` and `max_size`. It keeps the size the user drags it to; `on_resize(size)` is called when the drag ends so you can save it.

## When to use

- For one resizable sidebar or bottom panel next to fixed content.

## Usage

```python
import pyzed as pz
from pyzed import ui

t = pz.theme.current()
pz.row([
    pz.resizable(pz.container(ui.label("Drag my right edge"), padding=12, width="fill", height="fill", bg=t.panel),
                 edge="right", size=260, min_size=160, color=t.border, hover_color=t.accent),
    pz.container(ui.muted("Content"), center=True, width="fill", height="fill"),
], height="fill")
```

## API

### `pz.resizable`

```python
resizable(
    content,
    *,
    edge='right',
    size=240.0,
    min_size=80.0,
    max_size=None,
    on_resize=None,
    color=None,
    hover_color=None,
    thickness=1.0,
    handle=8.0,
    width=None,
    height=None,
)
```

A panel whose `edge` can be dragged to resize it. It keeps the size the user drags it to; `on_resize(size)` is called when a drag ends so you can save it. Changing `size` later resets it.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | The panel's content. |
| `edge` | `"right"` | The edge with the handle: `"right"` (a left sidebar), `"left"`, `"top"` (a bottom panel) or `"bottom"`. |
| `size` | `240.0` | Starting width (height for top/bottom edges). |
| `min_size` | `80.0` | Smallest size. |
| `max_size` | `None` | Largest size. |
| `on_resize` | `None` | Called with the new size when a drag ends. |
| `color` | `None` | Line color. |
| `hover_color` | `None` | Line color while hovered or dragged. |
| `thickness` | `1.0` | Line thickness. |
| `handle` | `8.0` | Width of the area that can be grabbed. |
| `width` | `None` | Width for top/bottom edges. |
| `height` | `None` | Height for left/right edges. |
