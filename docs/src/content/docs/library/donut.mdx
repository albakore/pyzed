## When to use

- To show the parts of a whole (disk usage, languages of a project) with three or four slices.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.donut([60, 25, 15], label="60%"),
    ui.donut([45, 35, 20], colors=["#e5c07b", "#c678dd", "#56b6c2"], size=120, thickness=20, label="3"),
], spacing=32, align="center")
```

## API

### `ui.donut`

```python
donut(values, *, colors=None, size=96, thickness=14, label=None, theme=None)
```

A donut chart; `label` is drawn in the center.

| Parameter | Default | Description |
| --- | --- | --- |
| `values` | *required* | Values. |
| `colors` | `None` | Colors (defaults to the theme's). |
| `size` | `96` | Size. |
| `thickness` | `14` | Ring thickness. |
| `label` | `None` | Center text. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
