## When to use

- At the top of a list, tree or table to filter it as you type.
- Pair it with `ui.fuzzy_filter` to rank results like Zed.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Finder(pz.App):
    def __init__(self):
        self.query = ""
        self.files = ["main.py", "app.py", "theme.py"]

    def view(self):
        matches = ui.fuzzy_filter(self.query, self.files)
        return pz.column([
            ui.search_input(self.query, lambda q: setattr(self, "query", q)),
            *[ui.list_item(name, icon="file") for name, _ in matches],
        ], spacing=6)
```

## API

### `ui.search_input`

```python
search_input(value, on_input=None, *, placeholder='Search…', **kwargs)
```

An `input` with a magnifying glass icon.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current text. |
| `on_input` | `None` | Callable that receives the new text on every keystroke. |
| `placeholder` | `"Search…"` | Hint text shown when empty. |
| `**kwargs` | — | Same as `input`. |
