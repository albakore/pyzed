:::tip[In plain words]
A button is something you click to make the app do something: save, send, open, delete.
:::

Displays a themed button. It reads its colors from the current theme, can carry an icon and a keyboard shortcut, and comes in several variants and sizes. Any style parameter of `pz.button` (`bg`, `hover_bg`, `color`, `shadow`, `radius`…) overrides the theme's.

`ui.button` · Category: [Actions](/pyzed/library/#actions) · [Full reference →](/pyzed/reference/ui/#button)

## When to use

- For the main actions of a form, dialog or toolbar.
- Use `variant="solid"` for the one primary action and `"ghost"` for secondary ones.
- For a button with only an icon, use [Icon button](/pyzed/library/icon-button/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Editor(pz.App):
    def save(self):
        ...

    def view(self):
        return ui.button("Save", self.save, icon="save", keys="ctrl-s")
```

To pass a value to the callback, bind it with a default argument: `ui.button(name, lambda n=name: self.open(n))`.

## API

### `ui.button`

```python
button(
    content=None,
    on_press=None,
    *,
    icon=None,
    icon_position='start',
    icon_color=None,
    variant='filled',
    tint=None,
    size='md',
    selected=False,
    disabled=False,
    full_width=False,
    keys=None,
    theme=None,
    **style,
)
```

A themed button with variants, sizes, an icon and a shortcut.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | `None` | Text or widget. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `icon_position` | `"start"` | `"start"` or `"end"`. |
| `icon_color` | `None` | Icon color: a theme token or a hex color. |
| `variant` | `"filled"` | `"filled"`, `"ghost"`, `"subtle"`, `"outline"`, `"solid"`, `"tinted"`, or a semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"`. |
| `tint` | `None` | Color for the `solid` and `tinted` variants. |
| `size` | `"md"` | `"xs"`, `"sm"`, `"md"` or `"lg"`. |
| `selected` | `False` | Marks it as selected. |
| `disabled` | `False` | Disables it (ignores clicks). |
| `full_width` | `False` | Fills the full width. |
| `keys` | `None` | Shortcut shown at the end, written as a string: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
| `**style` | — | Any `pyzed.button` style parameter (`bg`, `hover_bg`, `color`…). |

### `pz.button`

```python
button(
    content,
    on_press=None,
    *,
    padding=None,
    width=None,
    height=None,
    bg=None,
    color=None,
    border_color=None,
    border_width=0.0,
    radius=None,
    shadow=None,
    hover_bg=None,
    hover_color=None,
    hover_border_color=None,
    pressed_bg=None,
    disabled_color=None,
    clip=False,
)
```

A button with no predefined style. For the themed button use `ui.button`.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Button content. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `color` | `None` | Text or icon color. |
| `border_color` | `None` | Border color. |
| `border_width` | `0.0` | Border width in pixels. |
| `radius` | `None` | Corner radius: a number or `(top_left, top_right, bottom_right, bottom_left)`. |
| `shadow` | `None` | Shadow: `(color, (dx, dy), blur)`. |
| `hover_bg` | `None` | Background on hover. |
| `hover_color` | `None` | Text color on hover. |
| `hover_border_color` | `None` | Border color on hover. |
| `pressed_bg` | `None` | Background while pressed. |
| `disabled_color` | `None` | Text color when disabled. |
| `clip` | `False` | Clips content that overflows the bounds. |
