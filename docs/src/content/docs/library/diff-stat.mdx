## Properties and API

### `ui.diff_stat`

```python
diff_stat(added, removed, *, blocks=5, theme=None)
```

`+12 −3` with GitHub-style colored blocks.

| Property | Default | Description |
| --- | --- | --- |
| `added` | *required* | Lines added. |
| `removed` | *required* | Lines removed. |
| `blocks` | `5` | Number of blocks. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
