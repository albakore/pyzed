## When to use

- Next to a file, commit or pull request in a list of changes.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    pz.row([ui.label("render.rs", mono=True), pz.hspace(), ui.diff_stat(42, 9)], align="center"),
    pz.row([ui.label("app.py", mono=True), pz.hspace(), ui.diff_stat(3, 27)], align="center"),
    pz.row([ui.label("README.md", mono=True), pz.hspace(), ui.diff_stat(12, 0)], align="center"),
], spacing=10, width=320)
```

## API

### `ui.diff_stat`

```python
diff_stat(added, removed, *, blocks=5, theme=None)
```

`+12 −3` with GitHub-style colored blocks.

| Parameter | Default | Description |
| --- | --- | --- |
| `added` | *required* | Lines added. |
| `removed` | *required* | Lines removed. |
| `blocks` | `5` | Number of blocks. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
