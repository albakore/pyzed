## When to use

- At the top of every dock (Project, Outline, Terminal) to name it and hold its actions.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.panel_header("Project", [ui.icon_button("plus", on_new, size="xs"),
                                ui.icon_button("ellipsis", on_menu, size="xs")]),
    ui.panel_header("Terminal", [ui.icon_button("x", on_close, size="xs")], icon="terminal"),
], spacing=12, width=320)
```

## Events

Panel header has no events of its own: it shows what you give it. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

## Properties and API

### `ui.panel_header`

```python
panel_header(title, actions=(), *, icon=None, height=32, theme=None)
```

A panel header: icon, title and actions.

| Property | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `actions` | `()` | Extra widgets (usually buttons) shown as actions. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `height` | `32` | Height. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
