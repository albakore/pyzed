:::tip[In plain words]
A sentence where some words are bold, colored or links.
:::

Combines `pz.span(text, color=, size=, font=, weight=, italic=, bg=, underline=, strikethrough=, link=)` fragments into a single block of text that wraps as a whole. Clicking a span with `link` sends that value.

## API

### `pz.rich_text`

```python
rich_text(
    spans,
    *,
    size=None,
    color=None,
    font=None,
    line_height=None,
    width=None,
    align_x=None,
    wrap=True,
)
```

Text made of spans with different styles. Plain strings are unstyled spans.

| Parameter | Default | Description |
| --- | --- | --- |
| `spans` | *required* | List of `span(...)` or strings. |
| `size` | `None` | Size. |
| `color` | `None` | Text or icon color. |
| `font` | `None` | Font of the span or text (family name, e.g. `"IBM Plex Mono"`). |
| `line_height` | `None` | Line height. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `align_x` | `None` | Horizontal alignment: `"start"`/`"left"`, `"center"`, `"end"`/`"right"`. |
| `wrap` | `True` | Line wrapping / moves children to a new row when they don't fit. |

[Full reference →](/pyzed/reference/widgets/#rich_text)

### `pz.span`

```python
span(
    text,
    *,
    color=None,
    size=None,
    font=None,
    weight=None,
    italic=False,
    bg=None,
    radius=0.0,
    padding=None,
    underline=False,
    strikethrough=False,
    link=None,
)
```

A styled span for `rich_text`. With `link`, clicking it sends (or calls) that value.

| Parameter | Default | Description |
| --- | --- | --- |
| `text` | *required* | The text. |
| `color` | `None` | Text or icon color. |
| `size` | `None` | Size. |
| `font` | `None` | Font of the span or text (family name, e.g. `"IBM Plex Mono"`). |
| `weight` | `None` | Font weight: `"normal"`, `"medium"`, `"semibold"` or `"bold"`. |
| `italic` | `False` | If `True`, the span is drawn in italics. |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `radius` | `0.0` | Background radius. |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `underline` | `False` | Underline. |
| `strikethrough` | `False` | Strikethrough. |
| `link` | `None` | Message or callable on click. |
