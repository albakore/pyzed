## When to use

- For right-click menus and the options of a split button or an ellipsis button.
- Mark destructive actions with `danger=True` and put them last.

## Usage

```python
from pyzed import ui

ui.menu([
    ui.MenuItem("New file", on_new, icon="file-plus", keys="ctrl-n"),
    ui.MenuItem("New folder", on_new_folder, icon="folder-plus"),
    ui.SEPARATOR,
    "EDIT",
    ui.MenuItem("Copy path", on_copy, keys="ctrl-alt-c"),
    ui.MenuItem("Soft wrap", on_wrap, checked=True),
    ui.SEPARATOR,
    ui.MenuItem("Delete", on_delete, icon="trash-2", danger=True),
])
```

## API

### `ui.menu`

```python
menu(items, *, width=240, theme=None)
```

A floating context menu. Use `ui.SEPARATOR` between groups; a plain string is a header.

| Parameter | Default | Description |
| --- | --- | --- |
| `items` | *required* | List of `MenuItem`, `ui.SEPARATOR` or strings. |
| `width` | `240` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

[Full reference →](/pyzed/reference/ui/#menu)

### `ui.MenuItem`

```python
@dataclass
class MenuItem(label, on_press=None, icon=None, keys=None, disabled=False, danger=False, checked=None)
```

An entry of `ui.menu`.

| Parameter | Default | Description |
| --- | --- | --- |
| `label` | *required* | Label text. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `keys` | `None` | Shortcut shown at the end, Zed style: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `disabled` | `False` | Disables it (ignores clicks). |
| `danger` | `False` | In red (destructive actions). |
| `checked` | `None` | Shows a check mark (`True`/`False`) or nothing (`None`). |
