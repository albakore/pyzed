## When to use

- To pass a link, a Wi-Fi password or a pairing code to a phone.

## Usage

```python
import pyzed as pz

pz.row([
    pz.qr_code("https://albakore.github.io/pyzed/", cell_size=5),
    pz.qr_code("pyzed", cell_size=5, color="#74ade8", bg="#282c33"),
], spacing=24, align="center")
```

## API

### `pz.qr_code`

```python
qr_code(data, *, cell_size=4.0, color=None, bg=None)
```

A QR code that encodes `data`.

| Parameter | Default | Description |
| --- | --- | --- |
| `data` | *required* | The text or URL to encode. |
| `cell_size` | `4.0` | Size of each module in pixels. |
| `color` | `None` | Text or icon color. |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
