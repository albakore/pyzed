:::tip[In plain words]
A half circle like a car's speedometer that shows one number.
:::

Shows one number between `min` and `max` on an arc, like a speedometer: CPU use, temperature, a score. `thresholds` recolor the arc as the value climbs.

`ui.gauge` · Category: [Data](/pyzed/library/#data) · [Full reference →](/pyzed/reference/ui/#gauge)

## When to use

- On dashboards, for a value with a known range and limits.
- For a value over time, use a [Line chart](/pyzed/library/line-chart/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.gauge(42, unit="%", label="CPU"),
    ui.gauge(78, unit="°C", label="GPU", thresholds=[(70, "warning"), (90, "error")]),
], spacing=24)
```

## Properties and API

### `ui.gauge`

```python
gauge(
    value,
    *,
    min=0.0,
    max=100.0,
    size=140,
    thickness=12,
    unit='',
    label=None,
    tint='accent',
    thresholds=None,
    theme=None,
)
```

A half-circle meter for one number, like a speedometer. `thresholds` recolor the arc as the value climbs.

| Property | Default | Description |
| --- | --- | --- |
| `value` | *required* | The number shown. |
| `min` | `0.0` | Value at the left end. |
| `max` | `100.0` | Value at the right end. |
| `size` | `140` | Width in pixels. |
| `thickness` | `12` | Width of the arc. |
| `unit` | `""` | Text after the number (`"%"`, `"°C"`). |
| `label` | `None` | Text under the number. |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `thresholds` | `None` | `(from_value, color)` pairs, such as `[(70, "warning"), (90, "error")]`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
