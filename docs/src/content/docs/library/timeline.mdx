A vertical list of what happened, joined by a line: each `ui.TimelineItem` has a title, an optional `time`, `description` and `icon` in its dot. `on_press` makes the entries clickable.

## When to use

- For the history of an order, a ticket or a file, or a changelog.
- For the steps still to come, use a [Stepper](/pyzed/library/stepper/).

## Events

Timeline has **1 event of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Handler gets | When |
| --- | --- | --- |
| `on_press` | `(index)` | Called with the index of a clicked entry. |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperative">

```python
class Orders(pz.App):
    def __init__(self):
        self.opened = None

    def open(self, index):               # on_press: the index of the clicked entry
        self.opened = index

    def view(self):
        return ui.timeline([
            ui.TimelineItem("Order placed", time="09:12", icon="shopping-cart"),
            ui.TimelineItem("Shipped", "On its way.", time="14:30", icon="truck",
                            tint="success" if self.opened == 1 else "accent"),
        ], on_press=self.open)
```

</TabItem>
<TabItem label="Declarative">

```python
from dataclasses import dataclass


@dataclass
class Open:
    index: int


class Orders(pz.App):
    opened = None

    def update(self, message):
        match message:
            case Open(index):
                self.opened = index

    def view(self):
        return ui.timeline(["Order placed", "Shipped", "Delivered"], on_press=Open)
```

</TabItem>
<TabItem label="Functional">

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    opened: int = -1


def view(state, set_state):
    return ui.timeline(["Order placed", "Shipped", "Delivered"], on_press=lambda index: set_state(opened=index))
```

## Properties and API

### `ui.timeline`

```python
timeline(items, *, on_press=None, dense=False, theme=None)
```

Events in order down a line: a history, a changelog, the steps of a delivery. Each entry gets a dot joined to the next one.

| Property | Default | Description |
| --- | --- | --- |
| `items` | *required* | `ui.TimelineItem` objects, dicts with the same keys or plain titles. |
| `dense` | `False` | Small dots and less space. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

Events: `on_press` ([events](#events)).

[Full reference →](/pyzed/reference/ui/#timeline)

### `ui.TimelineItem`

```python
@dataclass
class TimelineItem(title, description=None, time=None, icon=None, tint='accent', content=None)
```

One entry of `ui.timeline`.

| Property | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `description` | `None` | Muted text under the title. |
| `time` | `None` | Text at the right of the title (a date, an hour). |
| `icon` | `None` | Icon inside the dot. |
| `tint` | `"accent"` | Color of the dot. |
| `content` | `None` | Any widget under the text. |
