`ui.ColorPicker` is a component that picks a color with alpha, a linear gradient (stops you add, drag and remove, plus an angle) or a fill with an opacity mask. `on_change` receives an event whose `value` is a `"#rrggbb[aa]"` string, a `pz.Gradient` or a `pz.Paint`, all valid backgrounds. `ui.color_swatch` shows any of them over a checkerboard.

## When to use

- For theme editors, drawing apps and style properties.
- Show a `color_swatch` and open the picker in a [Popover](/pyzed/library/popover/) when it is pressed.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Styles(pz.App):
    def __init__(self):
        self.fill = "#3b82f6"

    def view(self):
        return pz.row([
            ui.ColorPicker(value=self.fill, on_change=lambda e: setattr(self, "fill", e.value)),
            pz.container(width=120, height=120, bg=self.fill, radius=8),
        ], spacing=16)
```

## API

### `ui.ColorPicker`

```python
class ColorPicker
```

A component that picks a color with alpha, a linear gradient (stops you add, drag and remove, plus an angle) or a fill with an opacity mask. `on_change` gets a `"#rrggbb[aa]"` string, a `pz.Gradient` or a `pz.Paint`, all valid as a `background`. Pass the picked value back as `value`. See [Styles](/pyzed/guides/styles/#color-picker).

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | `"#3b82f6"` | A color, theme token, `pz.Gradient` or `pz.Paint`. |
| `alpha` | `True` | Shows the alpha bar and field. |
| `gradients` | `True` | Shows the Solid/Gradient switch. |
| `masks` | `True` | Shows the mask editor. |
| `swatches` | `None` | Quick colors (default: the theme's accent and status colors). |
| `on_change` | `None` | Receives `event.value`. |
