`pz.shader` runs a function you write in WGSL, `fn shade(uv, px, size, time) -> vec4<f32>`, for every pixel of the widget, every frame, on the GPU: animated backgrounds, plasma, fire or a radar sweep cost Python nothing. Each entry of `uniforms` becomes a WGSL function of the same name, and `mouse()` gives the pointer. Without a GPU the widget shows `fallback`. See the [Shaders guide](/pyzed/guides/shaders/) and the [showcase](/pyzed/showcase/).

## When to use

- For animated backgrounds behind glass panels, menus and HUDs.
- For game visuals and effects that would be too slow to draw from Python every frame.

## Usage

```python
import pyzed as pz

pz.shader("""
fn shade(uv: vec2<f32>, px: vec2<f32>, size: vec2<f32>, time: f32) -> vec4<f32> {
    let wave = 0.5 + 0.5 * sin(uv.x * 12.0 + uv.y * 4.0 + time * speed());
    return vec4<f32>(mix(vec3<f32>(0.08, 0.09, 0.2), tint().rgb, wave), 1.0);
}
""", uniforms={"speed": 2.0, "tint": "#c678dd"}, width=640, height=240, time=0.5,
    fallback=pz.Gradient(["#14172f", "#c678dd"], angle=0))
```

## Tips

Shaders need the GPU renderer. Always pass a `fallback` that looks right on its own: it is what the software renderer and machines without a GPU draw.

## API

### `pz.shader`

```python
shader(
    code,
    *,
    uniforms=None,
    width=None,
    height=None,
    animate=True,
    time=None,
    fallback=None,
)
```

A widget painted on the GPU by your WGSL `fn shade(uv, px, size, time) -> vec4<f32>`, which returns each pixel's color. Each entry of `uniforms` becomes a function of the same name (`{"speed": 2}` -> `speed()`); `mouse()` gives the pointer. Without a GPU the widget shows `fallback`. Raises `ValueError` with the compiler's message for invalid code. See the [shaders](/pyzed/guides/shaders/) guide.

| Parameter | Default | Description |
| --- | --- | --- |
| `code` | *required* | WGSL source that defines `shade` (and any helper functions). |
| `uniforms` | `None` | Up to 8 named values: a number, 2 to 4 numbers or a color. |
| `width` | `None` | Width (`"fill"` by default). |
| `height` | `None` | Height (`"fill"` by default). |
| `animate` | `True` | Redraw every frame so `time` moves (`True`). |
| `time` | `None` | A fixed `time` in seconds, for a still frame. |
| `fallback` | `None` | Color or gradient shown without a GPU. |
