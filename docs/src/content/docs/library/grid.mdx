Lays out children in a grid. With `columns=3` the columns are equal, and `max_width` fits as many as possible. With track lists (`columns=[200, "1fr", "auto"]`) it works like a CSS grid, and `pz.cell(child, column=, row=, column_span=, row_span=)` places a child explicitly.

## When to use

- For galleries, dashboards and page layouts with a header, sidebar and content.

## Usage

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.container(pz.grid([box(str(i), w="fill") for i in range(1, 9)], columns=4, spacing=8), width=440)
```

## API

### `pz.grid`

```python
grid(
    children=None,
    *,
    columns=None,
    rows=None,
    max_width=None,
    spacing=0.0,
    row_spacing=None,
    height=None,
    aspect_ratio=None,
    width=None,
    padding=None,
    align_x=None,
    align_y=None,
)
```

Lays out its children in a grid. With `columns=3` the columns are equal (or `max_width` fits as many as possible). With track lists (`columns=[200, "1fr", "auto"]`, `rows=...`) it works like a CSS grid: numbers are pixels, `"auto"` fits the content and `"<n>fr"` shares the space left. Wrap children in `pz.cell` to place them and make them span; the rest fill the free cells row by row. See [Layout](/pyzed/guides/layout/#grids).

| Parameter | Default | Description |
| --- | --- | --- |
| `children` | `None` | List of children. Nested lists are flattened and `None` and `False` are ignored, so you can write `cond and widget`. |
| `columns` | `None` | Number of equal columns, or tracks: a list (`[200, "1fr", "auto"]`) or a string (`"200 1fr auto"`). |
| `rows` | `None` | Row tracks, like `columns`. Rows beyond the list are `"auto"`. |
| `max_width` | `None` | Fits as many columns of at most this width as possible (`columns=<int>` only). |
| `spacing` | `0.0` | Space between cells. |
| `row_spacing` | `None` | Space between rows, if different. |
| `height` | `None` | With `columns=<int>`: height of each row. With tracks: the grid's height. |
| `aspect_ratio` | `None` | Keeps cells at this width/height ratio (`columns=<int>` only). |
| `width` | `None` | With `columns=<int>`: pixels. With tracks: the grid's width (default `"fill"`). |
| `padding` | `None` | Space around the cells. |
| `align_x` | `None` | Horizontal alignment of items in their cells: `"start"`, `"center"`, `"end"`. |
| `align_y` | `None` | Vertical alignment of items in their cells. |

### `pz.cell`

```python
cell(
    content,
    *,
    column=None,
    row=None,
    column_span=1,
    row_span=1,
    align_x=None,
    align_y=None,
)
```

Places a child in a track grid: its column and row (from 0) and how many it spans. Children without a cell fill the free cells row by row. Outside a grid it is just the child.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | The widget. |
| `column` | `None` | Column index (from 0). |
| `row` | `None` | Row index (from 0). |
| `column_span` | `1` | Columns it covers. |
| `row_span` | `1` | Rows it covers. |
| `align_x` | `None` | Horizontal alignment in the cell. |
| `align_y` | `None` | Vertical alignment in the cell. |
