:::tip[In plain words]
A blank sheet to draw shapes, lines and text on, for charts and games.
:::

A 2D drawing surface. `shapes` is a list made with [`pyzed.draw`](/pyzed/reference/draw/) (rectangles, circles, arcs, paths, text, images…). Mouse callbacks receive coordinates relative to the canvas; with an `id` the geometry is cached between frames. The charts of this library are drawn with it.

## Events

Canvas has **5 events of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Handler gets | When |
| --- | --- | --- |
| `on_press` | `(x, y)` | Callable that receives `(x, y)` on press. |
| `on_release` | `(x, y)` | Callable that receives `(x, y)` on release. |
| `on_right_press` | `(x, y)` | Callable that receives `(x, y)` on right click. |
| `on_move` | `(x, y)` | Called with `(x, y)` when the mouse moves. |
| `on_scroll` | `(dx, dy)` | Callable that receives `(dx, dy)` in lines when the wheel is used. |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperative">

```python
class Paint(pz.App):
    def __init__(self):
        self.dots, self.drawing = [], False

    def press(self, x, y):               # on_press / on_move get the position
        self.drawing = True
        self.dots.append((x, y))

    def move(self, x, y):
        if self.drawing:
            self.dots.append((x, y))

    def view(self):
        return pz.canvas([draw.circle(x, y, 3, fill="#74ade8") for x, y in self.dots],
                         width=420, height=200, cursor="crosshair",
                         on_press=self.press, on_move=self.move,
                         on_release=lambda x, y: setattr(self, "drawing", False),
                         on_right_press=lambda x, y: self.dots.clear())
```

<TabItem label="Declarative">

```python
from dataclasses import dataclass


@dataclass
class Dot:
    x: float
    y: float


class Paint(pz.App):
    dots = []

    def update(self, message):
        match message:
            case Dot(x, y):
                self.dots = self.dots + [(x, y)]
            case "clear":
                self.dots = []

    def view(self):
        return pz.canvas([draw.circle(x, y, 3, fill="#74ade8") for x, y in self.dots],
                         width=420, height=200, on_press=Dot, on_right_press=lambda x, y: "clear")
```

<TabItem label="Functional">

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    dots: tuple = ()
    zoom: float = 1.0


def view(state, set_state):
    shapes = [draw.circle(x, y, 3 * state.zoom, fill="#74ade8") for x, y in state.dots]
    return pz.canvas(shapes, width=420, height=200,
                     on_press=lambda x, y: set_state(dots=state.dots + ((x, y),)),
                     on_scroll=lambda dx, dy: set_state(zoom=max(0.5, state.zoom + dy * 0.1)))
```

## Properties and API

### `pz.canvas`

```python
canvas(
    shapes=None,
    *,
    width=None,
    height=None,
    id=None,
    on_press=None,
    on_release=None,
    on_right_press=None,
    on_move=None,
    on_scroll=None,
    cursor=None,
    spin=None,
)
```

A 2D drawing surface. `shapes` is a list created with [`pyzed.draw`](/pyzed/reference/draw/). Mouse callbacks receive coordinates relative to the canvas. With an `id`, the geometry is cached between frames and only recomputed when the shapes change. See the [drawing with canvas](/pyzed/guides/canvas/) guide.

| Property | Default | Description |
| --- | --- | --- |
| `shapes` | `None` | List of `pyzed.draw` shapes (nested lists are accepted). |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `id` | `None` | Enables the geometry cache. |
| `cursor` | `None` | Mouse cursor (`"crosshair"`, `"pointer"`…). |
| `spin` | `None` | Turns per second: the drawing rotates around its center by itself, without calling `view()` again (a spinner). |

Events: `on_press`, `on_release`, `on_right_press`, `on_move`, `on_scroll` ([events](#events)).
