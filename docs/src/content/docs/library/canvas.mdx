:::tip[In plain words]
A blank sheet to draw shapes, lines and text on, for charts and games.
:::

A 2D drawing surface. `shapes` is a list made with [`pyzed.draw`](/pyzed/reference/draw/) (rectangles, circles, arcs, paths, text, images…). Mouse callbacks receive coordinates relative to the canvas; with an `id` the geometry is cached between frames. The charts of this library are drawn with it.

## Usage

```python
import pyzed as pz
from pyzed import draw

pz.canvas([
    draw.rect(10, 10, 120, 80, fill="#74ade8", radius=8),
    draw.circle(200, 50, 40, fill="#a1c181"),
    draw.arc(300, 50, 40, 0, 270, stroke="#e5c07b", width=8, cap="round"),
    draw.polygon([(360, 90), (400, 10), (440, 90)], fill="#d07277"),
    draw.line(10, 120, 440, 120, stroke="#5d636f", width=2, dash=[6, 4]),
    draw.text(225, 150, "pz.canvas + pyzed.draw", color="#a9afbc", size=16, align_x="center"),
```

## API

### `pz.canvas`

```python
canvas(
    shapes=None,
    *,
    width=None,
    height=None,
    id=None,
    on_press=None,
    on_release=None,
    on_right_press=None,
    on_move=None,
    on_scroll=None,
    cursor=None,
)
```

A 2D drawing surface. `shapes` is a list created with [`pyzed.draw`](/pyzed/reference/draw/). Mouse callbacks receive coordinates relative to the canvas. With an `id`, the geometry is cached between frames and only recomputed when the shapes change. See the [drawing with canvas](/pyzed/guides/canvas/) guide.

| Parameter | Default | Description |
| --- | --- | --- |
| `shapes` | `None` | List of `pyzed.draw` shapes (nested lists are accepted). |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `id` | `None` | Enables the geometry cache. |
| `on_press` | `None` | Callable that receives `(x, y)` on press. |
| `on_release` | `None` | Callable that receives `(x, y)` on release. |
| `on_right_press` | `None` | Callable that receives `(x, y)` on right click. |
| `on_move` | `None` | Called with `(x, y)` when the mouse moves. |
| `on_scroll` | `None` | Callable that receives `(dx, dy)` in lines when the wheel is used. |
| `cursor` | `None` | Mouse cursor (`"crosshair"`, `"pointer"`…). |
