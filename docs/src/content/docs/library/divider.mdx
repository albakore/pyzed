## When to use

- To separate groups in a column or items in a toolbar.
- Prefer spacing first; add a divider when groups really need a visual break.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.label("Account"),
    ui.divider(),
    pz.row([ui.label("Edit"), ui.divider(vertical=True), ui.label("View"),
            ui.divider(vertical=True), ui.label("Help")], spacing=12, height=20),
    ui.divider(),
    ui.muted("Sign out"),
], spacing=10, width=300)
```

## API

### `ui.divider`

```python
divider(*, vertical=False, color=None, theme=None)
```

A divider line in the theme color.

| Parameter | Default | Description |
| --- | --- | --- |
| `vertical` | `False` | Vertical instead of horizontal. |
| `color` | `None` | Text or icon color. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

[Full reference →](/pyzed/reference/ui/#divider)

### `pz.rule`

```python
rule(*, vertical=False, thickness=1.0, color=None)
```

A horizontal (or vertical) divider line.

| Parameter | Default | Description |
| --- | --- | --- |
| `vertical` | `False` | Vertical line instead of horizontal. |
| `thickness` | `1.0` | Thickness in pixels. |
| `color` | `None` | Text or icon color. |

[Full reference →](/pyzed/reference/widgets/#rule)
