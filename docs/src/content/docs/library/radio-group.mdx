A set of radio buttons where one option is selected. `options` are strings or `(value, label)` pairs; `on_select` receives the value. `horizontal=True` lays them out in a row.

`ui.radio_group` · Category: [Forms](/pyzed/library/#forms) · [Full reference →](/pyzed/reference/ui/#radio_group)

## When to use

- When the options need a label each and should all be visible (indentation: spaces or tabs).
- For many options use a [Select](/pyzed/library/select/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.indent = "spaces"

    def view(self):
        return ui.radio_group([("spaces", "Spaces"), ("tabs", "Tabs")], self.indent,
                              lambda value: setattr(self, "indent", value))
```

## API

### `ui.radio_group`

```python
radio_group(
    options,
    selected,
    on_select=None,
    *,
    horizontal=False,
    spacing=8,
    disabled=False,
    descriptions=None,
    theme=None,
)
```

Mutually exclusive options as radio buttons.

| Parameter | Default | Description |
| --- | --- | --- |
| `options` | *required* | Strings or `(value, label)` pairs. |
| `selected` | *required* | Current value. |
| `on_select` | `None` | Callable that receives the chosen value. |
| `horizontal` | `False` | In a row instead of a column. |
| `spacing` | `8` | Space between children, in pixels. |
| `disabled` | `False` | `True`, or the values to disable. |
| `descriptions` | `None` | Maps values to a muted line under their label. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

[Full reference →](/pyzed/reference/ui/#radio_group)

### `pz.radio`

```python
radio(
    label,
    selected,
    on_select=None,
    *,
    size=None,
    text_size=None,
    spacing=None,
    accent=None,
    bg=None,
    border_color=None,
    color=None,
)
```

A radio button. Group several yourself (or use `ui.radio_group`); `on_select` is sent when it is clicked.

| Parameter | Default | Description |
| --- | --- | --- |
| `label` | *required* | Label text. |
| `selected` | *required* | Whether it is checked. |
| `on_select` | `None` | Message or callable on click. |
| `size` | `None` | Size. |
| `text_size` | `None` | Text size. |
| `spacing` | `None` | Space between the circle and the text. |
| `accent` | `None` | Accent color (active part). |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `border_color` | `None` | Border color. |
| `color` | `None` | Text or icon color. |
