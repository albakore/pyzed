## When to use

- To split a list into groups (RECENT, PINNED) or to add an action to a list.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.list_header("RECENT", end=ui.icon_button("plus", on_new, size="xs")),
    ui.list_item("main.py", on_open, icon="file-code", inset=True),
    ui.list_item("app.py", on_open, icon="file-code", inset=True),
    ui.list_header("PINNED"),
    ui.list_item("README.md", on_open, icon="file-text", inset=True),
], width=300)
```

## API

### `ui.list_header`

```python
list_header(title, *, end=None, theme=None)
```

A section header for lists.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `end` | `None` | Widgets at the end (right). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
