`ui.IconPicker` is a component with a search box, a category drop-down and a grid of every bundled Lucide icon. The search matches names and tags ("person" finds `user`), Enter picks the first match and `on_change` receives the icon's name in `event.value`. `ui.icon_picker_dialog` puts it in a dialog that picks on a click, and `ui.icon_grid` is the bare grid, which only builds the rows in view.

## When to use

- To let users choose an icon for a folder, a tag, a shortcut or a toolbar button.
- Show the current icon as a button and open `icon_picker_dialog` in a [Dialog layer](/pyzed/library/dialog-layer/) when it is pressed.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Shortcuts(pz.App):
    def __init__(self):
        self.icon = "rocket"
        self.picking = False

    def pick(self, name):
        self.icon, self.picking = name or "circle-dashed", False

    def view(self):
        page = ui.button("Change icon", lambda: setattr(self, "picking", True), icon=self.icon)
        dialog = ui.icon_picker_dialog(self.icon, self.pick, on_close=lambda: setattr(self, "picking", False))
        return ui.dialog_layer(page, dialog if self.picking else None,
                               on_dismiss=lambda: setattr(self, "picking", False))
```

## API

### `ui.IconPicker`

```python
class IconPicker
```

A component that picks a Lucide icon: a search box (names and tags), a category drop-down and a grid that only builds the rows in view. Enter picks the first match. `on_change` gets the icon's name (`""` when cleared); pass it back as `value`. See the [Icon picker](/pyzed/library/icon-picker/) page.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | `""` | The picked icon's name. |
| `columns` | `8` | Icons per row. |
| `height` | `288` | Height of the grid. |
| `clearable` | `False` | Shows a button that clears the icon. |
| `autofocus` | `False` | Focuses the search box when it appears. |
| `on_change` | `None` | Receives `event.value`. |

### `ui.icon_grid`

### `pz.icons.search`

```python
search(query, among=None)
```

Icons matching a search by name and tag, best first: exact names, then names that start with the query, names with every word and icons found by their tags (`search("person")` finds `user`).

| Parameter | Default | Description |
| --- | --- | --- |
| `query` | *required* | Words that must all appear in the name or the tags. |
| `among` | `None` | Only search these names (default: every icon). |

[Full reference →](/pyzed/reference/icons/#search)

### `pz.icons.category`

```python
category(key, among=None)
```

The icons of a category of `CATEGORIES`, sorted. An icon can be in several.

| Parameter | Default | Description |
| --- | --- | --- |
| `key` | *required* | A key of `CATEGORIES` (`"arrows"`, `"files"`, `"people"`...). |
| `among` | `None` | Only look at these names. |
