:::tip[In plain words]
Shows what changed in a file: new lines in green, deleted lines in red.
:::

`ui.diff_view(diff)` shows an edit: the file's name, then the lines that changed (added in green, removed in red) with two lines of context around each change; changes far apart are split by `⋯`. `diff` is a dict with `path`, `old` and `new`, the whole texts before and after, and `max_lines` limits how many lines show before `… N more lines`. It is what a [Tool call](/pyzed/library/tool-call/) shows for the edits it made.

## When to use

- To show what an agent or a tool changed in a file.
- To review a change before saving it, next to Keep and Reject buttons.
- For the counts alone (`+12 −3`), use [Diff stat](/pyzed/library/diff-stat/).

## Usage

```python
import pyzed as pz
from pyzed import ui

old = "def save(path):\n    data = load()\n    write(path, data)\n    return True\n"
new = "def save(path, data):\n    write(path, data)\n    log(path)\n    return True\n"
pz.container(ui.diff_view({"path": "app/storage.py", "old": old, "new": new}), width=420)
```

## Properties and API

### `ui.diff_view`

```python
diff_view(diff, *, theme=None, max_lines=120)
```

An edit as Zed shows it in a thread: the file's name, then the changed lines (green added, red removed) with a few lines around them.

| Property | Default | Description |
| --- | --- | --- |
| `diff` | *required* | A dict with `path`, `old` and `new` (the texts before and after). |
| `theme` | `None` | Theme. |
| `max_lines` | `120` | Lines shown before `… N more lines`. |
