Pyzed widgets react to events in two layers:

- **Their own events**: the `on_*` parameters of each component, such as `on_press` of a button or
  `on_select` of a tree. They report what the component means (a tab was closed, a row was opened)
  and usually pass a value (the text, the item, the new state).
- **The common events**: 18 events every widget has, whatever it is, attached with `.on(...)`:
  clicks, hover, drag, focus, keys and size. A `pz.Component` also raises `on_mount` and `on_unmount`.

So a component can have up to its own events plus 18 common ones. Across the 108 components of
the library there are **141 own events**; the ones with the most are listed first in the table at the end.

```python
ui.list_item("main.py", self.open, icon="file").on(   # on_press is its own event
    right_click=self.show_menu,                        # the common ones: any widget
    mouse_enter=lambda: setattr(self, "hovered", "main.py"),
    drag=lambda e: self.move(e.dx, e.dy),              # takes the pz.Event
)
```

## The common events

Every widget has them. A handler without arguments is called with nothing; one with an argument gets a `pz.Event`.

| Group | Event | When |
| --- | --- | --- |
| Mouse | `click` | The widget was clicked (pressed and released with the left button). |
| Mouse | `double_click` | Two clicks in quick succession. |
| Mouse | `right_click` | The right button was pressed (use it for context menus). |
| Mouse | `middle_click` | The middle button (wheel) was pressed. |
| Mouse | `mouse_down` | Any button was pressed over the widget (`event.button`). |
| Mouse | `mouse_up` | Any button was released over the widget (`event.button`). |
| Mouse | `mouse_enter` | The pointer moved onto the widget. |
| Mouse | `mouse_leave` | The pointer left the widget. |
| Mouse | `mouse_move` | The pointer moved over the widget (`event.x`, `event.y`). |
| Mouse | `scroll` | The wheel turned over the widget (`event.dx`, `event.dy` in lines). |
| Drag | `drag_start` | The left button was pressed and the pointer moved a few pixels. |
| Drag | `drag` | The pointer moved while dragging (`event.dx`, `event.dy` since the last one). |
| Drag | `drag_end` | The button was released after a drag. |
| Focus | `focus` | The widget was clicked and now receives key events. |
| Focus | `blur` | A click elsewhere took the focus away. |
| Keyboard | `key_down` | A key was pressed while focused (`event.key`, e.g. `"ctrl-s"`). |
| Keyboard | `key_up` | A key was released while focused (`event.key`). |
| Layout | `resize` | The widget got a new size, including its first one (`event.width`, `event.height`). |

### Fields of `pz.Event`

| Property | Description |
| --- | --- |
| `type` | The event name (`"click"`, or a component's own event). |
| `x`, `y` | Pointer position relative to the widget (`position` gives both). |
| `window_x`, `window_y` | Pointer position in the window. |
| `screen_x`, `screen_y` | On the screen (`None` where the system does not say, such as Wayland). |
| `dx`, `dy` | Scroll amount, or drag movement since the previous `drag`. |
| `width`, `height` | The widget's size (`size` gives both). |
| `button` | `"left"`, `"right"`, `"middle"`… |
| `key` | The key combo, such as `"ctrl-s"`. |
| `shift`, `ctrl`, `alt`, `logo` | Modifiers held. |
| `value`, `source` | For a component's own events: the data and the component. |

## What handlers get

Controls that produce a value call your callable with it. The most common shapes:

| Handler | Description | Events |
| --- | --- | --- |
| `()` | Nothing: the event is the news (a press, a close, Enter). | `ui.alert(on_close=)`, `ui.badge(on_press=)`, `ui.breadcrumbs(on_more=)`, `ui.button(on_press=)`… |
| `(event)` | A `pz.Event`: its `value` holds the data, `source` the component. | `ui.Catalog(on_install=)`, `ui.ColorPicker(on_change=)`, `ui.EditsBar(on_keep=)`, `ui.EditsBar(on_reject=)`… |
| `(text)` | The new text, on every keystroke. | `ui.command_palette(on_query=)`, `ui.console(on_query=)`, `ui.editor(on_change=)`, `ui.input(on_input=)`… |
| `(x, y)` | The pointer position, relative to the widget. | `pz.canvas(on_press=)`, `pz.canvas(on_release=)`, `pz.canvas(on_right_press=)`, `pz.canvas(on_move=)`… |
| `(info)` | A dict (scroll offset and sizes) or a `ui.ErrorInfo`. | `ui.editor(on_scroll=)`, `ui.error_boundary(on_error=)`, `ui.error_boundary(on_details=)`, `pz.scrollable(on_scroll=)`… |
| `(value)` | The new value: a number, a color, an option… | `ui.number_field(on_change=)`, `ui.radio_group(on_select=)`, `ui.slider(on_change=)`, `ui.toggle_group(on_select=)` |
| `(tab_id)` | The id of the tab. | `ui.tab_bar(on_select=)`, `ui.tab_bar(on_close=)`, `ui.tab_bar(on_drag=)`, `ui.tab_bar(on_context=)` |
| `(id)` | The id of the row or tab (for a tree, its path). | `ui.tree(on_toggle=)`, `ui.tree(on_select=)`, `ui.tree(on_open=)`, `ui.tree(on_context=)` |
| `(row)` | The row (the dict or object you passed in `rows`). | `ui.table(on_row_press=)`, `ui.table(on_row_double_press=)`, `ui.table(on_row_context=)` |
| `(dx, dy)` | How far the wheel turned, in lines. | `pz.canvas(on_scroll=)`, `pz.mouse_area(on_scroll=)` |
| `(checked)` | The new state, `True` or `False`. | `ui.checkbox(on_toggle=)`, `ui.switch(on_toggle=)` |
| `(line)` | The log line (a `ui.LogEntry`). | `ui.console(on_context=)`, `ui.console(on_open=)` |
| `(name)` | A name: of the icon, or of the editor action. | `ui.editor(on_action=)`, `ui.icon_picker_dialog(on_pick=)` |
| `(url)` | The URL of the link. | `ui.markdown(on_link=)`, `ui.reference_browser(on_open_url=)` |
| `(size)` | The new size in pixels, when a drag ends. | `ui.panel(on_resize=)`, `pz.resizable(on_resize=)` |
| `(item)` | The option that was chosen. | `ui.segmented(on_select=)`, `ui.select(on_select=)` |
