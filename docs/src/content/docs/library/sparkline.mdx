## When to use

- Inline next to a number or in a table cell, where the trend matters more than the values.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.sparkline([1, 4, 2, 6, 3, 7, 5, 8], width=240, height=48),
    ui.sparkline([8, 6, 7, 4, 5, 3, 2, 1], width=240, height=48, tint="error", fill=False),
], spacing=16)
```

## Properties and API

### `ui.sparkline`

```python
sparkline(values, *, width=120, height=32, tint='accent', fill=True, theme=None)
```

A tiny line chart for trends.

| Property | Default | Description |
| --- | --- | --- |
| `values` | *required* | Values. |
| `width` | `120` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `32` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `fill` | `True` | Fills the area under the line. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
