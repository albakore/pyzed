## When to use

- For the account in the title bar, comment authors or collaborators.
- For several people at once use [Facepile](/pyzed/library/facepile/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.avatar("AL", index=0),
    ui.avatar("KV", index=1),
    ui.avatar("MZ", index=2, size=28),
    ui.avatar("JD", index=3, size=36),
], spacing=8, align="center")
```

## API

### `ui.avatar`

```python
avatar(initials, *, color=None, size=22, index=0, theme=None)
```

A round avatar with initials.

| Parameter | Default | Description |
| --- | --- | --- |
| `initials` | *required* | Initials (the first two are used). |
| `color` | `None` | Background color. |
| `size` | `22` | Diameter. |
| `index` | `0` | Picks a collaborator color from the theme (`theme.players`). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
