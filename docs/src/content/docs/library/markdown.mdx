:::tip[In plain words]
Shows formatted text (titles, lists, links) written in the simple Markdown format.
:::

Renders Markdown (headings, lists, code blocks, quotes, tables, links) with the theme's text, link and code colors. `on_link(url)` receives clicked links. `pz.markdown` is the base widget with explicit colors.

## API

### `ui.markdown`

```python
markdown(source, *, size=None, on_link=None, width=None, theme=None)
```

`pz.markdown` with the theme's text, link and code colors.

| Parameter | Default | Description |
| --- | --- | --- |
| `source` | *required* | The Markdown text. |
| `size` | `None` | Size. |
| `on_link` | `None` | Callable that receives the URL when a link is clicked. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

[Full reference →](/pyzed/reference/ui/#markdown)

### `pz.markdown`

```python
markdown(
    source,
    *,
    size=14.0,
    color=None,
    link_color=None,
    code_color=None,
    code_bg=None,
    on_link=None,
    width=None,
)
```

Renders Markdown (headings, lists, code blocks, quotes, tables, links…). For the theme colors use `ui.markdown`.

| Parameter | Default | Description |
| --- | --- | --- |
| `source` | *required* | The Markdown text. |
| `size` | `14.0` | Size. |
| `color` | `None` | Text or icon color. |
| `link_color` | `None` | Link color. |
| `code_color` | `None` | Code color. |
| `code_bg` | `None` | Code background. |
| `on_link` | `None` | Callable that receives the URL when a link is clicked. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
