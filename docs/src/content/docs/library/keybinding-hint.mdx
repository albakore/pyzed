## When to use

- In empty editors and footers, to teach the shortcuts of the most useful actions.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.keybinding_hint("Open file", "ctrl-p"),
    ui.keybinding_hint("Command palette", "ctrl-shift-p"),
    ui.keybinding_hint("Toggle terminal", "ctrl-j"),
], spacing=10, align="center")
```

## API

### `ui.keybinding_hint`

```python
keybinding_hint(text, keys, *, theme=None)
```

A muted hint like “Open file Ctrl P” for footers and empty states.

| Parameter | Default | Description |
| --- | --- | --- |
| `text` | *required* | Text. |
| `keys` | *required* | Shortcut shown at the end, Zed style: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
