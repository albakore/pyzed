## When to use

- For settings that take effect immediately (Wi-Fi, autosave, dark mode).
- Put it on the right of a [Field](/pyzed/library/field/) to build settings screens.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.autosave = True

    def view(self):
        return ui.switch(self.autosave, lambda on: setattr(self, "autosave", on), label="Autosave")
```

## Events

Switch has **1 event of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Of | Handler gets | When |
| --- | --- | --- | --- |
| `on_toggle` | `ui.switch`, `pz.toggler` | `(checked)` | Callable that receives the new `bool` (or a message to send). |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperative">

```python
class Settings(pz.App):
    def __init__(self):
        self.autosave = True

    def set_autosave(self, on):          # on_toggle: the new state
        self.autosave = on

    def view(self):
        return pz.column([
            ui.switch(self.autosave, self.set_autosave, label="Autosave"),
            ui.label("Saving as you type" if self.autosave else "Save with Ctrl+S"),
        ], spacing=8)
```

</TabItem>
<TabItem label="Declarative">

```python
from dataclasses import dataclass


@dataclass
class SetAutosave:
    on: bool


class Settings(pz.App):
    autosave = True

    def update(self, message):
        match message:
            case SetAutosave(on):
                self.autosave = on

    def view(self):
        return ui.switch(self.autosave, SetAutosave, label="Autosave")
```

from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    autosave: bool = True


def view(state, set_state):
    return ui.switch(state.autosave, lambda on: set_state(autosave=on), label="Autosave")

## Properties and API

### `ui.switch`

```python
switch(checked, on_toggle=None, *, label=None, size='md', disabled=False, theme=None)
```

An on/off switch.

| Property | Default | Description |
| --- | --- | --- |
| `checked` | *required* | Current state. |
| `label` | `None` | Label text. |
| `size` | `"md"` | `"sm"`, `"md"` or `"lg"`. |
| `disabled` | `False` | Greys it out and ignores clicks. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

Events: `on_toggle` ([events](#events)).
