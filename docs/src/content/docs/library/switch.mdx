## When to use

- For settings that take effect immediately (Wi-Fi, autosave, dark mode).
- Put it on the right of a [Field](/pyzed/library/field/) to build settings screens.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.autosave = True

    def view(self):
        return ui.switch(self.autosave, lambda on: setattr(self, "autosave", on), label="Autosave")
```

## API

### `ui.switch`

```python
switch(checked, on_toggle=None, *, label=None, theme=None)
```

An on/off switch.

| Parameter | Default | Description |
| --- | --- | --- |
| `checked` | *required* | Current state. |
| `on_toggle` | `None` | Callable that receives the new `bool` (or a message to send). |
| `label` | `None` | Label text. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
