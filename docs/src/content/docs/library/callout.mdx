An inline notice (Zed's `Callout`/`Banner`): an icon, a title, an optional description, action buttons and a close button with `on_dismiss`. `tint` is `"info"` (default), `"success"`, `"warning"`, `"error"` or any theme token.

## When to use

- For messages that belong to a place in the UI: a read-only file, a new version, a failed sync.
- For short-lived messages, use a [Toast](/pyzed/library/toast/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.callout("A new version is out", "Pyzed 0.4 adds the component designer.", tint="info",
               actions=[ui.button("What's new", on_open, size="sm")], on_dismiss=on_dismiss),
    ui.callout("Could not save", "The file is read-only.", tint="error"),
], spacing=10, width=520)
```

## API

### `ui.callout`

```python
callout(
    title,
    description=None,
    *,
    tint='info',
    icon=None,
    actions=(),
    on_dismiss=None,
    theme=None,
)
```

An inline notice (Zed's `Callout`/`Banner`).

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title (text or widget). |
| `description` | `None` | Secondary text. |
| `tint` | `"info"` | `"info"`, `"success"`, `"warning"`, `"error"` or `"hint"`: picks the color and icon. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `actions` | `()` | Extra widgets (usually buttons) shown as actions. |
| `on_dismiss` | `None` | Adds a close button. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
