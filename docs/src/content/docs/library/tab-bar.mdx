:::tip[In plain words]
The tabs at the top of an editor, one per open document.
:::

A row of editor tabs with optional controls at the start and end. `ui.Tab.for_file(path)` creates a tab with the file's name, icon and path as id. `dirty=True` shows a dot that turns into the close button on hover, `preview=True` draws the name in italics, and `status` tints it with a git color. `on_select(id)` and `on_close(id)` receive the tab id.

## When to use

- For open documents in an editor, or any set of views the user opens and closes.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Editor(pz.App):
    def __init__(self):
        self.open, self.active = ["main.py", "app.py"], "main.py"

    def close(self, path):
        i = self.open.index(path)
        self.open.remove(path)
        if self.active == path:
            self.active = self.open[min(i, len(self.open) - 1)] if self.open else None

    def view(self):
        return ui.tab_bar([ui.Tab.for_file(p) for p in self.open], self.active,
                          on_select=lambda p: setattr(self, "active", p), on_close=self.close)
```

## API

### `ui.tab_bar`

```python
tab_bar(
    tabs,
    active,
    *,
    on_select=None,
    on_close=None,
    start=(),
    end=(),
    height=32,
    on_drag=None,
    on_drop=None,
    on_drag_over=None,
    dragging=None,
    drop_index=None,
    on_context=None,
    on_new=None,
    theme=None,
)
```

A row of tabs with optional controls at the start and end (navigation, split, +). The close button appears on the active tab and on hover. Tabs can be dragged to reorder them or out of the window: see [Draggable tabs](/pyzed/guides/windows/#draggable-tabs-and-detachable-windows).

| Parameter | Default | Description |
| --- | --- | --- |
| `tabs` | *required* | List of `Tab`. |
| `active` | *required* | Id of the active tab. |
| `on_select` | `None` | Callable that receives the chosen item. |
| `on_close` | `None` | Message or callable sent when the X is pressed. |
| `start` | `()` | Widgets at the start (left). |
| `end` | `()` | Widgets at the end (right). |
| `height` | `32` | Height. |
| `on_drag` | `None` | Called with the tab id when a tab starts being dragged. |
| `on_drop` | `None` | Called with the tab id and the `Event` when the dragged tab is released: `event.window_x`/`window_y` (outside the window if it was dropped outside) and `event.screen`. |
| `on_drag_over` | `None` | While `dragging` is set: called with the insertion index under the pointer, or `None` when it leaves the bar. |
| `dragging` | `None` | Id of the tab being dragged (dims it and turns on `on_drag_over`). |
| `drop_index` | `None` | Draws the insertion mark before the tab at this index (`len(tabs)`: after the last one). |
| `on_context` | `None` | Called with the id of a tab that is right-clicked. |
| `on_new` | `None` | Sent on a double click of the empty space after the tabs. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `ui.Tab`

```python
@dataclass
class Tab(id, label, icon=None, icon_color=None, dirty=False, preview=False, status=None, pinned=False, tooltip=None)
```

A tab. `Tab.for_file(path, **kwargs)` creates it with the file's name and icon.

| Parameter | Default | Description |
| --- | --- | --- |
| `id` | *required* | Stable identifier used to focus or scroll it with a `Command`. |
| `label` | *required* | Label text. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `icon_color` | `None` | Icon color: a theme token or a hex color. |
| `dirty` | `False` | Unsaved changes (shows a dot). |
| `preview` | `False` | Preview tab (in italics). |
| `status` | `None` | Git status (tints the name). |
| `pinned` | `False` | Shows only the icon, has no close button and goes first in `tab_bar`. |
| `tooltip` | `None` | Text shown on hover (the full path…). |

### `ui.tab`

```python
tab(item, *, active, on_select=None, on_close=None, height=32, dimmed=False, theme=None)
```

A single tab. You normally use `tab_bar`.

| Parameter | Default | Description |
| --- | --- | --- |
| `item` | *required* | The `Tab`. |
| `active` | *required* | Whether it is the active one. |
| `on_select` | `None` | Callable that receives the chosen item. |
| `on_close` | `None` | Message or callable sent when the X is pressed. |
| `height` | `32` | Height. |
| `dimmed` | `False` | Mutes the label (the tab being dragged). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
