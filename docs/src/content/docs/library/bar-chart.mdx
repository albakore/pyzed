## When to use

- To compare a handful of values side by side (per day, per category).

## Usage

```python
from pyzed import ui

ui.bar_chart([12, 19, 8, 15, 22, 17, 9], labels=["M", "T", "W", "T", "F", "S", "S"],
             width=360, height=180)
```

## API

### `ui.bar_chart`

```python
bar_chart(values, *, labels=None, width=320, height=160, tint='accent', theme=None)
```

A vertical bar chart with optional labels.

| Parameter | Default | Description |
| --- | --- | --- |
| `values` | *required* | Values. |
| `labels` | `None` | Labels under each bar. |
| `width` | `320` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `160` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
