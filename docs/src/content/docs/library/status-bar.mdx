## When to use

- For always-visible state: errors and warnings, cursor position, language, git branch.

## Usage

```python
from pyzed import ui

ui.status_bar(
    [ui.status_item(icon="panel-left", on_press=on_toggle, selected=True, tooltip="Project panel", keys="ctrl-b"),
     ui.status_item("0", icon="circle-x"), ui.status_item("2", icon="triangle-alert", icon_color="warning")],
    [ui.status_item("Ln 12, Col 8"), ui.status_item("UTF-8"), ui.status_item("Python", icon="file-code")],
)
```

## API

### `ui.status_bar`

```python
status_bar(start=(), end=(), *, height=28, theme=None)
```

The bottom status bar.

| Parameter | Default | Description |
| --- | --- | --- |
| `start` | `()` | Widgets at the start (left). |
| `end` | `()` | Widgets at the end (right). |
| `height` | `28` | Height. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `ui.status_item`

```python
status_item(
    content=None,
    on_press=None,
    *,
    icon=None,
    color=None,
    icon_color=None,
    selected=False,
    tooltip=None,
    keys=None,
    theme=None,
)
```

An icon and/or text in the status bar (diagnostics, cursor position, language…).

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | `None` | Text. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `color` | `None` | Text or icon color. |
| `icon_color` | `None` | Icon color: a theme token or a hex color. |
| `selected` | `False` | Marks it as selected. |
| `tooltip` | `None` | Tooltip text. |
| `keys` | `None` | Shortcut shown at the end, written as a string: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
