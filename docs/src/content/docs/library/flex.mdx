:::tip[In plain words]
Spreads things along a line: packed together, evenly spaced, or with one that grows.
:::

Lays children out along one axis like CSS flexbox: `justify` on the main axis (`start`, `center`, `end`, `between`, `around`, `evenly`), `align` on the cross axis, `gap` and `wrap`. `pz.flex_item(child, grow=, basis=)` makes a child grow or gives it a base size.

`pz.flex` · Category: [Layout](/pyzed/library/#layout) · [Full reference →](/pyzed/reference/widgets/#flex)

## When to use

- When `row`/`column` are not enough: even distribution, growing items, wrapping cards.

## Usage

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.flex([box("A"), box("B"), box("C")], justify="between", width=440),
    pz.flex([box("fixed"), pz.flex_item(box("grows", w="fill"), grow=1), box("fixed")], gap=8, width=440),
    pz.flex([box("A"), box("B")], justify="center", gap=8, width=440),
], spacing=14)
```

## API

### `pz.flex`

```python
flex(
    children=(),
    *,
    direction='row',
    justify='start',
    align='start',
    gap=0,
    wrap=False,
    padding=None,
    width=None,
    height=None,
)
```

Lays children out along one axis, like CSS flexbox, with `justify` on the main axis and `align` on the cross axis. Use `pz.flex_item` to make a child grow or give it a fixed size.

| Parameter | Default | Description |
| --- | --- | --- |
| `children` | `()` | The widgets, or `pz.flex_item(...)` for children with their own sizing. |
| `direction` | `"row"` | `"row"` or `"column"`. |
| `justify` | `"start"` | `"start"`, `"center"`, `"end"`, `"between"`, `"around"` or `"evenly"`. No effect when a child grows. |
| `align` | `"start"` | Cross-axis alignment: `"start"`, `"center"` or `"end"`. |
| `gap` | `0` | Space between children. |
| `wrap` | `False` | Wraps onto new lines (rows with `justify="start"` only). |
| `padding` | `None` | Space around the children. |
| `width` | `None` | Width. |
| `height` | `None` | Height. |

[Full reference →](/pyzed/reference/widgets/#flex)

### `pz.flex_item`

```python
flex_item(content, *, grow=1, basis=None, align=None)
```

Sizes a child of `pz.flex`.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | The widget. |
| `grow` | `1` | Share of the free space on the main axis (`0` keeps its natural size). |
| `basis` | `None` | A fixed main size in pixels, instead of growing. |
| `align` | `None` | Cross-axis alignment for this child. |

[Full reference →](/pyzed/reference/widgets/#flex_item)
