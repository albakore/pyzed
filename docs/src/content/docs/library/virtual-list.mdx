A scrolling list for thousands or millions of items. Only the rows in view are built: `render(item)` is called when an item scrolls into view, so the list costs the same whatever its length. Every row has the same `item_height`. `pz.virtual_column` is the building block underneath (rows by index, inside any `scrollable`), and [Table](/pyzed/library/table/) uses it for its rows too.

## When to use

- For logs, search results, file lists or any list that can grow past a few hundred rows.
- For short lists, a `pz.column` of [List items](/pyzed/library/list-item/) is simpler.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Logs(pz.App):
    def __init__(self):
        self.lines = [f"[{i:06}] request handled" for i in range(500_000)]

    def view(self):
        return ui.virtual_list(self.lines, lambda line: pz.text(line, font="mono", size=12),
                               item_height=20, id="logs")
```

## Examples

### Rows by index

`pz.virtual_column(count, item, item_height=...)` calls `item(index)`, handy when the rows come from an array, a database cursor or a computed value. Scroll it like any `scrollable`: row `i` starts at `i * (item_height + spacing)`.

## Tips

- Rows are built again when they scroll back into view, so keep `render` cheap or wrap it in `@pz.memo`.
- `items` should be a list or another sequence: other iterables are copied into a list on every `view()`.

## API

### `ui.virtual_list`

```python
virtual_list(
    items,
    render,
    *,
    item_height=26,
    spacing=0,
    width='fill',
    height='fill',
    padding=None,
    overscan=4,
    id=None,
    on_scroll=None,
    theme=None,
)
```

A scrolling list that only builds the rows in view, for thousands or millions of items. `render(item)` returns the widget for one item and is called when it scrolls into view. Every row has the same height.

| Parameter | Default | Description |
| --- | --- | --- |
| `items` | *required* | The items: a list or any sequence (other iterables are turned into a list). |
| `render` | *required* | Function that receives an item and returns its widget. |
| `item_height` | `26` | Height of every row, in pixels. |
| `spacing` | `0` | Space between children, in pixels. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `"fill"` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `overscan` | `4` | Extra rows built above and below the visible ones. |
| `id` | `None` | Stable identifier used to focus or scroll it with a `Command`. |
| `on_scroll` | `None` | Callable that receives the scroll viewport, as in `pz.scrollable`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `pz.virtual_column`

```python
virtual_column(count, item, *, item_height, spacing=0.0, overscan=4, width=None)
```

A column of `count` rows of the same height that only builds the rows in view: `item(index)` is called when row `index` scrolls into view, and rows that leave it are dropped. A column of a million rows costs the same as one of fifty. Put it in a `scrollable` (it virtualizes against the visible area of the closest one, or the window).

| Parameter | Default | Description |
| --- | --- | --- |
| `count` | *required* | Number of rows. |
| `item` | *required* | Function that receives a row index and returns its widget. |
| `item_height` | *required* | Height of every row, in pixels. |
| `spacing` | `0.0` | Space between rows, in pixels. |
| `overscan` | `4` | Extra rows built above and below the visible ones, so fast scrolling shows no gaps. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
