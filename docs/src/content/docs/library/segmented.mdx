## When to use

- To switch between two to five views or modes (Day / Week / Month).
- For icons only, use a [Toggle group](/pyzed/library/toggle-group/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Calendar(pz.App):
    def __init__(self):
        self.mode = "Week"

    def view(self):
        return ui.segmented(["Day", "Week", "Month"], self.mode, lambda m: setattr(self, "mode", m))
```

## API

### `ui.segmented`

```python
segmented(
    options,
    selected,
    on_select=None,
    *,
    size='md',
    width=None,
    disabled=False,
    theme=None,
)
```

A group of mutually exclusive buttons.

| Parameter | Default | Description |
| --- | --- | --- |
| `options` | *required* | Strings, `(value, label)` or `(value, label, icon)`. |
| `selected` | *required* | The active value. |
| `on_select` | `None` | Callable that receives the chosen item. |
| `size` | `"md"` | `"sm"`, `"md"` or `"lg"`. |
| `width` | `None` | `"fill"` stretches the buttons evenly. |
| `disabled` | `False` | `True`, or the values to disable. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
