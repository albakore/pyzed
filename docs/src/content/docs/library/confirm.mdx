## When to use

- Before destructive or irreversible actions: delete, overwrite, discard.

## Usage

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.confirm(
    "Delete notes.py? This can't be undone.", on_delete, on_cancel,
    title="Delete file", danger=True, confirm_label="Delete", width=360,
))
```

## API

### `ui.confirm`

```python
confirm(
    message,
    on_confirm,
    on_cancel,
    *,
    title=None,
    confirm_label=None,
    cancel_label=None,
    danger=False,
    kind=None,
    width=420,
    theme=None,
)
```

Asks a yes/no question.

| Parameter | Default | Description |
| --- | --- | --- |
| `message` | *required* | Text or widget. |
| `on_confirm` | *required* | The confirm button. |
| `on_cancel` | *required* | Cancel, the close icon. |
| `title` | `None` | Title. |
| `confirm_label` | `None` | Confirm button text. |
| `cancel_label` | `None` | Cancel button text. |
| `danger` | `False` | Paints the confirm button red and labels it Delete. |
| `kind` | `None` | Adds an icon, as in `alert`. |
| `width` | `420` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
