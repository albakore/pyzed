:::tip[In plain words]
A box that asks you to sign in, with a button for each way to do it.
:::

`ui.AuthPrompt` is a component that asks to sign in, for an agent or a service that needs it. It shows a `title`, an optional `detail` and one button per way to sign in: `methods` are dicts with `id`, `name` and optional `description` (shown as a tooltip) and `icon`, and the first one is the main button. Picking one reports `on_pick` with its id. While `waiting` holds that id it shows a spinner and what is happening (`waiting_text`, or "Waiting for the browser…"), the `code` to type with a copy button when there is one, Open the page again when `url` is set, and Cancel. `error` shows a message in red.

## When to use

- Where an agent or a connected service needs the user to sign in before it can work.
- For a device sign-in: show the `code` the user types on the page that opened.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Agent(pz.App):
    def __init__(self):
        self.waiting, self.code = "", ""

    def sign_in(self, method):
        self.waiting = method
        self.code = start_device_login()  # opens the browser and returns the code to type

    def view(self):
        return ui.AuthPrompt(title="Sign in to use the agent", waiting=self.waiting, code=self.code,
                             methods=[{"id": "browser", "name": "Log in with the browser"}],
                             on_pick=lambda e: self.sign_in(e.value),
                             on_cancel=lambda e: setattr(self, "waiting", ""),
                             on_copy=lambda e: pz.Command.copy(e.value))
```

## Tips

:::tip
The copy button only reports `on_copy` with the code in `event.value`; return `pz.Command.copy(e.value)` from it to put the code on the clipboard.
:::

## API

### `ui.AuthPrompt`

```python
class AuthPrompt
```

A component that asks to sign in, like Zed when an agent needs it: one button per way to sign in, then, while one runs, what is happening (the browser or a terminal is open), a code to type when there is one, Open the page again and Cancel.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | `""` | The heading. |
| `detail` | `""` | A line under it. |
| `methods` | `None` | Dicts with `id`, `name`, optional `description` and `icon`; the first is the main one. |
| `waiting` | `""` | The id of the method in progress (`""` when none). |
| `waiting_text` | `""` | What to show while waiting. |
| `code` | `""` | A code to type (device sign-in). |
| `url` | `""` | The page that was opened. |
| `error` | `""` | An error to show. |
| `icon_name` | `"key-round"` | The icon. |
| `theme` | `None` | Theme. |
| `on_pick` | `None` | A method was picked (`event.value` is its id). |
| `on_cancel` | `None` | Cancel. |
| `on_open_url` | `None` | Open the page again. |
| `on_copy` | `None` | The code was copied. |
