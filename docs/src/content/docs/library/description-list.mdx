:::tip[In plain words]
A short list of names and values, like the details of a file.
:::

The details of something, one property per row: names on the left (or above with `vertical`) and their values, which can be text or any widget such as a badge. Text values can be selected and copied.

## When to use

- For the properties of a file, an order, a user or a device.
- For many rows of the same columns, use a [Table](/pyzed/library/table/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.description_list({
    "Name": "report.pdf",
    "Size": "2.4 MB",
    "Modified": "Today, 10:42",
    "Status": ui.badge("Synced", tint="success"),
}), width=360)
```

## Properties and API

### `ui.description_list`

```python
description_list(
    items,
    *,
    label_width=140,
    vertical=False,
    dividers=True,
    mono_values=False,
    selectable=True,
    theme=None,
)
```

Name and value pairs, one per row: the details of a file, an order or a device. A value can be text or any widget.

| Property | Default | Description |
| --- | --- | --- |
| `items` | *required* | A dict or `(name, value)` pairs. |
| `label_width` | `140` | Width of the names column. |
| `vertical` | `False` | Puts each name above its value. |
| `dividers` | `True` | Lines between rows. |
| `mono_values` | `False` | Text values in the monospace font (ids, hashes). |
| `selectable` | `True` | Text values can be selected and copied. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
