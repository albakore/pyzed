## When to use

- For short waits with an unknown duration: connecting, searching, loading a file.
- For long work with known progress use [Progress](/pyzed/library/progress/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Loader(pz.App):
    def __init__(self):
        self.loading = True

    def subscription(self):
        return pz.every(1 / 30, lambda: None) if self.loading else None

    def view(self):
        return ui.spinner() if self.loading else ui.label("Done")
```

## API

### `ui.spinner`

```python
spinner(*, size=16, tint='accent', speed=1.0, theme=None)
```

A spinning arc for loading states. Its angle comes from the clock, so keep a `pz.every(1/30, ...)` subscription active while it is shown.

| Parameter | Default | Description |
| --- | --- | --- |
| `size` | `16` | Size. |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `speed` | `1.0` | Turns per second. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
