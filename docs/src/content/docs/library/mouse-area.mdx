:::tip[In plain words]
An invisible layer that lets anything (a picture, a card, a drawing) notice clicks and the mouse.
:::

`pz.mouse_area` wraps any widget and reports what the mouse does over it: presses (left, right, middle, double click), entering and leaving, moving (`on_move(x, y)`) and the wheel (`on_scroll(dx, dy)`); `cursor` changes the pointer. `pz.hover(base, top)` shows `top` over `base` only while the pointer is over it, and `pz.opaque` stops clicks from reaching what is under a widget in a `stack`.

## When to use

- To make a card, an image or a custom drawing clickable without turning it into a button.
- For right-click menus (`on_right_press`), drag gestures (`on_move`) and zoom with the wheel.
- `pz.hover` for actions that appear on hover, like the close button of a tab.

## Usage

```python
import pyzed as pz

class Board(pz.App):
    def __init__(self):
        self.pointer = (0, 0)
        self.zoom = 1.0

    def view(self):
        return pz.mouse_area(
            self.drawing(),
            on_move=lambda x, y: setattr(self, "pointer", (x, y)),
            on_scroll=lambda dx, dy: setattr(self, "zoom", max(0.1, self.zoom + dy * 0.1)),
            on_double_click=self.reset, cursor="crosshair",
        )
```

## API

### `pz.mouse_area`

```python
mouse_area(
    content,
    *,
    on_press=None,
    on_release=None,
    on_right_press=None,
    on_double_click=None,
    on_enter=None,
    on_exit=None,
    on_move=None,
    on_scroll=None,
    on_middle_press=None,
    on_middle_release=None,
    cursor=None,
)
```

Detects mouse events over its content.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
| `on_press` | `None` | Left click (on press). |
| `on_release` | `None` | On releasing the left button. |
| `on_right_press` | `None` | Right click (context menus). |
| `on_double_click` | `None` | Double click. |
| `on_enter` | `None` | The mouse enters. |
| `on_exit` | `None` | The mouse leaves. |
| `on_move` | `None` | Called with `(x, y)` when the mouse moves. |
| `on_scroll` | `None` | Callable that receives `(dx, dy)` in lines when the wheel is used. |
| `on_middle_press` | `None` | Middle-button click. |
| `on_middle_release` | `None` | Middle button released (pan gestures, for example). |
| `cursor` | `None` | `"pointer"`, `"text"`, `"grab"`, `"grabbing"`, `"crosshair"`, `"not-allowed"`, `"resize-horizontal"`, `"resize-vertical"`, `"move"` or `"default"`. |

[Full reference →](/pyzed/reference/widgets/#mouse_area)

### `pz.hover`

```python
hover(base, top)
```

Shows `top` over `base` only while the mouse is over it (for example, a tab's close button).

| Parameter | Default | Description |
| --- | --- | --- |
| `base` | *required* | Widget underneath. |
| `top` | *required* | Widget that appears on hover. |

[Full reference →](/pyzed/reference/widgets/#hover)

### `pz.opaque`

```python
opaque(content)
```

Makes a widget block the mouse for whatever is below it in a `stack`.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
