## When to use

- For short read-only statuses: `beta`, `M` (modified), `v0.4`, `3 errors`.
- For a round number on top of an icon use [Count badge](/pyzed/library/count-badge/).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.badge("accent"),
    ui.badge("success", tint="success"),
    ui.badge("warning", tint="warning"),
    ui.badge("error", tint="error", icon="circle-x"),
], spacing=8)
```

## API

### `ui.badge`

```python
badge(content, *, tint='accent', variant='soft', icon=None, theme=None)
```

A small pill for statuses and counters.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Content: a `Widget`, a string or a number (converted to text). |
| `tint` | `"accent"` | Semantic color: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` or a token. |
| `variant` | `"soft"` | `"soft"`, `"solid"` or `"outline"`. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
