Separates two widgets with a draggable divider in the theme's border color (accent while dragging). The `ratio` is yours: store it in `on_resize(ratio)`. `vertical=True` stacks the panes. `pz.split` is the base version with configurable `color`, `hover_color`, `thickness` and `handle`.

## When to use

- For side-by-side editors, a preview next to its source, or an editor above a terminal.
- For one resizable side panel, [Resizable](/pyzed/library/resizable/) is simpler.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Panes(pz.App):
    def __init__(self):
        self.ratio = 0.3

    def view(self):
        return ui.split(self.sidebar(), self.editor(), ratio=self.ratio,
                        on_resize=lambda r: setattr(self, "ratio", r))
```

## API

### `ui.split`

```python
split(
    first,
    second,
    *,
    ratio=0.5,
    on_resize=None,
    vertical=False,
    min_size=80,
    theme=None,
    **kwargs,
)
```

`pz.split` with the divider in the theme's border color (accent while dragging).

| Parameter | Default | Description |
| --- | --- | --- |
| `first` | *required* | First pane. |
| `second` | *required* | Second pane. |
| `ratio` | `0.5` | Proportion of the first pane (0–1). |
| `on_resize` | `None` | Callable that receives the new ratio. |
| `vertical` | `False` | Vertical orientation. |
| `min_size` | `80` | Minimum size of each pane. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
| `**kwargs` | — | Same as `pz.split`. |

### `pz.split`

```python
split(
    first,
    second,
    *,
    ratio=0.5,
    on_resize=None,
    vertical=False,
    min_size=80.0,
    min_size_second=None,
    color=None,
    hover_color=None,
    thickness=1.0,
    handle=8.0,
    width=None,
    height=None,
)
```

Two panes with a draggable divider. For the theme style use `ui.split`.

| Parameter | Default | Description |
| --- | --- | --- |
| `first` | *required* | First pane. |
| `second` | *required* | Second pane. |
| `ratio` | `0.5` | Proportion of the first pane (0–1). The split keeps the ratio the user drags to until this changes. |
| `on_resize` | `None` | Callable that receives the new ratio while dragging. |
| `vertical` | `False` | Stacks the panes top/bottom. |
| `min_size` | `80.0` | Minimum size of the first pane. |
| `min_size_second` | `None` | Minimum size of the second pane. |
| `color` | `None` | Divider color. |
| `hover_color` | `None` | Divider color on hover or while dragging. |
| `thickness` | `1.0` | Line thickness. |
| `handle` | `8.0` | Width of the draggable area. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
