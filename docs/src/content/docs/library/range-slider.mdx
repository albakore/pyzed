:::tip[In plain words]
A bar with two handles to choose “from this much to that much”.
:::

Picks a range such as a price from 20 to 80. `value` is `(low, high)` and `on_change` receives the new pair. Pressing the track moves the nearer knob there and dragging keeps moving it; the knobs never cross.

`ui.range_slider` · Category: [Forms](/pyzed/library/#forms) · [Full reference →](/pyzed/reference/ui/#range_slider)

## When to use

- To filter by a range: prices, dates, sizes, years.
- For a single number, use [Slider](/pyzed/library/slider/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Shop(pz.App):
    def __init__(self):
        self.price = (20, 80)

    def view(self):
        return ui.range_slider(self.price, lambda value: setattr(self, "price", value),
                               min=0, max=500, step=5, show_value="{:.0f} €")
```

## Events

Range slider has **2 events of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Handler gets | When |
| --- | --- | --- |
| `on_change` | `((low, high))` | Callable that receives the new `(low, high)`. |
| `on_release` | `()` | Sent when the knob is let go (save or apply there). |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperative">

```python
class Shop(pz.App):
    def __init__(self):
        self.price = (20, 80)

    def set_price(self, value):          # on_change: the new (low, high)
        self.price = value

    def search(self):                    # on_release: the knob was let go
        print("search", self.price)

    def view(self):
        return ui.range_slider(self.price, self.set_price, min=0, max=100, step=5,
                               on_release=self.search, show_value=True)
```

</TabItem>
<TabItem label="Declarative">

```python
from dataclasses import dataclass


@dataclass
class Price:
    value: tuple


class Shop(pz.App):
    price = (20, 80)

    def update(self, message):
        match message:
            case Price(value):
                self.price = value

    def view(self):
        return ui.range_slider(self.price, Price, min=0, max=100, step=5)
```

## Properties and API

### `ui.range_slider`

```python
range_slider(
    value,
    on_change=None,
    *,
    min=0.0,
    max=1.0,
    step=0.01,
    min_gap=0.0,
    on_release=None,
    width='fill',
    tint='accent',
    disabled=False,
    show_value=False,
    theme=None,
)
```

A slider with two knobs that picks a range. Pressing the track moves the nearer knob there and dragging keeps moving it; the knobs never cross.

| Property | Default | Description |
| --- | --- | --- |
| `value` | *required* | `(low, high)`. |
| `min` | `0.0` | Smallest value. |
| `max` | `1.0` | Largest value. |
| `step` | `0.01` | Values snap to multiples of this. |
| `min_gap` | `0.0` | Smallest distance kept between both knobs. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `tint` | `"accent"` | Color of the range between the knobs. |
| `disabled` | `False` | Disables it (ignores clicks). |
| `show_value` | `False` | Adds `low – high` next to it: `True`, or a format for each end such as `"{:.0f} €"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

Events: `on_change`, `on_release` ([events](#events)).
