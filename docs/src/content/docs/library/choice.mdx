## When to use

- When a question has more than two answers (Keep both / Replace / Skip).

## Usage

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.choice(
    "notes.py already exists in this folder.",
    [("Keep both", on_keep), ("Skip", on_skip), ("Replace", on_replace)],
    on_cancel, title="File exists", width=420,
))
```

## API

### `ui.choice`

```python
choice(message, options, on_cancel, *, title=None, width=440, theme=None)
```

A message with your own buttons.

| Parameter | Default | Description |
| --- | --- | --- |
| `message` | *required* | Any Python value, or a callable. |
| `options` | *required* | `(label, on_press)` pairs; the last one is the main button. |
| `on_cancel` | *required* | The close icon. |
| `title` | `None` | Title. |
| `width` | `440` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
