A form row like the ones of a settings screen: the title (and an optional description) on the left and any control on the right. Stack several in a column or a [Settings group](/pyzed/library/settings-group/).

## When to use

- For preferences and forms where each control needs a label and maybe a hint.
- It lines up switches, selects and number fields of different widths.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.field("Autosave", ui.switch(True, on_toggle), description="Saves when you switch tabs"),
    ui.field("Format on save", ui.checkbox(False, on_toggle)),
    ui.field("Font size", ui.number_field(14, on_change, suffix="px")),
], spacing=14, width=440)
```

## Events

Field has no events of its own: it shows what you give it. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

## Properties and API

### `ui.field`

```python
field(
    title,
    control,
    *,
    description=None,
    error=None,
    required=False,
    vertical=False,
    theme=None,
)
```

A form row: title and description on the left, control on the right (like a settings screen).

| Property | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `control` | *required* | The control (switch, input…). |
| `description` | `None` | Help text. |
| `error` | `None` | A validation message shown under the title in the error color (see `pz.validation_errors`). |
| `required` | `False` | Adds a red `*` after the title. |
| `vertical` | `False` | Puts the control under the title. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
