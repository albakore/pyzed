## When to use

- For an empty list, a search with no results, or a panel before the first file is opened.
- Offer the next step as an action (Create, Clear filters, Open folder).

## Usage

```python
from pyzed import ui

ui.empty_state("No results", "Try a different search.", icon="search",
               actions=[ui.button("Clear filters", on_clear, size="sm")])
```

## API

### `ui.empty_state`

```python
empty_state(
    title,
    description=None,
    *,
    icon='inbox',
    actions=(),
    size='md',
    height='fill',
    theme=None,
)
```

A centered placeholder for empty lists, searches with no results, etc.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `description` | `None` | Secondary text. |
| `icon` | `"inbox"` | Name of a Lucide icon (`pyzed icons` lists them). |
| `actions` | `()` | Extra widgets (usually buttons) shown as actions. |
| `size` | `"md"` | `"sm"`, `"md"` or `"lg"`. |
| `height` | `"fill"` | `"fill"` (default), pixels or `"shrink"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
