A compact square button that shows a [Lucide](https://lucide.dev) icon, like Zed's `IconButton`. It is ghost by default, so it fits in toolbars, panel headers and tab bars. `tooltip=` adds a Zed-style tooltip on hover.

`ui.icon_button` · Category: [Actions](/pyzed/library/#actions) · [Full reference →](/pyzed/reference/ui/#icon_button)

## When to use

- For frequent actions whose icon is obvious (search, settings, close, add).
- Always give it a `tooltip` when the icon alone may be ambiguous.
- `selected=True` shows a toggled state (a panel that is open, a filter that is on).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.icon_button("search", on_search, tooltip="Search"),
    ui.icon_button("settings", on_settings, tooltip="Settings"),
    ui.icon_button("bell", on_notifications, selected=True),
    ui.icon_button("plus", on_new, variant="filled"),
], spacing=6)
```

## API

### `ui.icon_button`

```python
icon_button(
    name,
    on_press=None,
    *,
    size='md',
    variant='ghost',
    color=None,
    selected=False,
    disabled=False,
    tooltip=None,
    theme=None,
)
```

A square button with just an icon (Zed's `IconButton`).

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | *required* | Icon name. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `size` | `"md"` | `"xs"`, `"sm"`, `"md"` or `"lg"`. |
| `variant` | `"ghost"` | As in `ui.button`. Defaults to `"ghost"`. |
| `color` | `None` | Icon color. |
| `selected` | `False` | Marks it as selected. |
| `disabled` | `False` | Disables it (ignores clicks). |
| `tooltip` | `None` | Tooltip text. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
