The built-in reference: a searchable class list (the library, your components and any section you `reference.register`) next to the page that is open, with back and forward, internal links and an Open online button. Keep a `pyzed.reference.Browser` in your state; the browser changes it. Links that leave the reference go to `on_open_url`. See [Built-in reference](/pyzed/editor/reference/).

## When to use

- In a Help tab or window of an app built on Pyzed, so its users can read the API offline.
- With your own `reference.Provider` sections, as your app's help.

## Usage

```python
from pyzed import ui

from pyzed import reference

help = reference.Browser("pyzed.ui.button")
ui.reference_browser(help, on_open_url=open_in_browser, sidebar_width=230)
```

## API

### `ui.reference_browser`

```python
reference_browser(

    *,
    on_open_url=None,
    sidebar_width=270,
    width='fill',
    height='fill',
    theme=None,
```
