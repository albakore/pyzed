:::tip[In plain words]
A help window with the documentation inside the app, searchable and offline.
:::

The built-in reference: a searchable class list (the library, your components and any section you `reference.register`) next to the page that is open, with back and forward, internal links and an Open online button. Keep a `pyzed.reference.Browser` in your state; the browser changes it. Links that leave the reference go to `on_open_url`. See [Built-in reference](/pyzed/editor/reference/).

## When to use

- In a Help tab or window of an app built on Pyzed, so its users can read the API offline.
- With your own `reference.Provider` sections, as your app's help.

## Usage

```python
from pyzed import ui

from pyzed import reference

help = reference.Browser("pyzed.ui.button")
ui.reference_browser(help, on_open_url=open_in_browser, sidebar_width=230)
```

## Events

Reference browser has **1 event of its own**, listed below. Like every widget it also has the **18 common events** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), attached with `.on(...)`: see [Events](/pyzed/guides/events/) and [Events of every component](/pyzed/library/events/).

| Event | Handler gets | When |
| --- | --- | --- |
| `on_open_url` | `(url)` | Called with the URL of a link that leaves the reference (open it in the browser). |

**Handler gets** is what Pyzed passes to your callable: `()` means nothing. Any handler can also be a message (a value that is not callable), which goes to `update()`.

### Handling the events

The same events written three ways. **Imperative**: methods of the app change `self`. **Declarative**: the handlers produce messages and one `update()` decides. **Functional**: a pure function draws an immutable state and asks for changes with `set_state(...)`. See [Imperative, declarative and functional](/pyzed/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperative">

```python
import webbrowser

from pyzed import reference


class Help(pz.App):
    def __init__(self):
        self.browser = reference.Browser("pyzed.ui.button")

    def view(self):
        return ui.reference_browser(self.browser, on_open_url=webbrowser.open)   # links to the web
```

<TabItem label="Declarative">

```python
from dataclasses import dataclass

from pyzed import reference


@dataclass
class OpenUrl:
    url: str


class Help(pz.App):
    browser = reference.Browser("pyzed.ui.button")

    def update(self, message):
        match message:
            case OpenUrl(url):
                print("open", url)

    def view(self):
        return ui.reference_browser(self.browser, on_open_url=OpenUrl)
```

</TabItem>
<TabItem label="Functional">

```python
from dataclasses import dataclass

from pyzed import reference

BROWSER = reference.Browser("pyzed.ui.button")


@dataclass(frozen=True)
class State:
    last_url: str = ""


def view(state, set_state):
    return ui.reference_browser(BROWSER, on_open_url=lambda url: set_state(last_url=url))
```
