## When to use

- To show who is in a project, a call or a document without listing names.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.facepile(["Ana", "Luis", "Kev", "Marta"]),
    ui.facepile(["Ana", "Luis", "Kev", "Marta", "Sam", "Jo", "Lee", "Max"], size=28, max_shown=4),
], spacing=16, align="center")
```

## API

### `ui.facepile`

```python
facepile(people, *, size=22, overlap=6, max_shown=5, theme=None)
```

Overlapping collaborator avatars, as in the title bar of a collaborative editor. Those beyond `max_shown` are grouped into `+N`.

| Parameter | Default | Description |
| --- | --- | --- |
| `people` | *required* | Initials or names. |
| `size` | `22` | Size. |
| `overlap` | `6` | Overlap in pixels. |
| `max_shown` | `5` | How many to show. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
