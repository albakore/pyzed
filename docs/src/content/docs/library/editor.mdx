:::tip[In plain words]
A box for writing code, with colors, line numbers and everything a programmer expects.
:::

A code editor with syntax highlighting in the theme colors (100+ languages), line numbers, git markers, auto-closing pairs, folding, a minimap and font zoom. It is **uncontrolled**: the text, cursor and undo history live in Rust, tied to `id`, and `text` is only the initial value. `on_change` receives the full text and `on_cursor` the `(line, column)`. `pz.code_editor` is the base widget without the theme.

## When to use

- For code, configuration files, logs you can edit, or any long text.
- Use the file path as `id`: each file keeps its cursor and history when you switch tabs.
- To replace the text from code, return `pz.Command.set_editor_text(id, text)`.

## Usage

```python
import pyzed as pz
from pyzed import ui

from pathlib import Path

class Editor(pz.App):
    def __init__(self):
        self.path = "main.py"
        self.text = Path(self.path).read_text()

    def save(self):
        Path(self.path).write_text(self.text)

    def view(self):
        return ui.editor(self.path, self.text, path=self.path,
                         on_change=lambda text: setattr(self, "text", text))
```

## Examples

### Folding, code lens and minimap

Blocks fold by indentation (Ctrl+Shift+[ and ]), `annotations` adds a code lens above a line and `minimap=True` draws the overview on the right.

from pyzed import ui


class Counter(pz.App):
    def __init__(self):
        self.count = 0

    def increment(self):
        self.count += 1

    def view(self):
        return ui.button(f"Clicks: {self.count}", self.increment)

## API

### `ui.editor`

```python
editor(
    id,
    text='',
    *,
    language=None,
    path=None,
    on_change=None,
    on_cursor=None,
    markers=None,
    font_size=None,
    line_height=None,
    gutter=True,
    wrap=False,
    active_line=True,
    height='fill',
    placeholder=None,
    annotations=None,
    show_whitespace=False,
    tab_size=None,
    capture_keys=(),
    on_scroll=None,
    auto_close=True,
    folding=True,
    minimap=False,
    cursor_shape='bar',
    cursor_blink=True,
    cursor_width=2.0,
    cursor_color=None,
    on_zoom=None,
    on_action=None,
    highlights=None,
    match_brackets=True,
    selection_highlight=True,
    font=None,
    keymap=None,
    scrollbar=True,
    readonly=False,
    theme=None,
)
```

A code editor: highlighting with the theme colors, line numbers and git markers.

| Parameter | Default | Description |
| --- | --- | --- |
| `id` | *required* | Identifies the buffer (use the file path). |
| `text` | `""` | Initial text. |
| `language` | `None` | Language. If missing, it is inferred from `path`. |
| `path` | `None` | File path. |
| `on_change` | `None` | Callable that receives the new value. |
| `on_cursor` | `None` | Callable that receives `(line, column)`. |
| `markers` | `None` | `{line: "created" \| "modified" \| "deleted"}`. |
| `font_size` | `None` | Font size (defaults to the theme's). |
| `line_height` | `None` | Line height. |
| `gutter` | `True` | Shows line numbers. |
| `wrap` | `False` | Line wrapping. |
| `active_line` | `True` | Background color of the cursor line. |
| `height` | `"fill"` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `placeholder` | `None` | Hint text shown when empty. |
| `annotations` | `None` | `{line: "text"}` or `{line: ("text", color)}`: virtual text at the end of the line (code lens, diagnostics). |
| `show_whitespace` | `False` | Draws spaces as `·` and tabs as `→`. |
| `tab_size` | `None` | Tab inserts spaces up to the next multiple; Enter keeps the indentation (one more level after `:`); Backspace removes a level. |
| `capture_keys` | `()` | Keys the editor leaves to the app's `on_key` (`"up"`, `"enter"`…), e.g. while a completion list is open. |
| `on_scroll` | `None` | Called on scroll. |
| `auto_close` | `True` | Closes brackets and quotes as you type (and wraps the selection). |
| `folding` | `True` | Fold chevrons in the gutter; Ctrl+Shift+[ folds and Ctrl+Shift+] unfolds. |
| `minimap` | `False` | `True` (or a width in pixels) shows a minimap on the right. |
| `cursor_shape` | `"bar"` | `"bar"`, `"block"`, `"underline"` or `"hollow"`. |
| `cursor_blink` | `True` | Whether the cursor blinks. |
| `cursor_width` | `2.0` | Width of the bar cursor. |
| `cursor_color` | `None` | Cursor color (the theme's player color by default). |
| `on_zoom` | `None` | Callable that receives `1`, `-1` or `0` for Ctrl+= / Ctrl+- / Ctrl+0 and Ctrl+wheel. |
| `on_action` | `None` | Callable that receives the name of each editor action that runs (`"undo"`, `"select_next"`…), e.g. to count them. |
| `highlights` | `None` | Ranges painted behind the text in the theme's search color: `[(line, column, end_line, end_column)]`, from 1, with exclusive ends. |
| `match_brackets` | `True` | Outlines the bracket that matches the one next to the cursor (Ctrl+M jumps to it). |
| `selection_highlight` | `True` | Highlights the other occurrences of the selected text (Ctrl+D adds the next one as a cursor). |
| `font` | `None` | Typeface: `"mono"` by default; `"sans"` makes a multi-line text box, like a chat's message box. |
| `keymap` | `None` | Zed-style `{binding: action}` dict (`{"ctrl-shift-d": "duplicate_line_down"}`); `None` as the action removes a default key. Build it from per-action overrides with `pyzed.ui.editor.keymap_for`. |
| `scrollbar` | `True` | `False` hides the scrollbars. |
| `readonly` | `False` | `True` lets the text be selected and copied but not changed (a log, a traceback). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `pz.code_editor`

```python

    text='',

    language='txt',

    on_action=None,
    highlights=None,
    highlight_color=None,
    match_brackets=True,
    selection_highlight=True,
    keymap=None,
    scrollbar=True,
    readonly=False,
)
```

A code editor with syntax highlighting, line numbers and git markers, based on Iced's
`text_editor`. It is **uncontrolled**: `text` is only the initial value for that `id`; the
text, cursor and history live in Rust. Use `Command.set_editor_text` to replace it.
For the themed editor use [`ui.editor`](/pyzed/components/code/).

| Parameter | Default | Description |
| --- | --- | --- |
| `id` | *required* | Identifies the buffer. Reuse it to keep state across renders. |
| `text` | `""` | Initial text. |
| `language` | `"txt"` | Language extension or name (`"py"`, `"rs"`, `"json"`…). |
| `size` | `14.0` | Font size. |
| `line_height` | `None` | Line height in pixels. |
| `font` | `None` | Family (monospace by default). |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `syntax` | `None` | Map of TextMate scopes to colors (provided by `Theme.syntax_scopes()`). |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `color` | `None` | Text or icon color. |
| `selection_color` | `None` | Selection color. |
| `placeholder` | `None` | Hint text shown when empty. |
| `placeholder_color` | `None` | Placeholder color. |
| `gutter` | `True` | Shows line numbers. |
| `gutter_color` | `None` | Line number color. |
| `gutter_active_color` | `None` | Color of the cursor line's number. |
| `gutter_width` | `None` | Gutter width (automatic by default). |
| `markers` | `None` | `{line: color}` for git markers in the gutter (lines from 1). |
| `wrap` | `False` | Line wrapping. |
| `on_change` | `None` | Callable that receives the full text after each edit. |
| `on_cursor` | `None` | Callable that receives `(line, column)`, from 1. |
| `active_line` | `None` | Background color of the cursor line. |
| `scrollbar_color` | `None` | Scrollbar color. |
| `annotations` | `None` | `{line: "text"}` or `{line: ("text", color)}`: virtual text at the end of the line (code lens, diagnostics). |
| `whitespace` | `None` | Draws spaces as `·` and tabs as `→` in this color. |
| `tab_size` | `None` | Tab inserts spaces up to the next multiple; Enter keeps the indentation; Backspace removes a level. |
| `capture_keys` | `None` | Keys the editor leaves to the app's `on_key` (`"up"`, `"enter"`…), e.g. while a completion list is open. |
| `on_scroll` | `None` | Called on scroll. |
| `auto_close` | `False` | Typing a bracket or quote also inserts its closing pair. |
| `folding` | `False` | Fold chevrons in the gutter and Ctrl+Shift+[ / ]. |
| `minimap` | `None` | Width of the minimap in pixels (`None`: no minimap). |
| `minimap_thumb` | `None` | Color of the minimap's visible-area highlight. |
| `cursor_shape` | `"bar"` | `"bar"`, `"block"`, `"underline"` or `"hollow"`. |
| `cursor_width` | `2.0` | Width of the bar cursor. |
| `cursor_blink` | `True` | Whether the cursor blinks. |
| `cursor_color` | `None` | Cursor color. |
| `on_zoom` | `None` | Callable that receives `1`, `-1` or `0` for Ctrl+= / Ctrl+- / Ctrl+0 and Ctrl+wheel. |
| `on_action` | `None` | Callable that receives the name of each editor action that runs (`"undo"`, `"select_next"`…). |
| `highlights` | `None` | Ranges painted behind the text (search results): `[(line, column, end_line, end_column)]`, from 1, with exclusive ends. |
| `highlight_color` | `None` | Color of `highlights`. |
