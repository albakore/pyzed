:::tip[In plain words]
A box where people type one line of text: a name, an email, a password.
:::

A themed single-line text field. It is **controlled**: it shows `value` and reports every keystroke to `on_input`, so you store the text in your state and pass it back in `view()`. `on_submit` runs on Enter.

`ui.input` · Category: [Forms](/pyzed/library/#forms) · [Full reference →](/pyzed/reference/ui/#input)

## When to use

- For names, paths, search boxes, emails and passwords (`secure=True`).
- For multi-line text or code use [Editor](/pyzed/library/editor/).
- Give it an `id` to focus it from code with `pz.Command.focus(id)`.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Form(pz.App):
    def __init__(self):
        self.name = ""

    def view(self):
        return ui.input(self.name, lambda text: setattr(self, "name", text),
                        placeholder="Project name", on_submit=self.create, id="name")

    def on_start(self):
        return pz.Command.focus("name")
```

## API

### `ui.input`

```python
input(
    value,
    on_input=None,
    *,
    placeholder='',
    icon=None,
    on_submit=None,
    on_clear=None,
    id=None,
    size='md',
    secure=False,
    width='fill',
    borderless=False,
    mono=False,
    disabled=False,
    readonly=False,
    invalid=False,
    max_length=None,
    align='start',
    theme=None,
)
```

A text field. Focus, blur and keys come from the common events: `.on(focus=..., blur=..., key_down=...)`.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current text. |
| `on_input` | `None` | Callable that receives the new text on every keystroke. |
| `placeholder` | `""` | Hint text shown when empty. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `on_submit` | `None` | Message or callable sent when Enter is pressed. |
| `on_clear` | `None` | Shows an ✕ while there is text; sent when it is clicked. |
| `id` | `None` | Stable identifier used to focus or scroll it with a `Command`. |
| `size` | `"md"` | `"sm"`, `"md"` or `"lg"`. |
| `secure` | `False` | Hides the text. |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `borderless` | `False` | No border or background (as in the command palette). |
| `mono` | `False` | Uses the monospace font (IBM Plex Mono). |
| `disabled` | `False` | Greys it out and ignores typing. |
| `readonly` | `False` | Selectable and copyable, but it can't be changed. |
| `invalid` | `False` | Paints the border in the error color. |
| `max_length` | `None` | Ignores edits longer than this. |
| `align` | `"start"` | Text alignment: `"start"`, `"center"` or `"end"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `pz.text_input`

```python
text_input(
    value,
    *,
    placeholder='',
    on_input=None,
    on_submit=None,
    id=None,
    size=None,
    font=None,
    padding=None,
    width=None,
    secure=False,
    icon=None,
    icon_size=None,
    bg=None,
    border_color=None,
    hover_border_color=None,
    focus_border_color=None,
    border_width=None,
    radius=None,
    color=None,
    placeholder_color=None,
    selection_color=None,
    icon_color=None,
    align_x=None,
)
```

A controlled text field: it shows `value` and notifies you of changes through `on_input`. For the themed field use `ui.input`.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current text. |
| `placeholder` | `""` | Hint text shown when empty. |
| `on_input` | `None` | Callable that receives the new text on every keystroke. |
| `on_submit` | `None` | Message or callable sent when Enter is pressed. |
| `id` | `None` | Stable identifier used to focus or scroll it with a `Command`. |
| `size` | `None` | Font size. |
| `font` | `None` | Font family. |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `secure` | `False` | Hides the text (passwords). |
| `icon` | `None` | Icon character (use `pyzed.icons.glyph(name)`). |
| `icon_size` | `None` | Icon size. |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `border_color` | `None` | Border color. |
| `hover_border_color` | `None` | Border color on hover. |
| `focus_border_color` | `None` | Border color when focused. |
| `border_width` | `None` | Border width in pixels. |
| `radius` | `None` | Corner radius: a number or `(top_left, top_right, bottom_right, bottom_left)`. |
| `color` | `None` | Text or icon color. |
| `placeholder_color` | `None` | Placeholder color. |
| `selection_color` | `None` | Selection color. |
| `icon_color` | `None` | Icon color. |
| `align_x` | `None` | Horizontal alignment: `"start"`/`"left"`, `"center"`, `"end"`/`"right"`. |
