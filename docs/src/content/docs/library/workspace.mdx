Builds the frame of a Zed window: the title bar on top, docks on the left, right and bottom, the center and the status bar. Pass `None` to hide a dock (that is how Ctrl+B works); `left_width`, `right_width` and `bottom_height` set their size and `on_resize` reports drags.

## When to use

- As the root of editor-like apps: IDEs, note apps, database clients, file managers.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Ide(pz.App):
    def __init__(self):
        self.show_left = True

    def on_key(self, combo):
        if combo == "ctrl-b":
            self.show_left = not self.show_left

    def view(self):
        return ui.workspace(
            self.editor_area(),
            title_bar=ui.title_bar([ui.title_button("my-project", chevron=True)]),
            left=self.project_panel() if self.show_left else None,
            status_bar=ui.status_bar([], [ui.status_item("Python")]),
        )
```

## API

### `ui.workspace`

```python
workspace(
    center,
    *,
    title_bar=None,
    left=None,
    right=None,
    bottom=None,
    status_bar=None,
    left_width=240,
    right_width=320,
    bottom_height=220,
    on_resize=None,
    theme=None,
)
```

The layout of a Zed window: title bar, left, right and bottom docks, center and status bar. Pass `None` to hide a dock.

| Parameter | Default | Description |
| --- | --- | --- |
| `center` | *required* | Central content (usually tabs + editor). |
| `title_bar` | `None` | Title bar (`ui.title_bar`). |
| `left` | `None` | Left dock. |
| `right` | `None` | Right dock. |
| `bottom` | `None` | Bottom dock. |
| `status_bar` | `None` | Status bar (`ui.status_bar`). |
| `left_width` | `240` | Width of the left dock. |
| `right_width` | `320` | Width of the right dock. |
| `bottom_height` | `220` | Height of the bottom dock. |
| `on_resize` | `None` | Called with `(side, size)` when the user finishes resizing a dock by dragging its inner border. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
