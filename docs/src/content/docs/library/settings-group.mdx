## When to use

- To organize a preferences screen into sections (Editor, Files, Git…).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.settings_group("Editor", [
    ui.field("Font size", ui.number_field(14, on_change, suffix="px")),
    ui.field("Soft wrap", ui.switch(True, on_toggle)),
    ui.field("Theme", ui.select(["One Dark", "One Light"], "One Dark", on_select, width=150)),
], description="Editor preferences."), width=460)
```

## API

### `ui.settings_group`

```python
settings_group(title, rows, *, description=None, theme=None)
```

A titled block of `ui.field` rows separated by lines, like a settings screen.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Group title. |
| `rows` | *required* | The rows (usually `ui.field`). |
| `description` | `None` | Secondary text. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
