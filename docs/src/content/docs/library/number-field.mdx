A numeric field with − and + buttons (Zed's `NumericStepper`). You can also type a value: `on_change` receives the number already clamped to `min`/`max`, and text that is not a number is ignored.

## When to use

- For exact values with sensible limits: font size, tab width, port, retries.
- Use `suffix` for units (`"px"`, `"ms"`, `"%"`).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.font_size = 14

    def view(self):
        return ui.number_field(self.font_size, lambda v: setattr(self, "font_size", v),
                               min=8, max=32, suffix="px")
```

## API

### `ui.number_field`

```python
number_field(
    value,
    on_change=None,
    *,
    min=None,
    max=None,
    step=1,
    width=120,
    suffix=None,
    align='center',
    theme=None,
)
```

A numeric field with −/+ buttons (Zed's `NumericStepper`). `on_change(value)` receives the number already clamped to `min`/`max`; anything that can't be parsed as a number is ignored.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current value. |
| `on_change` | `None` | Callable that receives the new value. |
| `min` | `None` | Minimum. |
| `max` | `None` | Maximum. |
| `step` | `1` | Button step. |
| `width` | `120` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `suffix` | `None` | Unit shown at the end (`"px"`, `"%"`…). |
| `align` | `"center"` | Where the number sits between the buttons: `"center"` (default), `"start"` or `"end"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
