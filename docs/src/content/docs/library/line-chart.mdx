:::tip[In plain words]
A drawing with lines that go up and down to show how numbers change.
:::

Draws one or several series of numbers as lines over the x `labels`, with a y axis of four steps. A `{name: values}` dict adds a legend; `fill` shades under each line and `points` marks each value.

`ui.line_chart` · Category: [Data](/pyzed/library/#data) · [Full reference →](/pyzed/reference/ui/#line_chart)

## When to use

- To show how values change over time: visits, sales, temperatures.
- Inside a card or a row, a [Sparkline](/pyzed/library/sparkline/) takes less space.

## Usage

```python
from pyzed import ui

ui.line_chart({"Visits": [12, 18, 15, 24, 30, 28, 36], "Sales": [4, 6, 5, 9, 11, 10, 14]},
              labels=["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"], width=440, height=200)
```

## Properties and API

### `ui.line_chart`

```python
line_chart(
    series,
    *,
    labels=None,
    width=360,
    height=180,
    colors=None,
    fill=False,
    points=False,
    grid=True,
    legend=None,
    min=None,
    max=None,
    theme=None,
)
```

A line chart with axes: one list of numbers, several lists or `{name: values}` (which adds a legend). The y axis shows four steps between `min` and `max`.

| Property | Default | Description |
| --- | --- | --- |
| `series` | *required* | A list of numbers, a list of lists or a `{name: values}` dict. |
| `labels` | `None` | Labels under the x axis (thinned out when they do not fit). |
| `width` | `360` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `180` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `colors` | `None` | Colors of the lines (defaults to the theme's). |
| `fill` | `False` | Shades under each line. |
| `points` | `False` | Marks each value with a dot. |
| `grid` | `True` | Draws the horizontal lines. |
| `legend` | `None` | With a dict, `False` hides the names under the chart. |
| `min` | `None` | Bottom of the y axis (from the data when `None`). |
| `max` | `None` | Top of the y axis (from the data when `None`). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
