:::tip[In plain words]
A box that opens a list so you can pick one option from it.
:::

A dropdown in the theme style. Options are shown with `str()`, so strings, enums or dataclasses all work, and `on_select` receives the chosen object.

## When to use

- To pick one of many options when there is no room to show them all (language, theme, encoding).
- With two to five short options, [Segmented](/pyzed/library/segmented/) or a [Radio group](/pyzed/library/radio-group/) shows them at a glance.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.language = "Python"

    def view(self):
        return ui.select(["Python", "Rust", "TypeScript"], self.language,
                         lambda value: setattr(self, "language", value), width=180)
```

## API

### `ui.select`

```python
select(
    options,
    selected=None,
    on_select=None,
    *,
    placeholder='Select…',
    width=None,
    size='md',
    disabled=False,
    invalid=False,
    on_open=None,
    on_close=None,
    theme=None,
)
```

A dropdown with the theme style. Options are displayed with `str()`, so strings, enums, dataclasses or database models all work; `on_select` receives the chosen object, not its label.

| Parameter | Default | Description |
| --- | --- | --- |
| `options` | *required* | List of options. |
| `selected` | `None` | Current option. |
| `on_select` | `None` | Callable that receives the chosen item. |
| `placeholder` | `"Select…"` | Hint text shown when empty. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `size` | `"md"` | `"sm"`, `"md"` or `"lg"`. |
| `disabled` | `False` | Greys it out. |
| `invalid` | `False` | Paints the border in the error color. |
| `on_open` | `None` | Sent when the menu opens. |
| `on_close` | `None` | Sent when the menu closes. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

### `pz.pick_list`

```python
pick_list(
    options,
    selected=None,
    on_select=None,
    *,
    on_open=None,
    on_close=None,
    placeholder=None,
    width=None,
    padding=None,
    text_size=None,
    font=None,
    handle=None,
    handle_size=12.0,
    menu_height=None,
    bg=None,
    color=None,
    placeholder_color=None,
    handle_color=None,
    border_color=None,
    hover_border_color=None,
    radius=None,
    menu_bg=None,
    menu_color=None,
    menu_border_color=None,
    selected_bg=None,
    selected_color=None,
)
```

A dropdown to choose one of `options`. `on_select(option)` receives the chosen one. For the themed dropdown use `ui.select`.

| Parameter | Default | Description |
| --- | --- | --- |
| `options` | *required* | List of options. |
| `selected` | `None` | Current option. |
| `on_select` | `None` | Callable that receives the chosen item. |
| `on_open` | `None` | Sent when the menu opens. |
| `on_close` | `None` | Sent when the menu closes. |
| `placeholder` | `None` | Hint text shown when empty. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `padding` | `None` | Inner padding: `8`, `(vertical, horizontal)` or `(top, right, bottom, left)`. |
| `text_size` | `None` | Text size. |
| `font` | `None` | Font family. |
| `handle` | `None` | Arrow icon character. |
| `handle_size` | `12.0` | Arrow size. |
| `menu_height` | `None` | Maximum menu height. |
| `bg` | `None` | Background color (`"#rrggbb[aa]"`, `(r, g, b[, a])` or `"transparent"`). |
| `color` | `None` | Text or icon color. |
| `placeholder_color` | `None` | Placeholder color. |
| `handle_color` | `None` | Arrow color. |
| `border_color` | `None` | Border color. |
| `hover_border_color` | `None` | Border color on hover. |
| `radius` | `None` | Corner radius: a number or `(top_left, top_right, bottom_right, bottom_left)`. |
| `menu_bg` | `None` | Menu background. |
| `menu_color` | `None` | Menu text. |
| `menu_border_color` | `None` | Menu border. |
| `selected_bg` | `None` | Background of the highlighted option. |
| `selected_color` | `None` | Text of the highlighted option. |
