:::tip[In plain words]
A bar with a knob you drag to pick an amount, like a volume control.
:::

A themed slider between `min` and `max` (0 to 1 by default) that moves in `step` increments. `on_change` receives the new value while dragging.

`ui.slider` · Category: [Forms](/pyzed/library/#forms) · [Full reference →](/pyzed/reference/ui/#slider)

## When to use

- For values where the exact number matters less than the feel: volume, opacity, zoom.
- When users need to type an exact value, use a [Number field](/pyzed/library/number-field/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Player(pz.App):
    def __init__(self):
        self.volume = 70

    def view(self):
        return pz.row([
            ui.slider(self.volume, lambda v: setattr(self, "volume", v), min=0, max=100, step=1),
            ui.label(f"{self.volume:.0f}%"),
        ], spacing=12, align="center")
```

## API

### `ui.slider`

```python
slider(
    value,
    on_change=None,
    *,
    min=0.0,
    max=1.0,
    step=0.01,
    on_release=None,
    vertical=False,
    width=None,
    height=None,
    disabled=False,
    show_value=False,
    theme=None,
)
```

A slider.

| Parameter | Default | Description |
| --- | --- | --- |
| `value` | *required* | Current value. |
| `on_change` | `None` | Callable that receives the new value. |
| `min` | `0.0` | Minimum. |
| `max` | `1.0` | Maximum. |
| `step` | `0.01` | Step. |
| `on_release` | `None` | Sent when the drag ends (save or apply there). |
| `vertical` | `False` | Stands it up. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `disabled` | `False` | Greys it out. |
| `show_value` | `False` | Shows the number next to it: `True`, or a format such as `"{:.0%}"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
