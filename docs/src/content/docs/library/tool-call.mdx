:::tip[In plain words]
One thing an AI assistant did, like reading or changing a file. Click it to see the details; if it needs your permission, it asks with Allow and Deny buttons.
:::

`ui.ToolCall` is a component for one action of an AI agent (reading a file, editing it, running a command). Its header shows the status, the `title` and what it works on (`detail`), and a click unfolds the `input` and the `output` (plus any `images`). `diffs` show the edits it made as colored diffs, and while it runs `progress` shows the last lines a command printed. While `status` is `"waiting"` it asks right on the card: Allow, Always allow or Deny, reported through `on_allow`, `on_allow_always` and `on_deny`. The component remembers whether it is unfolded; your app only keeps the data.

## When to use

- In an agent's chat, one per step the agent takes.
- With `status="waiting"`, to ask before a risky step such as writing files or running a command.
- For an edit on its own, outside a tool call, use [Diff view](/pyzed/library/diff-view/).

## Usage

```python
import pyzed as pz
from pyzed import ui

class Chat(pz.App):
    def __init__(self):
        self.status = "waiting"

    def answer(self, allowed):
        self.status = "done" if allowed else "rejected"

    def view(self):
        return ui.ToolCall(title="Run", detail="pytest -q", kind="execute", status=self.status,
                           input={"command": "pytest -q"}, output="24 passed",
                           on_allow=lambda e: self.answer(True), on_deny=lambda e: self.answer(False))
```

## Tips

:::tip
`status` is yours: set it from what the agent reports (`pending`, then `running`, then `done` or `failed`; `rejected` after a Deny). `kind` only picks the icon: `read`, `edit`, `delete`, `move`, `search`, `execute`, `think`, `fetch`, `switch_mode` or `other`. The header only unfolds when there is something to show (`input`, `output`, `images` or `diffs`).
:::

## API

### `ui.ToolCall`

```python
class ToolCall
```

A component for one action of an AI agent, like the cards in Zed's Agent panel: a header with the status, the title and what it works on, which unfolds to show the input and the output. While `status` is `"waiting"` it asks right on the card: Allow, Always allow or Deny. See [AI agents](/pyzed/editor/ai-agents/).

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | `""` | What it does ("Edit file"). |
| `detail` | `""` | What it works on, in a monospace font. |
| `kind` | `""` | ACP's kind: `read`, `edit`, `delete`, `move`, `search`, `execute`, `think`, `fetch` or `other` (its icon). |
| `status` | `"done"` | `pending`, `running`, `waiting`, `done`, `failed` or `rejected`. |
| `input` | `None` | The arguments (a dict or text). |
| `output` | `None` | The answer (text or a dict). |
| `images` | `None` | PNG bytes shown under the output. |
| `diffs` | `None` | The edits it made: `{"path", "old", "new"}` dicts, shown as colored diffs (see `ui.diff_view`). |
| `progress` | `""` | What it printed so far (a command's output); its last lines show under the header while it runs. |
| `allow_always` | `True` | Shows Always allow. |
| `theme` | `None` | Theme. |
| `on_allow` | `None` | Allow was pressed. |
| `on_allow_always` | `None` | Always allow was pressed. |
| `on_deny` | `None` | Deny was pressed. |
