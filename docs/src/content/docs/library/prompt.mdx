## When to use

- For quick names: rename a file, name a new branch, save a view.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Files(pz.App):
    def __init__(self):
        self.new_name = None

    def view(self):
        dialog = None
        if self.new_name is not None:
            dialog = ui.prompt("Rename", self.new_name, lambda t: setattr(self, "new_name", t),
                               self.rename, lambda: setattr(self, "new_name", None))
        return ui.dialog_layer(self.main_view(), dialog)
```

## API

### `ui.prompt`

```python
prompt(
    title,
    value,
    on_input,
    on_submit,
    on_cancel,
    *,
    message=None,
    placeholder='',
    submit_label=None,
    cancel_label=None,
    id=None,
    width=440,
    theme=None,
)
```

Asks for a line of text.

| Parameter | Default | Description |
| --- | --- | --- |
| `title` | *required* | Title. |
| `value` | *required* | Current text. |
| `on_input` | *required* | Receives each edit. |
| `on_submit` | *required* | Enter or the submit button. |
| `on_cancel` | *required* | Cancel, the close icon. |
| `message` | `None` | Text above the field. |
| `placeholder` | `""` | Hint text shown when empty. |
| `submit_label` | `None` | Submit button text. |
| `cancel_label` | `None` | Cancel button text. |
| `id` | `None` | Field id (for `Command.focus`). |
| `width` | `440` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
