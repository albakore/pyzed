## When to use

- Inside buttons, list rows and headers. Run `pyzed icons` to search the names.

## Usage

```python
import pyzed as pz

pz.row([
    pz.icon("sparkles", size=28, color="#e5c07b"),
    pz.icon("git-branch", size=28, color="#a1c181"),
    pz.icon("folder-open", size=28, color="#74ade8"),
    pz.icon("bug", size=28, color="#d07277"),
    pz.icon("terminal", size=28, color="#c678dd"),
    pz.svg("logo.svg", width=40, height=40),
], spacing=20, align="center")
```

## API

### `pz.icon`

```python
icon(name, *, size=16, color=None)
```

A [Lucide](https://lucide.dev) icon. `color` defaults to the surrounding text color.

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | *required* | Icon name (`pyzed icons` lists them). |
| `size` | `16` | Size in pixels. |
| `color` | `None` | Color. |

[Full reference →](/pyzed/reference/widgets/#icon)

### `pz.svg`

```python
svg(
    source,
    *,
    width=None,
    height=None,
    color=None,
    content_fit=None,
    opacity=1.0,
    rotation=0.0,
)
```

An SVG image.

| Parameter | Default | Description |
| --- | --- | --- |
| `source` | *required* | Path to an `.svg`, the SVG code as a string (starting with `<`) or `bytes`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `color` | `None` | If given, tints the whole SVG with that color (useful for monochrome icons). |
| `content_fit` | `None` | `"contain"`, `"cover"`, `"fill"`, `"none"` or `"scale-down"`. |
| `opacity` | `1.0` | Opacity from 0 to 1. |
| `rotation` | `0.0` | Rotation in degrees. |
