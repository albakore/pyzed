Darkens the app and shows a dialog in the middle, so the question can't be missed.

Shows a dialog centered over `base` with a dimmed backdrop; clicking the backdrop calls `on_dismiss`. With `dialog=None` it returns `base` unchanged, so keep which dialog is open in your state and always wrap the view with it.

## When to use

- Around your whole view, to show any of the dialogs on this page or a `ui.modal`.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Files(pz.App):
    def __init__(self):
        self.asking = False

    def close(self):
        self.asking = False

    def view(self):
        dialog = None
        if self.asking:
            dialog = ui.confirm("Delete main.py?", self.delete, self.close, title="Delete file", danger=True)
        return ui.dialog_layer(self.main_view(), dialog, on_dismiss=self.close)
```

## API

### `ui.dialog_layer`

```python
dialog_layer(base, dialog=None, *, on_dismiss=None, theme=None)
```

Shows a dialog centered over `base` with a dimmed backdrop. With `dialog=None` it returns `base` unchanged, so it can always wrap the view. See [Dialogs](/pyzed/guides/i18n/#dialogs).

| Parameter | Default | Description |
| --- | --- | --- |
| `base` | *required* | The UI underneath. |
| `dialog` | `None` | A dialog from the functions below, or `ui.modal`. |
| `on_dismiss` | `None` | Sent when the backdrop is clicked. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
