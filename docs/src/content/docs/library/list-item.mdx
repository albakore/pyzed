A list row (Zed's `ListItem`): an icon, the text and `start`/`end` slots for any widget. It supports `selected`, `focused` (focus border), `disabled`, nesting with `indent`, and `on_right_press` for a context menu.

## When to use

- For any vertical list: recent files, search results, settings categories, people.
- Use `inset=True` inside panels so the highlight has a margin, like Zed.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Recent(pz.App):
    def __init__(self):
        self.files = ["main.py", "app.py", "README.md"]
        self.current = "main.py"

    def view(self):
        return pz.column([
            ui.list_item(f, lambda f=f: setattr(self, "current", f), icon="file",
                         selected=f == self.current, inset=True)
            for f in self.files
        ])
```

## API

### `ui.list_item`

```python
list_item(
    content,
    on_press=None,
    *,
    icon=None,
    icon_color=None,
    start=None,
    end=None,
    selected=False,
    focused=False,
    indent=0,
    height=26,
    color=None,
    inset=False,
    disabled=False,
    on_right_press=None,
    theme=None,
)
```

A list row (Zed's `ListItem`): icon, text and a slot at the end.

| Parameter | Default | Description |
| --- | --- | --- |
| `content` | *required* | Text or widget. |
| `on_press` | `None` | Message or callable sent on press. `None` disables the control. |
| `icon` | `None` | Name of a Lucide icon (`pyzed icons` lists them). |
| `icon_color` | `None` | Icon color: a theme token or a hex color. |
| `start` | `None` | Widgets at the start (left). |
| `end` | `None` | Widgets at the end (right). |
| `selected` | `False` | Marks it as selected. |
| `focused` | `False` | Draws a focus border. |
| `indent` | `0` | Left indentation, in pixels. |
| `height` | `26` | Row height. |
| `color` | `None` | Text color. |
| `inset` | `False` | With margin and rounded corners (menus, palettes). |
| `disabled` | `False` | Disables it (ignores clicks). |
| `on_right_press` | `None` | Right click. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
