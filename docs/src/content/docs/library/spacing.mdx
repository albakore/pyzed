:::tip[In plain words]
Empty space: a fixed gap, or a spring that pushes things apart.
:::

`pz.space(width, height)` is an empty box of a given size. `pz.hspace()` and `pz.vspace()` are flexible gaps that take the free space, pushing their siblings to the edges of a row or column.

`pz.space` · Category: [Layout](/pyzed/library/#layout) · [Full reference →](/pyzed/reference/widgets/#space)

## When to use

- To push actions to the right of a toolbar, or a footer to the bottom of a panel.

## Usage

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.row([box("left"), pz.hspace(), box("right")], width=440),
    pz.row([box("a"), pz.space(width=60), box("60 px later", w=140)]),
], spacing=16)
```

## API

### `pz.space`

```python
space(width=None, height=None)
```

Empty space of a given size.

| Parameter | Default | Description |
| --- | --- | --- |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |

[Full reference →](/pyzed/reference/widgets/#space)

### `pz.hspace`

```python
hspace(width='fill')
```

Flexible horizontal gap: pushes the siblings in a row towards the edges.

| Parameter | Default | Description |
| --- | --- | --- |
| `width` | `"fill"` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |

[Full reference →](/pyzed/reference/widgets/#hspace)

### `pz.vspace`

```python
vspace(height='fill')
```

Flexible vertical gap: pushes the siblings in a column towards the edges.

| Parameter | Default | Description |
| --- | --- | --- |
| `height` | `"fill"` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |

[Full reference →](/pyzed/reference/widgets/#vspace)
