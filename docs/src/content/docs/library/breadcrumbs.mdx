## When to use

- Above an editor or a nested view, to show where you are and jump to a parent.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.breadcrumbs(["src", "ui", "button.rs"]),
    ui.breadcrumbs([("folder", "src"), ("file-code", "main.rs"), "fn main"], on_press=on_press),
    ui.breadcrumbs(["Settings", "Editor", "Font"], separator="/"),
], spacing=14)
```

## API

### `ui.breadcrumbs`

```python
breadcrumbs(parts, *, separator='›', on_press=None, theme=None)
```

`src › main.rs › fn main`. Parts can be strings or `(icon, text)` tuples.

| Parameter | Default | Description |
| --- | --- | --- |
| `parts` | *required* | The parts. |
| `separator` | `"›"` | Separator. |
| `on_press` | `None` | Called with the index of the clicked part. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
