:::tip[In plain words]
Shows where you are, step by step: Folder › Subfolder › File.
:::

The path to the current location. Parts are strings or `(icon, text)` tuples; `on_press` receives the index of the clicked part.

## When to use

- Above an editor or a nested view, to show where you are and jump to a parent.

## API

### `ui.breadcrumbs`

```python
breadcrumbs(
    parts,
    *,
    separator='›',
    on_press=None,
    max_items=None,
    on_more=None,
    theme=None,
)
```

`src › main.rs › fn main`. Parts can be strings or `(icon, text)` tuples.

| Parameter | Default | Description |
| --- | --- | --- |
| `parts` | *required* | The parts. |
| `separator` | `"›"` | Separator. |
| `on_press` | `None` | Called with the index of the clicked part. |
| `max_items` | `None` | Keeps the first part and the last ones and shows `…` for the rest. |
| `on_more` | `None` | Makes the `…` clickable. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
