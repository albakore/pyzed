:::tip[In plain words]
A safety net for one part of a window: if that part breaks, a small error box shows there and the rest of the app keeps working.
:::

`ui.error_boundary(build)` returns `build()` or, when it raises, an error card in its place, so one broken part of the view (a sidebar, a panel) never takes the whole window down. The card shows the error, the file and line it comes from and a Copy error button; `on_details` adds a Details button and `fallback` replaces the card with your own widget. `on_error(info)` is told about the error each time the part fails to draw. `ui.ErrorInfo` describes an error (its type, message, traceback and origin) and `ui.error_card` is the card on its own.

## When to use

- Around each panel of a big window, so a bug in one leaves the others working.
- Around parts that draw data you don't control: a plugin, a file the user opened, a reply from a server.
- Open an [Error dialog](/pyzed/library/error-dialog/) from `on_details` to show the whole traceback.

## Usage

```python
import pyzed as pz
from pyzed import ui

class Report(pz.App):
    def __init__(self):
        self.error = None  # the ui.ErrorInfo shown in the dialog

    def totals(self):
        ...  # may raise

    def show(self, info):
        self.error = info

    def close(self):
        self.error = None

    def view(self):
        page = pz.row([
            self.files(),
            ui.error_boundary(self.totals, title="Totals", on_details=self.show),
        ])
        dialog = ui.error_dialog(self.error, self.close) if self.error else None
        return ui.dialog_layer(page, dialog, on_dismiss=self.close)
```

## Tips

:::tip
The boundary runs `build()` on every redraw, so `on_error` is called again each time the part fails. To report an error once, compare it with the last one: two `ErrorInfo` with the same type, message, traceback and origin are equal (`time` is left out). `ErrorInfo.from_exception(err)` describes any exception you catch yourself, and `info.report()` gives the text to paste in a bug report.
:::

## API

### `ui.error_boundary`

```python
error_boundary(
    build,
    *,
    on_error=None,
    title=None,
    where='',
    on_details=None,
    fallback=None,
    theme=None,
)
```

Draws `build()`, or an error card when it raises, so one part of the view that fails never takes the whole window down (like React's error boundaries). `on_error(info)` is told about the error each time the part is drawn and fails, so report it once (compare `info.traceback`).

| Parameter | Default | Description |
| --- | --- | --- |
| `build` | *required* | A function that returns the part's widget. |
| `on_error` | `None` | Receives the `ui.ErrorInfo`. |
| `title` | `None` | Heading of the card (and the error's `where`). |
| `where` | `""` | What the part is, for the report. |
| `on_details` | `None` | Adds a Details button; receives the `ui.ErrorInfo` (open a `ui.error_dialog`). |
| `fallback` | `None` | Your own widget for the error: `fallback(info)`. |
| `theme` | `None` | Theme override. |

[Full reference →](/pyzed/reference/ui/#error_boundary)

### `ui.error_card`

```python
error_card(info, *, title=None, on_details=None, actions=(), theme=None)
```

The card `ui.error_boundary` draws in place of what failed: the error, where it comes from and a Copy error button (and Details with `on_details`).

| Parameter | Default | Description |
| --- | --- | --- |
| `info` | *required* | A `ui.ErrorInfo`. |
| `title` | `None` | Heading. |
| `on_details` | `None` | Adds a Details button. |
| `actions` | `()` | More buttons after them. |
| `theme` | `None` | Theme override. |

[Full reference →](/pyzed/reference/ui/#error_card)

### `ui.ErrorInfo`

```python
@dataclass
class ErrorInfo(kind, message, traceback='', origin=None, where='', time=0.0)
```

An error as `ui.error_card` and `ui.error_dialog` show it: `kind` (the exception's type), `message`, the whole `traceback`, the `origin` `(path, line)` it comes from (the last frame outside the standard library, installed packages and Pyzed), `where` it happened and `time`. `ErrorInfo.from_exception(err, where=...)` makes one (`prefer=` picks which frames may be the origin); `ErrorInfo.current()` describes the exception being handled. `summary` is `Type: message`, `location` is `file.py:12` and `report()` is everything as text for a bug report.

| Parameter | Default | Description |
| --- | --- | --- |
| `kind` | *required* | The exception's type name. |
| `message` | *required* | Its message. |
| `traceback` | `""` | The whole traceback, as Python prints it. |
| `origin` | `None` | `(path, line)` of the code it comes from, or `None`. |
| `where` | `""` | What was running. |
| `time` | `0.0` | When it happened (`time.time()`). |
