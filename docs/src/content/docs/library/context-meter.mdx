:::tip[In plain words]
A little ring that fills up as a chat with an AI gets longer, like a fuel gauge.
:::

`ui.context_meter(used, limit)` shows how full an AI model's context window is: a small ring and `48k / 200k`. It is gray below 80%, yellow from 80% and red from 95%, and its tooltip gives the exact counts. `ui.format_tokens(count)` writes a count the short way: `950`, `4.5k`, `48k`, `1.25M`.

## When to use

- In the toolbar or the input box of an agent's chat, so the user sees when a conversation gets long.

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.context_meter(48_000, 200_000),
    ui.context_meter(170_000, 200_000),
    ui.context_meter(196_000, 200_000),
], spacing=24, align="center")
```

## API

### `ui.context_meter`

```python
context_meter(used, limit, *, theme=None)
```

How full a model's context window is, like Zed's token counter: a small ring and `48k / 200k`, yellow past 80% and red past 95%.

| Parameter | Default | Description |
| --- | --- | --- |
| `used` | *required* | Tokens in use. |
| `limit` | *required* | The model's window. |
| `theme` | `None` | Theme. |

[Full reference →](/pyzed/reference/ui/#context_meter)

### `ui.format_tokens`

```python
format_tokens(count)
```

A short token count: `950`, `4.5k`, `48k`, `1.25M`.

| Parameter | Default | Description |
| --- | --- | --- |
| `count` | *required* | Tokens. |

[Full reference →](/pyzed/reference/ui/#format_tokens)
