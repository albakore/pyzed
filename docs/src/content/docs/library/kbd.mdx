:::tip[In plain words]
Draws keyboard keys, so people learn the shortcut: Ctrl + S.
:::

Draws a shortcut written as a string (`"ctrl-shift-p"`, chords like `"cmd-k cmd-s"`) as key caps. On macOS it uses symbols (⌘⇧P) and words elsewhere; `pyzed.ui.base.KEY_STYLE` forces `"symbols"` or `"words"`. `ui.format_keys` returns the labels if you draw them yourself.

`ui.kbd` · Category: [Display](/pyzed/library/#display) · [Full reference →](/pyzed/reference/ui/#kbd)

## When to use

- In menus, tooltips, palettes and help screens, to teach shortcuts.
- Most components already accept `keys=` and draw it for you (button, menu item, tooltip).

## Usage

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.kbd("ctrl-shift-p"),
    ui.kbd("ctrl-k ctrl-s"),
    pz.row([ui.kbd("escape", size="xs"), ui.kbd("enter", size="xs"), ui.kbd("tab", size="xs")], spacing=8),
], spacing=12, align="center")
```

## Properties and API

### `ui.kbd`

```python
kbd(keys, *, size='sm', theme=None)
```

Draws a shortcut as keys: `"ctrl-shift-p"`, `"cmd-k cmd-s"`. Uses symbols on macOS (⌘⇧P) and words elsewhere.

| Property | Default | Description |
| --- | --- | --- |
| `keys` | *required* | The shortcut. |
| `size` | `"sm"` | `"xs"` or `"sm"`. |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |

[Full reference →](/pyzed/reference/ui/#kbd)

### `ui.format_keys`

```python
format_keys(keys)
```

Splits a shortcut into labels per chord: `format_keys("ctrl-shift-p") == [["Ctrl", "Shift", "P"]]`. The style is controlled by `pyzed.ui.base.KEY_STYLE` (`"auto"`, `"symbols"` or `"words"`).

| Property | Default | Description |
| --- | --- | --- |
| `keys` | *required* | The shortcut. |

[Full reference →](/pyzed/reference/ui/#format_keys)
