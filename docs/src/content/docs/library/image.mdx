:::tip[In plain words]
Shows a picture from a file: a photo, a logo, a screenshot.
:::

`pz.image(source)` shows a PNG, JPEG, GIF, WebP, BMP… from a path, `bytes`, or raw RGBA pixels with `size=(w, h)`. Options: `content_fit` (`"contain"`, `"cover"`, `"fill"`, `"none"`, `"scale_down"`), `filter` (`"linear"` or `"nearest"`), `opacity`, `radius`, `rotation` and `scale`. `pz.image_viewer` adds pan (drag) and zoom (wheel).

## Properties and API

### `pz.image`

```python
image(
    source,
    *,
    width=None,
    height=None,
    content_fit=None,
    filter='linear',
    opacity=1.0,
    radius=0.0,
    rotation=0.0,
    scale=1.0,
    size=None,
    background=None,
)
```

A bitmap image (PNG, JPEG, GIF, BMP, WebP…) from a path or `bytes`, or raw RGBA pixels.

| Property | Default | Description |
| --- | --- | --- |
| `source` | *required* | File path, `bytes` of the encoded file, or raw RGBA pixels with `size=(width, height)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `content_fit` | `None` | `"contain"`, `"cover"`, `"fill"`, `"none"` or `"scale-down"`. |
| `filter` | `"linear"` | `"linear"` (smooth) or `"nearest"` (crisp pixels, for pixel art). |
| `opacity` | `1.0` | Opacity from 0 to 1. |
| `radius` | `0.0` | Corner radius. |
| `rotation` | `0.0` | Rotation in degrees. |
| `scale` | `1.0` | Scale. |
| `size` | `None` | `(width, height)` when `source` is raw RGBA pixels. |
| `background` | `None` | Decode on a worker thread: `None` (the default) does it for files of 256 KB and up, `True` always, `False` never. Until it is ready the image shows nothing, so give it a `width` and `height` to keep its space. |

### `pz.image_viewer`

```python
image_viewer(
    source,
    *,
    width=None,
    height=None,
    min_scale=0.25,
    max_scale=10.0,
    scale_step=0.1,
    filter='linear',
    size=None,
)
```

An image you can pan (by dragging) and zoom (mouse wheel), like Iced's viewer.

| Property | Default | Description |
| --- | --- | --- |
| `source` | *required* | File path, `bytes` of the encoded file, or raw RGBA pixels with `size=(width, height)`. |
| `width` | `None` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `height` | `None` | Height: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `min_scale` | `0.25` | Minimum zoom. |
| `max_scale` | `10.0` | Maximum zoom. |
| `scale_step` | `0.1` | How much the zoom changes per wheel step. |
| `filter` | `"linear"` | `"linear"` (smooth) or `"nearest"` (crisp pixels, for pixel art). |
| `size` | `None` | `(width, height)` for raw RGBA pixels. |
