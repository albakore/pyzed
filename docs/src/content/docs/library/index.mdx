Every component of `pyzed.ui`, plus the layout and content widgets of `pyzed`, with a live
preview, the code that draws it, examples and its API. Components are **functions that return
widgets**, so they combine freely with each other and with the [base widgets](/pyzed/reference/widgets/).

```python
import pyzed as pz
from pyzed import ui

ui.button("Save", self.save, icon="save", variant="solid", keys="ctrl-s")
```

- **Theme colors.** Every component reads the current theme (`App.theme`, or the window's theme
  in [multi-window](/pyzed/guides/windows/) apps), and accepts `theme=` to use another one.
- **Tokens or hex.** Color parameters (`color`, `icon_color`, `tint`…) take a theme token such as
  `"accent"`, `"text_muted"` or `"error"`, or a `"#rrggbb"` color.
- **Messages or callables.** `on_press`, `on_select`, `on_toggle`… take a message for `update`
  or a callable; those that produce a value (text, `bool`, id) call it with that value.
- **Icons.** `icon=` takes any [Lucide](https://lucide.dev) name (`pyzed icons` lists them).

To see them all running, open the gallery: `python examples/gallery.py`.
Looking for whole screens built from them (login, dashboard, settings, chat, kanban...)? See
[Blocks](/pyzed/blocks/).
