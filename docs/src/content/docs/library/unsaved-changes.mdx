## When to use

- When closing a tab or a window with unsaved edits.

## Usage

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.unsaved_changes("notes.py", on_save, on_discard, on_cancel))
```

## API

### `ui.unsaved_changes`

```python
unsaved_changes(name, on_save, on_discard, on_cancel, *, width=440, theme=None)
```

"Save your changes to *name* before closing?" with Don't save, Cancel and Save.

| Parameter | Default | Description |
| --- | --- | --- |
| `name` | *required* | File or document name. |
| `on_save` | *required* | Save. |
| `on_discard` | *required* | Don't save. |
| `on_cancel` | *required* | Cancel. |
| `width` | `440` | Width: pixels, `"fill"`, `"shrink"` or `"fill:N"` (proportion). |
| `theme` | `None` | Theme to use instead of the current one (`pyzed.theme.current()`). |
