## Math

Every math node works on numbers **and** vectors: with a `vec3` it works on each component (red, green and blue at once). Their inputs and outputs have the generic type `T`.

### Math

`math` · Math · `g.math(...)`

An arithmetic operation on two values (of any type: vectors work per component).

<Media src={node_math} alt="The Math node as it looks in the Shader view, with its preview" size="small" plain />

Two values in, one out. In Python you rarely add it by hand: `a + b`, `a * 2` or `a ** 2` on ports add Math nodes for you. Each operation is its own entry in the sidebar (Add, Multiply, Step...).

| Input | Type | Default |
| --- | --- | --- |
| `a` | `T` | `0` |
| `b` | `T` | `1` |

| Output | Type |
| --- | --- |
| `result` | `T` |

| Setting | Values | Default |
| --- | --- | --- |
| `op` | `add`, `subtract`, `multiply`, `divide`, `modulo`, `power`, `min`, `max`, `step`, `atan2`, `snap` | `add` |

**Sidebar entries**

| Entry | What it does | In Python |
| --- | --- | --- |
| Add | a + b | `g.add(...)` |
| Subtract | a − b | `g.subtract(...)` |
| Multiply | a × b | `g.multiply(...)` |
| Divide | a ÷ b | `g.divide(...)` |
| Modulo | The remainder of a ÷ b (always the sign of b). | `g.modulo(...)` |
| Power | a to the power of b. | `g.power(...)` |
| Min | The smaller of a and b. | `g.min(...)` |
| Max | The larger of a and b. | `g.max(...)` |
| Step | 0 where b is below the edge a, 1 from there on. | `g.step(...)` |
| Atan2 | The angle of the point (b, a) in radians: a is y, b is x. | `g.atan2(...)` |
| Snap | a rounded to the nearest multiple of b. | `g.snap(...)` |

```python title="Example"
uv = g.uv()
stripes = g.step(0.5, g.fract(uv["x"] * 8.0))
g.output(g.rgba(stripes * 0.8 + 0.1, 1.0))
```

### Mix

`mix` · Math · `g.mix(...)`

Blends from a (t = 0) to b (t = 1): a lerp.

<Media src={node_mix} alt="The Mix node as it looks in the Shader view, with its preview" size="small" plain />

Blends two values: `t` = 0 gives `a`, 1 gives `b`, 0.5 half of each. The node you will use most to combine colors.

| Input | Type | Default |
| --- | --- | --- |
| `a` | `T` | `0` |
| `b` | `T` | `1` |
| `t` | `T` | `0.5` |

| Output | Type |
| --- | --- |
| `result` | `T` |

```python title="Example"
uv = g.uv()
sky = g.mix([0.1, 0.2, 0.5], [0.9, 0.6, 0.3], uv["y"])
g.output(g.rgba(sky, 1.0))
```

### Clamp

`clamp` · Math · `g.clamp(...)`

x kept between min and max.

<Media src={node_clamp} alt="The Clamp node as it looks in the Shader view, with its preview" size="small" plain />

Keeps a value inside a range, so a bright spot never goes over 1 or a dark one under 0.

| Input | Type | Default |
| --- | --- | --- |
| `x` | `T` | `0` |
| `min` | `T` | `0` |
| `max` | `T` | `1` |

| Output | Type |
| --- | --- |
| `result` | `T` |

```python title="Example"
v = g.uv()["x"] * 2.0 - 0.5
g.output(g.rgba(g.clamp(v, 0.0, 1.0), 1.0))
```

### Smoothstep

`smoothstep` · Math · `g.smoothstep(...)`

0 below edge0, 1 above edge1 and a smooth curve between them.

<Media src={node_smoothstep} alt="The Smoothstep node as it looks in the Shader view, with its preview" size="small" plain />

A soft threshold: 0 below `edge0`, 1 above `edge1`, and a smooth curve between. Use it to turn a distance or a noise into a soft-edged mask.

| Input | Type | Default |
| --- | --- | --- |
| `edge0` | `T` | `0` |
| `edge1` | `T` | `1` |
| `x` | `T` | `0.5` |

| Output | Type |
| --- | --- |
| `result` | `T` |

```python title="Example"
n = g.noise(scale=6.0)
mask = g.smoothstep(0.45, 0.55, n)
g.output(g.rgba(mask, 1.0))
```

### Remap

`remap` · Math · `g.remap(...)`

x moved from the range in_min..in_max to out_min..out_max.

<Media src={node_remap} alt="The Remap node as it looks in the Shader view, with its preview" size="small" plain />

Moves a value from one range to another: −1..1 (a sine) to 0..1 (a color), or 0..1 to 0.2..0.8.

| Input | Type | Default |
| --- | --- | --- |
| `x` | `T` | `0.5` |
| `in_min` · in min | `T` | `0` |
| `in_max` · in max | `T` | `1` |
| `out_min` · out min | `T` | `-1` |
| `out_max` · out max | `T` | `1` |

| Output | Type |
| --- | --- |
| `result` | `T` |

```python title="Example"
s = g.time()["sin"]
v = g.remap(s, -1.0, 1.0, 0.2, 0.8)
g.output(g.rgba(v, 1.0))
```

### Multiply add

`multiply_add` · Math · `g.multiply_add(...)`

a × b + c

<Media src={node_multiply_add} alt="The Multiply add node as it looks in the Shader view, with its preview" size="small" plain />

`a × b + c` in one node: scale and shift a value, such as `sin × 0.5 + 0.5` to bring −1..1 into 0..1.

| Input | Type | Default |
| --- | --- | --- |
| `a` | `T` | `1` |
| `b` | `T` | `1` |
| `c` | `T` | `0` |

| Output | Type |
| --- | --- |
| `result` | `T` |

```python title="Example"
s = g.time()["sin"]
g.output(g.rgba(g.multiply_add(s, 0.5, 0.5), 1.0))
```
