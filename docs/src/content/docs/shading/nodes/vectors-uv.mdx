## Vector

Vectors are groups of 2, 3 or 4 numbers: a position (x, y), a color (r, g, b) or a color with alpha (r, g, b, a). These nodes build, split and measure them.

### Compose

`compose` · Vector · `g.compose(...)`

Builds a vector from its components.

<Media src={node_compose} alt="The Compose node as it looks in the Shader view, with its preview" size="small" plain />

Builds a vector from separate numbers: three values into an RGB color, two into a point. The `type` setting picks vec2, vec3 or vec4 (the sidebar has *Compose vec2* and *Compose vec4* too).

| Input | Type | Default |
| --- | --- | --- |
| `x` | `float` | `0` |
| `y` | `float` | `0` |
| `z` | `float` | `0` |

| Output | Type |
| --- | --- |
| `vector` | `vec3` |

| Setting | Values | Default |
| --- | --- | --- |
| `type` | `vec2`, `vec3`, `vec4` | `vec3` |

The inputs follow the `type` setting: `x` and `y` for vec2, up to `w` for vec4.

**Sidebar entries**

| Entry | What it does | In Python |
| --- | --- | --- |
| Compose | Builds a vector from its components. | `g.compose(...)` |
| Compose vec2 | Builds a vec2 from x and y. | `g.compose_vec2(...)` |
| Compose vec4 | Builds a vec4 from x, y, z and w. | `g.compose_vec4(...)` |

```python title="Example"
uv = g.uv()
rgb = g.compose(uv["x"], uv["y"], 0.5)
g.output(g.rgba(rgb, 1.0))
```

### Decompose

### Swizzle

`swizzle` · Vector · `g.swizzle(...)`

### Dot

`dot` · Vector · `g.dot(...)`

The dot product of a and b: how much they point the same way.

<Media src={node_dot} alt="The Dot node as it looks in the Shader view, with its preview" size="small" plain />

The dot product: how much two directions point the same way (1 same, 0 square, −1 opposite). Also `p · p` is the squared length.

| Input | Type | Default |
| --- | --- | --- |
| `a` | `T` | `(1, 0)` |

How far apart a and b are.

<Media src={node_distance} alt="The Distance node as it looks in the Shader view, with its preview" size="small" plain />

### Normalize

`normalize` · Vector · `g.normalize(...)`

The vector made 1 long.

<Media src={node_normalize} alt="The Normalize node as it looks in the Shader view, with its preview" size="small" plain />

The same direction with a length of 1: for directions, light vectors and reflections.

### Polar

`polar` · Vector · `g.polar(...)`

The distance and angle of the pixel around center (aspect kept): angle in radians (−π..π) and from 0 to 1.

<Media src={node_polar} alt="The Polar node as it looks in the Shader view, with its preview" size="small" plain />

Distance and angle around a center: the key to radial things such as radar sweeps, pie charts, sun rays and spirals. `angle01` goes 0..1 around the circle.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (context) |
| `center` | `vec2` | `(0.5, 0.5)` |

| Output | Type |
| --- | --- |
| `radius` | `float` |
| `angle` | `float` |
| `angle01` · angle 0..1 | `float` |
| `polar` | `vec2` |

```python title="Example"
p = g.polar()

```

## UV

UV nodes change **where** the next nodes look, not the color: feed their `uv` output into the `uv` (or `p`) input of a pattern, a noise or a shape to move, repeat, rotate or distort it.

### Tiling and offset

`tiling_offset` · UV · `g.tiling_offset(...)`

uv × tiling + offset: repeats and moves what uses it.

<Media src={node_tiling_offset} alt="The Tiling and offset node as it looks in the Shader view, with its preview" size="small" plain />

Repeats and moves what comes next: `tiling` (2, 2) shows it twice in each direction, `offset` slides it.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (context) |
| `tiling` | `vec2` | `(2, 2)` |
| `offset` | `vec2` | `(0, 0)` |

| Output | Type |
| --- | --- |
| `uv` | `vec2` |

```python title="Example"
uv = g.tiling_offset(tiling=[4.0, 4.0])
g.output(g.rgba(g.fract(uv["uv"]).x, 1.0))
```

`scroll` · UV · `g.scroll(...)`

<Media src={node_scroll} alt="The Scroll node as it looks in the Shader view, with its preview" size="small" plain />

Moves the coordinates over time: wire it before a noise or a pattern to make it drift like clouds or a conveyor belt.

| Input | Type | Default |

### Barrel

`barrel` · UV · `g.barrel(...)`

Bends uv like a curved CRT screen; inside is 0 where the bent uv leaves the screen.

<Media src={node_barrel} alt="The Barrel node as it looks in the Shader view, with its preview" size="small" plain />

Bends the coordinates like the curved glass of an old CRT. Multiply the color by `inside` to black out the corners that fall off the screen.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (context) |
| `amount` | `float` | `0.25` |

| Output | Type |
| --- | --- |
| `uv` | `vec2` |
| `inside` | `float` |

```python title="Example"
b = g.barrel(amount=0.3)
c = g.checker(b["uv"], cells=[10.0, 8.0])

```

### Repeat
