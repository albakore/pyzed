## Input

Where the pixel being painted is, how big the area is, the time and the mouse. Almost every graph starts with one of these.

### UV

`uv` · Input · `g.uv(...)`

Where the pixel is, from (0, 0) at the top left to (1, 1) at the bottom right.

<Media src={node_uv} alt="The UV node as it looks in the Shader view, with its preview" size="small" plain />

The most used node. `x` goes from 0 at the left to 1 at the right and `y` from 0 at the top to 1 at the bottom, whatever the size of the widget. Wire `x` into a Gradient to get a horizontal ramp.

| Output | Type |
| --- | --- |
| `uv` | `vec2` |
| `x` | `float` |
| `y` | `float` |

```python title="Example"
uv = g.uv()
g.output(g.gradient(uv["x"]))
```

### Pixel

`pixel` · Input · `g.pixel(...)`

Where the pixel is, in pixels from the top left.

<Media src={node_pixel} alt="The Pixel node as it looks in the Shader view, with its preview" size="small" plain />

The same as UV but in pixels: use it for things that must keep their size in pixels when the widget grows, such as scanlines every 3 pixels.

| Output | Type |
| --- | --- |
| `px` · pixel | `vec2` |
| `x` | `float` |
| `y` | `float` |

```python title="Example"
px = g.pixel()
lines = g.fract(px["y"] / 4.0)
g.output(g.rgba(g.step(0.5, lines), 1.0))
```

### Size

`size` · Input · `g.size(...)`

The size of the shaded area in pixels, and its aspect ratio (width / height).

<Media src={node_size} alt="The Size node as it looks in the Shader view, with its preview" size="small" plain />

The width and height of the area in pixels. `aspect` (width ÷ height) keeps circles round on wide widgets; Centered UV already uses it for you.

| Output | Type |
| --- | --- |
| `size` | `vec2` |
| `width` | `float` |
| `height` | `float` |
| `aspect` | `float` |

```python title="Example"
s = g.size()
g.output(g.rgba(g.fract(s["aspect"]), 1.0))
```

### Time

`time` · Input · `g.time(...)`

Seconds since the app started (times scale), and their sine and cosine.

<Media src={node_time} alt="The Time node as it looks in the Shader view, with its preview" size="small" plain />

Seconds since the app started: anything wired to it moves. `sin` and `cos` swing smoothly between −1 and 1, perfect for pulses. `scale` speeds it up or slows it down.

| Input | Type | Default |
| --- | --- | --- |
| `scale` | `float` | `1` |

| Output | Type |
| --- | --- |
| `time` | `float` |
| `sin` | `float` |
| `cos` | `float` |

```python title="Example"
t = g.time(scale=2.0)
pulse = t["sin"] * 0.5 + 0.5
g.output(g.rgba(g.hsv_to_rgb(0.6, 0.8, pulse), 1.0))
```

### Mouse

`mouse` · Input · `g.mouse(...)`

Where the pointer is from 0 to 1 (the center while it is outside), and whether it is over the shader.

<Media src={node_mouse} alt="The Mouse node as it looks in the Shader view, with its preview" size="small" plain />

Where the pointer is, in UV (0 to 1). While it is outside the shader, `position` is the center and `inside` is false. Great for spotlights and hover effects.

| Output | Type |
| --- | --- |
| `position` | `vec2` |
| `inside` | `bool` |

```python title="Example"
m = g.mouse()
light = g.radial_gradient(center=m["position"], radius=0.3)
g.output(g.rgba(light, 1.0))
```

### Centered UV

`centered_uv` · Input · `g.centered_uv(...)`

UV with (0, 0) in the middle and circles kept round: the place to draw shapes. Aspect UV goes from 0 to the aspect ratio across, so noise and cells stay square.

<Media src={node_centered_uv} alt="The Centered UV node as it looks in the Shader view, with its preview" size="small" plain />

The coordinates to draw shapes with: (0, 0) is the middle and one unit is the height, so a circle stays round on any widget. `aspect_uv` keeps noise and cells square.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (context) |

| Output | Type |
| --- | --- |
| `centered` | `vec2` |
| `aspect_uv` · aspect uv | `vec2` |

```python title="Example"
c = g.centered_uv()
d = g.length(c["centered"])
g.output(g.rgba(g.smoothstep(0.4, 0.0, d), 1.0))
```

## Parameters

A **Parameter** node reads one of the shader's variables: the values your Python code (or a slider in the Preview tab) changes.

### Parameter

`parameter` · Parameters · `g.parameter(...)`

Reads a variable of the shader (see the Variables list): a mutable one changes without recompiling, a constant is built into the code.

<Media src={node_parameter} alt="The Parameter node as it looks in the Shader view, with its preview" size="small" plain />

Your shader's knobs. `g.uniform(...)` adds a mutable variable and a Parameter node at once; in the designer, drag a variable from the Outline onto the graph. A `color` variable gives `color`, `rgb` and `alpha` outputs.

| Output | Type |
| --- | --- |
| `value` | `float` |

| Setting | Values | Default |
| --- | --- | --- |
| `name` | `variable` | — |

The output takes the variable's type; a `color` variable gives `color`, `rgb` and `alpha`.

```python title="Example"
tint = g.uniform("tint", "color", "#22d3ee")
glow = g.radial_gradient(radius=0.6)
g.output(g.rgba(tint["rgb"] * glow, 1.0))
```

## Constants

Fixed values written into the shader. When a value never changes, a constant is the simplest choice; when you want to change it from code, use a variable instead.

### Float

`float` · Constants · `g.float(...)`

A fixed number.

<Media src={node_float} alt="The Float node as it looks in the Shader view, with its preview" size="small" plain />

One fixed number. Most inputs already take a typed value directly, so you only need this node to feed the same number into several places.

| Output | Type |
| --- | --- |
| `value` | `float` |

| Setting | Values | Default |
| --- | --- | --- |
| `value` | `float` | `0.5` |

```python title="Example"
half = g.float(0.5)
g.output(g.rgba(g.compose(half, half, 1.0), 1.0))
```

`int` · Constants · `g.int(...)`

### Math constants

`math_constants` · Constants · `g.math_constants(...)`

π, τ (2π), e and the golden ratio.

<Media src={node_math_constants} alt="The Math constants node as it looks in the Shader view, with its preview" size="small" plain />

π, τ (2π), e and φ, so you don't have to type 3.14159. Multiply a 0..1 value by τ to get a full turn in radians.

| Output | Type |
| --- | --- |
| `pi` · π | `float` |
| `tau` · τ | `float` |
| `e` | `float` |
| `phi` · φ | `float` |

```python title="Example"
k = g.math_constants()
wave = g.sin(g.uv()["x"] * k["tau"] * 3.0) * 0.5 + 0.5
g.output(g.rgba(wave, 1.0))
```
