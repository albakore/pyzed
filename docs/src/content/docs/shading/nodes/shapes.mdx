## Shapes

Shapes are **signed distances** (SDF): each pixel gets its distance to the edge of the shape, negative inside and positive outside. A distance is not a picture yet: **Fill**, **Stroke** and **Glow** turn it into a mask from 0 to 1. Distances can be combined (union, subtract, intersect) before drawing, even with a smooth seam.

### Circle

`circle` · Shapes · `g.circle(...)`

The signed distance to a circle (negative inside). Use Fill or Stroke to draw it.

{/* media: shading/nodes/circle */}

A circle around `center` with a `radius` (in units of the height). Draw it with Fill, Stroke or Glow.

| Input | Type | Default |
| --- | --- | --- |
| `p` | `vec2` | *Centered* (context) |
| `center` | `vec2` | `(0, 0)` |
| `radius` | `float` | `0.3` |

| Output | Type |
| --- | --- |
| `distance` | `float` |

```python title="Example"
d = g.circle(radius=0.3)
g.output(g.rgba(g.fill(d), 1.0))
```

### Combine shapes

`sdf_op` · Shapes · `g.sdf_op(...)`

Joins two shapes (union), cuts b out of a (subtract) or keeps where they overlap (intersect); smooth melts the seam.

{/* media: shading/nodes/sdf_op */}

Combines two shapes before drawing them: **Union** joins them, **Subtract shape** cuts `b` out of `a`, **Intersect** keeps the overlap. `smooth` above 0 melts the seam, like two drops of water merging.

| Input | Type | Default |
| --- | --- | --- |
| `a` | `float` | `1` |
| `b` | `float` | `1` |
| `smooth` | `float` | `0` |

| Output | Type |
| --- | --- |
| `distance` | `float` |

| Setting | Values | Default |
| --- | --- | --- |
| `op` | `union`, `subtract`, `intersect` | `union` |

**Sidebar entries**

| Entry | What it does | In Python |
| --- | --- | --- |
| Union | Joins two shapes; smooth melts them together. | `g.union(...)` |
| Subtract shape | Cuts shape b out of shape a. | `g.subtract_shape(...)` |
| Intersect | Keeps where two shapes overlap. | `g.intersect(...)` |

```python title="Example"
a = g.circle(center=[-0.15, 0.0], radius=0.25)
b = g.circle(center=[0.15, 0.0], radius=0.25)
d = g.union(a, b, smooth=0.1)
g.output(g.rgba(g.fill(d), 1.0))
```

### Glow

`glow` · Shapes · `g.glow(...)`

A soft light around a shape that fades over radius.

{/* media: shading/nodes/glow */}

A soft light around a shape that fades over `radius`: neon signs and halos. Add it to a Fill for a solid shape with a glow.

| Input | Type | Default |
| --- | --- | --- |
| `distance` | `float` | `0` |
| `radius` | `float` | `0.08` |
| `intensity` | `float` | `1` |

| Output | Type |
| --- | --- |
| `value` | `float` |

```python title="Example"
d = g.ring(radius=0.3, thickness=0.01)
light = g.glow(d, radius=0.1)
g.output(g.rgba(g.compose(0.1, 0.8, 1.0) * light, 1.0))
```
