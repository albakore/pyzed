## Noise

Noise gives values between 0 and 1 that look random but change smoothly: the base of clouds, fire, water, marble and terrain.

### Noise

`noise` · Noise · `g.noise(...)`

Smooth random values from 0 to 1 (value, Perlin or simplex noise).

{/* media: shading/nodes/noise */}

Smooth randomness from 0 to 1. **Perlin** is the classic, **simplex** looks more natural, **value** is blockier and cheaper. `scale` is how many bumps fit across.

| Input | Type | Default |
| --- | --- | --- |
| `p` | `vec2` | *Aspect UV* (context) |
| `scale` | `float` | `8` |

| Output | Type |
| --- | --- |
| `value` | `float` |

| Setting | Values | Default |
| --- | --- | --- |
| `kind` | `value`, `perlin`, `simplex` | `perlin` |

**Sidebar entries**

| Entry | What it does | In Python |
| --- | --- | --- |
| Noise | Smooth random values from 0 to 1 (value, Perlin or simplex noise). | `g.noise(...)` |
| Value noise | Blocky smooth noise from 0 to 1. | `g.value_noise(...)` |
| Simplex noise | Simplex noise from 0 to 1. | `g.simplex_noise(...)` |

```python title="Example"
n = g.noise(scale=5.0, kind="simplex")
g.output(g.rgba(n, 1.0))
```

### Fractal noise

### Voronoi

`voronoi` · Noise · `g.voronoi(...)`

Cells around random points: the distance to the nearest point and the second nearest, to the nearest edge, and a random number per cell. Phase moves the points.

{/* media: shading/nodes/voronoi */}

Cells around random points, like cracked mud, crystals or giraffe skin. `edge` is small near the borders, `cell` is a random number per cell (great for a color each). `phase` moves the points.

| Input | Type | Default |
| --- | --- | --- |
| `p` | `vec2` | *Aspect UV* (context) |
| `scale` | `float` | `6` |
| `jitter` | `float` | `1` |
| `phase` | `float` | *Time* (context) |

| Output | Type |
| --- | --- |
| `distance` | `float` |
| `second` | `float` |
| `edge` | `float` |
| `cell` | `float` |

```python title="Example"
v = g.voronoi(scale=6.0)
color = g.palette(v["cell"])
g.output(g.rgba(color * g.smoothstep(0.0, 0.05, v["edge"]), 1.0))
```

### Random

`random` · Noise · `g.random(...)`

A random number from 0 to 1 for a seed (the same seed, the same number).

{/* media: shading/nodes/random */}

A random number for a seed: the same seed always gives the same number. Feed it a cell number to give each cell its own value.

| Input | Type | Default |
| --- | --- | --- |
| `seed` | `float` | `1` |

| Output | Type |
| --- | --- |
| `value` | `float` |

```python title="Example"
r = g.repeat(cell=[0.2, 0.2])
v = g.random(r["cell"].x * 7.0 + r["cell"].y)
g.output(g.rgba(v, 1.0))
```

## Patterns

Regular patterns, mostly 0 or 1 (black or white). Multiply a color by them, or use them as the `t` of a Mix or a Gradient.

### Checker

`checker` · Patterns · `g.checker(...)`

A checkerboard of 0 and 1.

{/* media: shading/nodes/checker */}

A checkerboard: 0 and 1 in alternating squares.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *Aspect UV* (context) |
| `cells` | `vec2` | `(8, 8)` |

| Output | Type |
| --- | --- |
| `value` | `float` |

```python title="Example"
c = g.checker(cells=[8.0, 8.0])
g.output(g.rgba(g.mix(0.2, 0.9, c), 1.0))
```

### Grid

`grid` · Patterns · `g.grid(...)`

Grid lines: 1 on the lines, 0 between them (thickness from 0 to 1 of a cell).

{/* media: shading/nodes/grid */}

Thin grid lines: graph paper, blueprints and synthwave floors.

| Input | Type | Default |
| --- | --- | --- |
| `uv` | `vec2` | *Aspect UV* (context) |
| `cells` | `vec2` | `(8, 8)` |
| `thickness` | `float` | `0.06` |

| Output | Type |
| --- | --- |
| `value` | `float` |

### Wave

`wave` · Patterns · `g.wave(...)`

A repeating wave from 0 to 1 in four shapes: **sine** (smooth), **triangle**, **square** (on/off, blinking) and **sawtooth** (ramp). With the default `x` (time) it animates; wire a UV coordinate to get bands.

| Input | Type | Default |

| Output | Type |
| --- | --- |

| Setting | Values | Default |
| --- | --- | --- |
| `shape` | `sine`, `triangle`, `square`, `sawtooth` | `sine` |

**Sidebar entries**

| Entry | What it does | In Python |
| --- | --- | --- |
| Wave | A repeating wave from 0 to 1 (sine, triangle, square or sawtooth): frequency waves per unit of x. | `g.wave(...)` |
