## Color

Colors are `vec3` (r, g, b) or `vec4` (r, g, b, a) with values from 0 to 1, not from 0 to 255: `(1, 0.5, 0)` is orange.

### HSV to RGB

`hsv_to_rgb` · Color · `g.hsv_to_rgb(...)`

A color from hue (0 to 1 around the wheel), saturation and value.

{/* media: shading/nodes/hsv_to_rgb */}

A color from hue (0..1 around the color wheel: red, yellow, green, cyan, blue, magenta, red), saturation and value. Wire Time into the hue for a rainbow that cycles.

| Input | Type | Default |
| --- | --- | --- |
| `h` · hue | `float` | `0` |
| `s` · saturation | `float` | `1` |
| `v` · value | `float` | `1` |

| Output | Type |
| --- | --- |
| `rgb` | `vec3` |

```python title="Example"
uv = g.uv()
g.output(g.rgba(g.hsv_to_rgb(uv["x"], 0.8, 1.0), 1.0))
```

### Palette

`palette` · Color · `g.palette(...)`

A smooth rainbow-like color for t, from Inigo Quilez's cosine palettes: a + b × cos(2π(c × t + d)).

{/* media: shading/nodes/palette */}

Turns a number from 0 to 1 into a smooth, rainbow-like color with a cosine formula. Change `d` to shift the colors; it is the quickest way to color noise.

| Input | Type | Default |
| --- | --- | --- |

| `a` | `vec3` | `(0.5, 0.5, 0.5)` |
| `b` | `vec3` | `(0.5, 0.5, 0.5)` |
| `c` | `vec3` | `(1, 1, 1)` |
| `d` | `vec3` | `(0, 0.33, 0.67)` |

| Output | Type |
| --- | --- |
| `rgb` | `vec3` |

## Texture

Images in a shader: add a `texture` variable (an image file) and read its colors.

### Sample texture

`sample_texture` · Texture · `g.sample_texture(...)`

The color of a texture (an image variable) at uv.

{/* media: shading/nodes/sample_texture */}

Reads the color of an image at a UV. Add a `texture` variable whose value is an image path (relative to the `.pzshad`), wire it into `texture`, and warp the UV first for ripples or pixelation.

| Input | Type | Default |
| --- | --- | --- |
| `texture` | `texture` | — |
| `uv` | `vec2` | *UV* (context) |

| Output | Type |
| --- | --- |
| `color` | `vec4` |
| `rgb` | `vec3` |
| `alpha` | `float` |

```python title="Example"
photo = g.uniform("photo", "texture", "photo.png")
uv = g.pixelate(cells=[40.0, 30.0])
g.output(g.sample_texture(photo, uv["uv"]))
```
