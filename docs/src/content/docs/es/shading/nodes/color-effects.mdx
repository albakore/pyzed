## Color

Los colores son `vec3` (r, g, b) o `vec4` (r, g, b, a) con valores de 0 a 1, no de 0 a 255: `(1, 0.5, 0)` es naranja.

### HSV a RGB

*HSV to RGB* · `hsv_to_rgb` · Color · `g.hsv_to_rgb(...)`

Un color a partir de tono (de 0 a 1 alrededor de la rueda), saturación y valor.

{/* media: shading/nodes/hsv_to_rgb */}

Un color a partir del tono (0..1 alrededor de la rueda: rojo, amarillo, verde, cian, azul, magenta, rojo), la saturación y el valor. Conecta el Tiempo al tono para un arcoíris que gira.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `h` · tono | `float` | `0` |
| `s` · saturación | `float` | `1` |
| `v` · valor | `float` | `1` |

| Salida | Tipo |
| --- | --- |
| `rgb` | `vec3` |

```python title="Ejemplo"
uv = g.uv()
g.output(g.rgba(g.hsv_to_rgb(uv["x"], 0.8, 1.0), 1.0))
```

| Entrada | Tipo | Por defecto |

### Paleta

*Palette* · `palette` · Color · `g.palette(...)`

Un color suave tipo arcoíris para t, con las paletas de coseno de Inigo Quilez: a + b × cos(2π(c × t + d)).

{/* media: shading/nodes/palette */}

Convierte un número de 0 a 1 en un color suave tipo arcoíris con una fórmula de cosenos. Cambia `d` para desplazar los colores; es la forma más rápida de colorear un ruido.

## Textura

### Muestrear textura

*Sample texture* · `sample_texture` · Textura · `g.sample_texture(...)`

El color de una textura (una variable de imagen) en uv.

{/* media: shading/nodes/sample_texture */}

Lee el color de una imagen en un UV. Añade una variable `texture` cuyo valor sea la ruta de una imagen (relativa al `.pzshad`), conéctala a `texture` y deforma antes el UV para ondas o pixelado.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `texture` · textura | `texture` | — |
| `uv` | `vec2` | *UV* (contexto) |

| Salida | Tipo |
| --- | --- |
| `color` | `vec4` |
| `rgb` | `vec3` |
| `alpha` | `float` |

