## Vector

Los vectores son grupos de 2, 3 o 4 números: una posición (x, y), un color (r, g, b) o un color con alfa (r, g, b, a). Estos nodos los crean, separan y miden.

### Componer

*Compose* · `compose` · Vector · `g.compose(...)`

Construye un vector a partir de sus componentes.

{/* media: shading/nodes/compose */}

Construye un vector a partir de números sueltos: tres valores en un color RGB, dos en un punto. El ajuste `type` elige vec2, vec3 o vec4 (la barra lateral también tiene *Componer vec2* y *Componer vec4*).

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `x` | `float` | `0` |
| `y` | `float` | `0` |
| `z` | `float` | `0` |

| Salida | Tipo |
| --- | --- |
| `vector` | `vec3` |

| Ajuste | Valores | Por defecto |
| --- | --- | --- |
| `type` | `vec2`, `vec3`, `vec4` | `vec3` |

Las entradas siguen el ajuste `type`: `x` e `y` para vec2, hasta `w` para vec4.

**Entradas de la barra lateral**

| Entrada | Qué hace | En Python |
| --- | --- | --- |
| Componer | Construye un vector a partir de sus componentes. | `g.compose(...)` |
| Componer vec2 | Construye un vec2 a partir de x e y. | `g.compose_vec2(...)` |
| Componer vec4 | Construye un vec4 a partir de x, y, z y w. | `g.compose_vec4(...)` |

```python title="Ejemplo"
uv = g.uv()
rgb = g.compose(uv["x"], uv["y"], 0.5)
g.output(g.rgba(rgb, 1.0))
```

### Descomponer

*Decompose* · `decompose` · Vector · `g.decompose(...)`

Los componentes de un vector (x, y, z y w; r, g, b y a para colores).

{/* media: shading/nodes/decompose */}

Separa un vector en sus componentes: `x`, `y`, `z`, `w` (el rojo, verde, azul y alfa de un color).

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `vector` | `T` | `(0, 0, 0, 1)` |

| Salida | Tipo |
| --- | --- |
| `x` | `float` |
| `y` | `float` |
| `z` | `float` |
| `w` | `float` |

```python title="Ejemplo"
c = g.color("#f97316")
parts = g.decompose(c)
g.output(g.rgba(parts["x"], 1.0))
```

### Reordenar

*Swizzle* · `swizzle` · Vector · `g.swizzle(...)`

Elige y reordena componentes: “yx”, “zzz”, “rgb”, “x”…

{/* media: shading/nodes/swizzle */}

Elige y reordena componentes con una máscara: `yx` intercambia x e y, `rgb` quita el alfa, `xxx` repite uno. En Python, `puerto.yx` o `puerto.rgb` lo añade por ti.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `vector` | `T` | `(0, 0, 0, 1)` |

| Salida | Tipo |
| --- | --- |
| `result` · resultado | `vec2` |

| Ajuste | Valores | Por defecto |
| --- | --- | --- |
| `mask` | `text` | `yx` |

```python title="Ejemplo"
uv = g.uv()["uv"]
g.output(g.rgba(g.compose(uv.y, uv.x, 0.0), 1.0))
```

### Producto escalar

*Dot* · `dot` · Vector · `g.dot(...)`

El producto escalar de a y b: cuánto apuntan en la misma dirección.

{/* media: shading/nodes/dot */}

El producto escalar: cuánto apuntan dos direcciones hacia el mismo lado (1 igual, 0 en ángulo recto, −1 opuestas). `p · p` es la longitud al cuadrado.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `a` | `T` | `(1, 0)` |
| `b` | `T` | `(1, 0)` |

| Salida | Tipo |
| --- | --- |
| `result` · resultado | `float` |

```python title="Ejemplo"
p = g.uv()["uv"] - 0.5
d = g.dot(p, p)
g.output(g.rgba(1.0 - d * 4.0, 1.0))
```

### Producto vectorial

| Entrada | Tipo | Por defecto |

| --- | --- |

### Distancia

*Distance* · `distance` · Vector · `g.distance(...)`

Lo lejos que están a y b.

{/* media: shading/nodes/distance */}

A qué distancia están dos puntos. Por defecto `a` es el UV del píxel, así que mide del píxel a `b`.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `a` | `T` | *UV* (contexto) |
| `b` | `T` | `(0.5, 0.5)` |

| Salida | Tipo |
| --- | --- |
| `distance` · distancia | `float` |

```python title="Ejemplo"
d = g.distance(b=[0.5, 0.5])
g.output(g.rgba(g.smoothstep(0.3, 0.0, d), 1.0))
```

### Normalizar

*Normalize* · `normalize` · Vector · `g.normalize(...)`

El vector con longitud 1.

{/* media: shading/nodes/normalize */}

La misma dirección con longitud 1: para direcciones, vectores de luz y reflejos.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |

| Salida | Tipo |

### Reflejar

*Reflect* · `reflect` · Vector · `g.reflect(...)`

| Entrada | Tipo | Por defecto |
| --- | --- | --- |


### Polar

`polar` · Vector · `g.polar(...)`

La distancia y el ángulo del píxel alrededor de center (respeta la proporción): ángulo en radianes (−π..π) y de 0 a 1.

{/* media: shading/nodes/polar */}

Distancia y ángulo alrededor de un centro: la clave de lo radial, como barridos de radar, gráficos de tarta, rayos de sol y espirales. `angle01` va de 0 a 1 alrededor del círculo.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (contexto) |
| `center` · centro | `vec2` | `(0.5, 0.5)` |

| Salida | Tipo |
| --- | --- |
| `radius` · radio | `float` |
| `angle` · ángulo | `float` |
| `angle01` · angle 0..1 | `float` |
| `polar` | `vec2` |

```python title="Ejemplo"
p = g.polar()
rays = g.step(0.5, g.fract(p["angle01"] * 12.0))
g.output(g.rgba(rays, 1.0))
```

## UV

Los nodos UV cambian **dónde** miran los nodos siguientes, no el color: conecta su salida `uv` a la entrada `uv` (o `p`) de un patrón, un ruido o una forma para moverlo, repetirlo, girarlo o deformarlo.

### Repetición y desplazamiento

*Tiling and offset* · `tiling_offset` · UV · `g.tiling_offset(...)`

uv × tiling + offset: repite y mueve lo que lo use.

{/* media: shading/nodes/tiling_offset */}

Repite y mueve lo que viene después: `tiling` (2, 2) lo muestra dos veces en cada dirección, `offset` lo desplaza.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (contexto) |
| `tiling` · repetición | `vec2` | `(2, 2)` |
| `offset` · desplazamiento | `vec2` | `(0, 0)` |

| Salida | Tipo |
| --- | --- |
| `uv` | `vec2` |

```python title="Ejemplo"
uv = g.tiling_offset(tiling=[4.0, 4.0])
g.output(g.rgba(g.fract(uv["uv"]).x, 1.0))
```

### Desplazar

*Scroll* · `scroll` · UV · `g.scroll(...)`

Mueve uv con el tiempo: uv + speed × time.

{/* media: shading/nodes/scroll */}

Mueve las coordenadas con el tiempo: ponlo antes de un ruido o un patrón para que se desplace como nubes o una cinta transportadora.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (contexto) |
| `speed` · velocidad | `vec2` | `(0.1, 0)` |
| `time` · tiempo | `float` | *Tiempo* (contexto) |

| Salida | Tipo |
| --- | --- |
| `uv` | `vec2` |

```python title="Ejemplo"
uv = g.scroll(speed=[0.1, 0.0])
n = g.fbm(uv["uv"], scale=3.0)
g.output(g.rgba(n, 1.0))
```

### Rotar

*Rotate* · `rotate` · UV · `g.rotate(...)`

Gira uv alrededor de center un ángulo angle (radianes).

{/* media: shading/nodes/rotate */}

Gira las coordenadas alrededor de `center` `angle` radianes (conecta el Tiempo para que gire solo).

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (contexto) |
| `center` · centro | `vec2` | `(0.5, 0.5)` |

| Salida | Tipo |
| --- | --- |
| `uv` | `vec2` |

### Barril

*Barrel* · `barrel` · UV · `g.barrel(...)`

Curva uv como una pantalla CRT; inside es 0 donde el uv curvado sale de la pantalla.

{/* media: shading/nodes/barrel */}

Curva las coordenadas como el cristal de un CRT antiguo. Multiplica el color por `inside` para oscurecer las esquinas que se salen de la pantalla.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `uv` | `vec2` | *UV* (contexto) |
| `amount` · cantidad | `float` | `0.25` |

| Salida | Tipo |
| --- | --- |
| `uv` | `vec2` |
| `inside` · dentro | `float` |

```python title="Ejemplo"

```

### Repetir

*Repeat* · `repeat` · UV · `g.repeat(...)`

Repite el espacio en celdas alrededor de (0, 0): dibuja una forma y obtén una cuadrícula de ellas. Cell indica en qué celda está el píxel.

{/* media: shading/nodes/repeat */}

Repite el espacio en celdas: dibuja una forma y obtén una cuadrícula entera. `cell` dice en qué celda está el píxel, para dar a cada copia su color.

| Entrada | Tipo | Por defecto |
| --- | --- | --- |
| `p` | `vec2` | *Centrado* (contexto) |
| `cell` · celda | `vec2` | `(0.25, 0.25)` |

| Salida | Tipo |
| --- | --- |
| `p` | `vec2` |
| `cell` · celda | `vec2` |

```python title="Ejemplo"

```
