Una fórmula empieza por `=` y calcula un valor a partir de números, texto y otras celdas. Se
escribe igual que en Excel y Google Sheets, así que las fórmulas copiadas de cualquiera de los
dos funcionan aquí, y los archivos que guardas las conservan.

```python
book["B5"] = "=SUM(B2:B4)"
book["C2"] = '=IF(B2>100, "Alto", "Bajo")'
book["D2"] = "=VLOOKUP(A2, Precios!A:B, 2, FALSE)"
book["B5"]           # el resultado: 1410
book.formula("B5")   # la fórmula: "=SUM(B2:B4)"
book.text("B5")      # lo que muestra la celda: "$1,410.00"
```

Las funciones se escriben con su nombre en inglés, como en Excel en inglés y en Google Sheets:
`SUM` (SUMA), `IF` (SI), `VLOOKUP` (BUSCARV), `COUNTIF` (CONTAR.SI). Los argumentos se separan
con comas y los decimales llevan punto.

Cuando una celda cambia, solo se recalculan las fórmulas que dependen de ella, en el orden
correcto. Una fórmula que acaba dependiendo de sí misma muestra `#CYCLE!` en lugar de colgar
la app.

<Aside type="note" title="En pocas palabras">
Una fórmula es un cálculo pequeño que vive en una celda. Escribe `=` y luego lo que hay que
calcular: `=2+2`, `=B2*1.21` (el valor de B2 más un 21 %), `=SUM(B2:B9)` (suma todo de B2 a
B9). Si B2 cambia, el resultado cambia también.
</Aside>

## Referencias

| Referencia | Significa |
| --- | --- |
| `B3` | Una celda. |
| `B2:D9` | Un rango: de B2 a D9. |
| `A:A`, `A:C` | Columnas enteras. |
| `2:2`, `2:5` | Filas enteras. |
| `$B$3`, `B$3`, `$B3` | Referencias absolutas: la parte con `$` no se mueve al copiar o rellenar la fórmula. |
| `Ventas!B3`, `'Datos brutos'!A1:A9` | Una celda o rango de otra hoja (entre comillas si el nombre tiene espacios). |

Al copiar, rellenar o pegar una fórmula, sus referencias relativas se mueven con ella: `=A1*2`
copiada una fila más abajo pasa a ser `=A2*2`. Al insertar o eliminar filas y columnas, las
referencias se actualizan para seguir apuntando a las mismas celdas (una celda eliminada pasa a
ser `#REF!`). Al renombrar una hoja, las fórmulas que la mencionan se reescriben.

Mientras escribes, pulsa <kbd>F4</kbd> para cambiar una referencia entre `A1`, `$A$1`, `A$1`
y `$A1`.

## Operadores

| Operador | Hace | Ejemplo |
| --- | --- | --- |
| `+` `-` `*` `/` | Aritmética | `=B2*C2-D2` |
| `^` | Potencia | `=2^10` |
| `%` | Porcentaje | `=B2*15%` |
| `&` | Une texto | `=A2&" "&B2` |
| `=` `<>` `<` `>` `<=` `>=` | Comparan (TRUE o FALSE) | `=B2>=100` |
| `-` delante de un valor | Negativo | `=-B2` |

El texto va entre comillas dobles (`"Norte"`) y `TRUE` / `FALSE` son valores lógicos. Los
números escritos como texto (`"12"`) se convierten cuando un operador necesita un número.

## Criterios

`COUNTIF`, `SUMIF`, `AVERAGEIF`, sus versiones `...IFS` y `MAXIFS` / `MINIFS` reciben un
criterio como texto, igual que en Excel:

| Criterio | Coincide con |
| --- | --- |
| `"Norte"` o `"=Norte"` | Igual a Norte (sin distinguir mayúsculas). |
| `">100"`, `"<=0"`, `"<>Hecho"` | Comparado con un número o un texto. |
| `"a*"`, `"*norte*"`, `"??-??"` | Comodines: `*` cualquier texto, `?` un carácter. |
| `">"&B1` | Construido a partir de una celda. |

## Matrices dinámicas

Las funciones que devuelven varios valores (`SEQUENCE`, `FILTER`, `SORT`, `UNIQUE`,
`TRANSPOSE`, `SPLIT`) se **desbordan** a las celdas de debajo y de la derecha, como en el Excel
actual y en Google Sheets. Solo la primera celda guarda la fórmula; las demás muestran sus
valores. Si una celda del camino ya tiene algo, la fórmula muestra `#SPILL!` hasta que se
vacía.

```python
book["A1"] = "=SEQUENCE(5)"                        # del 1 al 5 en A1:A5
book["C1"] = '=FILTER(A2:B20, B2:B20>100)'          # las filas con más de 100
book["F1"] = "=UNIQUE(Ventas!B2:B9)"                # cada región una vez
```

## Errores

| Error | Por qué |
| --- | --- |
| `#DIV/0!` | Una división entre cero. |
| `#VALUE!` | Un valor del tipo equivocado (texto donde hacía falta un número). |
| `#REF!` | Una referencia a celdas que se eliminaron. |
| `#NAME?` | Una función o un nombre desconocido. |
| `#N/A` | Una búsqueda que no encontró nada. |
| `#NUM!` | Un número fuera de rango (la raíz cuadrada de -1). |
| `#CYCLE!` | La fórmula depende de sí misma. |
| `#SPILL!` | Una fórmula de matriz no puede desbordarse porque hay celdas en medio. |
| `#ERROR!` | La fórmula no se puede leer (le falta un paréntesis, por ejemplo). |

Los errores se propagan: una fórmula que usa una celda con un error muestra el mismo error.
`IFERROR` e `IFNA` los capturan: `=IFERROR(B2/C2, 0)`.

## Fechas y horas

Las fechas son números de días, como en toda hoja de cálculo, así que se pueden restar
(`=B2-A2` es el número de días entre dos fechas) y se les pueden sumar días (`=A2+30`).
`TODAY()` y `NOW()` cambian cada vez que se recalcula el libro; llama a `book.recalculate()`
para actualizarlas.

## Tus datos en las fórmulas

Las fórmulas solo leen celdas. Para usar datos de tu app, escríbelos en una hoja (puede ser una
hoja auxiliar oculta) con `book.write(filas, at="A1")` y las fórmulas podrán referenciarlos.
`pz.Workbook.functions()` devuelve la lista de abajo como tuplas
`(nombre, argumentos, descripción)`, por ejemplo para montar tu propio selector de funciones.
