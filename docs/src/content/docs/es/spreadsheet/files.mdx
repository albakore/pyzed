## Abrir

```python
book = pz.Workbook.open("ventas.xlsx")    # .xlsx, .xlsm, .xls, .ods
book = pz.Workbook.open("datos.csv")      # .csv, .tsv, .txt
book = pz.Workbook.from_bytes(datos)      # un archivo de Excel u OpenDocument ya en memoria
book = pz.Workbook.from_csv(texto)        # texto CSV; el separador se detecta (, ; tab |)
book = pz.Workbook.from_csv(texto, delimiter=";")
```

De un archivo de Excel u OpenDocument el libro lee todas las hojas con sus valores, fórmulas,
formatos de número, fuentes, colores, bordes, alineación y celdas combinadas. De los `.xlsx`
lee además el ancho de las columnas, el alto de las filas, las filas y columnas ocultas, los
paneles inmovilizados, el rango del filtro, las líneas de la cuadrícula, el color de las
pestañas y la validación de datos. Al abrir el archivo, el motor de Pyzed vuelve a calcular
las fórmulas.

Los campos de un CSV o TSV se leen como si se escribieran: los números, porcentajes, monedas
y fechas se convierten en valores, y un campo entre comillas puede tener separadores y saltos
de línea. La hoja toma el nombre del archivo.

## Guardar

```python
book.save("ventas.xlsx")      # todas las hojas
book.save("ventas.csv")       # la hoja activa, tal como se ve (o .tsv)
datos = book.to_xlsx()        # los bytes de un .xlsx, para enviarlo o guardarlo
texto = book.to_csv()         # el CSV de la hoja activa (to_csv("Equipo") para otra)
```

Un `.xlsx` guarda:

- los valores y las fórmulas (con su último resultado, para que otros programas los muestren
  antes de recalcular),
- los formatos de número, las fuentes, negrita, cursiva, subrayado, tachado, colores, rellenos,
  bordes y alineación,
- las celdas combinadas, el ancho de las columnas, el alto de las filas y las filas y columnas
  ocultas,
- las filas y columnas inmovilizadas, el rango del filtro y las líneas ocultas,
- las notas y el color de las pestañas,
- la validación de datos (listas, números, fechas, longitudes y fórmulas; las casillas se
  escriben como listas `TRUE` / `FALSE`) y el formato condicional (también escalas de color y
  barras de datos).

Así un libro hecho en Pyzed se ve igual en Excel, Google Sheets, LibreOffice y Numbers.

<Aside type="caution">
Las notas y el formato condicional se guardan en los `.xlsx`, pero todavía no se leen de
ellos, y los `.xls` y `.ods` se leen sin su diseño (tamaños, paneles inmovilizados,
validación).
</Aside>

## Diálogos de abrir y guardar

`pz.Command.pick_files` y `pz.Command.save_file` muestran los diálogos de archivos del
sistema. Esta es la barra de título de
[`examples/spreadsheet.py`](https://github.com/albakore/pyzed/blob/main/examples/spreadsheet.py):

```python
class HojaDeCalculo(pz.App):
    def __init__(self):
        self.book = pz.Workbook()
        self.path = None

    def open(self):
        def opened(paths):
            if paths:
                self.book = pz.Workbook.open(paths[0])
                self.path = paths[0]

        return pz.Command.pick_files(opened, multiple=False,
                                     filters=[("Hojas de cálculo", ["xlsx", "xls", "ods", "csv", "tsv"])])

    def save(self):
        def chosen(paths):
            if paths:
                self.book.save(paths[0])
                self.path = paths[0]

        return pz.Command.save_file(chosen, file_name="libro.xlsx",
                                    filters=[("Excel", ["xlsx"]), ("CSV", ["csv"])])

    def view(self):
        bar = ui.toolbar(
            [ui.label(self.path or "Hoja sin título", weight="semibold")],
            [ui.button("Abrir…", self.open, icon="folder-open", size="sm"),
             ui.button("Guardar como…", self.save, icon="save", size="sm")],
        )
        return pz.column([bar, ui.Spreadsheet(book=self.book)], width="fill", height="fill")
```

## Sin ventana

El libro no necesita ventana, así que puede convertir datos en informes de Excel desde un
script o un servidor:

```python
import pyzed as pz

book = pz.Workbook.from_rows(pedidos)           # una lista de dicts
book["F1"] = "Total"
book.write([[f"=D{r}*E{r}"] for r in range(2, len(pedidos) + 2)], at="F2")
book.format("A1:F1", bold=True, fill="#e8f0fe")
book.format("F2:F999", number_format="#,##0.00 €")
book.freeze(rows=1)
book.autofit()
book.save("pedidos.xlsx")
```

O leer un archivo que alguien rellenó en Excel:

```python
book = pz.Workbook.open("encuesta.xlsx")
for fila in book.records():
    print(fila["Nombre"], fila["Nota"])
```
