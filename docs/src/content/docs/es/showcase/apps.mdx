Programas de todos los días, cada uno un único archivo de Python en
[`examples/`](https://github.com/albakore/pyzed/tree/main/examples) que funciona tal cual. Son cortos a propósito:
lee uno de arriba abajo y habrás visto el estado, una vista, eventos y una suscripción trabajando juntos. Varios son
versiones en Pyzed de las demos clásicas de [Iced](https://iced.rs), la biblioteca de interfaces de Rust con la que
dibuja Pyzed.

<Aside type="tip" title="Cómo leer estas apps">
Cada app es una clase con **estado** (atributos que se crean en `__init__`), un **`view()`** que construye la
pantalla a partir del estado y **métodos** que cambian el estado cuando pasa algo. Pyzed redibuja después de cada
cambio. ¿Es nueva para ti esta idea? Empieza por el tutorial de la
[Lista de tareas](/pyzed/es/tutorials/basic/todo-app/).
</Aside>

## Datos en vivo

Un panel de cotizaciones alimentado por `pz.listen`: una suscripción respaldada por un generador async. Corre
mientras `subscriptions()` la devuelva y envía cada valor que produce a `update`.

<Media src={tickerShot} alt="Cuatro símbolos con su precio, su variación y un pequeño gráfico" />

```python
async def feed():                       # una app real leería aquí un websocket
    prices = {s: random.uniform(50, 150) for s in SYMBOLS}
    while True:
        await asyncio.sleep(0.25)
        symbol = random.choice(SYMBOLS)
        prices[symbol] *= 1 + random.gauss(0, 0.01)
        yield symbol, prices[symbol]    # cada valor va a update()

class Ticker(pz.App):
    def subscriptions(self):
        return [pz.listen(feed)] if self.connected else []   # el interruptor pausa el flujo

    def update(self, message):
        symbol, price = message
        self.history[symbol] = (self.history[symbol] + [price])[-60:]
```

## Editor de proyectos

Un workspace de editor de código completo en unas 450 líneas: un panel de proyecto con los archivos de una
carpeta, pestañas, un editor con resaltado de sintaxis (editar, deshacer, guardar con <kbd>Ctrl</kbd>+<kbd>S</kbd>),
colores de estado de git, un panel de estructura, cambio de tema, una paleta de comandos
(<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) y un buscador de archivos (<kbd>Ctrl</kbd>+<kbd>P</kbd>). Su
aspecto recrea el del editor [Zed](https://zed.dev), cuya interfaz inspiró el tema por defecto de Pyzed. El panel de
terminal muestra una salida de ejemplo; no ejecuta una shell.
