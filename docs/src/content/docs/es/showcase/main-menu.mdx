## Cómo está hecho

### Shader interactivo

El grafo tiene un nodo **Mouse**: la posición del puntero sobre el widget, de 0 a 1. Unos pocos nodos de
operaciones mueven un poco el horizonte con él, así que la escena se inclina cuando mueves el puntero. En Python es
un widget detrás del contenido:

```python
pz.stack([
    pz.shader(SHADER, width="fill", height="fill",
              fallback=pz.Gradient(["#08021a", "#4a0d5e", "#d9468f"], angle=180)),
    content,
])
```

### Título brillante

`bloom` en un texto sin caja lo ilumina desde sus propios trazos.

```python
pz.text("NEON DRIFT", size=72, weight="black").style(bloom=("#f472b6", 1.0))
```

### Movimiento del menú

Los botones se elevan en hover, se encogen al pulsar y el seleccionado se desliza con una transición.

```python
button.animate("lift", on="hover").animate("shrink", on="press").transition(x=6 if selected else 0)
```

## Prueba esto

- Añade una opción al menú y dale su propia acción.
- Cambia el color y la intensidad del `bloom` del título.
- Abre `shaders/synthwave.pzshad` en Pyzed Design y cambia los colores del sol.
