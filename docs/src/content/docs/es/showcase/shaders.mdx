Pyzed lo dibuja todo con la GPU, así que una app de escritorio puede tener lo que tienen los videojuegos: fondos en
movimiento, luz que desborda de lo brillante, cristal esmerilado. Hay dos capas:

- **Shaders**: un pequeño programa que la tarjeta gráfica ejecuta para cada píxel de un widget, en cada fotograma.
  En Pyzed los haces como **grafos de nodos** en la vista de shader de [Pyzed Design](/pyzed/es/shading/), guardados
  como archivos `.pzshad`, o en Python con `pyzed.shading.Graph`. No hay que aprender un lenguaje de shaders.
- **Efectos**: `glass`, `bloom`, `glow`, `blur`, rotación y animaciones, que cualquier widget tiene con
  `widget.style(...)` y `widget.animate(...)`.

## Seis shaders a la vez

Seis grafos lado a lado, con un deslizador que cambia la variable `speed` de todos a la vez. Las variables
(uniforms) son solo valores, así que cambiarlas nunca recompila el shader.

<Media src={galleryShot} alt="Seis shaders: plasma, ondas, túnel, CRT, celdas de Voronoi y fuego" size="wide" />

<Run file="examples/showcase/shaders.py" lang="es" />

```python
from pyzed import shading

plasma = shading.load("shaders/plasma.pzshad")          # se compila una vez
pz.shader(plasma, uniforms={"speed": self.speed},       # variables por nombre, desde tu estado
          width=340, height=210,
          fallback=pz.Gradient(["#7c3aed", "#ec4899"]))  # se muestra donde no hay shaders
```

## Efectos en cualquier widget

Rotación, cristal esmerilado, bloom y desenfoque, aplicados con `style(...)` y animados. Los botones de abajo animan
el desenfoque y el tamaño; el tamaño, el relleno y el tamaño de letra recolocan el layout mientras se mueven.

<Media src={effectsShot} alt="Cuatro tarjetas sobre un degradado: girada, de cristal, con bloom y desenfocada" />

```python
card.style(rotate=-8)                       # girarla
card.style(glass=True)                      # un panel tintado que desenfoca lo que tiene detrás
card.style(bloom=("#fbbf24", 0.8))          # luz alrededor de sus partes brillantes
card.style(blur=4)                          # desenfocar el propio widget
spinner.animate("spin")                     # un preset que se repite
```

## Animaciones

Cada preset, que se reproduce al hacer clic o al pasar el puntero; cristal, resplandor, bloom y opacidad sobre un
degradado; y transiciones que animan un panel, una página y una contraseña incorrecta.

<Media src={animationsShot} alt="Una cuadrícula de presets de animación y cuatro efectos visuales" />

```python
button.animate("lift", on="hover").animate("shrink", on="press")   # con eventos
title.animate("fade_in_up")                                         # al aparecer
panel.transition(x=0 if self.open else -260, opacity=1 if self.open else 0)  # al cambiar un valor
pz.presence(page, key=self.page)                                    # sale y entra al cambiar la key
```

## Dónde se usan

- [HUD de videojuego](/pyzed/es/showcase/hud/): los grafos Nebula y Radar, paneles de cristal y bloom.
- [Menú principal](/pyzed/es/showcase/main-menu/): el grafo Synthwave y un título brillante.
- [Inventario RPG](/pyzed/es/showcase/inventory/): el grafo Embers, bloom según la rareza y estadísticas animadas.
- [Centro de control de cristal](/pyzed/es/showcase/glass-dashboard/): el grafo Blobs detrás de tarjetas de cristal
  esmerilado.

<Aside type="caution" title="Cuando no hay GPU">
En máquinas sin una tarjeta gráfica compatible (algunas máquinas virtuales y escritorios remotos) los shaders no
pueden correr, y Pyzed dibuja en su lugar el `fallback` del widget, un degradado o un color. Dale siempre uno a los
shaders que van detrás de tu contenido.
</Aside>
