Seis efectos clásicos, cada uno una función WGSL corta. Un slider cambia el uniform `speed` de todos a la vez: los uniforms son solo valores, así que cambiarlos nunca recompila el shader.

![Galería de shaders](../../../../assets/showcase/shaders.png)

```sh
python examples/showcase/shaders.py
```

## Cómo está hecho

### Una función por efecto

`shade` recibe el `uv` del píxel, su posición en píxeles, el tamaño del widget y `time`, y devuelve un color.

```rust
fn shade(uv: vec2<f32>, px: vec2<f32>, size: vec2<f32>, time: f32) -> vec4<f32> {
    return vec4<f32>(uv.x, uv.y, 0.5 + 0.5 * sin(time), 1.0);
}
```

### Uniforms desde Python

Cada uniform se convierte en una función que llamas en WGSL.

```python
pz.shader(code, uniforms={"speed": self.speed, "tint": "#a78bfa"})
```
