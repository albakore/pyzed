Todo lo que hay en estas páginas es un programa real de la carpeta
[`examples`](https://github.com/albakore/pyzed/tree/main/examples) del repositorio, dibujado por Pyzed con la GPU.
Haz clic en una tarjeta para ver cómo está hecho, leer el código completo y ejecutarlo. ¿Quieres construir uno tú,
paso a paso? Los [Tutoriales](/pyzed/es/tutorials/) te llevan ahí.

<Aside type="tip" title="Ejecuta cualquiera">
Descarga o clona el [repositorio](https://github.com/albakore/pyzed), abre una terminal en su carpeta y ejecuta el
archivo. Cada página tiene un bloque como este, con los comandos para uv, pip y Python a secas en Windows, macOS y
Linux:

<Run file="examples/todos.py" lang="es" />
</Aside>
