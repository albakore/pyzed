Un centro de control domótico con el estilo de cristal esmerilado de los sistemas operativos modernos. Las manchas de color detrás de las tarjetas son un grafo de shader (`shaders/blobs.pzshad`), así que el desenfoque que ves a través de cada tarjeta se mueve con ellas.

![Centro de control de cristal](../../../../assets/showcase/glass-dashboard.png)

<Run file="examples/showcase/glass_dashboard.py" lang="es" />

## Cómo está hecho

### Desenfoque real del fondo

`glass` desenfoca lo que hay detrás de la tarjeta; no es un degradado falso.

```python
GLASS = {"tint": "#ffffff", "strength": 0.10, "blur": 28}
card.style(glass=GLASS, radius=22, padding=20)
```

### Detalles vivos

La portada gira mientras suena la música; las bombillas encendidas brillan con bloom.

```python
cover.animate("spin", duration=12000)
```

### Controles reales

Los sliders y switches cambian el estado como en cualquier app de Pyzed.

```python
pz.slider(0, 100, self.volume, on_change=self.set_volume)
```

## Prueba esto

- Cambia `tint` y `strength` en `GLASS` y mira cuánto del fondo se ve a través.
- Enciende todas las luces y mira el bloom.
- Cambia las manchas por otro grafo de [Shaders y efectos](/pyzed/es/showcase/shaders/#todos-los-grafos), como
  `nebula.pzshad`.

<Aside type="tip">
El cristal luce mejor sobre algo que se mueve y tiene color. Sobre un fondo plano es solo un panel tintado.
</Aside>
