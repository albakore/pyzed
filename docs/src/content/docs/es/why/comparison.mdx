Cada toolkit GUI de Python hace concesiones distintas. Esta página las pone lado a lado, incluidos los casos
en los que Pyzed **no** es la mejor elección. Para números medidos, mira los [Benchmarks](/pyzed/es/why/benchmarks/).

:::note[Cómo leer las tablas]
Los datos se comprobaron con la documentación de cada proyecto en octubre de 2026. «De terceros» significa
que existe pero fuera del proyecto; «–» significa que el proyecto no lo ofrece (hasta donde pudimos
encontrar). Si algo está desactualizado, [abre un issue](https://github.com/albakore/pyzed/issues) y lo
corregimos.
:::

## Los contendientes

| Toolkit | Qué es | Desde |
| --- | --- | --- |
| **[Pyzed](https://github.com/albakore/pyzed)** | API de Python sobre [Iced](https://iced.rs) (Rust), con componentes al estilo de Zed | 2026 |
| **[tkinter](https://docs.python.org/es/3/library/tkinter.html)** | El binding estándar de Python a Tcl/Tk | años 90 |
| **[CustomTkinter](https://customtkinter.tomschimansky.com)** | Widgets de aspecto moderno dibujados sobre tkinter | 2021 |
| **[PyQt](https://www.riverbankcomputing.com/software/pyqt/) / [PySide](https://doc.qt.io/qtforpython-6/)** | Bindings al framework Qt (C++) | 1998 / 2009 |
| **[wxPython](https://wxpython.org)** | Bindings a wxWidgets, que envuelve los widgets nativos | 1998 |
| **[Kivy](https://kivy.org)** | Widgets dibujados con OpenGL, con su propio lenguaje KV, para escritorio y móvil | 2011 |
| **[Dear PyGui](https://github.com/hoffstadt/DearPyGui)** | Bindings a Dear ImGui, un toolkit en modo inmediato por GPU | 2020 |
| **[Flet](https://flet.dev)** | Python controlando una interfaz Flutter | 2022 |
| **[Toga](https://toga.readthedocs.io)** | El toolkit de BeeWare sobre los widgets nativos de cada plataforma | 2014 |
| **[NiceGUI](https://nicegui.io)** | Interfaz web (Vue + Quasar) servida desde Python, en un navegador o un webview | 2021 |

## ¿Cuál debería usar?

- **Necesitas Android o iOS:** Kivy, Flet o Toga. Pyzed es solo para escritorio.
- **Necesitas una app web:** NiceGUI o Flet (o un framework web). Pyzed dibuja ventanas nativas.
- **El soporte de lectores de pantalla es un requisito hoy:** Qt, wxPython, Toga o Flet.
- **Necesitas un conjunto enorme de widgets** (gráficas, vídeo, un navegador embebido, 3D) y te encajan su
  tamaño y su licencia: Qt. Mira [Pyzed vs PyQt/PySide](/pyzed/es/why/vs-pyqt-pyside/).
- **Un script diminuto que debe funcionar sin instalar nada:** tkinter, que viene con Python. Mira
  [Pyzed vs tkinter](/pyzed/es/why/vs-tkinter/).
- **Gráficas en tiempo real y herramientas de depuración:** Dear PyGui es excelente. Mira
  [Pyzed vs Dear PyGui](/pyzed/es/why/vs-dear-pygui/).
- **Una app de escritorio moderna** (una herramienta interna, un editor, un panel, un lanzador, un cliente
  para tu API) que se vea bien sin trabajo de diseño, arranque rápido, se construya visualmente y con ayuda
  de IA, y se distribuya como un único ejecutable: **para eso está Pyzed.** Empieza con el
  [inicio rápido](/pyzed/es/getting-started/quickstart/).
