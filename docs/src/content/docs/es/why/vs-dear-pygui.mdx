[Dear PyGui](https://github.com/hoffstadt/DearPyGui) envuelve [Dear ImGui](https://github.com/ocornut/imgui),
el toolkit en modo inmediato que usan los motores de videojuegos para sus herramientas de depuración. Se
dibuja por GPU y es muy rápido, y brilla en gráficas en tiempo real, editores de nodos y herramientas
internas. Su aspecto es el de «herramienta» de ImGui, y redibuja continuamente, algo que encaja mejor en un
panel que cambia en cada fotograma que en un formulario que cambia cuando haces clic.

## En resumen

| | Pyzed | Dear PyGui |
| --- | --- | --- |
| Modelo | Estado + `view()` (arquitectura Elm) | Elementos creados una vez con etiquetas, cambiados con `set_value` / `configure_item` |
| Redibujado | Cuando algo cambia | En cada fotograma, por defecto |
| Aspecto | Componentes modernos listos, temas, modo oscuro | Estilo de herramienta ImGui, configurable con temas |
| Texto | Shaping completo, cualquier escritura, emoji, texto enriquecido y markdown | Fuentes y rangos de glifos que cargas tú |
| Gráficas | [Sparklines, barras y donuts](/pyzed/es/library/bar-chart/), un canvas | Excelentes gráficas integradas (ImPlot) |
| Escritorio | Menús, atajos, varias ventanas, docks, editor de código | Docking y viewports de ImGui |
| Diseñador, recarga | Pyzed Design, `pyzed dev` | – |
| Accesibilidad | Teclado; sin lectores de pantalla todavía | Sin lectores de pantalla |

## De los conceptos de Dear PyGui a Pyzed

| Dear PyGui | Pyzed |
| --- | --- |
| `create_context`, `create_viewport`, `start_dearpygui` | `pz.run(MiApp)` |
| `with dpg.window(...)` | la raíz que devuelve `view()` |
| `dpg.add_text(tag="x")` + `dpg.set_value("x", ...)` | `ui.label(self.x)`: cambia `self.x` |
| `callback=fn` | `on_press=fn` |
| `dpg.group(horizontal=True)` | `pz.row` |
| `dpg.child_window` | `pz.scrollable`, `ui.card`, `ui.panel` |
| `dpg.theme()` + `bind_item_theme` | [temas](/pyzed/es/theming/themes/) y [estilos](/pyzed/es/theming/styles/) |
| `dpg.add_plot` | [`ui.bar_chart`](/pyzed/es/library/bar-chart/), [`ui.sparkline`](/pyzed/es/library/sparkline/), o [`pz.canvas`](/pyzed/es/guides/canvas/) para dibujo propio |

## Cuándo elegir cada uno

- **Elige Dear PyGui** para gráficas en tiempo real, editores de nodos, paneles de instrumentos y
  herramientas de depuración donde el aspecto de ImGui está bien.
- **Elige Pyzed** para apps de usuario final: formularios, listas, editores y paneles que deban verse
  pulidos, con texto de calidad, un diseñador, recarga en caliente y empaquetado.
