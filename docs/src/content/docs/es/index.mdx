## Una app en 20 líneas

```python title="counter.py"
import pyzed as pz
from pyzed import ui


class Counter(pz.App):
    title = "Counter"
    size = (360, 220)

    def __init__(self):
        self.count = 0

    def view(self):
        return pz.center(
            pz.row([
                ui.button("-1", lambda: setattr(self, "count", self.count - 1), icon="minus"),
                ui.heading(str(self.count)),
                ui.button("+1", lambda: setattr(self, "count", self.count + 1), icon="plus", variant="solid"),
            ], spacing=12, align="center"),
            bg=self.resolved_theme().editor,
        )


pz.run(Counter)
```

## Por qué Pyzed

<CardGrid>
	<Card title="Rendimiento nativo" icon="rocket">
		Python solo describe la interfaz. Layout, texto y dibujado (wgpu, con tiny-skia de respaldo)
		los hace Iced 0.14 en Rust mediante PyO3.
	</Card>
	<Card title="Sencillo" icon="pencil">
		La arquitectura Elm de Iced (estado, `update`, `view`) sin ceremonia: un botón puede llamar
		directamente a `self.guardar`.
	</Card>
	<Card title="Componentes de Zed" icon="puzzle">
		Botones, pestañas, árbol de archivos, paleta de comandos, editor con resaltado, terminal,
		menús, toasts y un workspace con docks.
	</Card>
	<Card title="Temas" icon="seti:pipeline">
		One, Ayu y Gruvbox con los tokens de color de Zed, modo claro/oscuro del sistema e importación
		de cualquier tema de Zed. Deriva el tuyo en una línea y cámbialo en caliente.
	</Card>
	<Card title="Async y varias ventanas" icon="random">
		`update` y los callbacks pueden ser `async`; `pz.every` y `pz.listen` para temporizadores y
		streams. Cada `pz.Window` tiene su propia vista y tema, con el estado compartido.
	</Card>
	<Card title="Multiplataforma" icon="laptop">
		Linux, macOS y Windows. Fuentes IBM Plex e iconos Lucide (~2000) incluidos.
	</Card>
	<Card title="Capturas sin ventana" icon="seti:image">
		`app.screenshot("ui.png")` renderiza fuera de pantalla, sin GPU. Todas las imágenes de esta
		web se generan así.
	</Card>
</CardGrid>
