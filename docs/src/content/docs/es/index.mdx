<SectionTitle id="code" eyebrow="También desde código" title="Una app en 20 líneas">
	¿Prefieres escribirlo todo a mano? Pyzed es una librería de Python normal. Esta es una app completa:

<CodeShowcase shot="counter" alt="La app contador: un número sobre los botones menos, más y reiniciar" caption="python counter.py">

```python title="counter.py"
import pyzed as pz
from pyzed import ui


class Counter(pz.App):
    title = "Counter"
    size = (360, 220)

    def __init__(self):
        self.count = 0

    def add(self, step):
        self.count += step

    def view(self):
        return pz.center(pz.column([
            ui.heading(str(self.count)),
            pz.row([
                ui.button("1", lambda: self.add(-1), icon="minus"),
                ui.button("1", lambda: self.add(1), icon="plus", variant="solid"),
                ui.icon_button("rotate-ccw", lambda: setattr(self, "count", 0)),
            ], spacing=8),
        ], spacing=16, align="center"), bg=self.theme.editor)


pz.run(Counter)
```
