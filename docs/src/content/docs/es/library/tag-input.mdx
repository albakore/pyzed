:::tip[En pocas palabras]
Una caja donde escribes palabras y cada una se convierte en una etiqueta que puedes quitar.
:::

Una caja de fichas con un campo al final. Intro o una coma convierten el texto en etiqueta y `on_change` recibe la lista nueva, igual que al pulsar la x de una ficha. `suggestions` ofrece etiquetas que coinciden.

## Cuándo usarlo

- Para etiquetas, palabras clave, destinatarios o cualquier lista corta que se escribe.
- Para un conjunto fijo de opciones, usa filtros [Chip](/pyzed/es/library/chip/) o un [desplegable](/pyzed/es/library/select/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Labels(pz.App):
    def __init__(self):
        self.tags = ["design"]
        self.typing = ""

    def view(self):
        return ui.tag_input(self.tags, lambda tags: setattr(self, "tags", tags),
                            text=self.typing, on_input=lambda text: setattr(self, "typing", text),
                            suggestions=["python", "rust", "docs"])
```

## Eventos

Campo de etiquetas tiene **2 eventos propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_change` | `(tags)` | Función que recibe la nueva lista de etiquetas. |
| `on_input` | `(text)` | Función que recibe el texto que se escribe. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Labels(pz.App):
    def __init__(self):
        self.tags = ["design", "rust"]
        self.typing = ""

    def set_tags(self, tags):            # on_change: the new list (a tag added or removed)
        self.tags = tags

    def type(self, text):                # on_input: the text in the field
        self.typing = text

    def view(self):
        return ui.tag_input(self.tags, self.set_tags, text=self.typing, on_input=self.type,
                            placeholder="Add a label…", suggestions=["python", "docs", "bug"])
```

<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class SetTags:
    tags: list


@dataclass
class Type:
    text: str


class Labels(pz.App):
    tags = ["design"]
    typing = ""

    def update(self, message):
        match message:
            case SetTags(tags):
                self.tags = tags
            case Type(text):
                self.typing = text

    def view(self):
        return ui.tag_input(self.tags, SetTags, text=self.typing, on_input=Type)
```

from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    tags: tuple = ("design",)
    typing: str = ""


def view(state, set_state):
    return ui.tag_input(state.tags, lambda tags: set_state(tags=tuple(tags)), text=state.typing,
                        on_input=lambda text: set_state(typing=text))

## Propiedades y API

### `ui.tag_input`

```python
tag_input(
    tags,
    on_change=None,
    *,
    text='',
    on_input=None,
    placeholder='',
    suggestions=(),
    max_tags=None,
    unique=True,
    tint='accent',
    width='fill',
    disabled=False,
    id=None,
    theme=None,
)
```

Una caja de fichas que se pueden quitar, con un campo para escribir más. Intro o una coma convierten el texto en etiqueta; `on_change` recibe la lista nueva, igual que al pulsar la x de una ficha.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `tags` | *obligatorio* | Tu lista de etiquetas. |
| `text` | `""` | Lo que se está escribiendo (también es tu estado). |
| `placeholder` | `""` | Texto de ayuda cuando está vacío. |
| `suggestions` | `()` | Etiquetas que se ofrecen bajo el campo mientras el texto coincide. |
| `max_tags` | `None` | Oculta el campo cuando la lista llega a este número. |
| `unique` | `True` | Una etiqueta que ya está en la lista no se vuelve a añadir. |
| `tint` | `"accent"` | Color de las fichas. |
| `width` | `"fill"` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `id` | `None` | Identificador estable para enfocarlo o desplazarlo con un `Command`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_change`, `on_input` ([eventos](#eventos)).
