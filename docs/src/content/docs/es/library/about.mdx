## Uso

```python

ui.about("Notes", "1.2.0", "A small notes app built with Pyzed.", icon="notebook-pen",
         details=[("Python", "3.12"), ("Pyzed", "0.4")],
```

## Propiedades y API

### `ui.about`

```python
about(
    name,
    version='',
    description='',
    *,
    icon='app-window',
    details=(),
    links=(),
    theme=None,
)
```

Un cuadro Acerca de: icono, nombre, versión, una descripción, algunos detalles y botones de enlace.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `name` | *obligatorio* | Nombre de la app. |
| `version` | `""` | Versión. |
| `description` | `""` | Una o dos frases. |
| `icon` | `"app-window"` | Icono de Lucide. |
| `details` | `()` | Filas `(etiqueta, valor)`. |
| `links` | `()` | Botones `(etiqueta, on_press)`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
