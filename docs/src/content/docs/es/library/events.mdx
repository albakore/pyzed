Los widgets de Pyzed reaccionan a eventos en dos capas:

- **Sus eventos propios**: los parámetros `on_*` de cada componente, como `on_press` de un botón o
  `on_select` de un árbol. Avisan de lo que significa para el componente (se cerró una pestaña, se abrió
  una fila) y suelen pasar un valor (el texto, el elemento, el estado nuevo).
- **Los eventos comunes**: 18 eventos que tiene cualquier widget, sea cual sea, y que se conectan con
  `.on(...)`: clics, paso del puntero, arrastre, foco, teclas y tamaño. Un `pz.Component` además lanza
  `on_mount` y `on_unmount`.

Así que un componente puede tener sus eventos propios más los 18 comunes. Entre los 114
componentes de la biblioteca hay **159 eventos propios**; los que más tienen aparecen primero en la tabla
del final.

```python
ui.list_item("main.py", self.abrir, icon="file").on(  # on_press es su evento propio
    right_click=self.mostrar_menu,                     # los comunes: cualquier widget
    mouse_enter=lambda: setattr(self, "encima", "main.py"),
    drag=lambda e: self.mover(e.dx, e.dy),             # recibe el pz.Event
)
```

## Los eventos comunes

Los tiene todo widget. Un handler sin argumentos se llama sin nada; uno con un argumento recibe un `pz.Event`.

| Grupo | Evento | Cuándo |
| --- | --- | --- |
| Ratón | `click` | Se hizo clic en el widget (se pulsó y soltó el botón izquierdo). |
| Ratón | `double_click` | Dos clics seguidos. |
| Ratón | `right_click` | Se pulsó el botón derecho (úsalo para menús contextuales). |
| Ratón | `middle_click` | Se pulsó el botón central (la rueda). |
| Ratón | `mouse_down` | Se pulsó cualquier botón sobre el widget (`event.button`). |
| Ratón | `mouse_up` | Se soltó cualquier botón sobre el widget (`event.button`). |
| Ratón | `mouse_enter` | El puntero entró en el widget. |
| Ratón | `mouse_leave` | El puntero salió del widget. |
| Ratón | `mouse_move` | El puntero se movió sobre el widget (`event.x`, `event.y`). |
| Ratón | `scroll` | La rueda giró sobre el widget (`event.dx`, `event.dy` en líneas). |
| Arrastre | `drag_start` | Se pulsó el botón izquierdo y el puntero se movió unos píxeles. |
| Arrastre | `drag` | El puntero se movió mientras se arrastra (`event.dx`, `event.dy` desde el anterior). |
| Arrastre | `drag_end` | Se soltó el botón después de arrastrar. |
| Foco | `focus` | Se hizo clic en el widget y ahora recibe las teclas. |
| Foco | `blur` | Un clic en otro sitio le quitó el foco. |
| Teclado | `key_down` | Se pulsó una tecla con el foco (`event.key`, por ejemplo `"ctrl-s"`). |
| Teclado | `key_up` | Se soltó una tecla con el foco (`event.key`). |
| Tamaño | `resize` | El widget cambió de tamaño, también la primera vez (`event.width`, `event.height`). |

### Campos de `pz.Event`

| Propiedad | Descripción |
| --- | --- |
| `type` | El nombre del evento (`"click"`, o un evento propio de un componente). |
| `x`, `y` | Posición del puntero relativa al widget (`position` da las dos). |
| `window_x`, `window_y` | Posición del puntero en la ventana. |
| `screen_x`, `screen_y` | En la pantalla (`None` donde el sistema no lo dice, como Wayland). |
| `dx`, `dy` | Cantidad de desplazamiento, o movimiento del arrastre desde el `drag` anterior. |
| `width`, `height` | El tamaño del widget (`size` da los dos). |
| `button` | `"left"`, `"right"`, `"middle"`… |
| `key` | La combinación de teclas, como `"ctrl-s"`. |
| `shift`, `ctrl`, `alt`, `logo` | Modificadores pulsados. |
| `value`, `source` | En los eventos propios de un componente: el dato y el componente. |

## Qué reciben los handlers

Los controles que producen un valor llaman a tu función con él. Las formas más habituales:

| Handler | Descripción | Eventos |
| --- | --- | --- |
| `()` | Nada: el evento ya es la noticia (una pulsación, un cierre, Enter). | `ui.alert(on_close=)`, `pz.mouse_area(on_press=)`, `pz.mouse_area(on_release=)`, `pz.mouse_area(on_right_press=)`… |
| `(event)` | Un `pz.Event`: su `value` trae el dato y `source` el componente. | `ui.AuthPrompt(on_pick=)`, `ui.AuthPrompt(on_cancel=)`, `ui.AuthPrompt(on_open_url=)`, `ui.AuthPrompt(on_copy=)`… |
| `(text)` | El texto nuevo, en cada pulsación de tecla. | `ui.shortcuts(on_query=)`, `ui.picker(on_query=)`, `ui.search_input(on_input=)`, `ui.input(on_input=)`… |
| `(x, y)` | La posición del puntero, relativa al widget. | `pz.mouse_area(on_move=)`, `pz.canvas(on_press=)`, `pz.canvas(on_release=)`, `pz.canvas(on_right_press=)`… |
| `(value)` | El valor nuevo: un número, un color, una opción… | `ui.number_field(on_change=)`, `ui.slider(on_change=)`, `ui.toggle_group(on_select=)`, `ui.radio_group(on_select=)`… |
| `(info)` | Un dict (desplazamiento y tamaños) o un `ui.ErrorInfo`. | `pz.scrollable(on_scroll=)`, `ui.editor(on_scroll=)`, `ui.error_boundary(on_error=)`, `ui.error_boundary(on_details=)`… |
| `(id)` | El id de la fila o pestaña (en un árbol, su ruta). | `ui.tree(on_toggle=)`, `ui.tree(on_select=)`, `ui.tree(on_open=)`, `ui.tree(on_context=)` |
| `(tab_id)` | El id de la pestaña. | `ui.tab_bar(on_select=)`, `ui.tab_bar(on_close=)`, `ui.tab_bar(on_drag=)`, `ui.tab_bar(on_context=)` |
| `(row)` | La fila (el dict u objeto que pasaste en `rows`). | `ui.table(on_row_press=)`, `ui.table(on_row_double_press=)`, `ui.table(on_row_context=)` |
| `(dx, dy)` | Cuánto giró la rueda, en líneas. | `pz.mouse_area(on_scroll=)`, `pz.canvas(on_scroll=)` |
| `(checked)` | El estado nuevo, `True` o `False`. | `ui.checkbox(on_toggle=)`, `ui.switch(on_toggle=)` |
| `(line)` | La línea del registro (un `ui.LogEntry`). | `ui.console(on_context=)`, `ui.console(on_open=)` |
| `(name)` | Un nombre: del icono o de la acción del editor. | `ui.editor(on_action=)`, `ui.icon_picker_dialog(on_pick=)` |
| `(url)` | La URL del enlace. | `ui.markdown(on_link=)`, `ui.reference_browser(on_open_url=)` |
| `(size)` | El tamaño nuevo en píxeles, al terminar de arrastrar. | `ui.panel(on_resize=)`, `pz.resizable(on_resize=)` |
| `(item)` | La opción elegida. | `ui.segmented(on_select=)`, `ui.select(on_select=)` |
