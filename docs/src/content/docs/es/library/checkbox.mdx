## Cuándo usarlo

- Para opciones que se aplican después (un formulario que envías) o una lista de opciones independientes.
- Para un ajuste que se aplica al momento, un [Interruptor](/pyzed/es/library/switch/) se entiende mejor.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.accepted = False

    def view(self):
        return ui.checkbox(self.accepted, lambda value: setattr(self, "accepted", value),
                           label="I accept the terms")
```

## API

### `ui.checkbox`

```python
checkbox(checked, on_toggle=None, *, label=None, size='md', disabled=False, theme=None)
```

Una casilla de verificación. `checked=None` muestra el estado mixto (parte de un grupo marcada); al pulsarla se marca.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `checked` | *obligatorio* | Estado actual. |
| `on_toggle` | `None` | Callable que recibe el nuevo `bool` (o mensaje que se envía). |
| `label` | `None` | Texto de la etiqueta. |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `disabled` | `False` | La atenúa e ignora los clics. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `pz.checkbox`

```python
checkbox(
    checked,
    label=None,
    *,
    on_toggle=None,
    size=None,
    text_size=None,
    accent=None,
    bg=None,
    border_color=None,
    check_color=None,
    color=None,
)
```

Una casilla de verificación.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `checked` | *obligatorio* | Estado actual. |
| `label` | `None` | Texto de la etiqueta. |
| `on_toggle` | `None` | Callable que recibe el nuevo `bool` (o mensaje que se envía). |
| `size` | `None` | Tamaño de la casilla. |
| `text_size` | `None` | Tamaño del texto. |
| `accent` | `None` | Color de acento (parte activa). |
| `bg` | `None` | Color de fondo (`"#rrggbb[aa]"`, `(r, g, b[, a])` o `"transparent"`). |
| `border_color` | `None` | Color del borde. |
| `check_color` | `None` | Color de la marca. |
| `color` | `None` | Color del texto o del icono. |
