Un buscador sobre una lista de resultados en una superficie flotante: la base de la paleta de comandos y del buscador de archivos. `ui.fuzzy_filter(query, items, key=)` ordena los elementos como Zed y devuelve `[(item, positions), ...]`; pasa esos pares a `picker` para resaltar las coincidencias. `ui.fuzzy_match` puntúa una cadena y `ui.highlighted` dibuja una con sus coincidencias.

## Cuándo usarlo

- Para tus propios buscadores: archivos, símbolos, ramas, proyectos, emoji.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Finder(pz.App):
    def __init__(self):
        self.query, self.selected = "", 0
        self.files = ["src/app.rs", "src/render.rs", "README.md"]

    def view(self):
        matches = ui.fuzzy_filter(self.query, self.files)
        items = [(ui.PaletteItem(f, lambda f=f: self.open(f), icon="file"), positions)
                 for f, positions in matches[:50]]
        return ui.picker(self.query, lambda q: setattr(self, "query", q), items,
                         selected=self.selected, placeholder="Search files…")
```

## API

### `ui.picker`

```python
picker(
    query,
    on_query,
    items,
    *,
    selected=0,
    placeholder='Search…',
    input_id='picker',
    on_submit=None,
    width=560,
    max_height=340,
    empty_text='No matches',
    theme=None,
)
```

Una lista con buscador en una superficie flotante. Es la base de la paleta y del buscador de archivos.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `query` | *obligatorio* | Texto buscado. |
| `on_query` | *obligatorio* | Callable que recibe el texto nuevo. |
| `items` | *obligatorio* | Pares `(PaletteItem, posiciones)`, por ejemplo de `fuzzy_filter`. |
| `selected` | `0` | Índice resaltado. |
| `placeholder` | `"Search…"` | Texto de ayuda cuando está vacío. |
| `input_id` | `"picker"` | Id del campo. |
| `on_submit` | `None` | Mensaje o callable que se envía al pulsar Enter. |
| `width` | `560` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `max_height` | `340` | Alto máximo en píxeles. |
| `empty_text` | `"No matches"` | Texto cuando no hay resultados. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.fuzzy_filter`

```python
fuzzy_filter(query, items, key=<class 'str'>)
```

Filtra y ordena `items` por puntuación difusa. Devuelve `[(item, posiciones), ...]`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `query` | *obligatorio* | Texto buscado. |
| `items` | *obligatorio* | Elementos. |
| `key` | `<class 'str'>` | Función que da el texto de cada elemento. |

[Referencia completa →](/pyzed/es/reference/ui/#fuzzy_filter)

### `ui.fuzzy_match`

```python
fuzzy_match(query, candidate)
```

Devuelve `(puntuación, posiciones)` si todas las letras de `query` aparecen en orden en `candidate`; si no, `None`. Premia los inicios de palabra y las letras consecutivas.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `query` | *obligatorio* | Texto buscado. |
| `candidate` | *obligatorio* | Texto candidato. |

[Referencia completa →](/pyzed/es/reference/ui/#fuzzy_match)

### `ui.highlighted`

```python
highlighted(text, positions, *, color, match_color, size=13.5, weight=None)
```

Texto con los caracteres de `positions` resaltados (coincidencias de la búsqueda difusa).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `text` | *obligatorio* | Texto. |
| `positions` | *obligatorio* | Índices a resaltar. |
| `color` | *obligatorio* | Color del texto o del icono. |
| `match_color` | *obligatorio* | Color de las coincidencias. |
| `size` | `13.5` | Tamaño. |
| `weight` | `None` | Peso del texto. |
