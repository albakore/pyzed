## Cuándo usarlo

- Junto a un icono o pestaña para indicar cuántos elementos sin leer o errores hay.
- Para estados de texto usa una [Insignia](/pyzed/es/library/badge/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.count_badge(3),
    ui.count_badge(42, tint="success"),
    ui.count_badge(120, tint="error"),
    pz.row([ui.icon_button("bell", on_press), ui.count_badge(7)], spacing=2, align="center"),
```

## Propiedades y API

### `ui.count_badge`

```python
count_badge(count, *, tint='accent', max=99, show_zero=True, theme=None)
```

Un contador redondo (notificaciones, problemas…). Muestra `99+` por encima de `max`.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `count` | *obligatorio* | El número. |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `max` | `99` | Máximo antes de mostrar `N+`. |
| `show_zero` | `True` | Con `False`, un 0 no dibuja nada. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
