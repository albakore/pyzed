Toda la disposición de una ventana tipo editor: barra arriba, paneles laterales, la zona principal y una barra abajo.
:::

Construye el marco de una ventana estilo editor: la barra de título arriba, docks a la izquierda, a la derecha y abajo, el centro y la barra de estado. Pasa `None` para ocultar un dock (así funciona Ctrl+B); `left_width`, `right_width` y `bottom_height` fijan su tamaño y `on_resize` avisa al arrastrar.

## Cuándo usarlo

- Como raíz de apps tipo editor: IDEs, apps de notas, clientes de bases de datos, gestores de archivos.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Ide(pz.App):
    def __init__(self):
        self.show_left = True

    def on_key(self, combo):
        if combo == "ctrl-b":
            self.show_left = not self.show_left

    def view(self):
        return ui.workspace(
            self.editor_area(),
            title_bar=ui.title_bar([ui.title_button("my-project", chevron=True)]),
            left=self.project_panel() if self.show_left else None,
            status_bar=ui.status_bar([], [ui.status_item("Python")]),
        )
```

## API

### `ui.workspace`

```python
workspace(
    center,
    *,
    title_bar=None,
    left=None,
    right=None,
    bottom=None,
    status_bar=None,
    left_width=240,
    right_width=320,
    bottom_height=220,
    on_resize=None,
    theme=None,
)
```

El layout de una ventana estilo editor: barra de título, docks izquierdo, derecho e inferior, centro y barra de estado. Pasa `None` para ocultar un dock.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `center` | *obligatorio* | Contenido central (normalmente pestañas + editor). |
| `title_bar` | `None` | Barra de título (`ui.title_bar`). |
| `left` | `None` | Dock izquierdo. |
| `right` | `None` | Dock derecho. |
| `bottom` | `None` | Dock inferior. |
| `status_bar` | `None` | Barra de estado (`ui.status_bar`). |
| `left_width` | `240` | Ancho del dock izquierdo. |
| `right_width` | `320` | Ancho del dock derecho. |
| `bottom_height` | `220` | Alto del dock inferior. |
| `on_resize` | `None` | Se llama con `(side, size)` cuando el usuario termina de cambiar el tamaño de un panel arrastrando su borde interior. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
