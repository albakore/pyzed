:::tip[En pocas palabras]
Un dibujo con líneas que suben y bajan para mostrar cómo cambian los números.
:::

Dibuja una o varias series de números como líneas sobre las etiquetas `labels` del eje x, con un eje y de cuatro pasos. Un dict `{nombre: valores}` añade una leyenda; `fill` sombrea y `points` marca cada valor.

`ui.line_chart` · Categoría: [Datos](/pyzed/es/library/#datos) · [Referencia completa →](/pyzed/es/reference/ui/#line_chart)

## Cuándo usarlo

- Para mostrar cómo cambian los valores en el tiempo: visitas, ventas, temperaturas.
- Dentro de una tarjeta o una fila, una [minigráfica](/pyzed/es/library/sparkline/) ocupa menos.

## Uso

```python
from pyzed import ui

ui.line_chart({"Visits": [12, 18, 15, 24, 30, 28, 36], "Sales": [4, 6, 5, 9, 11, 10, 14]},
              labels=["Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun"], width=440, height=200)
```

## Propiedades y API

### `ui.line_chart`

```python
line_chart(
    series,
    *,
    labels=None,
    width=360,
    height=180,
    colors=None,
    fill=False,
    points=False,
    grid=True,
    legend=None,
    min=None,
    max=None,
    theme=None,
)
```

Un gráfico de líneas con ejes: una lista de números, varias listas o `{nombre: valores}` (que añade una leyenda). El eje y muestra cuatro pasos entre `min` y `max`.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `series` | *obligatorio* | Una lista de números, una lista de listas o un dict `{nombre: valores}`. |
| `labels` | `None` | Etiquetas bajo el eje x (se aclaran si no caben). |
| `width` | `360` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `180` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `colors` | `None` | Colores de las líneas (por defecto, los del tema). |
| `fill` | `False` | Sombrea bajo cada línea. |
| `points` | `False` | Marca cada valor con un punto. |
| `grid` | `True` | Dibuja las líneas horizontales. |
| `legend` | `None` | Con un dict, `False` oculta los nombres bajo el gráfico. |
| `min` | `None` | Base del eje y (sale de los datos con `None`). |
| `max` | `None` | Tope del eje y (sale de los datos con `None`). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
