Una fila de pestañas de editor con controles opcionales al principio y al final. `ui.Tab.for_file(path)` crea una pestaña con el nombre del archivo, su icono y la ruta como id. `dirty=True` muestra un punto que se convierte en el botón de cerrar al pasar el ratón, `preview=True` pone el nombre en cursiva y `status` lo tiñe con un color de git. `on_select(id)` y `on_close(id)` reciben el id de la pestaña.

## Cuándo usarlo

- Para los documentos abiertos de un editor, o cualquier conjunto de vistas que se abren y cierran.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Editor(pz.App):
    def __init__(self):
        self.open, self.active = ["main.py", "app.py"], "main.py"

    def close(self, path):
        i = self.open.index(path)
        self.open.remove(path)
        if self.active == path:
            self.active = self.open[min(i, len(self.open) - 1)] if self.open else None

    def view(self):
        return ui.tab_bar([ui.Tab.for_file(p) for p in self.open], self.active,
                          on_select=lambda p: setattr(self, "active", p), on_close=self.close)
```

## API

### `ui.tab_bar`

```python
tab_bar(
    tabs,
    active,
    *,
    on_select=None,
    on_close=None,
    start=(),
    end=(),
    height=32,
    on_drag=None,
    on_drop=None,
    on_drag_over=None,
    dragging=None,
    drop_index=None,
    theme=None,
)
```

Una fila de pestañas con controles opcionales al principio y al final (navegación, dividir, +). El botón de cerrar aparece en la activa y al pasar el ratón. Las pestañas se pueden arrastrar para reordenarlas o sacarlas de la ventana: ver [Pestañas arrastrables](/pyzed/es/guides/windows/#pestañas-arrastrables-y-ventanas-desprendibles).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `tabs` | *obligatorio* | Lista de `Tab`. |
| `active` | *obligatorio* | Id de la pestaña activa. |
| `on_select` | `None` | Callable que recibe el elemento elegido. |
| `on_close` | `None` | Mensaje o callable que se envía al pulsar la X. |
| `start` | `()` | Widgets al inicio (izquierda). |
| `end` | `()` | Widgets al final (derecha). |
| `height` | `32` | Alto. |
| `on_drag` | `None` | Se llama con el id de la pestaña cuando empieza a arrastrarse. |
| `on_drop` | `None` | Se llama con el id de la pestaña y el `Event` al soltar la pestaña arrastrada: `event.window_x`/`window_y` (fuera de la ventana si se soltó fuera) y `event.screen`. |
| `on_drag_over` | `None` | Mientras `dragging` tiene valor: se llama con el índice de inserción bajo el puntero, o `None` cuando sale de la barra. |
| `dragging` | `None` | Id de la pestaña que se arrastra (la apaga y activa `on_drag_over`). |
| `drop_index` | `None` | Dibuja la marca de inserción antes de la pestaña de este índice (`len(tabs)`: después de la última). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.Tab`

```python
@dataclass
class Tab(id, label, icon=None, icon_color=None, dirty=False, preview=False, status=None)
```

Una pestaña. `Tab.for_file(path, **kwargs)` la crea con el nombre y el icono del archivo.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `id` | *obligatorio* | Identificador estable para enfocarlo o desplazarlo con un `Command`. |
| `label` | *obligatorio* | Texto de la etiqueta. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `icon_color` | `None` | Color del icono: un token del tema o un color hex. |
| `dirty` | `False` | Cambios sin guardar (muestra un punto). |
| `preview` | `False` | Pestaña de vista previa (en cursiva). |
| `status` | `None` | Estado de git (tiñe el nombre). |

### `ui.tab`

```python
tab(item, *, active, on_select=None, on_close=None, height=32, dimmed=False, theme=None)
```

Una sola pestaña. Normalmente se usa `tab_bar`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `item` | *obligatorio* | El `Tab`. |
| `active` | *obligatorio* | Si es la activa. |
| `on_select` | `None` | Callable que recibe el elemento elegido. |
| `on_close` | `None` | Mensaje o callable que se envía al pulsar la X. |
| `height` | `32` | Alto. |
| `dimmed` | `False` | Apaga la etiqueta (la pestaña que se arrastra). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
