## Cuándo usarlo

- Para el título de una página, una sección de un diálogo o un grupo de ajustes.
- Para un título pequeño de lista en mayúsculas, usa [Cabecera de lista](/pyzed/es/library/list-header/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.heading("Heading 1"),
    ui.heading("Heading 2", level=2),
    ui.heading("Heading 3", level=3),
    ui.muted("Body text below the headings."),
], spacing=6)
```

## API

### `ui.heading`

```python
heading(content, *, level=1, theme=None, **kwargs)
```

Un título en semibold.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `level` | `1` | 1 (26 px), 2 (20 px), 3 (16 px) o 4 (13.5 px). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
| `**kwargs` | — | Los de `label`. |
