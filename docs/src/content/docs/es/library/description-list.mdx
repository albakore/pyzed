:::tip[En pocas palabras]
Una lista corta de nombres y valores, como los detalles de un archivo.
:::

Los detalles de algo, una propiedad por fila: los nombres a la izquierda (o encima con `vertical`) y sus valores, que pueden ser texto o cualquier widget, como una insignia. Los textos se pueden copiar.

## Cuándo usarlo

- Para las propiedades de un archivo, un pedido, un usuario o un dispositivo.
- Para muchas filas con las mismas columnas, usa una [tabla](/pyzed/es/library/table/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.description_list({
    "Name": "report.pdf",
    "Size": "2.4 MB",
    "Modified": "Today, 10:42",
    "Status": ui.badge("Synced", tint="success"),
}), width=360)
```

## Propiedades y API

### `ui.description_list`

```python
description_list(
    items,
    *,
    label_width=140,
    vertical=False,
    dividers=True,
    mono_values=False,
    selectable=True,
    theme=None,
)
```

Pares de nombre y valor, uno por fila: los detalles de un archivo, un pedido o un dispositivo. Un valor puede ser texto o cualquier widget.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `items` | *obligatorio* | Un dict o pares `(nombre, valor)`. |
| `label_width` | `140` | Ancho de la columna de nombres. |
| `vertical` | `False` | Pone cada nombre sobre su valor. |
| `dividers` | `True` | Líneas entre filas. |
| `mono_values` | `False` | Valores de texto en fuente monoespaciada (ids, hashes). |
| `selectable` | `True` | Los valores de texto se pueden seleccionar y copiar. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
