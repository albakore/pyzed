:::tip[En pocas palabras]
Muestra qué cambió en un archivo: las líneas nuevas en verde y las borradas en rojo.
:::

`ui.diff_view(diff)` muestra un cambio: el nombre del archivo y luego las líneas que cambiaron (las añadidas en verde, las quitadas en rojo) con dos líneas de contexto alrededor de cada cambio; los cambios alejados se separan con `⋯`. `diff` es un diccionario con `path`, `old` y `new`, los textos completos de antes y de después, y `max_lines` limita cuántas líneas se ven antes de `… N líneas más`. Es lo que muestra una [Llamada a herramienta](/pyzed/es/library/tool-call/) para los cambios que hizo.

## Cuándo usarlo

- Para mostrar lo que un agente o una herramienta cambió en un archivo.
- Para revisar un cambio antes de guardarlo, junto a botones de Conservar y Rechazar.
- Para las cifras solas (`+12 −3`), usa el [Resumen de cambios](/pyzed/es/library/diff-stat/).

## Uso

```python
import pyzed as pz
from pyzed import ui

old = "def save(path):\n    data = load()\n    write(path, data)\n    return True\n"
new = "def save(path, data):\n    write(path, data)\n    log(path)\n    return True\n"
pz.container(ui.diff_view({"path": "app/storage.py", "old": old, "new": new}), width=420)
```

## API

### `ui.diff_view`

```python
diff_view(diff, *, theme=None, max_lines=120)
```

Un cambio tal como lo muestra Zed en un hilo: el nombre del archivo y las líneas cambiadas (en verde las añadidas, en rojo las quitadas) con unas pocas líneas alrededor.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `diff` | *obligatorio* | Un dict con `path`, `old` y `new` (los textos antes y después). |
| `theme` | `None` | Tema. |
| `max_lines` | `120` | Líneas que se muestran antes de `… N líneas más`. |
