:::tip[En pocas palabras]
Una lista de cosas que pasaron, en orden, unidas por una línea.
:::

Una lista vertical de lo que pasó, unida por una línea: cada `ui.TimelineItem` tiene un título y, si quieres, `time`, `description` e `icon` en su punto. `on_press` hace pulsables las entradas.

## Cuándo usarlo

- Para el historial de un pedido, una incidencia o un archivo, o un registro de cambios.
- Para los pasos que faltan, usa [Pasos](/pyzed/es/library/stepper/).

## Eventos

Línea de tiempo tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_press` | `(index)` | Se llama con el índice de la entrada pulsada. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Orders(pz.App):
    def __init__(self):
        self.opened = None

    def open(self, index):               # on_press: the index of the clicked entry
        self.opened = index

    def view(self):
        return ui.timeline([
            ui.TimelineItem("Order placed", time="09:12", icon="shopping-cart"),
            ui.TimelineItem("Shipped", "On its way.", time="14:30", icon="truck",
                            tint="success" if self.opened == 1 else "accent"),
        ], on_press=self.open)
```

</TabItem>
<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class Open:
    index: int


class Orders(pz.App):
    opened = None

    def update(self, message):
        match message:
            case Open(index):
                self.opened = index

    def view(self):
        return ui.timeline(["Order placed", "Shipped", "Delivered"], on_press=Open)
```

</TabItem>
<TabItem label="Funcional">

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    opened: int = -1


def view(state, set_state):
    return ui.timeline(["Order placed", "Shipped", "Delivered"], on_press=lambda index: set_state(opened=index))
```

## Propiedades y API

### `ui.timeline`

```python
timeline(items, *, on_press=None, dense=False, theme=None)
```

Sucesos en orden a lo largo de una línea: un historial, un registro de cambios, los pasos de un envío. Cada entrada lleva un punto unido al siguiente.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `items` | *obligatorio* | Objetos `ui.TimelineItem`, dicts con las mismas claves o títulos sueltos. |
| `dense` | `False` | Puntos pequeños y menos espacio. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_press` ([eventos](#eventos)).

[Referencia completa →](/pyzed/es/reference/ui/#timeline)

### `ui.TimelineItem`

```python
@dataclass
class TimelineItem(title, description=None, time=None, icon=None, tint='accent', content=None)
```

Una entrada de `ui.timeline`.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `description` | `None` | Texto atenuado bajo el título. |
| `time` | `None` | Texto a la derecha del título (una fecha, una hora). |
| `icon` | `None` | Icono dentro del punto. |
| `tint` | `"accent"` | Color del punto. |
| `content` | `None` | Cualquier widget bajo el texto. |
