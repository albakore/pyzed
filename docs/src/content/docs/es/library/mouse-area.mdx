:::tip[En pocas palabras]
Una capa invisible que permite que cualquier cosa (una imagen, una tarjeta, un dibujo) note los clics y el ratón.
:::

`pz.mouse_area` envuelve cualquier widget y avisa de lo que hace el ratón encima: pulsaciones (izquierda, derecha, central, doble clic), entrar y salir, moverse (`on_move(x, y)`) y la rueda (`on_scroll(dx, dy)`); `cursor` cambia el puntero. `pz.hover(base, top)` muestra `top` encima de `base` solo mientras el puntero está encima, y `pz.opaque` impide que los clics lleguen a lo que hay debajo de un widget en un `stack`.

## Cuándo usarlo

- Para que una tarjeta, una imagen o un dibujo propio se puedan pulsar sin convertirlos en botón.
- Para menús de clic derecho (`on_right_press`), gestos de arrastre (`on_move`) y zoom con la rueda.
- `pz.hover` para acciones que aparecen al pasar el ratón, como el botón de cerrar de una pestaña.

## Uso

```python
import pyzed as pz

class Board(pz.App):
    def __init__(self):
        self.pointer = (0, 0)
        self.zoom = 1.0

    def view(self):
        return pz.mouse_area(
            self.drawing(),
            on_move=lambda x, y: setattr(self, "pointer", (x, y)),
            on_scroll=lambda dx, dy: setattr(self, "zoom", max(0.1, self.zoom + dy * 0.1)),
            on_double_click=self.reset, cursor="crosshair",
        )
```

## API

### `pz.mouse_area`

```python
mouse_area(
    content,
    *,
    on_press=None,
    on_release=None,
    on_right_press=None,
    on_double_click=None,
    on_enter=None,
    on_exit=None,
    on_move=None,
    on_scroll=None,
    on_middle_press=None,
    on_middle_release=None,
    cursor=None,
)
```

Detecta eventos del ratón sobre su contenido.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `on_press` | `None` | Clic izquierdo (al pulsar). |
| `on_release` | `None` | Al soltar el botón izquierdo. |
| `on_right_press` | `None` | Clic derecho (menús contextuales). |
| `on_double_click` | `None` | Doble clic. |
| `on_enter` | `None` | El ratón entra. |
| `on_exit` | `None` | El ratón sale. |
| `on_move` | `None` | Se llama con `(x, y)` al mover el ratón. |
| `on_scroll` | `None` | Callable que recibe `(dx, dy)` en líneas al usar la rueda. |
| `on_middle_press` | `None` | Clic con el botón central. |
| `on_middle_release` | `None` | Se suelta el botón central (para desplazar la vista, por ejemplo). |
| `cursor` | `None` | `"pointer"`, `"text"`, `"grab"`, `"grabbing"`, `"crosshair"`, `"not-allowed"`, `"resize-horizontal"`, `"resize-vertical"`, `"move"` o `"default"`. |

[Referencia completa →](/pyzed/es/reference/widgets/#mouse_area)

### `pz.hover`

```python
hover(base, top)
```

Muestra `top` encima de `base` solo mientras el ratón está encima (por ejemplo, el botón de cerrar de una pestaña).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `base` | *obligatorio* | Widget de abajo. |
| `top` | *obligatorio* | Widget que aparece al pasar el ratón. |

[Referencia completa →](/pyzed/es/reference/widgets/#hover)

### `pz.opaque`

```python
opaque(content)
```

Hace que un widget bloquee el ratón para lo que está debajo en un `stack`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
