:::tip[En pocas palabras]
Varias secciones apiladas; cada una se abre o se cierra al pulsar su título.
:::

Secciones plegables apiladas separadas por divisores. Las secciones son tuplas `(key, title, content)` u objetos `ui.AccordionSection` (con `icon` y un widget `end` en la cabecera). El estado abierto es tuyo: `open` es un conjunto de claves, un dict `{clave: bool}` o `True`, y `on_toggle` recibe la clave.

`ui.accordion` · Categoría: [Listas y menús](/pyzed/es/library/#listas-y-menús) · [Referencia completa →](/pyzed/es/reference/ui/#accordion)

## Cuándo usarlo

- Para paneles largos de ajustes o propiedades en los que solo hacen falta algunas secciones a la vez.
- Para un solo bloque plegable, usa un [Desplegable](/pyzed/es/library/disclosure/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.open = {"editor"}

    def view(self):
        return ui.accordion(
            [("editor", "Editor", ui.muted("…")), ("files", "Files", ui.muted("…"))],
            open=self.open, on_toggle=lambda key: self.open.symmetric_difference_update({key}),
        )
```

## Eventos

Acordeón tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_toggle` | `(key)` | Se llama con la clave de la cabecera pulsada. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

```python
class Settings(pz.App):
    def __init__(self):
        self.open = {"editor"}

    def toggle(self, key):               # on_toggle: the key of the clicked header
        self.open ^= {key}

    def view(self):
        return ui.accordion([("editor", "Editor", ui.muted("Font, tabs, wrapping")),
                             ("files", "Files", ui.muted("Autosave, encoding"))],
                            open=self.open, on_toggle=self.toggle)
```

## Propiedades y API

### `ui.accordion`

```python
accordion(
    sections,
    *,
    open=(),
    on_toggle=None,
    icons=None,
    spacing=8,
    padding=(6, 12, 10, 12),
    theme=None,
)
```

Secciones plegables apiladas y separadas por divisores, como los paneles de una pantalla de ajustes. Cada cabecera ocupa todo el ancho, así que el contenido queda alineado con el resto del panel. El estado abierto es tuyo: cámbialo en `on_toggle`.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `sections` | *obligatorio* | Elementos `ui.AccordionSection(key, title, content, icon=None, end=None)` (o tuplas `(key, title, content)`). |
| `open` | `()` | El conjunto de ids abiertos, un dict `{id: bool}` o `True` para todos. |
| `icons` | `None` | `{id: icono}`: un icono de Lucide para cada cabecera. |
| `spacing` | `8` | Espacio alrededor de los divisores entre secciones. |
| `padding` | `(6, 12, 10, 12)` | Relleno alrededor del contenido de una sección abierta. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_toggle` ([eventos](#eventos)).

### `ui.AccordionSection`

```python
class AccordionSection
```

Una sección de `ui.accordion`: `key`, `title`, `content` y, opcionales, `icon` y un widget `end` en la cabecera.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `key` | *obligatorio* | Clave que identifica la suscripción (por defecto, el mensaje o la función). |
| `title` | *obligatorio* | Título. |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `end` | `None` | Widgets al final (derecha). |
