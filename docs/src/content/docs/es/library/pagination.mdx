:::tip[En pocas palabras]
Números de página con flechas, para recorrer listas largas página a página.
:::

Recorre resultados largos de página en página: `‹ 1 … 4 5 6 … 20 ›`. `page` empieza en 1; `siblings` páginas se ven a cada lado y `boundaries` en cada extremo. `compact` muestra `4 / 20`.

## Cuándo usarlo

- Bajo una tabla o una lista de resultados dividida en páginas.
- Si todo cabe con desplazamiento, una [lista virtual](/pyzed/es/library/virtual-list/) es más sencilla.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.pagination(5, 20, on_page),
    ui.pagination(1, 3, on_page),
    ui.pagination(4, 20, on_page, compact=True),
], spacing=12, align="center")
```

## Eventos

Paginación tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_change` | `(page)` | Se llama con la página pulsada. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Results(pz.App):
    def __init__(self):
        self.page = 1

    def go(self, page):                  # on_change: the page that was clicked, from 1
        self.page = page

    def view(self):
        return pz.column([ui.label(f"Results of page {self.page}"),
                          ui.pagination(self.page, 20, self.go)], spacing=8)
```

</TabItem>
<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class Page:
    number: int


class Results(pz.App):
    page = 1

    def update(self, message):
        match message:
            case Page(number):
                self.page = number

    def view(self):
        return ui.pagination(self.page, 20, Page)
```

</TabItem>
<TabItem label="Funcional">

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    page: int = 1


def view(state, set_state):
    return ui.pagination(state.page, 20, lambda page: set_state(page=page))
```

## Propiedades y API

### `ui.pagination`

```python
pagination(
    page,
    pages,
    on_change=None,
    *,
    siblings=1,
    boundaries=1,
    size='md',
    compact=False,
    theme=None,
)
```

Números de página con flechas de anterior y siguiente (`‹ 1 … 4 5 6 … 20 ›`). Las páginas empiezan en 1.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `page` | *obligatorio* | La página actual, desde 1. |
| `pages` | *obligatorio* | Cuántas páginas hay. |
| `siblings` | `1` | Páginas a cada lado de la actual. |
| `boundaries` | `1` | Páginas que siempre se ven en cada extremo. |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `compact` | `False` | Muestra `4 / 20` entre las flechas en lugar de los números. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_change` ([eventos](#eventos)).
