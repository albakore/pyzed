## Cuándo usarlo

- Para el estado siempre visible: errores y avisos, posición del cursor, lenguaje, rama de git.

## Uso

```python
from pyzed import ui

ui.status_bar(
    [ui.status_item(icon="panel-left", on_press=on_toggle, selected=True, tooltip="Project panel", keys="ctrl-b"),
     ui.status_item("0", icon="circle-x"), ui.status_item("2", icon="triangle-alert", icon_color="warning")],
    [ui.status_item("Ln 12, Col 8"), ui.status_item("UTF-8"), ui.status_item("Python", icon="file-code")],
)
```

## API

### `ui.status_bar`

```python
status_bar(start=(), end=(), *, height=28, theme=None)
```

La barra de estado inferior.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `start` | `()` | Widgets al inicio (izquierda). |
| `end` | `()` | Widgets al final (derecha). |
| `height` | `28` | Alto. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.status_item`

```python
status_item(
    content=None,
    on_press=None,
    *,
    icon=None,
    color=None,
    icon_color=None,
    selected=False,
    tooltip=None,
    keys=None,
    theme=None,
)
```

Un icono y/o texto en la barra de estado (diagnósticos, posición del cursor, lenguaje…).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | `None` | Texto. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `color` | `None` | Color del texto o del icono. |
| `icon_color` | `None` | Color del icono: un token del tema o un color hex. |
| `selected` | `False` | Lo marca como seleccionado. |
| `tooltip` | `None` | Texto del tooltip. |
| `keys` | `None` | Atajo que se muestra al final, escrito como texto: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
