## Cuándo usarlo

- Dentro de un `ui.modal` que se abre desde el menú Ayuda o con Ctrl+K Ctrl+S.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.shortcuts([
    ("File", [("Save", "ctrl-s"), ("Open file", "ctrl-p")]),
    ("View", [("Command palette", "ctrl-shift-p"), ("Toggle left dock", "ctrl-b")]),
], on_query=on_query, height=240), width=420)
```

## API

### `ui.shortcuts`

```python
shortcuts(groups, *, query='', on_query=None, height=380, theme=None)
```

Una lista de atajos de teclado agrupada y con búsqueda (para un diálogo de atajos).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `groups` | *obligatorio* | `[(título, [(etiqueta, teclas), ...]), ...]`, teclas como `"ctrl-s"`. |
| `query` | `""` | Texto del filtro. |
| `on_query` | `None` | Añade un buscador. |
| `height` | `380` | Alto de la lista. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
