:::tip[En pocas palabras]
Una caja donde la gente escribe una línea de texto: un nombre, un correo, una contraseña.
:::

Un campo de texto de una línea con el estilo del tema. Es **controlado**: muestra `value` y avisa de cada tecla a `on_input`, así que guardas el texto en tu estado y lo devuelves en `view()`. `on_submit` se ejecuta al pulsar Enter.

## Cuándo usarlo

- Para nombres, rutas, búsquedas, correos y contraseñas (`secure=True`).
- Para texto de varias líneas o código usa el [Editor](/pyzed/es/library/editor/).
- Dale un `id` para enfocarlo desde código con `pz.Command.focus(id)`.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Form(pz.App):
    def __init__(self):
        self.name = ""

    def view(self):
        return ui.input(self.name, lambda text: setattr(self, "name", text),
                        placeholder="Project name", on_submit=self.create, id="name")

    def on_start(self):
        return pz.Command.focus("name")
```

## API

### `ui.input`

```python
input(
    value,
    on_input=None,
    *,
    placeholder='',
    icon=None,
    on_submit=None,
    on_clear=None,
    id=None,
    size='md',
    secure=False,
    width='fill',
    borderless=False,
    mono=False,
    disabled=False,
    readonly=False,
    invalid=False,
    max_length=None,
    align='start',
    theme=None,
)
```

Un campo de texto. El foco, la pérdida de foco y las teclas vienen de los eventos comunes: `.on(focus=..., blur=..., key_down=...)`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Texto actual. |
| `on_input` | `None` | Callable que recibe el texto nuevo en cada pulsación. |
| `placeholder` | `""` | Texto de ayuda cuando está vacío. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `on_submit` | `None` | Mensaje o callable que se envía al pulsar Enter. |
| `on_clear` | `None` | Muestra una ✕ mientras hay texto; se envía al pulsarla. |
| `id` | `None` | Identificador estable para enfocarlo o desplazarlo con un `Command`. |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `secure` | `False` | Oculta el texto. |
| `width` | `"fill"` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `borderless` | `False` | Sin borde ni fondo (como en la paleta de comandos). |
| `mono` | `False` | Usa la fuente monoespaciada (IBM Plex Mono). |
| `disabled` | `False` | Lo atenúa e ignora lo que se escribe. |
| `readonly` | `False` | Se puede seleccionar y copiar, pero no cambiar. |
| `invalid` | `False` | Pinta el borde con el color de error. |
| `max_length` | `None` | Ignora los cambios más largos que esto. |
| `align` | `"start"` | Alineación del texto: `"start"`, `"center"` o `"end"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `pz.text_input`

```python
text_input(
    value,
    *,
    placeholder='',
    on_input=None,
    on_submit=None,
    id=None,
    size=None,
    font=None,
    padding=None,
    width=None,
    secure=False,
    icon=None,
    icon_size=None,
    bg=None,
    border_color=None,
    hover_border_color=None,
    focus_border_color=None,
    border_width=None,
    radius=None,
    color=None,
    placeholder_color=None,
    selection_color=None,
    icon_color=None,
    align_x=None,
)
```

Un campo de texto controlado: muestra `value` y te avisa de los cambios con `on_input`. Para el campo con tema usa `ui.input`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Texto actual. |
| `placeholder` | `""` | Texto de ayuda cuando está vacío. |
| `on_input` | `None` | Callable que recibe el texto nuevo en cada pulsación. |
| `on_submit` | `None` | Mensaje o callable que se envía al pulsar Enter. |
| `id` | `None` | Identificador estable para enfocarlo o desplazarlo con un `Command`. |
| `size` | `None` | Tamaño de la fuente. |
| `font` | `None` | Familia de la fuente. |
| `padding` | `None` | Relleno interior: `8`, `(vertical, horizontal)` o `(arriba, derecha, abajo, izquierda)`. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `secure` | `False` | Oculta el texto (contraseñas). |
| `icon` | `None` | Carácter del icono (usa `pyzed.icons.glyph(nombre)`). |
| `icon_size` | `None` | Tamaño del icono. |
| `bg` | `None` | Color de fondo (`"#rrggbb[aa]"`, `(r, g, b[, a])` o `"transparent"`). |
| `border_color` | `None` | Color del borde. |
| `hover_border_color` | `None` | Color del borde al pasar el ratón. |
| `focus_border_color` | `None` | Color del borde con el foco. |
| `border_width` | `None` | Grosor del borde en píxeles. |
| `radius` | `None` | Radio de las esquinas: un número o `(sup_izq, sup_der, inf_der, inf_izq)`. |
| `color` | `None` | Color del texto o del icono. |
| `placeholder_color` | `None` | Color del placeholder. |
| `selection_color` | `None` | Color de la selección. |
| `icon_color` | `None` | Color del icono. |
| `align_x` | `None` | Alineación horizontal: `"start"`/`"left"`, `"center"`, `"end"`/`"right"`. |
