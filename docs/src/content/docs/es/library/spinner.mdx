## Cuándo usarlo

- Para esperas cortas de duración desconocida: conectando, buscando, cargando un archivo.
- Para trabajos largos con avance conocido usa [Progreso](/pyzed/es/library/progress/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Loader(pz.App):
    def __init__(self):
        self.loading = True

    def subscription(self):
        return pz.every(1 / 30, lambda: None) if self.loading else None

    def view(self):
        return ui.spinner() if self.loading else ui.label("Done")
```

## API

### `ui.spinner`

```python
spinner(*, size=16, tint='accent', speed=1.0, theme=None)
```

Un arco que gira para estados de carga. Su ángulo sale del reloj, así que mantén una suscripción `pz.every(1/30, ...)` activa mientras se muestra.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `size` | `16` | Tamaño. |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `speed` | `1.0` | Vueltas por segundo. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
