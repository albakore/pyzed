## Cuándo usarlo

- Arriba de cada dock (Proyecto, Esquema, Terminal) para nombrarlo y poner sus acciones.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.panel_header("Project", [ui.icon_button("plus", on_new, size="xs"),
                                ui.icon_button("ellipsis", on_menu, size="xs")]),
    ui.panel_header("Terminal", [ui.icon_button("x", on_close, size="xs")], icon="terminal"),
], spacing=12, width=320)
```

## Propiedades y API

### `ui.panel_header`

```python
panel_header(title, actions=(), *, icon=None, height=32, theme=None)
```

La cabecera de un panel: icono, título y acciones.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `actions` | `()` | Widgets extra (normalmente botones) que se muestran como acciones. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `height` | `32` | Alto. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
