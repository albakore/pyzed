:::tip[En pocas palabras]
Una lista de mensajes de la app (información, avisos, errores) que puedes filtrar y copiar.
:::

`ui.Log` reúne entradas (seguro entre hilos, con un tope de `limit`, líneas repetidas agrupadas) y puede capturar `print` y las trazas de error. `ui.console` las muestra como la consola de las dev tools de un navegador: un filtro, un interruptor por nivel con su cuenta, copiar y limpiar. Los niveles son `info`, `event`, `stdout`, `stderr`, `warning` y `error` (`ui.LOG_LEVELS`).

## Cuándo usarlo

- Para un panel de depuración en tu app, o para mostrar lo que hace una tarea en segundo plano.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Debug(pz.App):
    def __init__(self):
        self.log = ui.Log(on_write=lambda: pz.post("log"))  # redraw when a line arrives
        self.log.capture()                                   # also collect print() and stderr
        self.query, self.hidden = "", set()

    def view(self):
        return ui.console(self.log.entries, query=self.query,
                          on_query=lambda q: setattr(self, "query", q),
                          hidden=self.hidden, on_toggle_level=lambda lvl: self.hidden.symmetric_difference_update({lvl}),
                          on_clear=self.log.clear, on_copy=lambda: pz.Command.copy(self.log.text()))
```

## API

### `ui.console`

```python
console(
    entries,
    *,
    query='',
    on_query=None,
    hidden=(),
    on_toggle_level=None,
    on_clear=None,
    on_copy=None,
    actions=(),
    font_size=12.5,
    id=None,
    theme=None,
)
```

Una vista de registro como la consola de las herramientas de desarrollo del navegador: filtro, un botón por nivel con su cuenta, copiar y limpiar, y las entradas en monoespaciada, siempre desplazada a la más nueva.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `entries` | *obligatorio* | Elementos `ui.LogEntry` (`log.entries`). |
| `query` | `""` | Texto del filtro. |
| `on_query` | `None` | Recibe cada edición del filtro. |
| `hidden` | `()` | Niveles ocultos. |
| `on_toggle_level` | `None` | Se llama con el nivel del botón pulsado. |
| `on_clear` | `None` | Añade el botón Limpiar. |
| `on_copy` | `None` | Añade el botón Copiar. |
| `actions` | `()` | Widgets extra al final de la barra. |
| `font_size` | `12.5` | Tamaño de las entradas. |
| `id` | `None` | Id del scrollable. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.Log`

```python
class Log
```

Las entradas de un `ui.console`: seguro entre hilos, limitado a `limit` y con las líneas repetidas agrupadas. `write(level, text)` añade una línea; `capture()` (o `with log:`) copia la salida de `print` y los tracebacks; `pipe(stream)` lee la salida de un subproceso en segundo plano; `text()` devuelve todo para copiarlo.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `limit` | `5000` | Máximo de entradas guardadas. |
| `on_write` | `None` | Se llama tras cada escritura (desde cualquier hilo). |

[Referencia completa →](/pyzed/es/reference/ui/#log)

### `ui.LogEntry`

```python
@dataclass
class LogEntry(level, text, time=time.time(), count=1)
```

Una línea de un `ui.Log`: `level`, `text`, `time`, `count` (líneas idénticas seguidas) y `clock` (`HH:MM:SS`).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `level` | *obligatorio* | Nivel. |
| `text` | *obligatorio* | La línea. |
| `time` | `time()` | Cuándo se escribió (`time.time()`). |
| `count` | `1` | Líneas idénticas seguidas. |

[Referencia completa →](/pyzed/es/reference/ui/#logentry)

### `ui.LOG_LEVELS`

Los niveles que colorea `ui.console`, en el orden de sus filtros: info, event, stdout, stderr, warning, error.
