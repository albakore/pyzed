`pz.shader` ejecuta una función que escribes en WGSL, `fn shade(uv, px, size, time) -> vec4<f32>`, para cada píxel del widget, en cada fotograma, en la GPU: fondos animados, plasma, fuego o el barrido de un radar no le cuestan nada a Python. Cada entrada de `uniforms` se convierte en una función WGSL con el mismo nombre, y `mouse()` da la posición del puntero. Sin GPU el widget muestra `fallback`. Ver la [guía de shaders](/pyzed/es/guides/shaders/) y las [demos](/pyzed/es/showcase/).

## Cuándo usarlo

- Para fondos animados detrás de paneles de cristal, menús y HUDs.
- Para gráficos y efectos de juegos que serían demasiado lentos de dibujar desde Python en cada fotograma.

## Uso

```python
import pyzed as pz

pz.shader("""
fn shade(uv: vec2<f32>, px: vec2<f32>, size: vec2<f32>, time: f32) -> vec4<f32> {
    let wave = 0.5 + 0.5 * sin(uv.x * 12.0 + uv.y * 4.0 + time * speed());
    return vec4<f32>(mix(vec3<f32>(0.08, 0.09, 0.2), tint().rgb, wave), 1.0);
}
""", uniforms={"speed": 2.0, "tint": "#c678dd"}, width=640, height=240, time=0.5,
    fallback=pz.Gradient(["#14172f", "#c678dd"], angle=0))
```

## Consejos

Los shaders necesitan el renderizador de GPU. Pasa siempre un `fallback` que se vea bien por sí solo: es lo que dibujan el renderizador por software y los equipos sin GPU.

## API

### `pz.shader`

```python
shader(
    code,
    *,
    uniforms=None,
    width=None,
    height=None,
    animate=True,
    time=None,
    fallback=None,
)
```

Un widget que pinta la GPU con tu función WGSL `fn shade(uv, px, size, time) -> vec4<f32>`, que devuelve el color de cada píxel. Cada entrada de `uniforms` se convierte en una función con su nombre (`{"speed": 2}` -> `speed()`); `mouse()` da la posición del puntero. Sin GPU el widget muestra `fallback`. Lanza `ValueError` con el mensaje del compilador si el código no es válido. Ver la guía de [shaders](/pyzed/es/guides/shaders/).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `code` | *obligatorio* | Código WGSL que define `shade` (y las funciones auxiliares que quieras). |
| `uniforms` | `None` | Hasta 8 valores con nombre: un número, de 2 a 4 números o un color. |
| `width` | `None` | Ancho (`"fill"` por defecto). |
| `height` | `None` | Alto (`"fill"` por defecto). |
| `animate` | `True` | Redibuja en cada frame para que avance `time` (`True`). |
| `time` | `None` | Un `time` fijo en segundos, para un fotograma quieto. |
| `fallback` | `None` | Color o degradado que se muestra sin GPU. |
