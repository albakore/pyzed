:::tip[En pocas palabras]
Una superficie pintada por la tarjeta gráfica, para fondos en movimiento y efectos visuales.
:::

`pz.shader` ejecuta una función que escribes en WGSL, `fn shade(uv, px, size, time) -> vec4<f32>`, para cada píxel del widget, en cada fotograma, en la GPU: fondos animados, plasma, fuego o el barrido de un radar no le cuestan nada a Python. Cada entrada de `uniforms` se convierte en una función WGSL con el mismo nombre, y `mouse()` da la posición del puntero. Sin GPU el widget muestra `fallback`. Ver la [guía de shaders](/pyzed/es/shading/shaders/) y las [demos](/pyzed/es/showcase/).

## Cuándo usarlo

- Para fondos animados detrás de paneles de cristal, menús y HUDs.
- Para gráficos y efectos de juegos que serían demasiado lentos de dibujar desde Python en cada fotograma.

## Uso

## Consejos

:::tip
Los shaders necesitan el renderizador de GPU. Pasa siempre un `fallback` que se vea bien por sí solo: es lo que dibujan el renderizador por software y los equipos sin GPU.
:::

## API

### `pz.shader`

```python
shader(
    code,
    *,
    uniforms=None,
    textures=None,
    width=None,
    height=None,
    animate=True,
    time=None,
    fallback=None,
)
```

Un widget que pinta la GPU con tu función WGSL `fn shade(uv, px, size, time) -> vec4<f32>`, que devuelve el color de cada píxel, o con un grafo de shader hecho de nodos (una ruta `.pzshad` o un `Graph` o `Shader` de [`pyzed.shading`](/pyzed/es/reference/shading/)). Cada entrada de `uniforms` se convierte en una función con su nombre (`{"speed": 2}` -> `speed()`); `mouse()` da la posición del puntero. Sin GPU el widget muestra `fallback`. Lanza `ValueError` con el mensaje del compilador si el código no es válido. Ver la guía de [shaders](/pyzed/es/shading/shaders/).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `code` | *obligatorio* | Código WGSL que define `shade` (y las funciones auxiliares que quieras), o una ruta `.pzshad`, un `Graph` o un `Shader`. |
| `uniforms` | `None` | Hasta 32 valores con nombre: un número, de 2 a 4 números o un color. Con un `.pzshad`, las variables mutables del shader por nombre. |
| `textures` | `None` | Hasta 8 imágenes, `{nombre: ruta}`: cada una se convierte en `nombre(uv)`, el color de la imagen en `uv`. |
| `width` | `None` | Ancho (`"fill"` por defecto). |
| `height` | `None` | Alto (`"fill"` por defecto). |
| `animate` | `True` | Redibuja en cada frame para que avance `time` (`True`). |
| `time` | `None` | Un `time` fijo en segundos, para un fotograma quieto. |
| `fallback` | `None` | Color o degradado que se muestra sin GPU. |
