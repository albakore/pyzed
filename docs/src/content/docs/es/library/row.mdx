:::tip[En pocas palabras]
Pone las cosas una al lado de la otra, de izquierda a derecha.
:::

Coloca sus hijos en horizontal, con `spacing` entre ellos y `align` en el eje cruzado. `wrap=True` pasa a la línea siguiente los hijos que no caben. Las listas se aplanan y se ignoran `None`/`False`, así que `cond and widget` funciona.

`pz.row` · Categoría: [Disposición](/pyzed/es/library/#disposición) · [Referencia completa →](/pyzed/es/reference/widgets/#row)

## Cuándo usarlo

- Para barras, grupos de botones, filas de formulario: todo lo que va lado a lado.
- Separa elementos con `pz.hspace()` entre ellos.

## Uso

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.row([box("A"), box("B"), box("C")], spacing=8),
    pz.row([box("Start"), pz.hspace(), box("End")], spacing=8, width=420),
    pz.row([box("tall", h=70), box("center"), box("end")], spacing=8, align="center"),
], spacing=14)
```

## Propiedades y API

### `pz.row`

```python
row(
    children=None,
    *,
    spacing=0.0,
    padding=None,
    width=None,
    height=None,
    align=None,
    clip=False,
    wrap=False,
    line_spacing=None,
)
```

Coloca los hijos en horizontal.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `children` | `None` | Lista de hijos. Se aplanan listas anidadas y se ignoran `None` y `False`, así que puedes escribir `cond and widget`. |
| `spacing` | `0.0` | Separación entre hijos, en píxeles. |
| `padding` | `None` | Relleno interior: `8`, `(vertical, horizontal)` o `(arriba, derecha, abajo, izquierda)`. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `align` | `None` | Alineación de los hijos en el eje cruzado: `"start"`, `"center"` o `"end"`. |
| `clip` | `False` | Recorta el contenido que se sale de los límites. |
| `wrap` | `False` | Ajuste de línea / pasa los hijos a una nueva fila cuando no caben. |
| `line_spacing` | `None` | Separación entre filas cuando `wrap=True`. |
