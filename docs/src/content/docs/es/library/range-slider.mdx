:::tip[En pocas palabras]
Una barra con dos asas para elegir “desde tanto hasta tanto”.
:::

Elige un rango, como un precio de 20 a 80. `value` es `(bajo, alto)` y `on_change` recibe el par nuevo. Al pulsar la barra se mueve allí el tirador más cercano y al arrastrar sigue moviéndose; nunca se cruzan.

`ui.range_slider` · Categoría: [Formularios](/pyzed/es/library/#formularios) · [Referencia completa →](/pyzed/es/reference/ui/#range_slider)

## Cuándo usarlo

- Para filtrar por un rango: precios, fechas, tamaños, años.
- Para un solo número, usa [Deslizador](/pyzed/es/library/slider/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Shop(pz.App):
    def __init__(self):
        self.price = (20, 80)

    def view(self):
        return ui.range_slider(self.price, lambda value: setattr(self, "price", value),
                               min=0, max=500, step=5, show_value="{:.0f} €")
```

## Eventos

Deslizador de rango tiene **2 eventos propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_change` | `((low, high))` | Función que recibe el nuevo `(bajo, alto)`. |
| `on_release` | `()` | Se envía al soltar el tirador (guarda o aplica ahí). |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Shop(pz.App):
    def __init__(self):
        self.price = (20, 80)

    def set_price(self, value):          # on_change: the new (low, high)
        self.price = value

    def search(self):                    # on_release: the knob was let go
        print("search", self.price)

    def view(self):
        return ui.range_slider(self.price, self.set_price, min=0, max=100, step=5,
                               on_release=self.search, show_value=True)
```

```python
from dataclasses import dataclass


@dataclass
class Price:
    value: tuple


class Shop(pz.App):
    price = (20, 80)

    def update(self, message):
        match message:
            case Price(value):
                self.price = value

    def view(self):
        return ui.range_slider(self.price, Price, min=0, max=100, step=5)
```

## Propiedades y API

### `ui.range_slider`

```python
range_slider(
    value,
    on_change=None,
    *,
    min=0.0,
    max=1.0,
    step=0.01,
    min_gap=0.0,
    on_release=None,
    width='fill',
    tint='accent',
    disabled=False,
    show_value=False,
    theme=None,
)
```

Un deslizador con dos tiradores que elige un rango. Al pulsar la barra se mueve allí el tirador más cercano y al arrastrar sigue moviéndose; los tiradores nunca se cruzan.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | `(bajo, alto)`. |
| `min` | `0.0` | Valor más pequeño. |
| `max` | `1.0` | Valor más grande. |
| `step` | `0.01` | Los valores se ajustan a múltiplos de esto. |
| `min_gap` | `0.0` | Distancia mínima entre los dos tiradores. |
| `width` | `"fill"` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `tint` | `"accent"` | Color del rango entre los tiradores. |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `show_value` | `False` | Añade `bajo – alto` al lado: `True` o un formato para cada extremo, como `"{:.0f} €"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_change`, `on_release` ([eventos](#eventos)).
