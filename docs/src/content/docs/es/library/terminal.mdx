:::tip[En pocas palabras]
Muestra el texto que imprime un programa, con sus colores, como una ventana de terminal.
:::

Una vista de solo lectura que entiende los colores ANSI y se queda al final. Pásale la salida de un proceso que ejecutes (por ejemplo con `subprocess` en un hilo y `pz.post`). También acepta líneas de segmentos `(texto, color)`; `ui.ansi(text)` convierte texto ANSI en esos segmentos.

## Cuándo usarlo

- Para mostrar la salida de una compilación, tests, registros de un servidor o cualquier comando.

## Uso

```python
import pyzed as pz
from pyzed import ui

out = ("$ pytest -q\n\x1b[32m........................\x1b[0m\n\x1b[32m24 passed\x1b[0m in 1.21s\n"
       "$ maturin develop --release\n\x1b[2m   Compiling pyzed v0.4.0\x1b[0m\n"
       "\x1b[32m✓\x1b[0m Installed pyzed-0.4.0\n$ ")
pz.container(ui.terminal(out), width=560, height=190)
```

## Propiedades y API

### `ui.terminal`

```python
terminal(lines, *, font_size=13, id=None, theme=None)
```

Una vista de terminal de solo lectura con colores ANSI. Se mantiene desplazada al final.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `lines` | *obligatorio* | Texto con escapes ANSI o lista de líneas de segmentos `(texto, color)`. |
| `font_size` | `13` | Tamaño de la fuente. |
| `id` | `None` | Identificador estable para enfocarlo o desplazarlo con un `Command`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

[Referencia completa →](/pyzed/es/reference/ui/#terminal)

### `ui.ansi`

```python
ansi(text)
```

Convierte texto con colores ANSI en líneas de segmentos `(texto, nombre_de_color)`.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `text` | *obligatorio* | Texto con escapes ANSI. |

[Referencia completa →](/pyzed/es/reference/ui/#ansi)
