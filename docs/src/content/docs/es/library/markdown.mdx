## Cuándo usarlo

- Para READMEs, notas de versión, páginas de ayuda y mensajes de chat.

## Uso

```python
from pyzed import ui

ui.markdown('''## Release notes

Pyzed **0.4** adds the *component designer*, `pyzed build` and [styles](https://iced.rs).

- Track grids and flex
- Ready-made dialogs
''', width=460, on_link=on_link)
```

## API

### `ui.markdown`

```python
markdown(source, *, size=None, on_link=None, width=None, theme=None)
```

`pz.markdown` con los colores de texto, enlaces y código del tema.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `source` | *obligatorio* | El texto Markdown. |
| `size` | `None` | Tamaño. |
| `on_link` | `None` | Callable que recibe la URL al pulsar un enlace. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `pz.markdown`

```python
markdown(
    source,
    *,
    size=14.0,
    color=None,
    link_color=None,
    code_color=None,
    code_bg=None,
    on_link=None,
    width=None,
)
```

Renderiza Markdown (títulos, listas, bloques de código, citas, tablas, enlaces…). Para los colores del tema usa `ui.markdown`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `source` | *obligatorio* | El texto Markdown. |
| `size` | `14.0` | Tamaño. |
| `color` | `None` | Color del texto o del icono. |
| `link_color` | `None` | Color de los enlaces. |
| `code_color` | `None` | Color del código. |
| `code_bg` | `None` | Fondo del código. |
| `on_link` | `None` | Callable que recibe la URL al pulsar un enlace. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
