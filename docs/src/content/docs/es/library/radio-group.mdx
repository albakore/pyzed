## Cuándo usarlo

- Cuando cada opción necesita su etiqueta y conviene verlas todas (indentación: espacios o tabuladores).
- Para muchas opciones usa un [Select](/pyzed/es/library/select/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.indent = "spaces"

    def view(self):
        return ui.radio_group([("spaces", "Spaces"), ("tabs", "Tabs")], self.indent,
                              lambda value: setattr(self, "indent", value))
```

## API

### `ui.radio_group`

```python
radio_group(
    options,
    selected,
    on_select=None,
    *,
    horizontal=False,
    spacing=8,
    theme=None,
)
```

Opciones mutuamente excluyentes como botones de radio.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `options` | *obligatorio* | Textos o pares `(valor, etiqueta)`. |
| `selected` | *obligatorio* | Valor actual. |
| `on_select` | `None` | Callable que recibe el valor elegido. |
| `horizontal` | `False` | En fila en lugar de columna. |
| `spacing` | `8` | Separación entre hijos, en píxeles. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
