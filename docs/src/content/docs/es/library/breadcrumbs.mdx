## Cuándo usarlo

- Encima de un editor o una vista anidada, para mostrar dónde estás y saltar a un nivel superior.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.breadcrumbs(["src", "ui", "button.rs"]),
    ui.breadcrumbs([("folder", "src"), ("file-code", "main.rs"), "fn main"], on_press=on_press),
    ui.breadcrumbs(["Settings", "Editor", "Font"], separator="/"),
], spacing=14)
```

## API

### `ui.breadcrumbs`

```python
breadcrumbs(parts, *, separator='›', on_press=None, theme=None)
```

`src › main.rs › fn main`. Las partes pueden ser textos o tuplas `(icono, texto)`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `parts` | *obligatorio* | Las partes. |
| `separator` | `"›"` | Separador. |
| `on_press` | `None` | Se llama con el índice de la parte pulsada. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
