## Cuándo usarlo

- Para avisar de algo que hay que confirmar (una exportación terminó, un archivo no se pudo abrir).

## Uso

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.alert("The export finished: 128 files were written.", on_close,
                                      title="Export", kind="success", width=360))
```

## API

### `ui.alert`

```python
alert(message, on_close, *, title=None, kind=None, ok_label=None, width=400, theme=None)
```

Un mensaje con un botón.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `message` | *obligatorio* | Texto o widget. |
| `on_close` | *obligatorio* | El botón y el icono de cerrar. |
| `title` | `None` | Título. |
| `kind` | `None` | `"info"`, `"success"`, `"warning"` o `"error"` añade un icono. |
| `ok_label` | `None` | Texto del botón (por defecto: Aceptar, traducido). |
| `width` | `400` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
