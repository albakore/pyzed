Coloca los hijos en un eje como el flexbox de CSS: `justify` en el eje principal (`start`, `center`, `end`, `between`, `around`, `evenly`), `align` en el eje cruzado, `gap` y `wrap`. `pz.flex_item(child, grow=, basis=)` hace crecer a un hijo o le da un tamaño base.

## Cuándo usarlo

- Cuando `row`/`column` no bastan: reparto uniforme, elementos que crecen, tarjetas que saltan de línea.

## Uso

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.flex([box("A"), box("B"), box("C")], justify="between", width=440),
    pz.flex([box("fixed"), pz.flex_item(box("grows", w="fill"), grow=1), box("fixed")], gap=8, width=440),
    pz.flex([box("A"), box("B")], justify="center", gap=8, width=440),
], spacing=14)
```

## API

### `pz.flex`

```python
flex(
    children=(),
    *,
    direction='row',
    justify='start',
    align='start',
    gap=0,
    wrap=False,
    padding=None,
    width=None,
    height=None,
)
```

Coloca los hijos a lo largo de un eje, como flexbox de CSS, con `justify` en el eje principal y `align` en el transversal. Usa `pz.flex_item` para que un hijo crezca o tenga un tamaño fijo.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `children` | `()` | Los widgets, o `pz.flex_item(...)` para hijos con su propio tamaño. |
| `direction` | `"row"` | `"row"` o `"column"`. |
| `justify` | `"start"` | `"start"`, `"center"`, `"end"`, `"between"`, `"around"` o `"evenly"`. No tiene efecto si algún hijo crece. |
| `align` | `"start"` | Alineación transversal: `"start"`, `"center"` o `"end"`. |
| `gap` | `0` | Espacio entre hijos. |
| `wrap` | `False` | Pasa a nuevas líneas (solo filas con `justify="start"`). |
| `padding` | `None` | Espacio alrededor de los hijos. |
| `width` | `None` | Ancho. |
| `height` | `None` | Alto. |

### `pz.flex_item`

```python
flex_item(content, *, grow=1, basis=None, align=None)
```

Da tamaño a un hijo de `pz.flex`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | El widget. |
| `grow` | `1` | Parte del espacio libre en el eje principal (`0` mantiene su tamaño natural). |
| `basis` | `None` | Un tamaño fijo en píxeles en el eje principal, en lugar de crecer. |
| `align` | `None` | Alineación transversal de este hijo. |
