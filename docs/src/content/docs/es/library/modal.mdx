Una superficie de diálogo con título, botón de cerrar, tu contenido y un pie de botones. Úsala como capa de `ui.layer` o `ui.dialog_layer`. Los [diálogos](/pyzed/es/library/confirm/) listos para usar están hechos con ella.

## Cuándo usarlo

- Para diálogos con tu propio contenido: un formulario, ajustes, una caja Acerca de.

## Uso

```python
from pyzed import ui

ui.modal(
    ui.muted("notes.py has unsaved changes. Save them before closing?"),
    title="Save changes?",
    on_close=on_close,
    footer=[ui.button("Don't save", on_discard, variant="ghost"), ui.button("Cancel", on_close),
            ui.button("Save", on_save, variant="solid")],
    width=440,
)
```

## API

### `ui.modal`

```python
modal(
    content,
    *,
    title=None,
    on_close=None,
    width=480,
    footer=(),
    description=None,
    icon=None,
    max_height=None,
    theme=None,
)
```

Un diálogo. Úsalo como `overlay` de `ui.layer`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `title` | `None` | Título. |
| `on_close` | `None` | El botón de cerrar; también lo envía Escape mientras el diálogo tiene el foco. |
| `width` | `480` | Píxeles o `"sm"` (360), `"md"` (480), `"lg"` (640) o `"xl"` (820). |
| `footer` | `()` | Botones del pie, alineados a la derecha. |
| `description` | `None` | Línea atenuada bajo el título. |
| `icon` | `None` | Icono antes del título. |
| `max_height` | `None` | Desplaza el contenido más alto que esto, sin ocultar la cabecera ni el pie. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
