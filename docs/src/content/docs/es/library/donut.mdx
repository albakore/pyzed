## Cuándo usarlo

- Para mostrar las partes de un todo (uso de disco, lenguajes de un proyecto) con tres o cuatro porciones.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.donut([60, 25, 15], label="60%"),
    ui.donut([45, 35, 20], colors=["#e5c07b", "#c678dd", "#56b6c2"], size=120, thickness=20, label="3"),
], spacing=32, align="center")
```

## API

### `ui.donut`

```python
donut(values, *, colors=None, size=96, thickness=14, label=None, theme=None)
```

Un gráfico de anillo; `label` se dibuja en el centro.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `values` | *obligatorio* | Valores. |
| `colors` | `None` | Colores (por defecto, los del tema). |
| `size` | `96` | Tamaño. |
| `thickness` | `14` | Grosor del anillo. |
| `label` | `None` | Texto central. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
