## Uso

```python
import pyzed as pz
from pyzed import draw

pz.canvas([
    draw.rect(10, 10, 120, 80, fill="#74ade8", radius=8),
    draw.circle(200, 50, 40, fill="#a1c181"),
    draw.arc(300, 50, 40, 0, 270, stroke="#e5c07b", width=8, cap="round"),
    draw.polygon([(360, 90), (400, 10), (440, 90)], fill="#d07277"),
    draw.line(10, 120, 440, 120, stroke="#5d636f", width=2, dash=[6, 4]),
```

## API

### `pz.canvas`

```python
canvas(
    shapes=None,
    *,
    width=None,
    height=None,
    id=None,
    on_press=None,
    on_release=None,
    on_right_press=None,
    on_move=None,
    on_scroll=None,
    cursor=None,
)
```

Una superficie de dibujo 2D. `shapes` es una lista creada con [`pyzed.draw`](/pyzed/es/reference/draw/). Los callbacks del ratón reciben coordenadas relativas al canvas. Con un `id`, la geometría se cachea entre frames y solo se recalcula cuando cambian las formas. Ver la guía de [dibujo con canvas](/pyzed/es/guides/canvas/).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `shapes` | `None` | Lista de formas de `pyzed.draw` (se aceptan listas anidadas). |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `id` | `None` | Activa la caché de geometría. |
| `on_press` | `None` | Callable que recibe `(x, y)` al pulsar. |
| `on_release` | `None` | Callable que recibe `(x, y)` al soltar. |
| `on_right_press` | `None` | Callable que recibe `(x, y)` con clic derecho. |
| `on_move` | `None` | Se llama con `(x, y)` al mover el ratón. |
| `on_scroll` | `None` | Callable que recibe `(dx, dy)` en líneas al usar la rueda. |
| `cursor` | `None` | Cursor del ratón (`"crosshair"`, `"pointer"`…). |
