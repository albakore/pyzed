## Cuándo usarlo

- Para estados cortos de solo lectura: `beta`, `M` (modificado), `v0.4`, `3 errores`.
- Para un número redondo encima de un icono usa [Contador](/pyzed/es/library/count-badge/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.badge("accent"),
    ui.badge("success", tint="success"),
    ui.badge("warning", tint="warning"),
    ui.badge("error", tint="error", icon="circle-x"),
], spacing=8)
```

## API

### `ui.badge`

```python
badge(content, *, tint='accent', variant='soft', icon=None, theme=None)
```

Una píldora pequeña para estados y contadores.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `variant` | `"soft"` | `"soft"`, `"solid"` o `"outline"`. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
