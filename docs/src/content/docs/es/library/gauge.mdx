:::tip[En pocas palabras]
Media circunferencia, como el velocímetro de un coche, que muestra un número.
:::

Muestra un número entre `min` y `max` sobre un arco, como un velocímetro: uso de CPU, temperatura, una nota. `thresholds` cambia el color del arco al subir el valor.

## Cuándo usarlo

- En paneles, para un valor con un rango y unos límites conocidos.
- Para un valor a lo largo del tiempo, usa un [gráfico de líneas](/pyzed/es/library/line-chart/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.gauge(42, unit="%", label="CPU"),
    ui.gauge(78, unit="°C", label="GPU", thresholds=[(70, "warning"), (90, "error")]),
], spacing=24)
```

## Propiedades y API

### `ui.gauge`

```python
gauge(
    value,
    *,
    min=0.0,
    max=100.0,
    size=140,
    thickness=12,
    unit='',
    label=None,
    tint='accent',
    thresholds=None,
    theme=None,
)
```

Un medidor de media circunferencia para un número, como un velocímetro. `thresholds` cambia el color del arco al subir el valor.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | El número que se muestra. |
| `min` | `0.0` | Valor del extremo izquierdo. |
| `max` | `100.0` | Valor del extremo derecho. |
| `size` | `140` | Ancho en píxeles. |
| `thickness` | `12` | Grosor del arco. |
| `unit` | `""` | Texto tras el número (`"%"`, `"°C"`). |
| `label` | `None` | Texto bajo el número. |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `thresholds` | `None` | Pares `(desde_valor, color)`, como `[(70, "warning"), (90, "error")]`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
