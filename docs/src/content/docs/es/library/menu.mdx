:::tip[En pocas palabras]
La lista de opciones que aparece al hacer clic derecho o pulsar un botón de “más”.
:::

Un menú contextual flotante. Las entradas son `ui.MenuItem(label, on_press, icon=, keys=, checked=, danger=, disabled=)`; `ui.SEPARATOR` dibuja una línea entre grupos y una cadena es una cabecera. Muéstralo con un [Popover](/pyzed/es/library/popover/) o una [Capa](/pyzed/es/library/layer/).

## Cuándo usarlo

- Para menús de clic derecho y las opciones de un botón dividido o de puntos suspensivos.
- Marca las acciones destructivas con `danger=True` y ponlas al final.

## Uso

```python
from pyzed import ui

ui.menu([
    ui.MenuItem("New file", on_new, icon="file-plus", keys="ctrl-n"),
    ui.MenuItem("New folder", on_new_folder, icon="folder-plus"),
    ui.SEPARATOR,
    "EDIT",
    ui.MenuItem("Copy path", on_copy, keys="ctrl-alt-c"),
    ui.MenuItem("Soft wrap", on_wrap, checked=True),
    ui.SEPARATOR,
    ui.MenuItem("Delete", on_delete, icon="trash-2", danger=True),
])
```

## API

### `ui.menu`

```python
menu(items, *, width=240, theme=None)
```

Un menú contextual flotante. Usa `ui.SEPARATOR` entre grupos; un texto suelto es un encabezado.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `items` | *obligatorio* | Lista de `MenuItem`, `ui.SEPARATOR` o textos. |
| `width` | `240` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

[Referencia completa →](/pyzed/es/reference/ui/#menu)

### `ui.MenuItem`

```python
@dataclass
class MenuItem(label, on_press=None, icon=None, keys=None, disabled=False, danger=False, checked=None)
```

Una entrada de `ui.menu`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `label` | *obligatorio* | Texto de la etiqueta. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `keys` | `None` | Atajo que se muestra al final, escrito como texto: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `danger` | `False` | En rojo (acciones destructivas). |
| `checked` | `None` | Muestra una marca (`True`/`False`) o nada (`None`). |
