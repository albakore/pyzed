Los efectos visuales son propiedades de [estilo](/pyzed/es/guides/styles/): `glow` (un halo suave), `bloom` (un resplandor amplio y brillante), `glass` (un panel translúcido y esmerilado), `opacity`, y `translate` y `scale`, que desplazan o escalan el dibujo sin cambiar el layout. Las animaciones también pueden cambiar `glow`.

## Cuándo usarlo

- Para destacar la acción principal o un estado en vivo (grabando, conectado).
- Para paneles flotantes sobre fondos coloridos (glass).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.container(pz.row([
    pz.container(ui.label("Glass"), width=150, height=70, padding=14).style(glass=True, radius=12),
    pz.container(ui.label("Glow"), width=150, height=70, padding=14).style(
        background="#0b1220", radius=12, glow=("#22d3ee", 18)),
    pz.container(ui.label("Bloom"), width=150, height=70, padding=14).style(
        background="#1a0b16", radius=12, bloom=("#f472b6", 0.8)),
    pz.container(ui.label("Opacity"), width=150, height=70, padding=14).style(
        background="#0b1220", radius=12, opacity=0.5),
], spacing=24), padding=32).style(
    background=pz.Gradient(["#0f172a", "#312e81", "#0e7490"], angle=90), radius=14)
```

## API

### `pz.Style`

```python
class Style
```

Un conjunto reutilizable de propiedades de estilo para `widget.style(...)`, el `style=` de un componente o `App.style`. Combina estilos con `|` (gana el de la derecha). Ver [Estilos](/pyzed/es/guides/styles/).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `*styles` | — | Estilos, dicts o nombres de estilo de partida. |
| `**props` | — | Propiedades: `background`, `color`, `font`, `weight`, `italic`, `size`, `line_height`, `border_color`, `border_width`, `border` (`(ancho, color)`), `radius`, `shadow`, `padding`, `margin`, `width`, `height`, `max_width`, `max_height`, `align_x`, `align_y`, `clip`. Efectos: `opacity`, `translate` (`(x, y)`, píxeles o `"50%"`), `scale`, `glow` (un color, un tamaño o `(color, tamaño)`), `bloom` (un color o `(color, intensidad)`) y `glass` (`True`, un tinte o `{"tint", "strength"}`). Los colores pueden ser tokens del tema. |
