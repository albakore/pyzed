:::tip[En pocas palabras]
Dibujos pequeños (una carpeta, una campana, un engranaje) de una biblioteca de más de 1.500.
:::

`pz.icon(name)` dibuja uno de los más de 1.500 iconos de [Lucide](https://lucide.dev); `color` toma por defecto el color del texto. `pz.svg(source)` dibuja cualquier SVG desde una ruta o bytes, teñido con `color` si quieres.

## Cuándo usarlo

- Dentro de botones, filas y cabeceras. Ejecuta `pyzed icons` para buscar los nombres.

## Uso

```python
import pyzed as pz

pz.row([
    pz.icon("sparkles", size=28, color="#e5c07b"),
    pz.icon("git-branch", size=28, color="#a1c181"),
```

### SVG

`color` pinta cada píxel visible del SVG de un color y deja los transparentes, como el tinte de un icono. Un SVG con fondo relleno, como `logo.svg`, queda como una placa lisa.

## Propiedades y API

### `pz.icon`

```python
icon(name, *, size=16, color=None)
```

Un icono de [Lucide](https://lucide.dev). `color` por defecto es el color del texto que lo rodea.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `name` | *obligatorio* | Nombre del icono (`pyzed icons` los lista). |
| `size` | `16` | Tamaño en píxeles. |
| `color` | `None` | Color. |

[Referencia completa →](/pyzed/es/reference/widgets/#icon)

### `pz.svg`

```python
svg(
    source,
    *,
    width=None,
    height=None,
    color=None,
    content_fit=None,
    opacity=1.0,
    rotation=0.0,
)
```

Una imagen SVG.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `source` | *obligatorio* | Ruta a un `.svg`, el código SVG como texto (empieza por `<`) o `bytes`. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `color` | `None` | Si se indica, tiñe todo el SVG de ese color (útil para iconos monocromos). |
| `content_fit` | `None` | `"contain"`, `"cover"`, `"fill"`, `"none"` o `"scale-down"`. |
| `opacity` | `1.0` | Opacidad de 0 a 1. |
| `rotation` | `0.0` | Rotación en grados. |

[Referencia completa →](/pyzed/es/reference/widgets/#svg)
