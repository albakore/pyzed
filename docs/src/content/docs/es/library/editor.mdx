:::tip[En pocas palabras]
Una caja para escribir código, con colores, números de línea y todo lo que espera un programador.
:::

Un editor de código con resaltado de sintaxis en los colores del tema (más de 100 lenguajes), números de línea, marcas de git, cierre automático de pares, plegado, minimapa y zoom de fuente. Es **no controlado**: el texto, el cursor y el historial viven en Rust, ligados al `id`, y `text` solo es el valor inicial. `on_change` recibe el texto completo y `on_cursor` la `(línea, columna)`. `pz.code_editor` es el widget base sin tema.

## Cuándo usarlo

- Para código, archivos de configuración, registros editables o cualquier texto largo.
- Usa la ruta del archivo como `id`: cada archivo conserva su cursor e historial al cambiar de pestaña.
- Para reemplazar el texto desde código, devuelve `pz.Command.set_editor_text(id, text)`.

## Uso

```python
import pyzed as pz
from pyzed import ui

from pathlib import Path

class Editor(pz.App):
    def __init__(self):
        self.path = "main.py"
        self.text = Path(self.path).read_text()

    def save(self):
        Path(self.path).write_text(self.text)

    def view(self):
        return ui.editor(self.path, self.text, path=self.path,
                         on_change=lambda text: setattr(self, "text", text))
```

## Ejemplos

### Plegado, code lens y minimapa

Los bloques se pliegan por indentación (Ctrl+Shift+[ y ]), `annotations` añade un code lens encima de una línea y `minimap=True` dibuja la vista general a la derecha.

### `ui.editor`

```python
editor(
    id,
    text='',
    *,
    language=None,
    path=None,
    on_change=None,
    on_cursor=None,
    markers=None,
    font_size=None,
    line_height=None,
    gutter=True,
    wrap=False,
    active_line=True,
    height='fill',
    placeholder=None,
    annotations=None,
    show_whitespace=False,
    tab_size=None,
    capture_keys=(),
    on_scroll=None,
    auto_close=True,
    folding=True,
    minimap=False,
    cursor_shape='bar',
    cursor_blink=True,
    cursor_width=2.0,
    cursor_color=None,
    on_zoom=None,
    on_action=None,
    highlights=None,
    match_brackets=True,
    selection_highlight=True,
    font=None,
    keymap=None,
    scrollbar=True,
    theme=None,
)
```

Un editor de código: resaltado con los colores del tema, números de línea y marcadores de git.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `id` | *obligatorio* | Identifica el buffer (usa la ruta del archivo). |
| `text` | `""` | Texto inicial. |
| `language` | `None` | Lenguaje. Si falta, se deduce de `path`. |
| `path` | `None` | Ruta del archivo. |
| `on_change` | `None` | Callable que recibe el nuevo valor. |
| `on_cursor` | `None` | Callable que recibe `(línea, columna)`. |
| `markers` | `None` | `{línea: "created" \| "modified" \| "deleted"}`. |
| `font_size` | `None` | Tamaño de la fuente (por defecto, el del tema). |
| `line_height` | `None` | Alto de línea. |
| `gutter` | `True` | Muestra los números de línea. |
| `wrap` | `False` | Ajuste de línea. |
| `active_line` | `True` | Color de fondo de la línea del cursor. |
| `height` | `"fill"` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `placeholder` | `None` | Texto de ayuda cuando está vacío. |
| `annotations` | `None` | `{línea: "texto"}` o `{línea: ("texto", color)}`: texto virtual al final de la línea (code lens, diagnósticos). |
| `show_whitespace` | `False` | Dibuja los espacios como `·` y los tabuladores como `→`. |
| `tab_size` | `None` | Tab inserta espacios hasta el siguiente múltiplo; Enter mantiene la sangría (un nivel más tras `:`); Backspace quita un nivel. |
| `capture_keys` | `()` | Teclas que el editor deja al `on_key` de la app (`"up"`, `"enter"`…), por ejemplo con una lista de autocompletado abierta. |
| `on_scroll` | `None` | Se llama al desplazar. |
| `auto_close` | `True` | Cierra paréntesis, corchetes, llaves y comillas al escribir (y envuelve la selección). |
| `folding` | `True` | Flechas de plegado en el margen; Ctrl+Shift+[ pliega y Ctrl+Shift+] despliega. |
| `minimap` | `False` | `True` (o un ancho en píxeles) muestra un minimapa a la derecha. |
| `cursor_shape` | `"bar"` | `"bar"`, `"block"`, `"underline"` o `"hollow"`. |
| `cursor_blink` | `True` | Si el cursor parpadea. |
| `cursor_width` | `2.0` | Ancho del cursor de barra. |
| `cursor_color` | `None` | Color del cursor (por defecto, el color de jugador del tema). |
| `on_zoom` | `None` | Callable que recibe `1`, `-1` o `0` con Ctrl+= / Ctrl+- / Ctrl+0 y Ctrl+rueda. |
| `on_action` | `None` | Callable que recibe el nombre de cada acción del editor que se ejecuta (`"undo"`, `"select_next"`…), por ejemplo para contarlas. |
| `highlights` | `None` | Rangos pintados detrás del texto con el color de búsqueda del tema: `[(línea, columna, línea_final, columna_final)]`, desde 1, con el final excluido. |
| `match_brackets` | `True` | Remarca el corchete pareja del que está junto al cursor (Ctrl+M salta a él). |
| `selection_highlight` | `True` | Resalta las demás apariciones del texto seleccionado (Ctrl+D añade la siguiente como cursor). |
| `font` | `None` | Tipografía: `"mono"` por defecto; `"sans"` hace un cuadro de texto de varias líneas, como el cuadro de mensaje de un chat. |
| `keymap` | `None` | Diccionario `{atajo: acción}` al estilo de Zed (`{"ctrl-shift-d": "duplicate_line_down"}`); `None` como acción quita una tecla por defecto. Créalo a partir de cambios por acción con `pyzed.ui.editor.keymap_for`. |
| `scrollbar` | `True` | `False` oculta las barras de desplazamiento. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
