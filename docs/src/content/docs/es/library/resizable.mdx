:::tip[En pocas palabras]
Un panel con un borde que puedes arrastrar para hacerlo más grande o más pequeño.
:::

Un panel cuyo `edge` (`"left"`, `"right"`, `"top"` o `"bottom"`) se puede arrastrar para cambiar su tamaño, entre `min_size` y `max_size`. Conserva el tamaño que elige el usuario; `on_resize(size)` se llama al soltar para que puedas guardarlo.

`pz.resizable` · Categoría: [Disposición](/pyzed/es/library/#disposición) · [Referencia completa →](/pyzed/es/reference/widgets/#resizable)

## Eventos

Redimensionable tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_resize` | `(size)` | Se llama con el nuevo tamaño al terminar de arrastrar. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Mail(pz.App):
    def __init__(self):
        self.width = 260

    def view(self):
        return pz.row([
            pz.resizable(ui.muted(f"{self.width:.0f} px"), edge="right", size=self.width, min_size=160,
                         on_resize=lambda size: setattr(self, "width", size)),   # when the drag ends
            main_view(),
        ], height="fill")
```

<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class Width:
    size: float


class Mail(pz.App):
    width = 260

    def update(self, message):
        match message:
            case Width(size):
                self.width = size

    def view(self):
        return pz.row([pz.resizable(ui.muted("Folders"), size=self.width, on_resize=Width), main_view()],
                      height="fill")
```

## Propiedades y API

### `pz.resizable`

```python
resizable(
    content,
    *,
    edge='right',
    size=240.0,
    min_size=80.0,
    max_size=None,
    on_resize=None,
    color=None,
    hover_color=None,
    thickness=1.0,
    handle=8.0,
    width=None,
    height=None,
)
```

Un panel cuyo borde `edge` se arrastra para cambiar su tamaño. Conserva el tamaño al que lo arrastra el usuario; `on_resize(size)` se llama al terminar de arrastrar para que puedas guardarlo. Si `size` cambia después, vuelve a ese valor.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | El contenido del panel. |
| `edge` | `"right"` | El borde con el asa: `"right"` (una barra lateral izquierda), `"left"`, `"top"` (un panel inferior) o `"bottom"`. |
| `size` | `240.0` | Ancho inicial (alto con los bordes top/bottom). |
| `min_size` | `80.0` | Tamaño mínimo. |
| `max_size` | `None` | Tamaño máximo. |
| `color` | `None` | Color de la línea. |
| `hover_color` | `None` | Color de la línea al pasar el ratón o arrastrar. |
| `thickness` | `1.0` | Grosor de la línea. |
| `handle` | `8.0` | Ancho de la zona que se puede agarrar. |
| `width` | `None` | Ancho con los bordes top/bottom. |
| `height` | `None` | Alto con los bordes left/right. |

Eventos: `on_resize` ([eventos](#eventos)).
