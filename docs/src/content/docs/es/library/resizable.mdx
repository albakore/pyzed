:::tip[En pocas palabras]
Un panel con un borde que puedes arrastrar para hacerlo más grande o más pequeño.
:::

Un panel cuyo `edge` (`"left"`, `"right"`, `"top"` o `"bottom"`) se puede arrastrar para cambiar su tamaño, entre `min_size` y `max_size`. Conserva el tamaño que elige el usuario; `on_resize(size)` se llama al soltar para que puedas guardarlo.

`pz.resizable` · Categoría: [Disposición](/pyzed/es/library/#disposición) · [Referencia completa →](/pyzed/es/reference/widgets/#resizable)

## Cuándo usarlo

- Para una barra lateral o un panel inferior redimensionable junto a contenido fijo.

## Uso

```python
import pyzed as pz
from pyzed import ui

t = pz.theme.current()
pz.row([
    pz.resizable(pz.container(ui.label("Drag my right edge"), padding=12, width="fill", height="fill", bg=t.panel),
                 edge="right", size=260, min_size=160, color=t.border, hover_color=t.accent),
    pz.container(ui.muted("Content"), center=True, width="fill", height="fill"),
], height="fill")
```

## API

### `pz.resizable`

```python
resizable(
    content,
    *,
    edge='right',
    size=240.0,
    min_size=80.0,
    max_size=None,
    on_resize=None,
    color=None,
    hover_color=None,
    thickness=1.0,
    handle=8.0,
    width=None,
    height=None,
)
```

Un panel cuyo borde `edge` se arrastra para cambiar su tamaño. Conserva el tamaño al que lo arrastra el usuario; `on_resize(size)` se llama al terminar de arrastrar para que puedas guardarlo. Si `size` cambia después, vuelve a ese valor.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | El contenido del panel. |
| `edge` | `"right"` | El borde con el asa: `"right"` (una barra lateral izquierda), `"left"`, `"top"` (un panel inferior) o `"bottom"`. |
| `size` | `240.0` | Ancho inicial (alto con los bordes top/bottom). |
| `min_size` | `80.0` | Tamaño mínimo. |
| `max_size` | `None` | Tamaño máximo. |
| `on_resize` | `None` | Se llama con el nuevo tamaño al terminar de arrastrar. |
| `color` | `None` | Color de la línea. |
| `hover_color` | `None` | Color de la línea al pasar el ratón o arrastrar. |
| `thickness` | `1.0` | Grosor de la línea. |
| `handle` | `8.0` | Ancho de la zona que se puede agarrar. |
| `width` | `None` | Ancho con los bordes top/bottom. |
| `height` | `None` | Alto con los bordes left/right. |
