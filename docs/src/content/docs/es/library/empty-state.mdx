## Cuándo usarlo

- Para una lista vacía, una búsqueda sin resultados o un panel antes de abrir el primer archivo.
- Ofrece el siguiente paso como acción (Crear, Quitar filtros, Abrir carpeta).

## Uso

```python
from pyzed import ui

ui.empty_state("No results", "Try a different search.", icon="search",
               actions=[ui.button("Clear filters", on_clear, size="sm")])
```

## API

### `ui.empty_state`

```python
empty_state(
    title,
    description=None,
    *,
    icon='inbox',
    actions=(),
    size='md',
    height='fill',
    theme=None,
)
```

Un marcador centrado para listas vacías, búsquedas sin resultados, etc.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `description` | `None` | Texto secundario. |
| `icon` | `"inbox"` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `actions` | `()` | Widgets extra (normalmente botones) que se muestran como acciones. |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `height` | `"fill"` | `"fill"` (por defecto), píxeles o `"shrink"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
