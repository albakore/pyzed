:::tip[En pocas palabras]
Una barra con un botón que arrastras para elegir una cantidad, como el control del volumen.
:::

Un deslizador con los colores del tema entre `min` y `max` (de 0 a 1 por defecto) que avanza de `step` en `step`. `on_change` recibe el nuevo valor mientras arrastras.

`ui.slider` · Categoría: [Formularios](/pyzed/es/library/#formularios) · [Referencia completa →](/pyzed/es/reference/ui/#slider)

## Cuándo usarlo

- Para valores en los que importa más la sensación que el número exacto: volumen, opacidad, zoom.
- Cuando haga falta escribir un valor exacto, usa un [Campo numérico](/pyzed/es/library/number-field/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Player(pz.App):
    def __init__(self):
        self.volume = 70

    def view(self):
        return pz.row([
            ui.slider(self.volume, lambda v: setattr(self, "volume", v), min=0, max=100, step=1),
            ui.label(f"{self.volume:.0f}%"),
        ], spacing=12, align="center")
```

## API

### `ui.slider`

```python
slider(
    value,
    on_change=None,
    *,
    min=0.0,
    max=1.0,
    step=0.01,
    on_release=None,
    vertical=False,
    width=None,
    height=None,
    disabled=False,
    show_value=False,
    theme=None,
)
```

Un deslizador.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Valor actual. |
| `on_change` | `None` | Callable que recibe el nuevo valor. |
| `min` | `0.0` | Mínimo. |
| `max` | `1.0` | Máximo. |
| `step` | `0.01` | Paso. |
| `on_release` | `None` | Se envía al terminar de arrastrar (guarda o aplica ahí). |
| `vertical` | `False` | Lo pone de pie. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `disabled` | `False` | Lo atenúa. |
| `show_value` | `False` | Muestra el número al lado: `True`, o un formato como `"{:.0%}"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
