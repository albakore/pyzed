## Cuándo usarlo

- Para cambiar entre dos y cinco vistas o modos (Día / Semana / Mes).
- Solo con iconos, usa un [Grupo de alternancia](/pyzed/es/library/toggle-group/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Calendar(pz.App):
    def __init__(self):
        self.mode = "Week"

    def view(self):
        return ui.segmented(["Day", "Week", "Month"], self.mode, lambda m: setattr(self, "mode", m))
```

## API

### `ui.segmented`

```python
segmented(
    options,
    selected,
    on_select=None,
    *,
    size='md',
    width=None,
    disabled=False,
    theme=None,
)
```

Un grupo de botones mutuamente excluyentes.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `options` | *obligatorio* | Textos, `(valor, etiqueta)` o `(valor, etiqueta, icono)`. |
| `selected` | *obligatorio* | El valor activo. |
| `on_select` | `None` | Callable que recibe el elemento elegido. |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `width` | `None` | `"fill"` reparte el ancho entre los botones. |
| `disabled` | `False` | `True`, o los valores a desactivar. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
