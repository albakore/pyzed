Una fila de botones de icono en la que hay exactamente uno seleccionado, como la alineación del texto en un editor. `options` son pares `(valor, icono)` y `on_select` recibe el valor elegido.

## Cuándo usarlo

- Para un conjunto pequeño de modos excluyentes con iconos claros.
- Con etiquetas de texto, usa [Segmentado](/pyzed/es/library/segmented/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Toolbar(pz.App):
    def __init__(self):
        self.align = "left"

    def view(self):
        return ui.toggle_group(
            [("left", "align-left"), ("center", "align-center"), ("right", "align-right")],
            self.align, lambda value: setattr(self, "align", value),
        )
```

## API

### `ui.toggle_group`

```python
toggle_group(options, selected, on_select, *, theme=None)
```

Un control segmentado solo con iconos.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `options` | *obligatorio* | Pares `(valor, nombre_de_icono)`. |
| `selected` | *obligatorio* | Valor actual. |
| `on_select` | *obligatorio* | Callable que recibe el elemento elegido. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
