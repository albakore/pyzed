Un botón cuadrado y compacto que muestra un icono de [Lucide](https://lucide.dev), como el `IconButton` de Zed. Es transparente por defecto, así que encaja en barras de herramientas, cabeceras de panel y barras de pestañas. `tooltip=` añade un tooltip al pasar el ratón.

## Cuándo usarlo

- Para acciones frecuentes con un icono evidente (buscar, ajustes, cerrar, añadir).
- Dale siempre un `tooltip` cuando el icono solo pueda ser ambiguo.
- `selected=True` muestra un estado activo (un panel abierto, un filtro activado).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.icon_button("search", on_search, tooltip="Search"),
    ui.icon_button("settings", on_settings, tooltip="Settings"),
    ui.icon_button("bell", on_notifications, selected=True),
    ui.icon_button("plus", on_new, variant="filled"),
], spacing=6)
```

## API

### `ui.icon_button`

```python
icon_button(
    name,
    on_press=None,
    *,
    size='md',
    variant='ghost',
    color=None,
    selected=False,
    disabled=False,
    tooltip=None,
    theme=None,
)
```

Un botón cuadrado con solo un icono (el `IconButton` de Zed).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `name` | *obligatorio* | Nombre del icono. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `size` | `"md"` | `"xs"`, `"sm"`, `"md"` o `"lg"`. |
| `variant` | `"ghost"` | Como en `ui.button`. Por defecto `"ghost"`. |
| `color` | `None` | Color del icono. |
| `selected` | `False` | Lo marca como seleccionado. |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `tooltip` | `None` | Texto del tooltip. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
