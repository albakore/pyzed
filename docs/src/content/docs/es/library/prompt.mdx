## Cuándo usarlo

- Para nombres rápidos: renombrar un archivo, nombrar una rama, guardar una vista.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Files(pz.App):
    def __init__(self):
        self.new_name = None

    def view(self):
        dialog = None
        if self.new_name is not None:
            dialog = ui.prompt("Rename", self.new_name, lambda t: setattr(self, "new_name", t),
                               self.rename, lambda: setattr(self, "new_name", None))
        return ui.dialog_layer(self.main_view(), dialog)
```

## API

### `ui.prompt`

```python
prompt(
    title,
    value,
    on_input,
    on_submit,
    on_cancel,
    *,
    message=None,
    placeholder='',
    submit_label=None,
    cancel_label=None,
    id=None,
    width=440,
    theme=None,
)
```

Pide una línea de texto.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `value` | *obligatorio* | Texto actual. |
| `on_input` | *obligatorio* | Recibe cada edición. |
| `on_submit` | *obligatorio* | Enter o el botón de aceptar. |
| `on_cancel` | *obligatorio* | Cancelar, el icono de cerrar. |
| `message` | `None` | Texto sobre el campo. |
| `placeholder` | `""` | Texto de ayuda cuando está vacío. |
| `submit_label` | `None` | Texto del botón de aceptar. |
| `cancel_label` | `None` | Texto del botón de cancelar. |
| `id` | `None` | Id del campo (para `Command.focus`). |
| `width` | `440` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
