## Cuándo usarlo

- Al cerrar una pestaña o una ventana con cambios sin guardar.

## Uso

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.unsaved_changes("notes.py", on_save, on_discard, on_cancel))
```

## API

### `ui.unsaved_changes`

```python
unsaved_changes(name, on_save, on_discard, on_cancel, *, width=440, theme=None)
```

«¿Guardar los cambios de *nombre* antes de cerrar?» con No guardar, Cancelar y Guardar.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `name` | *obligatorio* | Nombre del archivo o documento. |
| `on_save` | *obligatorio* | Guardar. |
| `on_discard` | *obligatorio* | No guardar. |
| `on_cancel` | *obligatorio* | Cancelar. |
| `width` | `440` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
