:::tip[En pocas palabras]
Una caja de color dentro de la página con un mensaje: un consejo, un aviso o un error.
:::

Un aviso en línea (un callout o banner): un icono, un título, una descripción opcional, botones de acción y un botón de cerrar con `on_dismiss`. `tint` es `"info"` (por defecto), `"success"`, `"warning"`, `"error"` o cualquier token del tema.

## Cuándo usarlo

- Para mensajes que pertenecen a un lugar de la interfaz: un archivo de solo lectura, una versión nueva, una sincronización fallida.
- Para mensajes pasajeros, usa una [Notificación](/pyzed/es/library/toast/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.callout("A new version is out", "Pyzed 0.4 adds the component designer.", tint="info",
               actions=[ui.button("What's new", on_open, size="sm")], on_dismiss=on_dismiss),
    ui.callout("Could not save", "The file is read-only.", tint="error"),
], spacing=10, width=520)
```

## API

### `ui.callout`

```python
callout(
    title,
    description=None,
    *,
    tint='info',
    icon=None,
    actions=(),
    on_dismiss=None,
    theme=None,
)
```

Un aviso en línea (un callout o banner).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título (texto o widget). |
| `description` | `None` | Texto secundario. |
| `tint` | `"info"` | `"info"`, `"success"`, `"warning"`, `"error"` o `"hint"`: elige el color y el icono. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `actions` | `()` | Widgets extra (normalmente botones) que se muestran como acciones. |
| `on_dismiss` | `None` | Añade un botón de cerrar. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
