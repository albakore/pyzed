:::tip[En pocas palabras]
Un anillo pequeño que se llena a medida que un chat con una IA se alarga, como el indicador de gasolina.
:::

`ui.context_meter(used, limit)` muestra cuánto se llenó la ventana de contexto de un modelo de IA: un anillo pequeño y `48k / 200k`. Es gris por debajo del 80 %, amarillo desde el 80 % y rojo desde el 95 %, y su tooltip da las cifras exactas. `ui.format_tokens(count)` escribe una cifra de forma corta: `950`, `4.5k`, `48k`, `1.25M`.

## Cuándo usarlo

- En la barra o en la caja de texto del chat de un agente, para que el usuario vea cuándo una conversación se hace larga.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.context_meter(48_000, 200_000),
    ui.context_meter(170_000, 200_000),
    ui.context_meter(196_000, 200_000),
], spacing=24, align="center")
```

## API

### `ui.context_meter`

```python
context_meter(used, limit, *, theme=None)
```

Cuánto se llenó la ventana de contexto de un modelo, como el contador de tokens de Zed: un anillo pequeño y `48k / 200k`, amarillo pasado el 80 % y rojo pasado el 95 %.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `used` | *obligatorio* | Tokens en uso. |
| `limit` | *obligatorio* | La ventana del modelo. |
| `theme` | `None` | Tema. |

[Referencia completa →](/pyzed/es/reference/ui/#context_meter)

### `ui.format_tokens`

```python
format_tokens(count)
```

Un número de tokens corto: `950`, `4.5k`, `48k`, `1.25M`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `count` | *obligatorio* | Tokens. |

[Referencia completa →](/pyzed/es/reference/ui/#format_tokens)
