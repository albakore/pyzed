## Cuándo usarlo

- Para comparar unos pocos valores lado a lado (por día, por categoría).

## Uso

```python
from pyzed import ui

ui.bar_chart([12, 19, 8, 15, 22, 17, 9], labels=["M", "T", "W", "T", "F", "S", "S"],
             width=360, height=180)
```

## API

### `ui.bar_chart`

```python
bar_chart(values, *, labels=None, width=320, height=160, tint='accent', theme=None)
```

Un gráfico de barras vertical con etiquetas opcionales.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `values` | *obligatorio* | Valores. |
| `labels` | `None` | Etiquetas bajo cada barra. |
| `width` | `320` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `160` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
