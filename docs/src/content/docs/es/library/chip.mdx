## Cuándo usarlo

- Para etiquetas, filtros y valores elegidos (una selección múltiple, destinatarios).
- Para estados de solo lectura usa una [Insignia](/pyzed/es/library/badge/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Tags(pz.App):
    def __init__(self):
        self.tags = ["python", "rust", "iced"]

    def view(self):
        return pz.row([ui.chip(t, on_remove=lambda t=t: self.tags.remove(t)) for t in self.tags],
                      spacing=6, wrap=True)
```

## API

### `ui.chip`

```python
chip(content, *, on_press=None, on_remove=None, selected=False, icon=None, theme=None)
```

Una etiqueta compacta, opcionalmente pulsable (filtros) y con botón para quitarla.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Texto. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `on_remove` | `None` | Muestra una ✕ que envía esto al pulsarla. |
| `selected` | `False` | Lo marca como seleccionado. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
