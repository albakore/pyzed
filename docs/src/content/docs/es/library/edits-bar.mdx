:::tip[En pocas palabras]
Una barra con los archivos que cambió un asistente de IA, para conservar o deshacer los cambios.
:::

`ui.EditsBar` es un componente que lista los archivos que cambió un agente: `3 archivos cambiados` con las líneas añadidas y quitadas, Rechazar todo y Conservar todo. Un clic en el título despliega una fila por archivo con su resumen de cambios y botones para rechazar o conservar solo ese archivo; un clic en el nombre de un archivo llega a `on_open`. `files` son diccionarios u objetos con `path` y, opcionales, las líneas añadidas (`added`) y quitadas (`removed`). Los eventos de un archivo (`on_keep_file`, `on_reject_file`, `on_open`) llevan la ruta en `event.value`.

## Cuándo usarlo

- Bajo el chat de un agente, cuando ya editó archivos, para que el usuario los revise antes de conservarlos.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Review(pz.App):
    def __init__(self):
        self.files = [{"path": "app/storage.py", "added": 12, "removed": 3}]

    def keep(self, path=None):  # None: every file
        self.files = [f for f in self.files if path is not None and f["path"] != path]

    def view(self):
        return ui.EditsBar(files=self.files, on_keep=lambda e: self.keep(),
                           on_keep_file=lambda e: self.keep(e.value), on_open=lambda e: self.open(e.value))
```

## API

### `ui.EditsBar`

```python
class EditsBar
```

Un componente con los archivos que cambió un agente, como la barra de cambios de Zed: `3 archivos cambiados` con Rechazar todo y Conservar todo, que se despliega en una fila por archivo con sus líneas, Rechazar y Conservar.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `files` | `None` | Dicts u objetos con `path` y, opcionalmente, `added` y `removed` (líneas). |
| `theme` | `None` | Tema. |
| `on_keep` | `None` | Conservar todo. |
| `on_reject` | `None` | Rechazar todo. |
| `on_keep_file` | `None` | Conservar en un archivo (`event.value` es su ruta). |
| `on_reject_file` | `None` | Rechazar en un archivo. |
| `on_open` | `None` | Se hizo clic en un archivo. |
