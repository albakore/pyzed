:::tip[En pocas palabras]
Una lista de tareas que un asistente de IA se escribe y va tachando mientras trabaja.
:::

`ui.Plan` es un componente que muestra el plan de un agente de IA como una lista: cada paso está pendiente (un círculo vacío), en curso (un punto, o un spinner con `running=True`) o hecho (un check verde, con el texto atenuado), y la cabecera cuenta `hechos/total`. Un clic en la cabecera pliega y despliega los pasos. `steps` son diccionarios con `step` (el texto) y `status`: `"pending"`, `"in_progress"` o `"done"`.

## Cuándo usarlo

- Encima del chat de un agente, mientras resuelve una tarea de varios pasos.
- Para cualquier lista de pasos que se actualiza mientras avanza el trabajo, como una instalación o una migración.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Agent(pz.App):
    def __init__(self):
        self.steps = [{"step": "Add the form", "status": "done"},
                      {"step": "Wire the events", "status": "in_progress"}]
        self.working = True

    def view(self):
        return ui.Plan(steps=self.steps, running=self.working)
```

## API

### `ui.Plan`

```python
class Plan
```

Un componente para el plan de un agente: una lista de pasos con `hechos/total` en la cabecera, que la pliega.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `steps` | `None` | Dicts `{"step": texto, "status": "pending" \| "in_progress" \| "done"}`. |
| `running` | `False` | Hace girar el paso en curso. |
| `theme` | `None` | Tema. |
