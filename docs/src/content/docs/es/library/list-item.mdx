## Cuándo usarlo

- Para cualquier lista vertical: archivos recientes, resultados, categorías de ajustes, personas.
- Usa `inset=True` dentro de paneles para que el resaltado tenga margen.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Recent(pz.App):
    def __init__(self):
        self.files = ["main.py", "app.py", "README.md"]
        self.current = "main.py"

    def view(self):
        return pz.column([
            ui.list_item(f, lambda f=f: setattr(self, "current", f), icon="file",
                         selected=f == self.current, inset=True)
            for f in self.files
        ])
```

## API

### `ui.list_item`

```python
list_item(
    content,
    on_press=None,
    *,
    icon=None,
    icon_color=None,
    start=None,
    end=None,
    selected=False,
    focused=False,
    indent=0,
    height=26,
    color=None,
    inset=False,
    disabled=False,
    on_right_press=None,
    theme=None,
)
```

Una fila de lista: icono, texto y un hueco al final.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Texto o widget. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `icon_color` | `None` | Color del icono: un token del tema o un color hex. |
| `start` | `None` | Widgets al inicio (izquierda). |
| `end` | `None` | Widgets al final (derecha). |
| `selected` | `False` | Lo marca como seleccionado. |
| `focused` | `False` | Dibuja un borde de foco. |
| `indent` | `0` | Sangría a la izquierda, en píxeles. |
| `height` | `26` | Alto de la fila. |
| `color` | `None` | Color del texto. |
| `inset` | `False` | Con margen y esquinas redondeadas (menús, paletas). |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `on_right_press` | `None` | Clic derecho. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
