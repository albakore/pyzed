## Cuándo usarlo

- Para cualquier lista vertical: archivos recientes, resultados, categorías de ajustes, personas.
- Usa `inset=True` dentro de paneles para que el resaltado tenga margen.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Recent(pz.App):
    def __init__(self):
        self.files = ["main.py", "app.py", "README.md"]
        self.current = "main.py"

    def view(self):
        return pz.column([
            ui.list_item(f, lambda f=f: setattr(self, "current", f), icon="file",
                         selected=f == self.current, inset=True)
            for f in self.files
        ])
```

## Eventos

Fila de lista tiene **3 eventos propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_press` | `()` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `on_right_press` | `()` | Clic derecho. |
| `on_double_press` | `()` | Se envía con un doble clic (abrir, renombrar…). |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class Select:
    path: str


@dataclass
class Open:
    path: str


class Recent(pz.App):
    files = ["main.py", "app.py", "README.md"]
    current, opened = "main.py", None

    def update(self, message):
        match message:
            case Select(path):
                self.current = path
            case Open(path):
                self.opened = path

    def view(self):
        return pz.column([ui.list_item(f, Select(f), icon="file", selected=f == self.current,
                                       on_double_press=Open(f)) for f in self.files], width=280)
```

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class State:
    files: tuple = ("main.py", "app.py", "README.md")
    current: str = "main.py"


def file_row(name, selected, select):
    return ui.list_item(name, select, icon="file", selected=selected, inset=True)


def view(state, set_state):
    return pz.column([file_row(f, f == state.current, lambda f=f: set_state(current=f))
                      for f in state.files], width=280)
```

```python
list_item(
    content,
    on_press=None,

    icon=None,
    icon_color=None,

    description=None,
    tooltip=None,
    theme=None,
```

Una fila de lista: icono, texto y un hueco al final.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Texto o widget. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `icon_color` | `None` | Color del icono: un token del tema o un color hex. |
| `start` | `None` | Widgets al inicio (izquierda). |
| `end` | `None` | Widgets al final (derecha). |
| `selected` | `False` | Lo marca como seleccionado. |
| `focused` | `False` | Dibuja un borde de foco. |
| `indent` | `0` | Sangría a la izquierda, en píxeles. |
| `height` | `26` | Alto de la fila. |
| `color` | `None` | Color del texto. |
| `inset` | `False` | Con margen y esquinas redondeadas (menús, paletas). |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `description` | `None` | Una segunda línea atenuada (la fila crece a 40 px salvo que fijes `height`). |
| `tooltip` | `None` | Texto al pasar el ratón. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
