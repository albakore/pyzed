## Cuándo usarlo

- Para la cuenta en la barra de título, autores de comentarios o colaboradores.
- Para varias personas a la vez usa [Facepile](/pyzed/es/library/facepile/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.avatar("AL", index=0),
    ui.avatar("KV", index=1),
    ui.avatar("MZ", index=2, size=28),
    ui.avatar("JD", index=3, size=36),
], spacing=8, align="center")
```

## API

### `ui.avatar`

```python
avatar(
    initials,
    *,
    color=None,
    size=22,
    index=0,
    image=None,
    status=None,
    tooltip=None,
    theme=None,
)
```

Un avatar redondo con iniciales.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `initials` | *obligatorio* | Iniciales (se usan las dos primeras). |
| `color` | `None` | Color de fondo. |
| `size` | `22` | Diámetro. |
| `index` | `0` | Elige un color de colaborador del tema (`theme.players`). |
| `image` | `None` | Una imagen (ruta o bytes) en lugar de las iniciales. |
| `status` | `None` | Punto de presencia: `"online"`, `"away"`, `"busy"`, `"offline"` o un color. |
| `tooltip` | `None` | Texto al pasar el ratón (el nombre de la persona). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
