:::tip[En pocas palabras]
Estrellitas que pulsas para decir cuánto te gusta algo.
:::

Una fila de estrellas (o cualquier icono) en la que las primeras `value` están encendidas. Al pulsar una estrella se envía su número a `on_change`; con `clearable`, pulsar la encendida envía 0. Sin `on_change` solo muestra la puntuación, redondeada a la estrella más cercana.

## Cuándo usarlo

- Para valorar un artículo, una canción o una respuesta.
- Para mostrar una nota media junto a un producto o una reseña.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Review(pz.App):
    def __init__(self):
        self.stars = 3

    def view(self):
        return ui.rating(self.stars, lambda stars: setattr(self, "stars", stars))
```

## Eventos

Valoración tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_change` | `(stars)` | Función que recibe el número de estrellas elegido (de 0 a `max`). |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<Tabs syncKey="code-style">
<TabItem label="Imperativo">

```python
class Review(pz.App):
    def __init__(self):
        self.stars = 3

    def rate(self, stars):               # on_change: the number of stars (0 when cleared)
        self.stars = stars

    def view(self):
        return pz.column([ui.rating(self.stars, self.rate), ui.label(f"{self.stars} of 5")], spacing=8)
```

</TabItem>
<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class Rate:
    stars: int


class Review(pz.App):
    stars = 3

    def update(self, message):
        match message:
            case Rate(stars):
                self.stars = stars

    def view(self):
        return ui.rating(self.stars, Rate)   # the class builds the message from the stars
```

from dataclasses import dataclass


@dataclass(frozen=True)
class State:

def view(state, set_state):

## Propiedades y API

### `ui.rating`

```python
rating(
    value,
    on_change=None,
    *,
    max=5,
    icon='star',
    size=18,
    tint='warning',
    clearable=True,
    disabled=False,
    theme=None,
)
```

Una fila de estrellas (o cualquier icono) para dar o mostrar una puntuación. Al pulsar una estrella se envía su número; con `clearable`, pulsar la encendida envía 0. Sin `on_change` solo muestra el valor, redondeado a la estrella más cercana. Con el foco, las flechas lo cambian de uno en uno.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Cuántas estrellas están encendidas (redondeado). |
| `max` | `5` | Cuántas estrellas hay. |
| `icon` | `"star"` | Icono de Lucide de cada estrella. |
| `size` | `18` | Tamaño del icono en píxeles. |
| `tint` | `"warning"` | Color de las estrellas encendidas (un token del tema o un color hex). |
| `clearable` | `True` | Pulsar el valor actual envía 0. |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_change` ([eventos](#eventos)).
