## Cuándo usarlo

- Encima de una lista, árbol o tabla para filtrarla mientras escribes.
- Combínalo con `ui.fuzzy_filter` para ordenar primero los mejores resultados.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Finder(pz.App):
    def __init__(self):
        self.query = ""
        self.files = ["main.py", "app.py", "theme.py"]

    def view(self):
        matches = ui.fuzzy_filter(self.query, self.files)
        return pz.column([
            ui.search_input(self.query, lambda q: setattr(self, "query", q)),
            *[ui.list_item(name, icon="file") for name, _ in matches],
        ], spacing=6)
```

## API

### `ui.search_input`

```python
search_input(value, on_input=None, *, placeholder='Search…', **kwargs)
```

Un `input` con icono de lupa.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Texto actual. |
| `on_input` | `None` | Callable que recibe el texto nuevo en cada pulsación. |
| `placeholder` | `"Search…"` | Texto de ayuda cuando está vacío. |
| `**kwargs` | — | Los de `input`. |
