Muestra en qué punto de un proceso de varios pasos está el usuario. Los pasos hechos llevan una marca, el actual (`current`) va rodeado y la línea se llena al avanzar. `on_select` deja volver a un paso.

## Cuándo usarlo

- Para registros, compras, instaladores y otros asistentes.
- Para secciones que se abren en cualquier orden, usa una [barra de pestañas](/pyzed/es/library/tab-bar/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Checkout(pz.App):
    def __init__(self):
        self.step = 0

    def view(self):
        return pz.column([
            ui.stepper(["Cart", "Address", "Payment"], self.step, lambda i: setattr(self, "step", i)),
            ui.button("Next", lambda: setattr(self, "step", min(self.step + 1, 3)), variant="solid"),
        ], spacing=16)
```

## Eventos

Pasos tiene **1 evento propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

| Evento | El handler recibe | Cuándo |
| --- | --- | --- |
| `on_select` | `(index)` | Se llama con el índice del paso pulsado. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

<TabItem label="Imperativo">

```python
class Checkout(pz.App):
    def __init__(self):
        self.step = 1

    def go(self, index):                 # on_select: the index of the clicked step
        self.step = index

    def view(self):
        return pz.column([
            ui.stepper(["Cart", "Address", "Payment", "Done"], self.step, self.go),
            ui.button("Next", lambda: self.go(min(self.step + 1, 4)), variant="solid"),
        ], spacing=16)
```

<TabItem label="Declarativo">

```python
from dataclasses import dataclass


@dataclass
class GoTo:
    index: int


class Checkout(pz.App):
    step = 1

    def update(self, message):
        match message:
            case GoTo(index):
                self.step = index

    def view(self):
        return ui.stepper(["Cart", "Address", "Payment"], self.step, GoTo)
```

from dataclasses import dataclass

## Propiedades y API

### `ui.stepper`

```python
stepper(
    steps,
    current,
    on_select=None,
    *,
    vertical=False,
    linear=True,
    errors=(),
    tint='accent',
    theme=None,
)
```

Los pasos de un asistente o de una compra: los hechos llevan una marca, el actual va rodeado y la línea entre ellos se llena al avanzar.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `steps` | *obligatorio* | Títulos o tuplas `(título, descripción)`. |
| `current` | *obligatorio* | Índice del paso en curso (`len(steps)` cuando están todos hechos). |
| `vertical` | `False` | Apila los pasos, con la descripción bajo cada título. |
| `linear` | `True` | Solo se pueden pulsar los pasos hechos y el actual. |
| `errors` | `()` | Índices de pasos pintados con el color de error. |
| `tint` | `"accent"` | Color de los pasos hechos y de la línea. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

Eventos: `on_select` ([eventos](#eventos)).
