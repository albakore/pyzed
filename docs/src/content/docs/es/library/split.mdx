:::tip[En pocas palabras]
Dos zonas lado a lado (o una encima de otra) con una línea que arrastras para cambiar su tamaño.
:::

Separa dos widgets con un divisor que se arrastra, en el color de borde del tema (acento mientras se arrastra). El `ratio` es tuyo: guárdalo en `on_resize(ratio)`. `vertical=True` apila los paneles. `pz.split` es la versión base con `color`, `hover_color`, `thickness` y `handle` configurables.

## Cuándo usarlo

- Para editores lado a lado, una vista previa junto a su código o un editor encima de una terminal.
- Para un solo panel lateral redimensionable, [Redimensionable](/pyzed/es/library/resizable/) es más simple.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Panes(pz.App):
    def __init__(self):
        self.ratio = 0.3

    def view(self):
        return ui.split(self.sidebar(), self.editor(), ratio=self.ratio,
                        on_resize=lambda r: setattr(self, "ratio", r))
```

## API

### `ui.split`

```python
split(
    first,
    second,
    *,
    ratio=0.5,
    on_resize=None,
    vertical=False,
    min_size=80,
    theme=None,
    **kwargs,
)
```

`pz.split` con el divisor del color de borde del tema (acento al arrastrarlo).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `first` | *obligatorio* | Primer panel. |
| `second` | *obligatorio* | Segundo panel. |
| `ratio` | `0.5` | Proporción del primero (0–1). |
| `on_resize` | `None` | Callable que recibe la nueva proporción. |
| `vertical` | `False` | Orientación vertical. |
| `min_size` | `80` | Tamaño mínimo de cada panel. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
| `**kwargs` | — | Los de `pz.split`. |

### `pz.split`

```python
split(
    first,
    second,
    *,
    ratio=0.5,
    on_resize=None,
    vertical=False,
    min_size=80.0,
    min_size_second=None,
    color=None,
    hover_color=None,
    thickness=1.0,
    handle=8.0,
    width=None,
    height=None,
)
```

Dos paneles con un divisor que se arrastra. Para el estilo del tema usa `ui.split`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `first` | *obligatorio* | Primer panel. |
| `second` | *obligatorio* | Segundo panel. |
| `ratio` | `0.5` | Proporción del primer panel (0–1). El divisor conserva la proporción a la que lo arrastra el usuario hasta que esto cambia. |
| `on_resize` | `None` | Callable que recibe la nueva proporción mientras se arrastra. |
| `vertical` | `False` | Apila los paneles arriba/abajo. |
| `min_size` | `80.0` | Tamaño mínimo del primer panel. |
| `min_size_second` | `None` | Tamaño mínimo del segundo panel. |
| `color` | `None` | Color del divisor. |
| `hover_color` | `None` | Color del divisor al pasar el ratón o arrastrar. |
| `thickness` | `1.0` | Grosor de la línea. |
| `handle` | `8.0` | Ancho de la zona que se puede arrastrar. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
