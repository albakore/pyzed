Muestra un botón con el estilo del tema. Toma los colores del tema actual, puede llevar un icono y un atajo de teclado, y tiene varias variantes y tamaños. Cualquier parámetro de estilo de `pz.button` (`bg`, `hover_bg`, `radius`…) reemplaza al del tema.

## Cuándo usarlo

- Para las acciones principales de un formulario, diálogo o barra.
- Usa `variant="solid"` para la acción principal y `"ghost"` para las secundarias.
- Para un botón con solo un icono, usa [Botón de icono](/pyzed/es/library/icon-button/).

## Uso

```python
import pyzed as pz
from pyzed import ui

class Editor(pz.App):
    def save(self):
        ...

    def view(self):
        return ui.button("Save", self.save, icon="save", keys="ctrl-s")
```

### Iconos, atajos y estados

`icon_position="end"` pone el icono después del texto. Sin `on_press` (o con `disabled=True`) el botón se dibuja deshabilitado; `selected=True` lo deja resaltado.

## Consejos

Para pasarle un valor al callback, átalo con un argumento por defecto: `ui.button(nombre, lambda n=nombre: self.abrir(n))`.

## API

### `ui.button`

```python
button(
    content=None,
    on_press=None,
    *,
    icon=None,
    icon_position='start',
    icon_color=None,
    variant='filled',
    tint=None,
    size='md',
    selected=False,
    disabled=False,
    full_width=False,
    keys=None,
    theme=None,
    **style,
)
```

Un botón con tema, con variantes, tamaños, un icono y un atajo.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | `None` | Texto o widget. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `icon_position` | `"start"` | `"start"` o `"end"`. |
| `icon_color` | `None` | Color del icono: un token del tema o un color hex. |
| `variant` | `"filled"` | `"filled"`, `"ghost"`, `"subtle"`, `"outline"`, `"solid"`, `"tinted"`, o un color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"`. |
| `tint` | `None` | Color de las variantes `solid` y `tinted`. |
| `size` | `"md"` | `"xs"`, `"sm"`, `"md"` o `"lg"`. |
| `selected` | `False` | Lo marca como seleccionado. |
| `disabled` | `False` | Lo deshabilita (ignora los clics). |
| `full_width` | `False` | Ocupa todo el ancho. |
| `keys` | `None` | Atajo que se muestra al final, escrito como texto: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
| `**style` | — | Cualquier parámetro de estilo de `pyzed.button` (`bg`, `hover_bg`, `color`…). |
