## Cuándo usarlo

- Junto a un archivo, commit o pull request en una lista de cambios.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    pz.row([ui.label("render.rs", mono=True), pz.hspace(), ui.diff_stat(42, 9)], align="center"),
```

## Propiedades y API

### `ui.diff_stat`

```python
diff_stat(added, removed, *, blocks=5, theme=None)
```

`+12 −3` con bloques de colores al estilo de GitHub.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `added` | *obligatorio* | Líneas añadidas. |
| `removed` | *obligatorio* | Líneas eliminadas. |
| `blocks` | `5` | Número de bloques. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
