## Cuándo usarlo

- Para esconder opciones avanzadas o detalles hasta que hagan falta.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Form(pz.App):
    def __init__(self):
        self.advanced = False

    def view(self):
        return ui.disclosure("Advanced options", self.advanced_options(), open=self.advanced,
                             on_toggle=lambda: setattr(self, "advanced", not self.advanced))
```

## API

### `ui.disclosure`

```python
disclosure(title, content, *, open, on_toggle=None, end=None, theme=None)
```

Una sección plegable: cabecera con flecha que muestra u oculta `content`. El estado abierto es tuyo: cámbialo en `on_toggle`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título (texto o widget). |
| `content` | *obligatorio* | Contenido. |
| `open` | *obligatorio* | Si está abierta. |
| `on_toggle` | `None` | Mensaje o callable al pulsar la cabecera. |
| `end` | `None` | Widgets al final (derecha). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
