Todos los componentes de `pyzed.ui`, más los widgets de disposición y contenido de `pyzed`, con
una vista previa, el código que la dibuja, ejemplos y su API. Los componentes son **funciones que
devuelven widgets**, así que se combinan libremente entre sí y con los
[widgets base](/pyzed/es/reference/widgets/).

```python
import pyzed as pz
from pyzed import ui

ui.button("Guardar", self.guardar, icon="save", variant="solid", keys="ctrl-s")
```

- **Colores del tema.** Todos los componentes leen el tema actual (`App.theme`, o el de la
  ventana en apps [multiventana](/pyzed/es/guides/windows/)) y aceptan `theme=` para usar otro.
- **Tokens o hex.** Los parámetros de color (`color`, `icon_color`, `tint`…) aceptan un token del
  tema como `"accent"`, `"text_muted"` o `"error"`, o un color `"#rrggbb"`.
- **Mensajes o funciones.** `on_press`, `on_select`, `on_toggle`… aceptan un mensaje para
  `update` o una función; los que producen un valor (texto, `bool`, id) la llaman con ese valor.
- **Iconos.** `icon=` acepta cualquier nombre de [Lucide](https://lucide.dev) (`pyzed icons` los lista).

Para verlos todos funcionando, abre la galería: `python examples/gallery.py`.
