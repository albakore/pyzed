Una fila de formulario como los ajustes de Zed: el título (y una descripción opcional) a la izquierda y cualquier control a la derecha. Apila varias en una columna o en un [Grupo de ajustes](/pyzed/es/library/settings-group/).

## Cuándo usarlo

- Para preferencias y formularios en los que cada control necesita una etiqueta y quizá una pista.
- Alinea interruptores, selects y campos numéricos de anchos distintos.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.field("Autosave", ui.switch(True, on_toggle), description="Saves when you switch tabs"),
    ui.field("Format on save", ui.checkbox(False, on_toggle)),
    ui.field("Font size", ui.number_field(14, on_change, suffix="px")),
], spacing=14, width=440)
```

## API

### `ui.field`

```python
field(title, control, *, description=None, theme=None)
```

Una fila de formulario: título y descripción a la izquierda, control a la derecha (como los ajustes de Zed).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `control` | *obligatorio* | El control (switch, input…). |
| `description` | `None` | Texto de ayuda. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
