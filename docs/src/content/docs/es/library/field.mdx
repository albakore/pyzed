Una fila de formulario como las de una pantalla de ajustes: el título (y una descripción opcional) a la izquierda y cualquier control a la derecha. Apila varias en una columna o en un [Grupo de ajustes](/pyzed/es/library/settings-group/).

## Cuándo usarlo

- Para preferencias y formularios en los que cada control necesita una etiqueta y quizá una pista.
- Alinea interruptores, selects y campos numéricos de anchos distintos.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.field("Autosave", ui.switch(True, on_toggle), description="Saves when you switch tabs"),
    ui.field("Format on save", ui.checkbox(False, on_toggle)),
    ui.field("Font size", ui.number_field(14, on_change, suffix="px")),
], spacing=14, width=440)
```

## Propiedades y API

### `ui.field`

```python
field(
    title,
    control,
    *,
    description=None,
    error=None,
    required=False,
    vertical=False,
    theme=None,
)
```

Una fila de formulario: título y descripción a la izquierda, control a la derecha (como una pantalla de ajustes).

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `control` | *obligatorio* | El control (switch, input…). |
| `description` | `None` | Texto de ayuda. |
| `error` | `None` | Un mensaje de validación que se muestra bajo el título con el color de error (ver `pz.validation_errors`). |
| `required` | `False` | Añade un `*` rojo tras el título. |
| `vertical` | `False` | Pone el control bajo el título. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
