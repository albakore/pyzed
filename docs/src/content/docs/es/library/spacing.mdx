`pz.space(width, height)` es una caja vacía de un tamaño dado. `pz.hspace()` y `pz.vspace()` son huecos flexibles que ocupan el espacio libre y empujan a sus hermanos a los extremos de una fila o columna.

## Cuándo usarlo

- Para llevar acciones a la derecha de una barra, o un pie al fondo de un panel.

## Uso

```python
import pyzed as pz
from pyzed import ui

box = lambda text, w=90, h=44: pz.container(ui.label(text), center=True, width=w, height=h, bg=pz.theme.current().element, radius=6)
pz.column([
    pz.row([box("left"), pz.hspace(), box("right")], width=440),
    pz.row([box("a"), pz.space(width=60), box("60 px later", w=140)]),
], spacing=16)
```

## API

### `pz.space`

```python
space(width=None, height=None)
```

Espacio vacío de un tamaño dado.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |

[Referencia completa →](/pyzed/es/reference/widgets/#space)

### `pz.hspace`

```python
hspace(width='fill')
```

Hueco horizontal flexible: empuja a los hermanos de una fila hacia los extremos.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `width` | `"fill"` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |

[Referencia completa →](/pyzed/es/reference/widgets/#hspace)

### `pz.vspace`

```python
vspace(height='fill')
```

Hueco vertical flexible: empuja a los hermanos de una columna hacia los extremos.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `height` | `"fill"` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
