## Cuándo usarlo

- Para separar grupos en una columna o elementos en una barra.
- Prueba primero con espacio; añade un divisor cuando los grupos necesiten un corte visual.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.label("Account"),
    ui.divider(),
    pz.row([ui.label("Edit"), ui.divider(vertical=True), ui.label("View"),
            ui.divider(vertical=True), ui.label("Help")], spacing=12, height=20),
    ui.divider(),
    ui.muted("Sign out"),
```

## Propiedades y API

### `ui.divider`

```python
divider(*, vertical=False, color=None, label=None, spacing=0, theme=None)
```

Una línea divisoria con el color del tema.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `vertical` | `False` | Vertical en lugar de horizontal. |
| `color` | `None` | Color del texto o del icono. |
| `label` | `None` | Texto atenuado en el centro de una línea horizontal (`"o"`, una fecha…). |
| `spacing` | `0` | Espacio a ambos lados de la línea. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

[Referencia completa →](/pyzed/es/reference/ui/#divider)

### `pz.rule`

```python
rule(*, vertical=False, thickness=1.0, color=None)
```

Una línea divisoria horizontal (o vertical).

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `vertical` | `False` | Línea vertical en lugar de horizontal. |
| `thickness` | `1.0` | Grosor en píxeles. |
| `color` | `None` | Color del texto o del icono. |
