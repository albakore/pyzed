## Cuándo usarlo

- Cuando montas tu propia disposición en lugar de `ui.workspace`: barras laterales, inspectores, esquemas.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.panel(
        pz.column([ui.list_item("Inbox", on_open, icon="inbox", selected=True, inset=True),
                   ui.list_item("Archive", on_open, icon="archive", inset=True)]),
        header=ui.panel_header("Mail", [ui.icon_button("plus", on_new, size="xs")], icon="mail"),
        width=220, side="left",
    ),
    pz.container(ui.muted("Content"), center=True, width="fill", height="fill"),
], height="fill")
```

## API

### `ui.panel`

```python
panel(
    content,
    *,
    header=None,
    width=None,
    height=None,
    side='left',
    resizable=True,
    on_resize=None,
    min_size=120,
    theme=None,
)
```

Un panel acoplable. `side` decide en qué borde va la línea; con un `width` numérico (`height` para el inferior) ese borde se arrastra para cambiar su tamaño.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `header` | `None` | Cabecera (`ui.panel_header`). |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `None` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `side` | `"left"` | `"left"`, `"right"` o `"bottom"`. |
| `resizable` | `True` | `False` mantiene el tamaño fijo. |
| `on_resize` | `None` | Se llama con el nuevo tamaño al terminar de arrastrar. |
| `min_size` | `120` | Tamaño mínimo al redimensionar. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
