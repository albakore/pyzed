## Cuándo usarlo

- Cuando una pregunta tiene más de dos respuestas (Conservar ambos / Reemplazar / Omitir).

## Uso

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.choice(
    "notes.py already exists in this folder.",
    [("Keep both", on_keep), ("Skip", on_skip), ("Replace", on_replace)],
    on_cancel, title="File exists", width=420,
))
```

## API

### `ui.choice`

```python
choice(message, options, on_cancel, *, title=None, width=440, theme=None)
```

Un mensaje con tus propios botones.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `message` | *obligatorio* | Cualquier valor de Python, o un callable. |
| `options` | *obligatorio* | Pares `(texto, on_press)`; el último es el botón principal. |
| `on_cancel` | *obligatorio* | El icono de cerrar. |
| `title` | `None` | Título. |
| `width` | `440` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
