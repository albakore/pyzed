La barra superior de la ventana: widgets al principio (`start`, selectores de proyecto y rama), un `center` opcional y widgets al final (`end`, cuenta, notificaciones). `ui.title_button` es el botón compacto que usa (`pyzed ▾`, `main`), con estilos `chevron` y `muted`.

## Cuándo usarlo

- Arriba de un `ui.workspace`, o de cualquier ventana con `decorations=False`.

## Uso

```python
from pyzed import ui

ui.title_bar(
    [ui.title_button("pyzed", on_projects, chevron=True),
     ui.title_button("main", on_branches, icon="git-branch", muted=True)],
    [ui.facepile(["Ana", "Luis"]), ui.icon_button("bell", on_bell, size="sm"), ui.avatar("KV")],
    center=ui.muted("notes.py"),
)
```

## API

### `ui.title_bar`

```python
title_bar(start=(), end=(), *, center=None, height=34, theme=None)
```

La barra superior: selectores de proyecto y rama a la izquierda, cuenta y acciones a la derecha.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `start` | `()` | Widgets al inicio (izquierda). |
| `end` | `()` | Widgets al final (derecha). |
| `center` | `None` | Widget centrado. |
| `height` | `34` | Alto. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.title_button`

```python
title_button(
    content,
    on_press=None,
    *,
    icon=None,
    muted=False,
    chevron=False,
    theme=None,
)
```

Un botón compacto para la barra de título (`pyzed ▾`, `main`…).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Texto. |
| `on_press` | `None` | Mensaje o callable que se envía al pulsar. `None` deshabilita el control. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `muted` | `False` | Texto atenuado. |
| `chevron` | `False` | Añade un ▾. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
