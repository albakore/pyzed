## Cuándo usarlo

- Para pasar un enlace, una contraseña de Wi-Fi o un código de emparejamiento a un móvil.

## Uso

```python
import pyzed as pz

pz.row([
    pz.qr_code("https://albakore.github.io/pyzed/", cell_size=5),
    pz.qr_code("pyzed", cell_size=5, color="#74ade8", bg="#282c33"),
], spacing=24, align="center")
```

## API

### `pz.qr_code`

```python
qr_code(data, *, cell_size=4.0, color=None, bg=None)
```

Un código QR que codifica `data`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `data` | *obligatorio* | El texto o URL a codificar. |
| `cell_size` | `4.0` | Tamaño de cada módulo en píxeles. |
| `color` | `None` | Color del texto o del icono. |
| `bg` | `None` | Color de fondo (`"#rrggbb[aa]"`, `(r, g, b[, a])` o `"transparent"`). |
