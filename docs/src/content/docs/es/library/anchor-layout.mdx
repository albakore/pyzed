:::tip[En pocas palabras]
Coloca las cosas justo donde las pones y dice a qué esquina se pega cada una cuando la ventana crece.
:::

Coloca los hijos en posiciones exactas, como un diseñador visual de formularios, y dice cómo sigue cada uno un cambio de tamaño: `pz.anchor(child, x=, y=, width=, height=, anchor=)` mantiene la distancia a los bordes a los que está anclado, se estira entre bordes opuestos y si no se queda centrado. Presets como `"top_right"`, `"bottom_wide"`, `"center"` o `"full"` cubren los casos habituales. `pyzed.anchors.place` es la cuenta que hay detrás, para tus propias disposiciones.

`pz.anchor_layout` · Categoría: [Disposición](/pyzed/es/library/#disposición) · [Referencia completa →](/pyzed/es/reference/widgets/#anchor_layout)

## Cuándo usarlo

- Para formularios dibujados en Pyzed Design (es lo que genera la vista de Formulario) o traídos de Visual Basic, Qt Designer o WinForms.
- Para HUDs de juegos y capas en las que las cosas se pegan a las esquinas.
- Para formularios que crecen y encogen con la ventana, mejor `row`, `column` y `grid`.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Report(pz.App):
    def view(self):
        return pz.anchor_layout([
            pz.anchor(ui.heading("Report"), x=16, y=12, width=368, height=28, anchor="top_wide"),
            pz.anchor(self.table(), x=16, y=48, width=368, height=196, anchor="full"),
            pz.anchor(ui.button("Close", self.close), x=284, y=252, width=100, height=32,
                      anchor="bottom_right"),
        ], design=(400, 300))
```

## Consejos

:::tip
`design` es el tamaño en el que se midieron las posiciones; cuando la disposición tiene más o menos espacio, cada hijo se mueve o se estira desde ahí. Pruébalo en vivo: arrastra la esquina de un formulario en Pyzed Design.
:::

## API

### `pz.anchor_layout`

```python
anchor_layout(children, *, design=None, width='fill', height='fill')
```

Coloca libremente hijos hechos con `pz.anchor`, como un formulario diseñado: al cambiar de tamaño, cada hijo mantiene su distancia a los bordes a los que está anclado, se estira entre bordes opuestos y se queda centrado en los demás casos. Los últimos hijos se dibujan encima. Ver [Disposiciones ancladas](/pyzed/es/guides/layout/#disposiciones-ancladas).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `children` | *obligatorio* | Hijos hechos con `pz.anchor(...)` (`None` se ignora). |
| `design` | `None` | `(ancho, alto)` en el que se colocaron los hijos; por defecto, el más pequeño que los contiene. |
| `width` | `"fill"` | Ancho. |
| `height` | `"fill"` | Alto. |

[Referencia completa →](/pyzed/es/reference/widgets/#anchor_layout)

### `pz.anchor`

```python
anchor(
    content,
    *,
    x=0,
    y=0,
    width=100,
    height=28,
    anchor='top_left',
    min_width=0,
    min_height=0,
    max_width=0,
    max_height=0,
    pivot=(0.5, 0.5),
    rotate=0,
)
```

Coloca un hijo de `pz.anchor_layout` en `x`, `y` con `width` y `height` (en el tamaño de diseño de la disposición) y dice cómo sigue a un cambio de tamaño.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | El widget. |
| `x` | `0` | Borde izquierdo en el tamaño de diseño. |
| `y` | `0` | Borde superior en el tamaño de diseño. |
| `width` | `100` | Ancho en el tamaño de diseño. |
| `height` | `28` | Alto en el tamaño de diseño. |
| `anchor` | `"top_left"` | Un preset de `pyzed.anchors.PRESETS` (`"top_right"`, `"bottom_wide"`, `"center"`, `"full"`...), palabras (`"left right bottom"`) o una tupla de bordes. |
| `min_width` | `0` | Ancho mínimo al estirarse (`0`: sin límite). |
| `min_height` | `0` | Alto mínimo al estirarse. |
| `max_width` | `0` | Ancho máximo al estirarse (`0`: sin límite). |
| `max_height` | `0` | Alto máximo al estirarse. |
| `pivot` | `(0.5, 0.5)` | `(x, y)` de `0` a `1`: el punto que queda fijo cuando un límite lo frena, y alrededor del que gira `rotate`. |
| `rotate` | `0` | Grados en sentido horario. |

[Referencia completa →](/pyzed/es/reference/widgets/#anchor)

### `pz.anchors.place`

```python
place(
    rect,
    anchor,
    design,
    actual,
    *,
    min_size=(0, 0),
    max_size=(0, 0),
    pivot=(0.5, 0.5),
)
```

Dónde va una caja diseñada en un padre de tamaño `design` dentro de un padre de tamaño `actual`, siguiendo su anclaje, con límites de tamaño y un pivote. La cuenta detrás de `pz.anchor_layout` y de los formularios diseñados.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `rect` | *obligatorio* | `(x, y, ancho, alto)` en el tamaño de diseño. |
| `anchor` | *obligatorio* | Un preset, palabras o bordes. |
| `design` | *obligatorio* | El tamaño de diseño del padre. |
| `actual` | *obligatorio* | El tamaño actual del padre. |
| `min_size` | `(0, 0)` | Límites inferiores `(ancho, alto)` (`0`: ninguno). |
| `max_size` | `(0, 0)` | Límites superiores `(ancho, alto)` (`0`: ninguno). |
| `pivot` | `(0.5, 0.5)` | El punto que queda fijo cuando un límite frena el estiramiento. |
