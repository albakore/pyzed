## Cuándo usarlo

- Mientras carga una lista, un perfil o una tarjeta.
- Para una espera corta sin forma conocida, basta un [indicador giratorio](/pyzed/es/library/spinner/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.container(pz.row([
    ui.skeleton(height=40, circle=True),
    pz.column([ui.skeleton(width=160, height=14), ui.skeleton(lines=2, height=10)], spacing=10, width="fill"),
], spacing=12), width=360)
```

## Propiedades y API

### `ui.skeleton`

```python
skeleton(
    width='fill',
    height=12,
    *,
    lines=1,
    circle=False,
    radius=None,
    spacing=8,
    animated=True,
    theme=None,
)
```

Un marcador gris que late donde el contenido aún está cargando. `lines` hace un párrafo y `circle` un avatar.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `width` | `"fill"` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `12` | Alto de cada barra (el diámetro con `circle`). |
| `lines` | `1` | Apila varias barras, la última más corta. |
| `circle` | `False` | Un marcador redondo de `height`. |
| `radius` | `None` | Radio de las esquinas: un número o `(sup_izq, sup_der, inf_der, inf_izq)`. |
| `spacing` | `8` | Separación entre hijos, en píxeles. |
| `animated` | `True` | Late (se queda quieto si el sistema pide reducir el movimiento). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
