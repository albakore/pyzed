:::tip[En pocas palabras]
Una paleta para elegir un color, su transparencia o una mezcla de colores.
:::

`ui.ColorPicker` es un componente que elige un color con alfa, un degradado lineal (paradas que añades, arrastras y quitas, más un ángulo) o un relleno con máscara de opacidad. `on_change` recibe un evento cuyo `value` es una cadena `"#rrggbb[aa]"`, un `pz.Gradient` o un `pz.Paint`, todos válidos como fondo. `ui.color_swatch` muestra cualquiera de ellos sobre un damero.

## Cuándo usarlo

- Para editores de temas, apps de dibujo y propiedades de estilo.
- Muestra un `color_swatch` y abre el selector en un [Popover](/pyzed/es/library/popover/) al pulsarlo.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Styles(pz.App):
    def __init__(self):
        self.fill = "#3b82f6"

    def view(self):
        return pz.row([
            ui.ColorPicker(value=self.fill, on_change=lambda e: setattr(self, "fill", e.value)),
            pz.container(width=120, height=120, bg=self.fill, radius=8),
        ], spacing=16)
```

## API

### `ui.ColorPicker`

```python
class ColorPicker
```

Un componente para elegir un color con alfa, un gradiente lineal (paradas que se añaden, arrastran y quitan, más un ángulo) o un relleno con máscara de opacidad. `on_change` recibe un texto `"#rrggbb[aa]"`, un `pz.Gradient` o un `pz.Paint`, todos válidos como `background`. Devuelve el valor elegido en `value`. Ver [Estilos](/pyzed/es/theming/styles/#selector-de-color).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | `"#3b82f6"` | Un color, token del tema, `pz.Gradient` o `pz.Paint`. |
| `alpha` | `True` | Muestra la barra y el campo de alfa. |
| `gradients` | `True` | Muestra el cambio Sólido/Gradiente. |
| `masks` | `True` | Muestra el editor de máscara. |
| `swatches` | `None` | Colores rápidos (por defecto: el acento y los colores de estado del tema). |
| `on_change` | `None` | Recibe `event.value`. |

[Referencia completa →](/pyzed/es/reference/ui/#colorpicker)

### `ui.color_swatch`

```python
color_swatch(value, *, size=20, on_press=None)
```

Un cuadrito que muestra un color, gradiente o pintura sobre un damero.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Qué mostrar. |
| `size` | `20` | Lado en píxeles. |
| `on_press` | `None` | Lo hace pulsable. |

[Referencia completa →](/pyzed/es/reference/ui/#color_swatch)

### `ui.checkerboard`

```python
checkerboard(width, height, size=6)
```

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `width` | *obligatorio* | Ancho. |
| `height` | *obligatorio* | Alto. |
| `size` | `6` | Tamaño de celda. |
