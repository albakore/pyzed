## Cuándo usarlo

- En línea junto a un número o en una celda, cuando importa más la tendencia que los valores.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.sparkline([1, 4, 2, 6, 3, 7, 5, 8], width=240, height=48),
    ui.sparkline([8, 6, 7, 4, 5, 3, 2, 1], width=240, height=48, tint="error", fill=False),
], spacing=16)
```

## API

### `ui.sparkline`

```python
sparkline(values, *, width=120, height=32, tint='accent', fill=True, theme=None)
```

Un gráfico de línea diminuto para tendencias.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `values` | *obligatorio* | Valores. |
| `width` | `120` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `height` | `32` | Alto: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `fill` | `True` | Rellena el área bajo la línea. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
