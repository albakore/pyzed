## Cuándo usarlo

- En botones de icono y controles compactos cuyo significado no es evidente.
- No escondas información esencial en un tooltip: no se ve al usar el teclado.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.tooltip(ui.icon_button("save", on_save), "Save", keys="ctrl-s"),
    ui.icon_button("settings", on_settings, tooltip="Settings"),
], spacing=8)
```

## Consejos

Los tooltips solo aparecen al pasar el ratón, así que la vista previa muestra los botones. `ui.icon_button(..., tooltip="Texto")` es un atajo para envolverlo en `ui.tooltip`.

## API

### `ui.tooltip`

```python
tooltip(content, text, *, keys=None, position='bottom', theme=None)
```

Envuelve `content` con un tooltip al estilo de Zed, opcionalmente con su atajo.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `text` | *obligatorio* | Texto del tooltip. |
| `keys` | `None` | Atajo que se muestra al final, al estilo de Zed: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `position` | `"bottom"` | `"top"`, `"bottom"`, `"left"`, `"right"` o `"cursor"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `pz.tooltip`

```python
tooltip(
    content,
    tip,
    *,
    position='bottom',
    gap=4.0,
    bg=None,
    color=None,
    border_color=None,
    border_width=0.0,
    radius=None,
    shadow=None,
)
```

Muestra `tip` junto a `content` al pasar el ratón. `ui.tooltip` añade el estilo de Zed.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `tip` | *obligatorio* | Contenido del tooltip. |
| `position` | `"bottom"` | `"top"`, `"bottom"`, `"left"`, `"right"` o `"cursor"`. |
| `gap` | `4.0` | Distancia al contenido. |
| `bg` | `None` | Color de fondo (`"#rrggbb[aa]"`, `(r, g, b[, a])` o `"transparent"`). |
| `color` | `None` | Color del texto o del icono. |
| `border_color` | `None` | Color del borde. |
| `border_width` | `0.0` | Grosor del borde en píxeles. |
| `radius` | `None` | Radio de las esquinas: un número o `(sup_izq, sup_der, inf_der, inf_izq)`. |
| `shadow` | `None` | Sombra: `(color, (dx, dy), desenfoque)`. |
