:::tip[En pocas palabras]
Pregunta “¿seguro?” antes de hacer algo que no se puede deshacer.
:::

Hace una pregunta de sí o no. `danger=True` pinta de rojo el botón de confirmar; `confirm_label` y `cancel_label` cambian el texto de los botones.

`ui.confirm` · Categoría: [Diálogos](/pyzed/es/library/#diálogos) · [Referencia completa →](/pyzed/es/reference/ui/#confirm)

## Cuándo usarlo

- Antes de acciones destructivas o irreversibles: borrar, sobrescribir, descartar.

## Uso

```python
from pyzed import ui

ui.dialog_layer(main_view(), ui.confirm(
    "Delete notes.py? This can't be undone.", on_delete, on_cancel,
    title="Delete file", danger=True, confirm_label="Delete", width=360,
))
```

## API

### `ui.confirm`

```python
confirm(
    message,
    on_confirm,
    on_cancel,
    *,
    title=None,
    confirm_label=None,
    cancel_label=None,
    danger=False,
    kind=None,
    width=420,
    theme=None,
)
```

Hace una pregunta de sí o no.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `message` | *obligatorio* | Texto o widget. |
| `on_confirm` | *obligatorio* | El botón de confirmar. |
| `on_cancel` | *obligatorio* | Cancelar, el icono de cerrar. |
| `title` | `None` | Título. |
| `confirm_label` | `None` | Texto del botón de confirmar. |
| `cancel_label` | `None` | Texto del botón de cancelar. |
| `danger` | `False` | Pinta el botón de rojo y lo llama Eliminar. |
| `kind` | `None` | Añade un icono, como en `alert`. |
| `width` | `420` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
