Texto que toma el color del tema. `color` es un token del tema (`"text"`, `"accent"`, `"error"`…) o un color hex, y `size` es un paso con nombre (`"xs"` a `"2xl"`) o un número. `ui.muted(...)` es una etiqueta con el color `"text_muted"`, para texto secundario.

## Cuándo usarlo

- Para cualquier texto en una interfaz con tema: sigue los cambios de tema, a diferencia de un `pz.text` con colores fijos.
- Usa `ui.muted` para descripciones, pistas y metadatos.
- Para títulos usa [Encabezado](/pyzed/es/library/heading/).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.label("Pyzed draws native UIs with Iced."),
    ui.muted("Secondary text uses the muted color."),
    ui.label("Accent and semibold", color="accent", weight="semibold"),
    ui.label("def mono(): ...", mono=True, size="sm"),
], spacing=8)
```

## API

### `ui.label`

```python
label(
    content,
    *,
    color='text',
    size='md',
    weight=None,
    mono=False,
    italic=False,
    wrap=True,
    theme=None,
    **kwargs,
)
```

Texto con un color del tema.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `color` | `"text"` | Token del tema o color hex. Por defecto `"text"`. |
| `size` | `"md"` | `"xs"` (11), `"sm"` (12), `"md"` (13.5), `"lg"` (16), `"xl"` (20), `"2xl"` (26) o un número. |
| `weight` | `None` | Peso: `"medium"`, `"semibold"`, `"bold"`… |
| `mono` | `False` | Usa la fuente monoespaciada (IBM Plex Mono). |
| `italic` | `False` | Cursiva. |
| `wrap` | `True` | Ajuste de línea. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
| `**kwargs` | — | Se pasan a `pyzed.text`. |
