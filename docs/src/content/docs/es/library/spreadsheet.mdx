Una hoja de cálculo completa: una cuadrícula de celdas con fórmulas (146 funciones), formatos de número, formato condicional, listas desplegables y casillas, orden y filtros, filas y columnas inmovilizadas, celdas combinadas, varias hojas, deshacer, autorrelleno y copiar y pegar con Sheets y Excel, más una barra de herramientas, menús y pestañas de hojas. ## Cuándo usarlo

- Cuando los usuarios introducen, calculan o revisan datos en tabla: presupuestos, inventarios, notas, listas de precios, importaciones.
- Para mostrar registros que solo se leen y ordenan, una [tabla](/pyzed/es/library/table/) es más sencilla.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Budget(pz.App):
    def __init__(self):
        self.book = pz.Workbook()
        self.book.write([["Item", "Cost"], ["Rent", 950], ["Food", 320]])
        self.book["B4"] = "=SUM(B2:B3)"

    def changed(self, event):
        print(event.value.action, event.value.range, self.book["B4"])

    def view(self):
        return ui.Spreadsheet(book=self.book, on_change=self.changed)
```

## Eventos

Hoja de cálculo tiene **8 eventos propios**, en la tabla de abajo. Como todo widget, también tiene los **18 eventos comunes** (`click`, `double_click`, `right_click`, `mouse_enter`, `drag`, `key_down`, `resize`…), que se conectan con `.on(...)`: mira [Eventos](/pyzed/es/guides/events/) y [Eventos de cada componente](/pyzed/es/library/events/).

Es un `pz.Component`, así que también lanza `on_mount` y `on_unmount`, y sus handlers reciben un `pz.Event` cuyo `value` trae el dato.

| Evento | De | El handler recibe | Cuándo |
| --- | --- | --- | --- |
| `on_change` | `ui.Spreadsheet`, `pz.sheet` | `(event)` | Recibe `event.value` con `action`, `range` y `sheet` cuando el usuario cambia algo. |
| `on_select` | `ui.Spreadsheet`, `pz.sheet` | `(event)` | Recibe `event.value` con `range` y `sheet` cuando cambia la selección. |
| `on_context` | `pz.sheet` | `(data)` | Recibe, con un clic derecho, `kind` (`"cell"`, `"row"` o `"column"`), `cell`, `x` e `y` (relativas a la cuadrícula): muestra ahí un menú. |
| `on_dropdown` | `pz.sheet` | `(data)` | Se llama cuando debe abrirse la lista de una celda: `cell`, `options`, `x`, `y`, `width`. |
| `on_filter` | `pz.sheet` | `(data)` | Se llama al pulsar un botón de filtro de la cabecera: `column`, `x`, `y`. |
| `on_find` | `pz.sheet` | `(data)` | Se llama con Ctrl+F o Ctrl+H: `mode` (`"find"` o `"replace"`). |
| `on_invalid` | `pz.sheet` | `(data)` | Se llama cuando un valor escrito incumple una validación estricta: `cell`, `value`, `message`. |
| `on_edit` | `pz.sheet` | `(data)` | Se llama cuando empieza o termina la escritura en una celda: `editing`. |

**El handler recibe** es lo que Pyzed le pasa a tu función: `()` es nada. Cualquier handler también puede ser un mensaje (un valor que no se puede llamar), que va a `update()`.

### Manejar los eventos

Los mismos eventos escritos de tres formas. **Imperativa**: métodos de la app que cambian `self`. **Declarativa**: los handlers producen mensajes y un único `update()` decide. **Funcional**: una función pura dibuja un estado inmutable y pide cambios con `set_state(...)`. Mira [Imperativo, declarativo y funcional](/pyzed/es/guides/code-styles/).

```python
class Budget(pz.App):
    def __init__(self):
        self.book = pz.Workbook()
        self.book.write([["Item", "Cost"], ["Rent", 950], ["Food", 320]])
        self.book["B4"] = "=SUM(B2:B3)"
        self.total = self.book["B4"]

    def changed(self, event):            # on_change: event.value has action, range and sheet
        self.total = self.book["B4"]

    def view(self):
        return pz.column([
            ui.label(f"Total: {self.total}"),
            ui.Spreadsheet(book=self.book, toolbar=False, on_change=self.changed),
        ], spacing=8)
```

```python
from dataclasses import dataclass


@dataclass
class Edited:
    range: str


class Budget(pz.App):
    def __init__(self):
        self.book = pz.Workbook()
        self.book.write([["Item", "Cost"], ["Rent", 950], ["Food", 320]])
        self.last = ""

    def update(self, message):
        match message:
            case Edited(range):
                self.last = range

    def view(self):
        return pz.column([
            ui.label(f"Last change: {self.last}"),
            ui.Spreadsheet(book=self.book, tabs=False, on_change=lambda e: Edited(e.value.range)),
        ], spacing=8)
```

from dataclasses import dataclass

BOOK = pz.Workbook()                     # the data lives in the workbook, not in the state
BOOK.write([["Item", "Cost"], ["Rent", 950], ["Food", 320]])


@dataclass(frozen=True)
class State:
    selection: str = "A1"


def view(state, set_state):
    return pz.column([
        ui.label(f"Selected: {state.selection}"),
        ui.Spreadsheet(book=BOOK, toolbar=False, on_select=lambda e: set_state(selection=e.value.range)),
    ], spacing=8)

### `pz.Workbook`

```python
class Workbook
```

Un libro de hoja de cálculo: hojas de celdas con valores, fórmulas y formatos. Las celdas se leen y escriben por su dirección (`book["B2"] = "=SUM(A1:A9)"`; `book["A1:C3"]` da filas de valores); además da formato, ordena, filtra, deshace y abre y guarda archivos CSV y Excel. Se muestra (y edita) con `ui.Spreadsheet(book=book)` o `pz.sheet(book)`. Las direcciones pueden nombrar una hoja (`"Ventas!A1"`); sin ella usan la hoja activa. Las filas y columnas empiezan en 1, como en la cuadrícula; las columnas también se aceptan como letras (`"C"`).

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `sheets` | `None` | Nombres de las hojas con que empieza (una `"Sheet1"` si no se indica). |
