`ui.toast` dibuja una notificación con título, mensaje, acciones y botón de cerrar; `kind` es `"info"`, `"success"`, `"warning"` o `"error"`. `ui.toasts(base, items)` las apila en la esquina inferior derecha encima de tu vista.

## Cuándo usarlo

- Para confirmar algo que pasó en segundo plano (guardado, copiado, conectado).
- Los mensajes que necesitan respuesta van en un [Diálogo](/pyzed/es/library/confirm/).

## Uso

```python
import pyzed as pz
from pyzed import ui

import threading

class Notes(pz.App):
    def __init__(self):
        self.messages = []

    def notify(self, title):
        self.messages.append(title)
        threading.Timer(3, pz.post, args=(("expire", title),)).start()  # hide it after 3 s

    def update(self, message):
        if message[0] == "expire":
            self.messages.remove(message[1])

    def view(self):
        items = [ui.toast(m, kind="success", on_dismiss=lambda m=m: self.messages.remove(m))
                 for m in self.messages]
        return ui.toasts(self.main_view(), items)
```

## API

### `ui.toast`

```python
toast(
    title,
    message=None,
    *,
    kind='info',
    icon=None,
    on_dismiss=None,
    actions=(),
    width=340,
    theme=None,
)
```

Una notificación.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título. |
| `message` | `None` | Texto secundario. |
| `kind` | `"info"` | `"info"`, `"success"`, `"warning"` o `"error"`. |
| `icon` | `None` | Nombre de un icono de Lucide (`pyzed icons` los lista). |
| `on_dismiss` | `None` | Mensaje o callable que se envía al cerrar. |
| `actions` | `()` | Widgets extra (normalmente botones) que se muestran como acciones. |
| `width` | `340` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

### `ui.toasts`

```python
toasts(base, items, *, spacing=8)
```

Muestra `items` (normalmente `toast(...)`) apilados en la esquina inferior derecha sobre `base`.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `base` | *obligatorio* | La interfaz de debajo. |
| `items` | *obligatorio* | Lista de toasts. |
| `spacing` | `8` | Separación entre hijos, en píxeles. |
