## Cuándo usarlo

- Para elegir una entre muchas opciones cuando no caben todas (idioma, tema, codificación).
- Con dos a cinco opciones cortas, [Segmentado](/pyzed/es/library/segmented/) o un [Grupo de radios](/pyzed/es/library/radio-group/) las muestran de un vistazo.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.language = "Python"

    def view(self):
        return ui.select(["Python", "Rust", "TypeScript"], self.language,
                         lambda value: setattr(self, "language", value), width=180)
```

## Consejos

El menú se abre al pulsar; la vista previa muestra el estado cerrado.

## API

### `ui.select`

```python
select(
    options,
    selected=None,
    on_select=None,
    *,
    placeholder='Select…',
    width=None,
    size='md',
    theme=None,
)
```

Un desplegable con el estilo del tema (el `DropdownMenu` de Zed). Las opciones se muestran con `str()`, así que sirven textos, enums o dataclasses.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `options` | *obligatorio* | Lista de opciones. |
| `selected` | `None` | Opción actual. |
| `on_select` | `None` | Callable que recibe el elemento elegido. |
| `placeholder` | `"Select…"` | Texto de ayuda cuando está vacío. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `size` | `"md"` | `"sm"`, `"md"` o `"lg"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
