## Cuándo usarlo

- Para ajustes que se aplican en el acto (Wi-Fi, autoguardado, modo oscuro).
- Ponlo a la derecha de un [Campo de formulario](/pyzed/es/library/field/) para hacer pantallas de ajustes.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Settings(pz.App):
    def __init__(self):
        self.autosave = True

    def view(self):
        return ui.switch(self.autosave, lambda on: setattr(self, "autosave", on), label="Autosave")
```

## API

### `ui.switch`

```python
switch(checked, on_toggle=None, *, label=None, theme=None)
```

Un interruptor encendido/apagado.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `checked` | *obligatorio* | Estado actual. |
| `on_toggle` | `None` | Callable que recibe el nuevo `bool` (o mensaje que se envía). |
| `label` | `None` | Texto de la etiqueta. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
