## Cuándo usarlo

- Para agrupar contenido relacionado: un resumen, una sección de formulario, un panel de un dashboard.
- Para un diálogo encima de la interfaz usa [Modal](/pyzed/es/library/modal/).

## Uso

```python
import pyzed as pz
from pyzed import ui

ui.card(
    pz.column([
        ui.muted("Pyzed draws the UI with Iced, in Rust."),
        pz.row([pz.hspace(), ui.button("Cancel", on_cancel, variant="ghost"),
                ui.button("OK", on_ok, variant="solid")], spacing=8),
    ], spacing=12),
    title="Card",
    actions=[ui.icon_button("ellipsis", on_menu, size="sm")],
    width=380,
)
```

## API

### `ui.card`

```python
card(content, *, title=None, actions=(), padding=16, width=None, theme=None)
```

Una superficie con borde para agrupar contenido, con título y acciones opcionales.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `content` | *obligatorio* | Contenido: un `Widget`, un texto o un número (se convierte en texto). |
| `title` | `None` | Título. |
| `actions` | `()` | Widgets extra (normalmente botones) que se muestran como acciones. |
| `padding` | `16` | Relleno interior. |
| `width` | `None` | Ancho: píxeles, `"fill"`, `"shrink"` o `"fill:N"` (proporción). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
