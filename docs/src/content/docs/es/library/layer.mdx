Apila `overlay` encima de `base`. Al pulsar fuera de la capa se envía `on_dismiss`, y `backdrop` oscurece la vista de detrás. Con `overlay=None` devuelve `base` sin cambios, así que puede envolver siempre tu vista. `align_x`, `align_y` y `offset` colocan la capa (por defecto centrada arriba, como la paleta de Zed).

## Cuándo usarlo

- Para mostrar paletas, buscadores, modales y menús encima de todo.
- Para diálogos, [Capa de diálogo](/pyzed/es/library/dialog-layer/) ya los centra sobre un fondo oscurecido.

## Uso

```python
import pyzed as pz
from pyzed import ui

class App(pz.App):
    def __init__(self):
        self.finder_open = False

    def view(self):
        overlay = self.finder() if self.finder_open else None
        return ui.layer(self.main_view(), overlay,
                        on_dismiss=lambda: setattr(self, "finder_open", False))
```

## API

### `ui.layer`

```python
layer(
    base,
    overlay=None,
    *,
    on_dismiss=None,
    backdrop=None,
    align_x='center',
    align_y='start',
    offset=72,
)
```

Apila `overlay` sobre `base`. Hacer clic fuera envía `on_dismiss`. Con `overlay=None` devuelve `base` tal cual.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `base` | *obligatorio* | La interfaz de debajo. |
| `overlay` | `None` | Lo que flota encima (modal, paleta, menú). |
| `on_dismiss` | `None` | Mensaje o callable que se envía al cerrar. |
| `backdrop` | `None` | Color del fondo que oscurece la interfaz. |
| `align_x` | `"center"` | Alineación horizontal: `"start"`/`"left"`, `"center"`, `"end"`/`"right"`. |
| `align_y` | `"start"` | Alineación vertical: `"start"`/`"top"`, `"center"`, `"end"`/`"bottom"`. |
| `offset` | `72` | Distancia desde arriba cuando `align_y` es `"start"`. |
