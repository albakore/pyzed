## Cuándo usarlo

- Para organizar una pantalla de preferencias en secciones (Editor, Archivos, Git…).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.container(ui.settings_group("Editor", [
    ui.field("Font size", ui.number_field(14, on_change, suffix="px")),
    ui.field("Soft wrap", ui.switch(True, on_toggle)),
    ui.field("Theme", ui.select(["One Dark", "One Light"], "One Dark", on_select, width=150)),
], description="Editor preferences."), width=460)
```

## API

### `ui.settings_group`

```python
settings_group(title, rows, *, description=None, theme=None)
```

Un bloque con título de filas `ui.field` separadas por líneas, como una pantalla de ajustes.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `title` | *obligatorio* | Título del grupo. |
| `rows` | *obligatorio* | Las filas (normalmente `ui.field`). |
| `description` | `None` | Texto secundario. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
