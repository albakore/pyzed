Un anillo que se llena en el sentido de las agujas del reloj desde arriba según `value` llega a `max`. `show_value` escribe el porcentaje en el centro; `value=None` gira mientras no se sabe cuánto falta.

## Cuándo usarlo

- Para una descarga, una subida o un objetivo en poco espacio.
- En una fila de una lista, usa uno pequeño sin texto.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.row([
    ui.progress_ring(0.25),
    ui.progress_ring(0.6, size=56, thickness=5, show_value=True),
    ui.progress_ring(1.0, size=56, thickness=5, tint="success", label="Done"),
```

## Propiedades y API

### `ui.progress_ring`

```python
progress_ring(
    value,
    *,
    max=1.0,
    size=40,
    thickness=4,
    tint='accent',
    show_value=False,
    label=None,
    theme=None,
)
```

Una barra de progreso redonda que se llena en el sentido de las agujas del reloj desde arriba. `value=None` gira.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `value` | *obligatorio* | Progreso hasta `max`, o `None` para que gire. |
| `max` | `1.0` | El valor del anillo lleno. |
| `size` | `40` | Diámetro en píxeles. |
| `thickness` | `4` | Grosor del anillo. |
| `tint` | `"accent"` | Color semántico: `"accent"`, `"error"`, `"warning"`, `"success"`, `"info"` o un token. |
| `show_value` | `False` | Escribe el porcentaje en el centro. |
| `label` | `None` | Otro texto en el centro (`"3/8"`). |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
