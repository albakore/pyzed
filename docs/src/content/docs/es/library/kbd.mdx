:::tip[En pocas palabras]
Dibuja teclas del teclado para que la gente aprenda el atajo: Ctrl + S.
:::

Dibuja un atajo escrito como texto (`"ctrl-shift-p"`, acordes como `"cmd-k cmd-s"`) como teclas. En macOS usa símbolos (⌘⇧P) y palabras en el resto; `pyzed.ui.base.KEY_STYLE` fuerza `"symbols"` o `"words"`. `ui.format_keys` devuelve las etiquetas si quieres dibujarlas tú.

## Cuándo usarlo

- En menús, tooltips, paletas y pantallas de ayuda, para enseñar atajos.
- Muchos componentes ya aceptan `keys=` y lo dibujan por ti (botón, entrada de menú, tooltip).

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.kbd("ctrl-shift-p"),
    ui.kbd("ctrl-k ctrl-s"),
    pz.row([ui.kbd("escape", size="xs"), ui.kbd("enter", size="xs"), ui.kbd("tab", size="xs")], spacing=8),
], spacing=12, align="center")
```

## API

### `ui.kbd`

```python
kbd(keys, *, size='sm', theme=None)
```

Dibuja un atajo como teclas: `"ctrl-shift-p"`, `"cmd-k cmd-s"`. En macOS usa símbolos (⌘⇧P) y en el resto palabras.

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `keys` | *obligatorio* | El atajo. |
| `size` | `"sm"` | `"xs"` o `"sm"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |

[Referencia completa →](/pyzed/es/reference/ui/#kbd)

### `ui.format_keys`

```python
format_keys(keys)
```

Separa un atajo en etiquetas por acorde: `format_keys("ctrl-shift-p") == [["Ctrl", "Shift", "P"]]`. El estilo se controla con `pyzed.ui.base.KEY_STYLE` (`"auto"`, `"symbols"` o `"words"`).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `keys` | *obligatorio* | El atajo. |

[Referencia completa →](/pyzed/es/reference/ui/#format_keys)
