## Cuándo usarlo

- En editores vacíos y pies de página, para enseñar los atajos de las acciones más útiles.

## Uso

```python
import pyzed as pz
from pyzed import ui

pz.column([
    ui.keybinding_hint("Open file", "ctrl-p"),
    ui.keybinding_hint("Command palette", "ctrl-shift-p"),
    ui.keybinding_hint("Toggle terminal", "ctrl-j"),
], spacing=10, align="center")
```

## Propiedades y API

### `ui.keybinding_hint`

```python
keybinding_hint(text, keys, *, theme=None)
```

Una pista atenuada como «Abrir archivo Ctrl P» para pies y estados vacíos.

| Propiedad | Por defecto | Descripción |
| --- | --- | --- |
| `text` | *obligatorio* | Texto. |
| `keys` | *obligatorio* | Atajo que se muestra al final, escrito como texto: `"ctrl-s"`, `"cmd-k cmd-s"`. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
