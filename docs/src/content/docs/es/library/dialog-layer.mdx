## Cuándo usarlo

- Alrededor de toda tu vista, para mostrar cualquiera de estos diálogos o un `ui.modal`.

## Uso

```python
import pyzed as pz
from pyzed import ui

class Files(pz.App):
    def __init__(self):
        self.asking = False

    def close(self):
        self.asking = False

    def view(self):
        dialog = None
        if self.asking:
            dialog = ui.confirm("Delete main.py?", self.delete, self.close, title="Delete file", danger=True)
        return ui.dialog_layer(self.main_view(), dialog, on_dismiss=self.close)
```

## Consejos

Las etiquetas de los botones (Aceptar, Cancelar, Guardar…) se traducen con [`pyzed.i18n`](/pyzed/es/guides/i18n/).

## API

### `ui.dialog_layer`

```python
dialog_layer(base, dialog=None, *, on_dismiss=None, theme=None)
```

Muestra un diálogo centrado sobre `base` con un fondo oscurecido. Con `dialog=None` devuelve `base` sin cambios, así que puede envolver siempre la vista. Ver [Diálogos](/pyzed/es/guides/i18n/#diálogos).

| Parámetro | Por defecto | Descripción |
| --- | --- | --- |
| `base` | *obligatorio* | La interfaz de debajo. |
| `dialog` | `None` | Un diálogo de las funciones de abajo, o `ui.modal`. |
| `on_dismiss` | `None` | Se envía al hacer clic en el fondo. |
| `theme` | `None` | Tema a usar en lugar del actual (`pyzed.theme.current()`). |
