Pyzed separa **qué** muestra tu interfaz de **cómo se ve**. Todos los componentes leen sus colores del **tema**
actual, un conjunto de colores con nombre llamados tokens (`background`, `text`, `border`, `accent`...). Cambia el
tema y toda la app lo sigue; cambia un widget con `style()` y solo cambia ese widget.

<Media src={themesShot} alt="La misma app con varios de los temas incluidos, claros y oscuros" caption="La misma interfaz con varios de los temas incluidos." eager />

```python
import pyzed as pz
from pyzed import ui


class Notas(pz.App):
    theme = "Gruvbox Dark"  # cualquier nombre de pz.themes.names()

    def view(self):
        tarjeta = pz.Style(background="elevated", border=(1, "border"), radius=10, padding=16)
        return pz.column([
            ui.heading("Notas"),
            pz.container(ui.label("Con estilo como en CSS, con los colores del tema.")).style(tarjeta),
        ])
```

<Aside type="tip" title="Usa tokens, no colores hex">
Escribe `"accent"` o `"border"` en lugar de `"#3a7bc8"` siempre que puedas. Los colores de los tokens cambian con
el tema, así tu app se sigue viendo bien en modo claro y oscuro.
