Un tema es una lista de **tokens**: nombres como `accent` o `text_muted` con un color (o un tamaño) cada uno. Los
componentes nunca fijan colores a mano; le piden un token al tema. Por eso un solo cambio en el tema lo reestiliza
todo.

Los tokens se usan de dos formas:

```python
pz.text("Total").style(color="text_muted")                 # por nombre, en cualquier sitio donde va un color
pz.container(cuerpo, bg=self.resolved_theme().surface)       # como atributo del tema
```

Los colores son `#rrggbb` o `#rrggbbaa` (los dos últimos dígitos son la opacidad). Los nombres de tokens funcionan en
`style()`, en los parámetros `color=`/`tint=` de los componentes, en
[`pz.Paint`](/pyzed/es/theming/styles/#gradientes-opacidad-y-máscaras) y en los campos de color del diseñador.

<Aside type="tip" title="Piensa en capas">
De atrás hacia adelante: la **ventana** (`background`), las **superficies** sobre ella (`surface`, `panel`,
`elevated`), los **elementos** sobre ellas (`element`, `ghost_*`) y el **texto y los iconos** encima. Haz cada capa un
poco más clara (temas oscuros) o más oscura (temas claros) que la de atrás.
</Aside>

## Sintaxis, terminal y personas

Estos tres son colecciones en lugar de colores sueltos.

- **`syntax`**: un diccionario de un nombre de resaltado a un color, o a `(color, "italic")` / `(color, "bold")`. Los
  nombres principales son `primary`, `comment`, `comment.doc`, `keyword`, `function`, `type`, `string`,
  `string.escape`, `number`, `boolean`, `constant`, `property`, `attribute`, `operator`, `variable`,
  `variable.special`, `punctuation`, `punctuation.bracket`, `tag`, `title` y `link_uri`. Un nombre con punto que
  falta usa su primera parte (`string.escape` → `string`).
- **`ansi`**: los colores de la terminal: `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan`, `white`,
  `bright_black` y `dim`.
- **`players`**: una tupla de colores para avatares y colaboradores; `ui.avatar(index=n)` y `ui.facepile` toman el
  n-ésimo.

## Tamaños y metadatos

| Token | Por defecto | Qué fija |
| --- | --- | --- |
| `radius` | `6.0` | Radio de las esquinas de tarjetas, diálogos y superficies grandes (las tarjetas usan `radius + 2`). |
| `radius_sm` | `4.0` | Radio de botones, campos, chips y filas de listas. |
| `ui_font_size` | `14.0` | El tamaño base del texto de la interfaz; lo fijan el **Tamaño de fuente** de un formulario y el `size` del estilo global. |
| `buffer_font_size` | `14.0` | Tamaño del texto en el editor de código. |
| `name` | | El nombre que usan `pz.themes.get` y `theme = "..."`. |
| `appearance` | | `"dark"` o `"light"`; `theme.is_dark` lo lee. |

## Desde Python

```python
t = pz.themes.get("One Dark")
t.accent                 # '#74ade8'
t.color("text_muted")    # lo mismo que t.text_muted; los colores hex pasan sin cambios
t.tokens()               # todos los tokens como diccionario
t.to_dict()              # apto para JSON, el formato que escribe Theme.save
```

Los nombres siguen el formato de temas del editor Zed, así que los temas hechos para él se pueden importar (mira
[Crear temas](/pyzed/es/theming/custom-themes/#importar-un-tema-de-zed)). La [API de temas](/pyzed/es/reference/theme/)
lista cada método.
