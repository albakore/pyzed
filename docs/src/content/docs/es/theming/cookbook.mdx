Seis temas completos, listos para copiar en tu app. Cada uno es un archivo de
[`examples/theming/`](https://github.com/albakore/pyzed/tree/main/examples/theming) y dibuja la misma pantalla
(`preview.py`: botones en cada variante, un pequeño formulario, insignias, un aviso y dos estadísticas), así puedes
comparar cómo la cambia cada tema.

<Aside type="note" title="Código en inglés">
Los ejemplos del repositorio están escritos en inglés, como el resto del código de Pyzed; los comentarios explican
cada parte.
</Aside>

## Ejecutarlos

Desde un clon del repositorio (mira [Ejecutar los ejemplos](/pyzed/es/examples/)):

<Tabs syncKey="pkg">
	<TabItem label="uv">
		```bash
		uv run python examples/theming/brand.py
		```
	</TabItem>
	<TabItem label="pip">
		```bash title="macOS y Linux"
		python3 examples/theming/brand.py
		```

		```powershell title="Windows (PowerShell)"
		py examples\theming\brand.py
		```
	</TabItem>
</Tabs>

Cambia `brand.py` por `high_contrast.py`, `retro_terminal.py`, `glassy_dark.py`, `pastel.py` o `mixed.py`.

<Aside type="tip" title="Copiar uno a tu proyecto">
Copia la parte del tema (todo lo que está encima de `class ...App`) a un módulo de tu proyecto, como `mitema.py`, e
impórtalo antes de que arranque la app. El import de `preview` es solo para estos ejemplos.
</Aside>

## Tema de marca, claro y oscuro

La paleta de una empresa en dos versiones que siguen el modo claro u oscuro del sistema. `Theme.generate` construye
cada versión a partir de tres colores; `derive` fija el verde propio de la marca para el éxito.

<Media src={brandDark} light={brandLight} alt="La pantalla de prueba con el tema de marca Acme" caption="Acme Dark y, con el sitio en modo claro, Acme Light." />

<Code code={brandSrc} lang="py" title="examples/theming/brand.py" />

**Qué cambiar:** los tres colores de cada `generate`, y `radius` para esquinas más redondas o más rectas.

## Alto contraste

Negro y blanco puros con foco amarillo, para quien necesita un contraste fuerte (y una buena prueba de cómo se ve tu
app con bordes grandes y claros). `Theme.from_dict` lista cada token que cambia; el resto viene de One Dark. El script
muestra la relación de contraste de los colores principales al arrancar.

<Media src={contrastShot} alt="La pantalla de prueba en negro, blanco y amarillo" caption="Alto contraste: bordes blancos, acento amarillo, esquinas rectas." />

<Code code={contrastSrc} lang="py" title="examples/theming/high_contrast.py" />

## Vidrio oscuro

Un degradado detrás de la ventana y un panel de vidrio esmerilado encima. El tema es One Dark con acento cian; el
aspecto viene del estilo global (`background=` un degradado) y del efecto `glass`.

<Media src={glassyShot} alt="Un panel esmerilado sobre un degradado azul y morado" caption="Vidrio oscuro: una ventana con degradado y un panel de vidrio." />

<Code code={glassySrc} lang="py" title="examples/theming/glassy_dark.py" />

<Aside type="caution" title="Efectos y GPU">
`glass`, `backdrop_blur` y `glow` están pensados para el renderizador por GPU. En equipos sin GPU (algunas máquinas
virtuales y escritorios remotos) o con el renderizador por CPU (`ICED_BACKEND=tiny-skia`), pueden verse más simples
que en esta captura. Asegúrate de que el texto se siga leyendo bien sin ellos.
</Aside>
