## Qué aprenderás

- Encontrar la **carpeta correcta** para las partidas guardadas en Windows, macOS y Linux.
- **Guardar con seguridad**: escribir un archivo temporal y cambiarlo de golpe, y sobrevivir a un archivo dañado.
- Pedir un **nombre** con `ui.input` (Enter confirma) y una **tabla de récords** hecha de filas.
- **Efectos de sonido**: un método al que se llama donde va un sonido, que toca percusión sintetizada con `pyzed.audio`.
- **Empaquetar** el juego como app.

<Steps>

1. **Dónde van las partidas guardadas.** Cada sistema tiene una carpeta para los datos de las apps, y los juegos no
   deberían escribir junto a su código (esa carpeta puede ser de solo lectura una vez instalado):

   ```python
   def data_dir(app_name):
       if sys.platform == "win32":
           base = Path(os.environ.get("APPDATA") or Path.home() / "AppData" / "Roaming")
       elif sys.platform == "darwin":
           base = Path.home() / "Library" / "Application Support"
       else:
           base = Path(os.environ.get("XDG_DATA_HOME") or Path.home() / ".local" / "share")
       return base / app_name
   ```

   | Sistema | Carpeta de "Target Rush" |
   | --- | --- |
   | Windows | `C:\Users\tú\AppData\Roaming\Target Rush` |
   | macOS | `~/Library/Application Support/Target Rush` |
   | Linux | `~/.local/share/Target Rush` |

2. **Cargar sin miedo.** La primera vez no hay archivo, y un archivo se puede dañar (un disco lleno, alguien que lo
   edita a mano). Las dos cosas deberían significar "aún no hay récords", nunca un error:

   ```python
   def load(self):
       try:
           data = json.loads(self.path.read_text(encoding="utf-8"))
           entries = [e for e in data.get("scores", []) if isinstance(e.get("score"), int)]
       except (OSError, ValueError, AttributeError):
           return []
       return sorted(entries, key=lambda e: -e["score"])[:KEEP]
   ```

3. **Guardar con seguridad.** Si el juego falla mientras escribe, un archivo a medias perdería todos los récords. Así
   que escribe un archivo temporal en la misma carpeta y sustituye el real en un solo paso; `os.replace` es atómico en
   todos los sistemas:

   ```python
   def save(self):
       self.path.parent.mkdir(parents=True, exist_ok=True)
       fd, tmp = tempfile.mkstemp(dir=self.path.parent, prefix=".scores-", suffix=".json")
       with os.fdopen(fd, "w", encoding="utf-8") as f:
           json.dump({"version": 1, "scores": self.entries}, f, indent=2)
       os.replace(tmp, self.path)
   ```

   El `"version": 1` no cuesta nada y permite que una versión futura del juego lea de otra forma las partidas antiguas.

4. **¿Entra en la tabla?** Una puntuación entra si la tabla aún no está llena o supera a la última. `add` la inserta,
   se queda con las 10 mejores, guarda y devuelve el puesto:

   ```python
   def qualifies(self, score):
       return score > 0 and (len(self.entries) < KEEP or score > self.entries[-1]["score"])

   def add(self, name, score):
       entry = {"name": name.strip()[:16] or "Player", "score": score, "date": time.strftime("%Y-%m-%d")}
       self.entries.append(entry)
       self.entries.sort(key=lambda e: -e["score"])
       del self.entries[KEEP:]
       self.save()
       return self.entries.index(entry) + 1 if entry in self.entries else None
   ```

5. **Pedir el nombre.** Cuando una ronda termina con una puntuación que entra, la escena pasa a `"name"`. `ui.input`
   mantiene el texto en tu estado con `on_input`, y `on_submit` se ejecuta con <kbd>Enter</kbd>, así que basta con
   escribir un nombre y pulsar Enter:

   ```python
   ui.input(self.name, self.set_name, placeholder="Your name", icon="user",
            on_submit=self.submit_name, id="name", max_length=16)
   ```

   La tabla es una columna de filas; la fila recién añadida tiene un fondo teñido, y las tres primeras tienen números
   de oro, plata y bronce.

6. **Ganchos de sonido.** Decide *dónde* van los sonidos antes de decidir *cómo* suenan. Target Rush llama a
   `self.sound("hit")`, `"miss"`, `"combo"`, `"start"`, `"end"` y `"record"` en el momento justo, y solo este método
   sabe qué hacer con ellos:

   ```python
   def sound(self, name):
       """Called wherever a sound belongs: "start", "hit", "miss", "combo", "end", "record"."""
       self.last_sound, self.sound_age = name, 0.0
       if self.sounds is None and self.sound_backend:
           self.sounds = Sounds(self.sound_backend)    # the first sound starts the engine
       if self.sounds:
           self.sounds.play(name)
   ```

   Además muestra el nombre en el HUD un momento, algo útil para comprobar el ritmo de tus sonidos.

7. **Crea los sonidos.** `Sounds` monta un pequeño patch con [`pyzed.audio`](/pyzed/es/audio/): cuatro voces
   `drum` que entran en un `mixer` y van a los altavoces. Cada efecto es una voz con su propia afinación, en una
   tabla al principio del archivo, así que no hay archivos de sonido que distribuir:

   ```python
   SOUNDS = {                # effect: (drum voice, tune in semitones, decay in seconds)
       "hit": ("tom", 7, 0.12),
       "miss": ("kick", -6, 0.25),
       ...
   }

   def play(self, name):
       kind, tune, decay = SOUNDS[name]
       voice = self.voices[kind]
       voice.set(tune=tune, decay=decay)
       voice.trigger()       # returns at once: the sound plays on the audio thread
   ```

</Steps>

## Efectos de sonido

`pyzed.audio` calcula el sonido en Rust, en su propio hilo de tiempo real, así que `trigger()` nunca frena el bucle
de fotogramas, y sin tarjeta de sonido el motor suena en silencio en vez de fallar. Algunas formas de ir más lejos:

- **Sonidos grabados**: un módulo `sampler` reproduce un archivo WAV. Llama a `node.load("coin.wav")` una vez al
  empezar y a `node.trigger()` en `sound()`.
- **Ajustes de volumen**: el módulo `audio_out` tiene un mando `volume`, y el mezclador un `level_1`…`level_4` por
  canal. Cámbialos desde los sliders de [Orb Rush](/pyzed/es/games/menus-hud/): `self.sounds.out["volume"] = valor`.
- **Música**: un `clock` y un `sequencer` tocan un bucle solos; mira el [motor de audio](/pyzed/es/audio/engine/getting-started/).
- **Pruebas**: `sound_backend="offline"` nunca abre un dispositivo; las pruebas llaman a `engine.render(segundos)`
  para comprobar que cada efecto suena, y `None` silencia el juego.

<Aside type="tip">
Que los sonidos sean cortos y un poco distintos cada vez (varía `tune` un semitono o dos), para que un sonido que se
oye cien veces en una partida no canse.
</Aside>

Guarda los ajustes igual que los récords: un `settings.json` junto a `scores.json`, escrito con el mismo `save()`
al cerrar la pantalla de ajustes, y cargado al empezar con valores por defecto para las claves que falten.
