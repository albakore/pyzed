Un **tema** es el conjunto de colores (y algunos tamaños, como el radio de las esquinas) que lee cada componente al
dibujarse. Cambias el tema y cambia toda la ventana a la vez: botones, campos, insignias, el editor de código... Nunca
coloreas los componentes uno por uno.

| Objetivo | Tiempo | Nivel | Necesitas |
| --- | --- | --- | --- |
| Una ventana con un selector de tema | 15 minutos | Básico · Python, o sin código en el diseñador | [Bases del diseño de pantallas](/pyzed/es/tutorials/basic/layout-basics/) |

## Qué vas a aprender

- Elegir un tema en código (`theme = "Pyzed Light"`) y en el diseñador (**Propiedades → Aspecto → Tema**).
- Cambiar solo el color de **acento**.
- Seguir el modo **claro u oscuro** del sistema operativo.
- Crear **tu propio tema** a partir de tres colores y darle un nombre.
- Usar **colores del tema** (`"accent"`, `"text_muted"`) en lugar de valores `#hex` fijos.

## Pasos

<Steps>

1. **Elige un tema incluido.** `theme` es un atributo de clase de tu app. Sirve cualquier nombre de
   `pz.themes.names()`: las familias One, Ayu y Gruvbox, claras y oscuras.

   ```python
   class ThemeSwitcher(pz.App):
       theme = "Pyzed Dark"
   ```

2. **Cámbialo mientras la app corre.** Asigna `self.theme`; el siguiente redibujado lo usa. Un desplegable con todos
   los temas es una línea:

   ```python
   ui.select(pz.themes.names(), self.base, lambda name: setattr(self, "theme", name))
   ```

3. **Cambia solo el acento.** El acento es el color de los botones principales, los anillos de foco, la selección y
   los enlaces:

   ```python
   self.theme = pz.themes.get("Pyzed Dark").with_accent("#e5c07b")
   ```

4. **Sigue al sistema.** `pz.themes.auto(light, dark)` cambia solo cuando el usuario pasa su sistema operativo de
   modo claro a oscuro:

   ```python
   self.theme = pz.themes.auto("Pyzed Light", "Pyzed Dark")
   ```

5. **Crea el tuyo.** `pz.Theme.generate` deduce cada superficie, borde, estado hover y texto atenuado a partir de
   tres colores; `pz.themes.register` lo añade a la lista con su nombre:

   ```python
   SUNSET = pz.themes.register(
       pz.Theme.generate("Sunset", background="#2b1d2f", text="#f5e6e8", accent="#ff8a65")
   )
   ```

6. **Lee el tema en tu vista.** `self.resolved_theme()` devuelve el `Theme` en uso, útil para un fondo o para
   decir "oscuro" o "claro":

   ```python
   t = self.resolved_theme()
   pz.container(..., bg=t.background)
   ui.muted(f"Using {t.name} ({'dark' if t.is_dark else 'light'})")
   ```

</Steps>

<Aside type="tip" title="Usa colores del tema, no #hex">
Donde un componente acepte un color, prefiere un **token** como `"accent"`, `"text_muted"`, `"success"` o
`"error"` en lugar de un `"#3b82f6"` fijo. Los tokens siguen al tema, así tu app se lee bien en temas claros y
oscuros.
</Aside>

## En Pyzed Design

Selecciona un lugar vacío del lienzo para que el panel Propiedades muestre el **formulario** y abre la sección
**Aspecto** (*Look*):

- **Tema** (*Theme*): todos los temas registrados.
- **Acento** (*Accent*): siete colores predefinidos, o un `#rrggbb` propio.
- **Fondo**, **Radio de esquina** y **Tamaño de letra** para todo el formulario.

## Eventos de este tutorial

| Widget | Evento | El handler recibe |
| --- | --- | --- |
| `ui.switch` (Seguir al sistema) | `on_toggle` | `True` o `False`. |
| `ui.select` (Tema) | `on_select` | El nombre del tema. |
| `ui.segmented` (Acento) | `on_select` | El nombre del acento. |
| `ui.input` (Tu nombre) | `on_input` | El texto. |

`self.choose("base")` devuelve el handler: una función pequeña que guarda lo que recibe en ese campo. Una sola
fábrica sirve a los tres controles.

### Prueba más eventos

```python
def on_key(self, combo):                    # un atajo para todas las ventanas de la app
    if combo == "ctrl-t":                   # Ctrl+T: alterna claro y oscuro
        self.base = "Pyzed Light" if self.resolved_theme().is_dark else "Pyzed Dark"
        self.follow_system = False

def on_resize(self, width, height):         # el evento de tamaño de la propia ventana
    self.compact = width < 600              # p. ej. ocultar la vista previa en ventanas pequeñas
```
