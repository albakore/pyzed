## 1. Una ventana

Una app es una clase que hereda de `pz.App` y define `view()`. `view()` devuelve un árbol de
widgets (`pz.text`, `pz.column`, `pz.row`, `pz.container`…). Pyzed la vuelve a llamar después de
cada cambio, así que nunca modificas widgets: describes cómo se ve el estado actual. Atributos
de clase como `title` y `size` configuran la ventana.

## 2. Estado y mensajes

El estado son atributos normales de tu objeto. Los widgets reciben qué hacer de dos formas:

- **Un valor** (`ui.button("Greet", "greet")`): se envía a `update(message)`.
- **Un callable** (`ui.button("Reset", self.reset)`): se llama directamente.

Los callbacks que traen datos reciben el valor nuevo: `on_input=lambda text: ...`,
`on_toggle=lambda checked: ...`, `on_change=lambda value: ...`.

## 3. Layout, componentes y temas

`pyzed.ui` trae componentes listos para usar (`button`, `input`, `select`, `number_field`,

## 4. Async

El trabajo lento no debe bloquear la ventana. `Command.perform` acepta funciones `async def`, que
corren en el loop de asyncio de Pyzed; el resultado llega a tu callback en el hilo de la interfaz.
Mientras carga, una suscripción `pz.every` redibuja la ventana para animar el spinner. También
puedes devolver corrutinas o generadores desde `update` y los callbacks: lo explica la guía
[Async y suscripciones](/pyzed/es/guides/async/).

## Eventos de este tutorial

| Paso | Widget | Evento | El handler recibe |
| --- | --- | --- | --- |
| 2 | `ui.input` | `on_input` | El texto nuevo, en cada tecla. |
| 2 | `ui.input`, `ui.button` | `on_submit`, `on_press` | Nada. Aquí son el *mensaje* `"greet"`, que va a `update`. |
| 3 | `ui.number_field`, `ui.switch`, `ui.select` | `on_change`, `on_toggle`, `on_select` | El número, `True`/`False`, la opción. |
| 4 | `subscriptions()` | un temporizador | `pz.every(segundos, mensaje)` manda el mensaje a `update`. |
| 5 | `on_key(combo)` | cada tecla | La combinación, como `"ctrl-n"`. |
| 5 | `ui.editor`, `ui.split` | `on_change`, `on_resize` | El texto; la parte del primer panel. |

El paso 2 maneja sus eventos en dos estilos a la vez: la caja llama a una lambda que cambia `self` (imperativo) y el
botón manda el mensaje `"greet"` a `update` (declarativo). El mismo saludador solo con mensajes:

```python
from dataclasses import dataclass


@dataclass
class Typed:
    text: str


class Greeter(pz.App):
    def __init__(self):
        self.name, self.greetings = "", 0

    def update(self, message):
        match message:
            case Typed(text):
                self.name = text
            case "greet" if self.name:
                self.greetings += 1

    def view(self):
        return pz.column([
            ui.input(self.name, Typed, placeholder="Tu nombre", on_submit="greet"),
            ui.button("Saludar", "greet", variant="solid"),
        ], spacing=12, padding=24)
```
