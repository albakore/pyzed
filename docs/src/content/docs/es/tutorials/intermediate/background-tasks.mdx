Una interfaz nunca debe bloquearse esperando a la red o al disco. Pyzed ofrece dos herramientas:

- **`Command.perform(fn, then)`** ejecuta una función bloqueante en otro hilo y te entrega el
  resultado.
- **`pz.post(mensaje)`** envía mensajes a la app desde cualquier hilo (progreso, eventos).

| Objetivo | Tiempo | Nivel | Necesitas |
| --- | --- | --- | --- |
| Descargas con barras de progreso y notificaciones que nunca congelan la ventana | 30 minutos | Intermedio · Python | [Diálogos y notificaciones](/pyzed/es/tutorials/intermediate/dialogs-feedback/) |

## Qué vas a aprender

- Por qué el trabajo lento debe salir del hilo de la interfaz, y las dos formas de sacarlo.
- Recibir un resultado con `Command.perform`.
- Informar del progreso desde un hilo con `pz.post` y manejarlo en `update`.
- Mostrar notificaciones que se cierran solas.

<Aside type="tip">
Si prefieres `asyncio`, `update` y los callbacks también pueden ser `async def` o generadores
`async`, y `pz.listen` convierte un stream en una suscripción. Lo cuenta la guía
[Async y suscripciones](/pyzed/es/guides/async/).
</Aside>

<Steps>

1. **Un resultado: `Command.perform`.** Para "haz esto y avísame cuando termine":

   ```python
   def check_updates(self):
       self.checking = True
       return Command.perform(self.fetch_latest_version, self.got_version)

   @staticmethod
   def fetch_latest_version():
       time.sleep(1.5)          # por ejemplo, una petición HTTP
       return "0.2.0"

   def got_version(self, version):     # se ejecuta en el hilo de la interfaz
       self.checking, self.latest = False, version
   ```

   Mientras `self.checking` es `True`, el botón se dibuja deshabilitado (`on_press=None`).

2. **Muchos resultados: `pz.post`.** Un hilo propio informa del progreso con mensajes que llegan
   a `update`:

   ```python
   def start(self, name):
       self.progress[name] = 0.0

       def worker():
           done = 0.0
           while done < 1.0:
               time.sleep(0.05)
               done = min(1.0, done + 0.05)
               pz.post(("progress", name, done))
           pz.post(("finished", name))

       threading.Thread(target=worker, daemon=True).start()

   def update(self, message):
       kind, name, *rest = message
       if kind == "progress":
           self.progress[name] = rest[0]
       elif kind == "finished":
           self.notify(f"{name} descargado", kind="success")
   ```

3. **Notificaciones que se cierran solas.** Un `threading.Timer` publica el mensaje de cierre:

   ```python
   def notify(self, title, message=None, kind="info"):
       toast_id = f"{time.monotonic()}"
       self.toasts.append((toast_id, title, message, kind))
       threading.Timer(4, pz.post, args=(("dismiss", toast_id),)).start()

   # en view():
   return ui.toasts(body, [ui.toast(t, m, kind=k, on_dismiss=("dismiss", i)) for i, t, m, k in self.toasts])
   ```

</Steps>

<Aside>
El estado solo se modifica en el hilo de la interfaz (en `update` y en los callbacks). Los hilos
de trabajo no tocan `self`: envían mensajes con `pz.post`.
</Aside>

## Eventos de este tutorial

Esta app es **declarativa**: los eventos de los hilos son mensajes. `pz.post(("progress", name, done))` desde un hilo
y el `on_dismiss=("dismiss", tid)` de cada aviso llegan a `update(message)`, que desempaqueta la tupla.

| Origen | Evento | Mensaje o handler |
| --- | --- | --- |
| Botón **Descargar** | `on_press` | `lambda: self.start(name)` |
| El hilo de trabajo | progreso, terminado | `pz.post(("progress", name, done))`, `pz.post(("finished", name))` |
| **Buscar actualizaciones** | `on_press` | `self.check_updates`, que devuelve `Command.perform(trabajo, hecho)` |
| `Command.perform` | terminó el trabajo | `self.got_version(resultado)` |
| Un aviso | `on_dismiss` | el mensaje `("dismiss", tid)` |

### Prueba más eventos

```python
def row(self, name):
    ...
    return pz.column([...]).on(double_click=lambda: self.start(name))   # doble clic: descargar otra vez

def subscriptions(self):                    # un evento por segundo mientras algo se descarga
    busy = any(v < 1 for v in self.progress.values())
    return [pz.every(1, ("tick", "", None))] if busy else []
```

`update` recibe `("tick", "", None)` cada segundo mientras hay una descarga y nada cuando terminan: la suscripción que
dejas de devolver se detiene.
