Las apps reales tienen más de una pantalla: un inicio, una bandeja de entrada, ajustes. En Pyzed, "qué pantalla se
ve" es solo **un dato del estado**, como cualquier otro. Lo cambias y `view()` dibuja la otra pantalla. No hay un
router que aprender.

| Objetivo | Tiempo | Nivel | Necesitas |
| --- | --- | --- | --- |
| Una app con barra lateral, tres páginas y pestañas | 25 minutos | Intermedio · Python | [Bases del diseño de pantallas](/pyzed/es/tutorials/basic/layout-basics/) |

## Qué vas a aprender

- Guardar la página actual en `self.page` y elegir la vista a partir de ella.
- Construir una **barra lateral** con filas `ui.list_item`, un estado seleccionado y un contador.
- Usar `ui.segmented` como **pestañas** dentro de una página.
- Mostrar **migas de pan** y saltar entre páginas con **atajos** (`on_key`).

## Pasos

<Steps>

1. **Un atributo decide la página.**

   ```python
   PAGES = {"Home": "house", "Inbox": "inbox", "Settings": "settings"}   # nombre → icono

   def __init__(self):
       self.page = "Home"

   def go(self, page):
       self.page = page
   ```

2. **La barra lateral.** Un `ui.list_item` por página. `selected=` resalta la actual y `end=` pone un contador a la
   derecha. El `name=name` del lambda guarda el nombre de cada página:

   ```python
   items = [
       ui.list_item(name, lambda name=name: self.go(name), icon=icon,
                    selected=name == self.page, height=34)
       for name, icon in PAGES.items()
   ]
   ```

3. **Elige la página en `view()`.** Cada página es un método que devuelve widgets; un dict relaciona nombres con
   métodos:

   ```python
   page = {"Home": self.home, "Inbox": self.inbox, "Settings": self.settings}[self.page]()
   return pz.row([self.sidebar(), pz.column([breadcrumbs, page], padding=24, width="fill")])
   ```

4. **Pestañas dentro de una página.** Un segundo atributo, `self.tab`, y un control `ui.segmented` para cambiarlo.
   El contenido de abajo depende de él:

   ```python
   tabs = ui.segmented(["General", "Notifications", "About"], self.tab,
                       lambda tab: setattr(self, "tab", tab))
   ```

   <Media src={settings} alt="La página Settings con la pestaña Notifications seleccionada" caption="Settings: un control segmentado funciona como pestañas." />

5. **Atajos.** `on_key` recibe cada combinación de teclas como texto. <kbd>Ctrl</kbd>+<kbd>1</kbd>,
   <kbd>Ctrl</kbd>+<kbd>2</kbd> y <kbd>Ctrl</kbd>+<kbd>3</kbd> abren las páginas:

   ```python
   def on_key(self, combo):
       shortcuts = {f"ctrl-{i}": page for i, page in enumerate(PAGES, start=1)}
       if combo in shortcuts:
           self.go(shortcuts[combo])
   ```

</Steps>

<Aside type="tip" title="El estado sobrevive al cambiar de página">
Como las páginas se dibujan a partir de tu estado, no se pierde nada al salir de una: la bandeja recuerda qué
mensajes leíste y Settings recuerda su pestaña. Para reiniciar una página, reinicia sus atributos en `go()`.
</Aside>

<Aside type="note" title="En Pyzed Design">
En el diseñador, un control **Pestañas** (*Tab bar*) lanza `change` con la pestaña elegida; muestra y oculta
paneles en su manejador (`form.general.visible = event.value == "General"`), o abre otro formulario en su propia
ventana con `form.open("settings")`. Mira [Eventos y manejadores](/pyzed/es/editor/events/).
</Aside>

## Eventos de este tutorial

| Widget | Evento | Handler |
| --- | --- | --- |
| `ui.list_item` de la barra lateral | `on_press` | `lambda name=name: self.go(name)` |
| La app | `on_key` | `ctrl-1`, `ctrl-2`, `ctrl-3` van a una página |
| `ui.breadcrumbs` | `on_press` | recibe el índice de la parte: `0` vuelve al inicio |
| `ui.list_item` del buzón | `on_press` | marca el mensaje como leído |
| `ui.segmented`, `ui.select`, `ui.switch` | `on_select`, `on_select`, `on_toggle` | la pestaña, el tema, sí/no |

### Prueba más eventos

Atrás y adelante con un historial, como un navegador:

```python
def __init__(self):
    ...
    self.history, self.future = [], []

def go(self, page):
    if page != self.page:
        self.history.append(self.page)
        self.future.clear()
        self.page = page

def on_key(self, combo):
    if combo == "alt-left" and self.history:
        self.future.append(self.page)
        self.page = self.history.pop()
    elif combo == "alt-right" and self.future:
        self.history.append(self.page)
        self.page = self.future.pop()
```

Los ratones con botones de atrás y adelante los mandan como `mouse_down` con `event.button`: añade
`.on(mouse_down=lambda e: ...)` a la página.
