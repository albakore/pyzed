Cada tutorial termina en un programa que puedes ejecutar, y su código completo está en la carpeta
[`examples`](https://github.com/albakore/pyzed/tree/main/examples) del repositorio. Para los básicos no necesitas
saber mucho Python: cada paso explica qué hace el código y por qué.

## Ejecutar los ejemplos

Clona el repositorio (o descárgalo como zip) y ejecuta cualquier ejemplo con la herramienta que uses. `uv` crea el
entorno por ti; con `pip`, primero crea y activa un entorno virtual.

<Tabs syncKey="pkg">
	<TabItem label="uv">
		```bash title="Windows, macOS y Linux"
		uv run --with pyzed-ui python examples/todo.py
		```
	</TabItem>
	<TabItem label="pip">
		```bash title="macOS y Linux"
		python3 -m venv .venv
		source .venv/bin/activate
		python -m pip install pyzed-ui
		python examples/todo.py
		```

		```powershell title="Windows (PowerShell)"
		py -m venv .venv
		.venv\Scripts\activate
		python -m pip install pyzed-ui
		python examples\todo.py
		```
	</TabItem>
</Tabs>
