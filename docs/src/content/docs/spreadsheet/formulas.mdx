A formula starts with `=` and computes a value from numbers, text and other cells. It is written
the same way as in Excel and Google Sheets, so formulas copied from either one work here, and
files you save keep them.

```python
book["B5"] = "=SUM(B2:B4)"
book["C2"] = '=IF(B2>100, "High", "Low")'
book["D2"] = "=VLOOKUP(A2, Prices!A:B, 2, FALSE)"
book["B5"]           # the result: 1410
book.formula("B5")   # the formula: "=SUM(B2:B4)"
book.text("B5")      # what the cell shows: "$1,410.00"
```

When a cell changes, only the formulas that depend on it are computed again, in the right
order. A formula that ends up depending on itself shows `#CYCLE!` instead of freezing the app.

<Aside type="note" title="In plain words">
A formula is a small calculation that lives in a cell. Write `=` and then what to compute:
`=2+2`, `=B2*1.21` (the value of B2 plus 21 %), `=SUM(B2:B9)` (add everything from B2 to B9).
If B2 changes, the result changes too.
</Aside>

## References

| Reference | Means |
| --- | --- |
| `B3` | One cell. |
| `B2:D9` | A range: from B2 to D9. |
| `A:A`, `A:C` | Whole columns. |
| `2:2`, `2:5` | Whole rows. |
| `$B$3`, `B$3`, `$B3` | Absolute references: the part with `$` does not move when the formula is copied or filled. |
| `Sales!B3`, `'Raw data'!A1:A9` | A cell or range of another sheet (quotes when the name has spaces). |

When you copy, fill, or paste a formula, its relative references move with it: `=A1*2` copied
one row down becomes `=A2*2`. When you insert or delete rows and columns, references are
updated so they keep pointing at the same cells (a deleted cell becomes `#REF!`). When you
rename a sheet, the formulas that mention it are rewritten.

While typing, press <kbd>F4</kbd> to cycle a reference between `A1`, `$A$1`, `A$1` and `$A1`.

## Operators

| Operator | Does | Example |
| --- | --- | --- |
| `+` `-` `*` `/` | Arithmetic | `=B2*C2-D2` |
| `^` | Power | `=2^10` |
| `%` | Percent | `=B2*15%` |
| `&` | Joins text | `=A2&" "&B2` |
| `=` `<>` `<` `>` `<=` `>=` | Compare (TRUE or FALSE) | `=B2>=100` |
| `-` before a value | Negative | `=-B2` |

Text goes in double quotes (`"North"`), and `TRUE` / `FALSE` are logical values. Numbers
that are text (`"12"`) are converted when an operator needs a number.

## Criteria

`COUNTIF`, `SUMIF`, `AVERAGEIF`, their `...IFS` versions and `MAXIFS` / `MINIFS` take a
criterion as text, like Excel:

| Criterion | Matches |
| --- | --- |
| `"North"` or `"=North"` | Equal to North (case does not matter). |
| `">100"`, `"<=0"`, `"<>Done"` | Compared with a number or text. |
| `"a*"`, `"*north*"`, `"??-??"` | Wildcards: `*` any text, `?` one character. |
| `">"&B1` | Built from a cell. |

## Dynamic arrays

Functions that return several values (`SEQUENCE`, `FILTER`, `SORT`, `UNIQUE`,
`TRANSPOSE`, `SPLIT`) **spill** into the cells below and to the right, like in current Excel
and Google Sheets. Only the first cell holds the formula; the others show its values. If a
cell in the way already has something, the formula shows `#SPILL!` until it is cleared.

```python
book["A1"] = "=SEQUENCE(5)"                       # 1 to 5 in A1:A5
book["C1"] = '=FILTER(A2:B20, B2:B20>100)'         # the rows with more than 100
book["F1"] = "=UNIQUE(Sales!B2:B9)"                # each region once
```

## Errors

| Error | Why |
| --- | --- |
| `#DIV/0!` | A division by zero. |
| `#VALUE!` | A value of the wrong type (text where a number was needed). |
| `#REF!` | A reference to cells that were deleted. |
| `#NAME?` | An unknown function or name. |
| `#N/A` | A lookup that found nothing. |
| `#NUM!` | A number out of range (the square root of -1). |
| `#CYCLE!` | The formula depends on itself. |
| `#SPILL!` | An array formula can't spill because cells are in the way. |
| `#ERROR!` | The formula can't be read (a missing parenthesis, for example). |

Errors travel: a formula that uses a cell with an error shows the same error. `IFERROR` and
`IFNA` catch them: `=IFERROR(B2/C2, 0)`.

## Dates and times

Dates are numbers of days, like in every spreadsheet, so you can subtract them (`=B2-A2` is
the number of days between two dates) and add days to them (`=A2+30`). `TODAY()` and `NOW()`
change every time the book is recalculated; call `book.recalculate()` to update them.

## Your own data in formulas

Formulas only read cells. To use data from your app, write it into a sheet (it can be a
hidden helper sheet) with `book.write(rows, at="A1")`, and formulas can reference it.
`pz.Workbook.functions()` returns the list below as `(name, arguments, description)`
tuples, for example to build your own function picker.
