A **theme** is the set of colors (and a few sizes, like the corner radius) every component reads when it draws
itself. Change the theme and the whole window changes at once: buttons, inputs, badges, the code editor... You
never color components one by one.

| Goal | Time | Level | You need |
| --- | --- | --- | --- |
| A window with a theme picker | 15 minutes | Basic · Python, or no code in the designer | [Layout basics](/pyzed/tutorials/basic/layout-basics/) |

## What you'll learn

- Pick a theme in code (`theme = "Pyzed Light"`) and in the designer (**Properties → Look → Theme**).
- Change only the **accent** color.
- Follow the operating system's **light or dark** mode.
- Make **your own theme** from three colors and give it a name.
- Use **theme colors** (`"accent"`, `"text_muted"`) instead of fixed `#hex` values.

## Steps

<Steps>

1. **Pick a bundled theme.** `theme` is a class attribute of your app. Any name from `pz.themes.names()` works:
   the One, Ayu and Gruvbox families, light and dark.

   ```python
   class ThemeSwitcher(pz.App):
       theme = "Pyzed Dark"
   ```

2. **Change it while the app runs.** Assign `self.theme`; the next redraw uses it. A drop-down of every theme is
   one line:

   ```python
   ui.select(pz.themes.names(), self.base, lambda name: setattr(self, "theme", name))
   ```

3. **Change only the accent.** The accent is the color of primary buttons, focus rings, selection and links:

   ```python
   self.theme = pz.themes.get("Pyzed Dark").with_accent("#e5c07b")
   ```

4. **Follow the system.** `pz.themes.auto(light, dark)` switches by itself when the user changes their operating
   system between light and dark mode:

   ```python
   self.theme = pz.themes.auto("Pyzed Light", "Pyzed Dark")
   ```

5. **Make your own.** `pz.Theme.generate` derives every surface, border, hover state and muted text from three
   colors; `pz.themes.register` adds it to the list under its name:

   ```python
   SUNSET = pz.themes.register(
       pz.Theme.generate("Sunset", background="#2b1d2f", text="#f5e6e8", accent="#ff8a65")
   )
   ```

6. **Read the theme in your view.** `self.resolved_theme()` returns the `Theme` in use, handy for a background or
   to say "dark" or "light":

   ```python
   t = self.resolved_theme()
   pz.container(..., bg=t.background)
   ui.muted(f"Using {t.name} ({'dark' if t.is_dark else 'light'})")
   ```

</Steps>

<Aside type="tip" title="Use theme colors, not #hex">
Wherever a component takes a color, prefer a **token** such as `"accent"`, `"text_muted"`, `"success"` or
`"error"` over a fixed `"#3b82f6"`. Tokens follow the theme, so your app stays readable in light and dark themes.
</Aside>

## In Pyzed Design

Select an empty spot of the canvas so the Properties panel shows the **form**, then open the **Look** section:

- **Theme**: every registered theme.
- **Accent**: seven preset colors, or a custom `#rrggbb`.
- **Background**, **Corner radius** and **Font size** for the whole form.

## Events in this tutorial

| Widget | Event | Handler gets |
| --- | --- | --- |
| `ui.switch` (Follow the system) | `on_toggle` | `True` or `False`. |
| `ui.select` (Theme) | `on_select` | The theme's name. |
| `ui.segmented` (Accent) | `on_select` | The accent's name. |
| `ui.input` (Your name) | `on_input` | The text. |

`self.choose("base")` returns the handler: a small function that stores what it receives in that field. One factory
serves the three controls.

### Try more events

```python
def on_key(self, combo):                    # a shortcut for every window of the app
    if combo == "ctrl-t":                   # Ctrl+T: flip between light and dark
        self.base = "Pyzed Light" if self.resolved_theme().is_dark else "Pyzed Dark"
        self.follow_system = False

def on_resize(self, width, height):         # the window's own resize event
    self.compact = width < 600              # e.g. hide the preview on small windows
```
