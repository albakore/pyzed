[`examples`](https://github.com/albakore/pyzed/tree/main/examples) folder of the repository. You don't need to know
much Python for the basic ones: each step explains what the code does and why.

## Running the examples

Clone the repository (or download it as a zip), then run any example with the tool you use. `uv` creates the
environment for you; with `pip`, create and activate a virtual environment first.

<Tabs syncKey="pkg">
	<TabItem label="uv">
		```bash title="Windows, macOS and Linux"
		uv run --with pyzed-ui python examples/todo.py
		```
	</TabItem>
	<TabItem label="pip">
		```bash title="macOS and Linux"
		python3 -m venv .venv
		source .venv/bin/activate
		python -m pip install pyzed-ui
		python examples/todo.py
		```

		```powershell title="Windows (PowerShell)"
		py -m venv .venv
		.venv\Scripts\activate
		python -m pip install pyzed-ui
		python examples\todo.py
		```
	</TabItem>
</Tabs>
