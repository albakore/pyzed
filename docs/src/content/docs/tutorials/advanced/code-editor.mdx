Let's build a Zed-style editor in about 150 lines: it opens a real folder, shows the file tree,
opens tabs, edits with syntax highlighting, saves with <kbd>Ctrl</kbd>+<kbd>S</kbd> and has a
command palette.

![The mini editor](../../../assets/tutorials/mini-editor.png)

<Steps>

1. **Reading the folder.** `TreeNode.from_paths` turns a list of paths into the project panel
   tree. We skip heavy folders such as `.git` or `node_modules`:

   ```python
   def scan(self):
       files = []
       for folder, dirs, names in os.walk(self.root):
           dirs[:] = [d for d in dirs if d not in IGNORED]
           rel = Path(folder).relative_to(self.root)
           files += [(rel / n).as_posix() for n in names]
       return files

   self.nodes = ui.TreeNode.from_paths(self.scan())
   self.expanded = set()          # expanded folders
   ```

2. **Opening and closing tabs.** The state is the open paths, the active one and the text of
   each. Each tab's id is its path:

   ```python
   def open_file(self, path):
       if path not in self.texts:
           self.texts[path] = (self.root / path).read_text(encoding="utf-8")
       if path not in self.open_tabs:
           self.open_tabs.append(path)
       self.active = path
   ```

3. **The editor.** We use the path as the editor's `id`, so each file keeps its cursor and undo
   history when switching tabs. `on_change` marks the file as modified:

   ```python
   ui.editor(self.active, self.texts[self.active], path=self.active,
             on_change=self.edited,
             on_cursor=lambda line, col: setattr(self, "cursor", (line, col)))

   def edited(self, text):
       self.texts[self.active] = text
       self.dirty.add(self.active)       # the tab shows a dot
   ```

4. **The workspace.** `ui.workspace` lays out the title bar, the left dock, the center and the
   status bar. Passing `None` as `left` hides the panel:

   ```python
   ui.workspace(
       self.center(),
       title_bar=ui.title_bar([ui.title_button(self.root.name, chevron=True)]),
       left=project if self.show_left else None,
       status_bar=ui.status_bar([...], [ui.status_item(f"Ln {line}, Col {col}")]),
   )
   ```

5. **Shortcuts.** We map <kbd>Cmd</kbd> to <kbd>Ctrl</kbd> so it works the same on macOS:

   ```python
   def on_key(self, combo):
       combo = combo.replace("cmd-", "ctrl-")
       if combo == "ctrl-s":
           self.save()
       elif combo == "ctrl-b":
           self.toggle_left()
   ```

6. **Command palette.** It opens with <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>, focuses its
   field and floats over the workspace with `ui.layer`:

   ```python
   if combo == "ctrl-shift-p":
       self.palette_open, self.query = True, ""
       return Command.focus("command-palette")

   # at the end of view():
   palette = ui.command_palette(self.query, lambda q: setattr(self, "query", q), self.commands(),
                                on_submit=self.run_first_match) if self.palette_open else None
   return ui.layer(layout, palette, on_dismiss=lambda: setattr(self, "palette_open", False))
   ```
