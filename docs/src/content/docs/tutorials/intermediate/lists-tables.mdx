Most apps show **data**: customers, files, orders, books. This tutorial takes a plain Python list and shows it two
ways, as a sortable **table** and as a simple **list**, with a search box and a panel with the details of the row
you click.

| Goal | Time | Level | You need |
| --- | --- | --- | --- |
| A book library with search, sorting and details | 30 minutes | Intermediate · Python | [A multi-view app](/pyzed/tutorials/intermediate/navigation/) |

## What you'll learn

- Filter data in `view()` from a search box.
- Draw a `ui.table` with columns, **sorting** by clicking a header, and clickable rows.
- Turn a cell into any widget (a colored badge) with `render=`.
- Show the same data as a list of `ui.list_item` rows.
- Keep the **selected** item and show it in a details panel; change it in place.

## Steps

<Steps>

1. **The data is just Python.** A list of dicts (objects or dataclasses work too):

   ```python
   BOOKS = [
       {"title": "Dune", "author": "Frank Herbert", "year": 1965, "status": "Read"},
       {"title": "Neuromancer", "author": "William Gibson", "year": 1984, "status": "Reading"},
       # ...
   ]
   ```

2. **Search.** Keep the text in `self.query` and filter on every redraw. No "refresh" is needed: typing changes
   the state and `view()` runs again.

   ```python
   def visible(self):
       q = self.query.lower()
       return [b for b in BOOKS if q in b["title"].lower() or q in b["author"].lower()]
   ```

3. **The columns.** A `ui.Column` has a title, the key it reads and a width (`("fill", 3)` takes three shares of
   the free space). `render=` turns the value into a widget:

   ```python
   columns = [
       ui.Column("Title", "title", width=("fill", 3)),
       ui.Column("Author", "author", width=("fill", 2)),
       ui.Column("Year", "year", width=70),
       ui.Column("Status", "status", width=100, render=lambda s: ui.badge(s, tint=TINTS[s])),
   ]
   ```

4. **Sorting.** Give the table the column it sorts by and the direction; clicking a header calls `on_sort` with
   that column's title, and you flip the direction when it is the same one:

   ```python
   def sort(self, column):
       self.descending = not self.descending if column == self.sort_by else False
       self.sort_by = column

   ui.table(columns, books, sort_by=self.sort_by, descending=self.descending, on_sort=self.sort,
            on_row_press=lambda book: setattr(self, "selected", book), selected=self.selected,
            striped=True, height="fill")
   ```

5. **The details panel** shows `self.selected`, or an empty state. Changing the status writes into the same dict,
   so the table shows it too:

   ```python
   ui.segmented(list(TINTS), book["status"], lambda s: book.__setitem__("status", s))
   ```

6. **A list view.** The same data as rows with an icon and a trailing year, switched with a segmented control:

   ```python
   ui.list_item(book["title"], lambda book=book: setattr(self, "selected", book), icon="book",
                selected=book is self.selected, end=ui.muted(str(book["year"])))
   ```

</Steps>

<Aside type="tip" title="Thousands of rows">
`ui.table` only builds the rows you can see, so a table of 100,000 rows scrolls as smoothly as one of ten. Keep
the list sorted in your state (or in a `@pz.memo` function) instead of sorting it on every redraw. The
[SQLAlchemy contacts](/pyzed/integrations/sqlalchemy/) demo shows 20,000 rows searched in SQL.
</Aside>

## Events in this tutorial

| Widget | Event | Handler gets |
| --- | --- | --- |
| `ui.table` | `on_sort` | The title of the clicked column. |
| `ui.table` | `on_row_press` | The row: the book's dict. |
| `ui.list_item` | `on_press` | Nothing (the book is bound with `book=book`). |
| `ui.search_input`, `ui.segmented` | `on_input`, `on_select` | The query; the mode. |

### Try more events

The table has two more row events: a double click and a right click.

```python
def table(self, books):
    return ui.table(
        columns, books, sort_by=self.sort_by, descending=self.descending, on_sort=self.sort,
        selected=self.selected,
        on_row_press=lambda book: setattr(self, "selected", book),
        on_row_double_press=lambda book: setattr(self, "editing", book),   # open an editor
        on_row_context=lambda book: setattr(self, "menu_for", book),       # a context menu
        striped=True, row_height=34, height="fill",
    )

def on_key(self, combo):                    # arrows move the selection
    books = self.visible()
    if combo in ("up", "down") and books:
        i = books.index(self.selected) if self.selected in books else -1
        self.selected = books[max(0, min(len(books) - 1, i + (1 if combo == "down" else -1)))]
```
