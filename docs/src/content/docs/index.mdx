	- **Smart guides**, snap to grid, align, distribute and anchors like WinForms

	- Saved as a readable `.pzform` plus a plain Python file, run with `pyzed run`

<SectionTitle n={6} id="code" eyebrow="Code first, too" title="An app in 20 lines">
	Prefer to write everything by hand? Pyzed is a regular Python library. This is a complete app:
</SectionTitle>

<CodeShowcase shot="counter" alt="The counter app: a number above the minus, plus and reset buttons" caption="python counter.py">

```python title="counter.py"
import pyzed as pz
from pyzed import ui


class Counter(pz.App):
    title = "Counter"
    size = (360, 220)

    def __init__(self):
        self.count = 0

    def add(self, step):
        self.count += step

    def view(self):
        return pz.center(pz.column([
            ui.heading(str(self.count)),
            pz.row([
                ui.button("1", lambda: self.add(-1), icon="minus"),
                ui.button("1", lambda: self.add(1), icon="plus", variant="solid"),
                ui.icon_button("rotate-ccw", lambda: setattr(self, "count", 0)),
            ], spacing=8),
        ], spacing=16, align="center"), bg=self.theme.editor)


pz.run(Counter)
```

</CodeShowcase>
