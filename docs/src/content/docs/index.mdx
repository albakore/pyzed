## An app in 20 lines

```python title="counter.py"
import pyzed as pz
from pyzed import ui


class Counter(pz.App):
    title = "Counter"
    size = (360, 220)

    def __init__(self):
        self.count = 0

    def view(self):
        return pz.center(
            pz.row([
                ui.button("-1", lambda: setattr(self, "count", self.count - 1), icon="minus"),
                ui.heading(str(self.count)),
                ui.button("+1", lambda: setattr(self, "count", self.count + 1), icon="plus", variant="solid"),
            ], spacing=12, align="center"),
            bg=self.resolved_theme().editor,
        )


pz.run(Counter)
```

## Why Pyzed

<CardGrid>
	<Card title="Native performance" icon="rocket">
		Python only describes the UI. Layout, text and drawing (wgpu, with tiny-skia as fallback)
		are handled by Iced 0.14 in Rust through PyO3.
	</Card>
	<Card title="Simple" icon="pencil">
		Iced's Elm architecture (state, `update`, `view`) without the ceremony: a button can call
		`self.save` directly.
	</Card>
	<Card title="Zed components" icon="puzzle">
		Buttons, tabs, file tree, command palette, editor with syntax highlighting, terminal,
		menus, toasts and a workspace with docks.
	</Card>
	<Card title="Themes" icon="seti:pipeline">
		One, Ayu and Gruvbox with Zed's color tokens, system light/dark mode and import of any
		Zed theme. Derive your own in one line and switch it at runtime.
	</Card>
	<Card title="Async and multiple windows" icon="random">
		`update` and callbacks can be `async`; `pz.every` and `pz.listen` for timers and
		streams. Each `pz.Window` has its own view and theme, with shared state.
	</Card>
	<Card title="Cross-platform" icon="laptop">
		Linux, macOS and Windows. IBM Plex fonts and Lucide icons (~2000) included.
	</Card>
	<Card title="Headless screenshots" icon="seti:image">
		`app.screenshot("ui.png")` renders off-screen, without a GPU. Every image on this
		site is generated that way.
	</Card>
</CardGrid>
