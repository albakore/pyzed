Most desktop apps talk to some web API. This demo explores packages on PyPI: it requests eight
packages at once, shows each as soon as it arrives, parses the JSON into Pydantic models and
draws the release history.

![A PyPI explorer listing packages with versions, and the details of FastAPI](../../../assets/integrations/httpx.png)

```bash
cd examples/integrations/httpx_pypi
uv run main.py
uv run main.py rich textual polars      # other packages
```

<Steps>

1. **Describe only what you use.** Pydantic ignores the rest of the response, converts the
   dates and fails loudly if the API changes shape:

   ```python
   class Info(BaseModel):
       name: str
       version: str
       summary: str | None = None
       requires_python: str | None = None
       project_urls: dict[str, str] | None = None

   class File(BaseModel):
       upload_time_iso_8601: datetime

   class Package(BaseModel):
       info: Info
       releases: dict[str, list[File]]
   ```

2. **Return a message, not an exception.** A function that turns every outcome into a value
   is easy to show: the model, or a short text for the list:

   ```python
   async def fetch(client, name):
       try:
           response = await client.get(f"https://pypi.org/pypi/{name}/json")
       except httpx.HTTPError as error:
           return f"Network error: {error}"
       if response.status_code == 404:
           return "Not on PyPI"
       try:
           return Package.model_validate_json(response.content)
       except ValidationError as error:
           return f"Unexpected response: {error.error_count()} problems"
   ```

3. **Stream concurrent requests with an async generator.** Each `yield` reaches `update`
   right away, so the list fills in as answers arrive instead of waiting for the slowest one:

   ```python
   async def fetch_all(names):
       async with httpx.AsyncClient(timeout=10, follow_redirects=True) as client:
           async def one(name):
               return name, await fetch(client, name)

           for done in asyncio.as_completed([one(n) for n in names]):
               yield await done

   class Explorer(pz.App):
       def on_start(self):
           return fetch_all(self.names)

       def update(self, message):
           name, result = message
           self.packages[name] = result
   ```

4. **Show the three states.** `None` while loading, a string on failure, a model on success:

   ```python
   if package is None:
       end = ui.spinner(size=12)
   elif isinstance(package, str):
       end = pz.icon("circle-alert", size=14, color=t.error)
   else:
       end = ui.muted(package.info.version, size="sm", mono=True)
   ```

</Steps>

<Aside type="tip">
For a blocking client such as `requests`, use `Command.perform(lambda: requests.get(url).json(),
self.loaded)`; it runs in a thread. Async clients scale better when you have many requests at
once.
</Aside>
