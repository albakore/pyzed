Everyday programs, each a single Python file in
[`examples/`](https://github.com/albakore/pyzed/tree/main/examples) that runs as it is. They are short on purpose:
read one from top to bottom and you will have seen state, a view, events and a subscription working together.
Several are Pyzed versions of the classic [Iced](https://iced.rs) demos, the Rust GUI library Pyzed draws with.

<Aside type="tip" title="How to read these apps">
Every app is a class with **state** (attributes set in `__init__`), a **`view()`** that builds the screen from the
state, and **methods** that change the state when something happens. Pyzed redraws after each change. New to that
idea? Start with the [To-do list tutorial](/pyzed/tutorials/basic/todo-app/).
</Aside>

## Live data

A price ticker fed by `pz.listen`: a subscription backed by an async generator. It runs while `subscriptions()`
returns it and sends every value it yields to `update`.

<Media src={tickerShot} alt="Four symbols with their price, change and a small chart" />

```python
async def feed():                       # a real app would read a websocket here
    prices = {s: random.uniform(50, 150) for s in SYMBOLS}
    while True:
        await asyncio.sleep(0.25)
        symbol = random.choice(SYMBOLS)
        prices[symbol] *= 1 + random.gauss(0, 0.01)
        yield symbol, prices[symbol]    # each value goes to update()

class Ticker(pz.App):
    def subscriptions(self):
        return [pz.listen(feed)] if self.connected else []   # the switch pauses the feed

    def update(self, message):
        symbol, price = message
        self.history[symbol] = (self.history[symbol] + [price])[-60:]
```

## Workspace editor

A full code editor workspace in about 450 lines: a project panel with the files of a folder, tabs, a
syntax-highlighted editor (edit, undo, save with <kbd>Ctrl</kbd>+<kbd>S</kbd>), git status colors, an outline
panel, theme switching, a command palette (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>) and a file finder
(<kbd>Ctrl</kbd>+<kbd>P</kbd>). Its look recreates the [Zed](https://zed.dev) editor, whose interface inspired
Pyzed's default theme. The terminal panel shows sample output; it does not run a shell.

<Media src={editorDark} light={editorLight} alt="A code editor with a project panel, tabs and an outline" size="wide" />

<Run file="examples/zed_editor.py" />
