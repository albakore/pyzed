A smart-home control center in the frosted-glass style of modern operating systems. The colored blobs behind the cards are a shader graph (`shaders/blobs.pzshad`), so the blur you see through each card moves with them.

![Glass control center](../../../assets/showcase/glass-dashboard.png)

<Run file="examples/showcase/glass_dashboard.py" />

## How it is made

### Real backdrop blur

`glass` blurs what is behind the card, not a fake gradient.

```python
GLASS = {"tint": "#ffffff", "strength": 0.10, "blur": 28}
card.style(glass=GLASS, radius=22, padding=20)
```

### Living details

The album cover spins while music plays; lit bulbs bloom.

```python
cover.animate("spin", duration=12000)
```

### Real controls

Sliders and switches update the state like in any Pyzed app.

```python
pz.slider(0, 100, self.volume, on_change=self.set_volume)
```

## Try this

- Change the `tint` and `strength` in `GLASS` and see how much of the background shows through.
- Turn every light on and watch the bloom.
- Swap the blobs for another graph from [Shaders and effects](/pyzed/showcase/shaders/#every-graph), such as
  `nebula.pzshad`.

<Aside type="tip">
Glass looks best over something that moves and has color. Over a flat background it is just a tinted panel.
</Aside>
