A title screen in the style of a synthwave racer. The sun, the stars and the endless grid are one shader graph, `shaders/synthwave.pzshad`, that scrolls with time and leans towards the pointer.

## How it is made

### Interactive shader

The graph has a **Mouse** node: the pointer position over the widget, from 0 to 1. A few math nodes move the
horizon a little with it, so the scene leans as you move. In Python it is one widget behind the content:

```python
pz.stack([
    pz.shader(SHADER, width="fill", height="fill",
              fallback=pz.Gradient(["#08021a", "#4a0d5e", "#d9468f"], angle=180)),
    content,
])
```

### Glowing title

`bloom` on a bare text lights it from its own strokes.

```python
pz.text("NEON DRIFT", size=72, weight="black").style(bloom=("#f472b6", 1.0))
```

### Menu motion

Buttons lift on hover, shrink on press and the selected one slides with a transition.

```python
button.animate("lift", on="hover").animate("shrink", on="press").transition(x=6 if selected else 0)
```
