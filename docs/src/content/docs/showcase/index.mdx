Everything on these pages is a real program in the
[`examples`](https://github.com/albakore/pyzed/tree/main/examples) folder of the repository, drawn by Pyzed with
the GPU. Click a card to see how it is made, read the full code and run it. Want to build one yourself, step by
step? The [Tutorials](/pyzed/tutorials/) take you there.

<Aside type="tip" title="Run any of them">
Download or clone the [repository](https://github.com/albakore/pyzed), open a terminal in its folder and run the
file. Every page has a block like this one, with the commands for uv, pip and plain Python on Windows, macOS and
Linux:

<Run file="examples/todos.py" />
</Aside>
