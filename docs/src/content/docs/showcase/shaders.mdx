Pyzed draws everything with the GPU, so a desktop app can have what games have: moving backgrounds, light that
spills out of bright things, frosted glass. There are two layers to it:

- **Shaders**: a small program that the graphics card runs for every pixel of a widget, every frame. In Pyzed you
  make them as **graphs of nodes** in the Shader view of [Pyzed Design](/pyzed/shading/), saved as `.pzshad` files,
  or in Python with `pyzed.shading.Graph`. No shader language to learn.
- **Effects**: `glass`, `bloom`, `glow`, `blur`, rotation and animations, which any widget has through
  `widget.style(...)` and `widget.animate(...)`.

## The shader gallery

Six graphs side by side, with a slider that changes the `speed` variable of all of them at once. Variables
(uniforms) are just values, so changing them never recompiles the shader.

<Media src={galleryShot} alt="Six shaders: plasma, ripple, tunnel, CRT, Voronoi cells and fire" size="wide" />

<Run file="examples/showcase/shaders.py" />

```python
from pyzed import shading

plasma = shading.load("shaders/plasma.pzshad")          # compile once
pz.shader(plasma, uniforms={"speed": self.speed},       # variables by name, from your state
          width=340, height=210,
          fallback=pz.Gradient(["#7c3aed", "#ec4899"]))  # shown where shaders are not available
```

## Effects on any widget

Rotation, frosted glass, bloom and blur, applied with `style(...)` and animated. The buttons at the bottom animate
blur and size; size, padding and font size reflow the layout as they move.

<Media src={effectsShot} alt="Four cards over a gradient: rotated, glass, bloom and blurred" />

```python
card.style(rotate=-8)                       # turn it
card.style(glass=True)                      # a tinted panel that blurs what is behind it
card.style(bloom=("#fbbf24", 0.8))          # light around its bright parts
card.style(blur=4)                          # blur the widget itself
spinner.animate("spin")                     # a looping preset
```

## Animations

Every preset, played on click or on hover; glass, glow, bloom and opacity over a gradient; and transitions that
animate a panel, a page and a wrong password.

<Media src={animationsShot} alt="A grid of animation presets and four visual effects" />

```python
button.animate("lift", on="hover").animate("shrink", on="press")   # on events
title.animate("fade_in_up")                                         # when it appears
panel.transition(x=0 if self.open else -260, opacity=1 if self.open else 0)  # when a value changes
pz.presence(page, key=self.page)                                    # out and in when the key changes
```

## Where they are used

- [Game HUD](/pyzed/showcase/hud/): the Nebula and Radar graphs, glass panels and bloom.
- [Game main menu](/pyzed/showcase/main-menu/): the Synthwave graph and a glowing title.
- [RPG inventory](/pyzed/showcase/inventory/): the Embers graph, bloom by rarity and animated stats.
- [Glass control center](/pyzed/showcase/glass-dashboard/): the Blobs graph behind frosted-glass cards.

<Aside type="caution" title="When there is no GPU">
On machines without a supported graphics card (some virtual machines and remote desktops) shaders cannot run, and
Pyzed draws the widget's `fallback` instead, a gradient or a color. Always give one to shaders that sit behind
your content.
</Aside>
