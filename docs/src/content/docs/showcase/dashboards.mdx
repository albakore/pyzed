Screens full of numbers, tables and lists: the kind of internal tool, admin panel or media app that many desktop
programs are. The first six are [Blocks](/pyzed/blocks/), complete screens written with the
[components library](/pyzed/library/) that you can copy and adapt; each block's page has its full code and notes on
what to change. Every capture follows this site's theme: switch between light and dark at the top of the page to
see them in both.

## Dashboard

An admin dashboard: sidebar navigation, KPI cards with trends, a revenue chart, traffic sources and a table of recent
orders.

<Media src={dashboardDark} light={dashboardLight} alt="A dashboard with KPI cards, a revenue chart and recent orders" size="wide" />

- KPI cards are `ui.stat` with a `delta` and a small `trend` line. The charts are ready-made components too:
  `ui.bar_chart` for revenue (its range is a `ui.segmented` control) and `ui.donut` for traffic sources, with a
  `ui.progress` bar for the monthly goal.
- The sidebar switches pages by changing one attribute of the state: see [A multi-view
  app](/pyzed/tutorials/intermediate/navigation/).

<Run file="examples/blocks/dashboard.py" />

The code: [Dashboard block](/pyzed/blocks/dashboard/).

## Contacts over SQLite

A contacts app on [SQLAlchemy](https://www.sqlalchemy.org) 2.0 with **20,000 rows** in a virtual table. Searching and sorting run as SQL queries in a worker thread (`Command.perform`), so the window never waits
for the database.

<Media src={shot_sqlalchemy_contacts} alt="The contacts app: totals, a chart of top cities, the table of 20,000 contacts and the edit panel" />
