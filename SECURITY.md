# Security policy

## Supported versions

Security fixes are released for the latest minor version published on
[PyPI](https://pypi.org/project/pyzed-ui/).

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/albakore/pyzed/security/advisories/new)
with a description, the affected version and, if possible, steps to reproduce.

You will get an answer as soon as possible. Once a fix is ready it is released
as a new version, and the advisory is published with credit to the reporter
(unless you prefer to stay anonymous).
